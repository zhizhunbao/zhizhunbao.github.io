# Peng Wang Knowledge Base

Source of <https://zhizhunbao.github.io>. Same setup as Microsoft Learn: Markdown in a GitHub repository, built with [DocFX](https://dotnet.github.io/docfx/), published by GitHub Actions to GitHub Pages.

- Pages: `docs/**/*.md`, each with YAML metadata (`title`, `description`, `ms.date`).
- Navigation: `docs/toc.yml` is the top bar; each section folder has its own `toc.yml` for the left sidebar.
- Config: `docs/docfx.json`. Look: `docs/templates/kb/`: the page shell follows a Microsoft Learn article page (two header bars, TOC tree, breadcrumbs, In this article, Light/Dark/Auto) and is styled by the open-source Atlas Design System (`public/atlas.min.css`, MIT); `public/kb.css` holds the Learn-only bits measured from Learn, `public/kb.js` draws the navigation from DocFX toc.json and searches index.json.
- Quizzes: pages are Markdown only, with one exception for quizzes. A quiz page is a Markdown page whose paragraph `[Start the quiz](wN.json)` links a JSON file of questions (`{ "questions": [{ "stem", "zhStem", "options", "answer", "zhTerm", "definition", "zh", "keys", "verbs", "zhVerbs" }] }`: a scenario in my own words and its Chinese, the answer's official definition and its translation); `public/quiz.js` replaces that paragraph with the questions: click an option to check it, then the right option turns green (a wrong pick red), and the question in Chinese and the answer's definition in English and Chinese show, marked like the term tables. Without JavaScript the link still opens the data. The CST8913 quiz pages and data are generated by `build_quiz.py` in the cloud notes repo.
- Term tables (`Term | Definition | 中文翻译 | Source`): the Chinese column translates the English definition. Key words are bold in the same order in both cells, and `kb.css` gives the n-th bold of each cell the same colour. `public/marks.js` (called from `kb.js`) puts the verb (谓语) of each English definition and of its Chinese translation with a red wavy underline, from `media/<page>.grammar.json` (`{ term: { "verbs": [[phrase, skip], ...], "zhVerbs": [[phrase, skip], ...] } }`: the verb phrases in order, `skip` passing over earlier matches, one Chinese entry per English one, contractions such as it's left out); quizzes use the same marks. The CST8913 tables and these files are generated by `build_site_pages.py`.
- Preview locally: double-click `start-knowledge-base.bat`, or run `python docs/templates/kb/git_times.py`, then `docfx docs/docfx.build.json --serve`, and open <http://localhost:8080>. The script writes `docs/docfx.build.json` (ignored by git): `docfx.json` plus each page's last commit time, shown as "Last updated on MM/DD/YYYY HH:MM:SS". Building `docs/docfx.json` directly still works, with the date from `ms.date` only. GitHub Actions does the same two steps.
- Publish: push to `main`; `.github/workflows/docfx.yml` builds and deploys.

## Content rules (the site is public)

- No lecture slide text, no lab answers. Exception (user, 2026-10-20): the lab quizzes use the instructor's lab questions word for word as their stems; options and explanations are my own.
- Definitions are quoted from official documentation (Microsoft Learn is CC BY 4.0) with an APA reference that names the section and paragraph and links the `#anchor`.
- Content that exists only in course materials is rewritten in my own words, without quotation marks.
- Cloud courses are in progress: no links to coursework code until grades are final. No student number anywhere.
- Never use the middle dot as a separator.
