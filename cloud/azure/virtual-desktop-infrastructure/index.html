              19. Virtual Desktop Infrastructure

              Classification

              Glossary

              Term Definition 中文翻译 Source
              Virtual Desktop Infrastructure
              虚拟桌面基础结构              		 "VDI is an IT infrastructure that enables employees to access virtual desktops hosted on centralized servers from almost any device." VDI 是一种 IT 基础结构，让员工几乎可以从任何设备访问托管在集中式服务器上的虚拟桌面。 Microsoft, n.d.-b, para. 1
              Azure Lab Services
              Azure 实验室服务              		 "Azure Lab Services enables you to create labs with infrastructure managed by Azure." Azure 实验室服务让你可以创建由 Azure 管理基础结构的实验室。 Microsoft, 2024, para. 1
              Azure Virtual Desktop
              Azure 虚拟桌面              		 "Azure Virtual Desktop is a desktop and app virtualization service that runs on Azure." Azure 虚拟桌面是一种桌面和应用虚拟化服务，它运行在 Azure 上。 Microsoft, 2026a, para. 1
              Microsoft Dev Box
              Microsoft 开发箱              		 "Microsoft Dev Box gives developers self-service access to ready-to-code cloud workstations called dev boxes." Microsoft Dev Box 为开发人员提供自助访问，可以使用称为 dev box 的随时可编码的云工作站。 Microsoft, 2026b, para. 1
