              3.1 Azure Regions

              Classification

              Glossary

              Term Definition 中文解释 Source
              Region
              区域              		 "Each region is a set of physical facilities that include datacenters and networking infrastructure." 每个区域都是一组物理设施，包括数据中心和网络基础设施。 Microsoft, 2026c, para. 1
              Geography
              地理区域              		 "Each geography represents a data residency boundary, for example the United States, or Europe, and may contain one or more regions." 每个地理区域代表一个数据驻留边界，例如美国或欧洲，并且可以包含一个或多个区域。 Microsoft, 2026c, para. 1
              Sovereign cloud
              主权云              		 "However, some regions belong to sovereign cloud geographies. Customers in specific geographic areas with stringent data residency regulations can access these regions." 但是，某些区域属于主权云地理区域。位于特定地理区域、受严格数据驻留法规约束的客户可以访问这些区域。 Microsoft, 2026c, "Understand Azure regions and geographies" section, Note
              Region pairs
              区域对              		 "Microsoft pairs some Azure regions with another Azure region to form region pairs." Microsoft 把一些 Azure 区域与另一个 Azure 区域配对，形成区域对。 Microsoft, 2026c, "Paired and nonpaired regions" section, para. 1
              Asymmetrical region pairs
              非对称区域对              		 "Asymmetrical region pairs involve regions that aren't bidirectionally paired." 非对称区域对指不是双向配对的区域。 Microsoft, 2026b, "Asymmetrically paired regions" section, para. 1
              Nonpaired regions
              非配对区域              		 "Many newer regions aren't paired, and instead use availability zones as their primary means of redundancy." 许多较新的区域没有配对，而是以可用区作为主要的冗余手段。 Microsoft, 2026c, "Paired and nonpaired regions" section, para. 2
              Nonregional services
              非区域服务              		 "Microsoft deploys nonregional services across two or more regions." Microsoft 把非区域服务部署在两个或更多区域中。 Microsoft, 2026c, "Nonregional services" section, para. 1
              Global services
              全局服务              		 "Global services are deployed to many Azure regions worldwide." 全局服务会部署到全球许多 Azure 区域。 Microsoft, 2026a, "Types of nonregional services" section, list item 1
              Geographic services
              地理服务              		 "Geographic services are deployed to a geographic area, and not a specific Azure region." 地理服务会部署到某个地理区域，而不是某个特定的 Azure 区域。 Microsoft, 2026a, "Types of nonregional services" section, list item 2
