              18. Security

              Classification

              Glossary

              Term Definition 中文翻译 Source
              Security
              安全              		 "Cybersecurity is the practice of protecting your critical systems, data, and networks from digital attacks." 网络安全是保护你的关键系统、数据和网络、使其免受数字攻击的做法。 Microsoft, n.d., "Key takeaways" section, list item 1
              Zero Trust model
              零信任模型              		 "Zero Trust is a security model that assumes the worst case scenario and protects resources with that expectation." 零信任是一种安全模型，它假设最坏的情况，并按照这种预期来保护资源。 Microsoft, 2026a, "Describe Zero Trust model" unit, para. 1
              Defense-in-depth
              纵深防御              		 "The objective of defense-in-depth is to protect information and prevent it from being stolen by those who aren't authorized to access it." 纵深防御的目标是保护信息，防止它被无权访问的人窃取。 Microsoft, 2026a, "Describe defense-in-depth" unit, para. 1
              Encryption and key management
              加密和密钥管理              		 "Encryption helps protect data confidentiality by making data unreadable to unauthorized users." 加密通过让数据对未授权用户不可读来帮助保护数据机密性。 Microsoft, 2026a, "Describe encryption and key management in Azure" unit, para. 1
              Microsoft Defender for Cloud
              Microsoft Defender for Cloud              		 "Defender for Cloud is a security posture management and threat protection service." Defender for Cloud 是一项安全态势管理和威胁防护服务。 Microsoft, 2026a, "Describe Microsoft Defender for Cloud" unit, para. 1
