              Classification

              Glossary

              Term Definition 中文翻译 Source
              Azure CycleCloud
              Azure CycleCloud              		 "Azure CycleCloud is an enterprise-friendly tool for orchestrating and managing High Performance Computing (HPC) environments on Azure." Azure CycleCloud 是一个适合企业使用的工具，用于在 Azure 上编排和管理高性能计算（HPC）环境。 Microsoft, 2026d, para. 1
              Azure Service Fabric
              Azure Service Fabric              		 "Azure Service Fabric is a distributed systems platform that makes it easy to package, deploy, and manage scalable and reliable microservices and containers." Azure Service Fabric 是一个分布式系统平台，它让打包、部署和管理可扩展、可靠的微服务和容器变得容易。 Microsoft, 2026c, para. 1
              Azure Quantum
              Azure 量子              		 "Azure Quantum is Microsoft Azure's cloud quantum computing service." Azure Quantum 是 Microsoft Azure 的云量子计算服务。 Microsoft, 2026e, para. 1
              Azure Virtual Desktop
              Azure 虚拟桌面              		 "Azure Virtual Desktop is a desktop and app virtualization service that runs on Azure." Azure 虚拟桌面是一种桌面和应用虚拟化服务，它运行在 Azure 上。 Microsoft, 2026f, para. 1
              Azure Dedicated Host
              Azure 专用主机              		 "Azure Dedicated Host is a service that provides physical servers able to host one or more virtual machines assigned to one Azure subscription." Azure 专用主机是一种服务，它提供物理服务器，这些服务器能托管一台或多台虚拟机，这些虚拟机分配给同一个 Azure 订阅。 Microsoft, 2026a, para. 1
