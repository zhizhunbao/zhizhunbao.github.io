              4.2 Platform as a Service (PaaS)

              Classification

              Glossary

              Term Definition 中文翻译 Source
              Azure App Service
              Azure 应用服务              		 "Azure App Service is a managed service for hosting web apps, mobile app back ends, RESTful APIs, or automated business processes." Azure App Service 是一项托管服务，用于托管 Web 应用、移动应用后端、RESTful API 或自动化业务流程。 Microsoft, 2026a, "Understand the basic features" section, list item 2
              Azure App Service plan
              Azure 应用服务计划              		 "An Azure App Service plan defines a set of compute resources for a web app to run. An app service always runs in an App Service plan." Azure App Service 计划定义一组计算资源，供 Web 应用运行。应用服务始终在某个 App Service 计划中运行。 Microsoft, 2026c, para. 1
              Hybrid Connections
              混合连接              		 "Within App Service, Hybrid Connections can be used to access application resources in any network that can make outbound calls to Azure over port 443. Hybrid Connections provides access from your app to a TCP endpoint." 在 App Service 中，Hybrid Connections 可用于访问任意网络中的应用程序资源，只要该网络能通过 443 端口向 Azure 发出出站调用。Hybrid Connections 提供从你的应用到 TCP 终结点的访问。 Microsoft, 2026b, para. 2
              Azure Kubernetes Service (AKS)
              Azure Kubernetes 服务（AKS）              		 "Azure Kubernetes Service (AKS) is a managed Kubernetes service for running containerized applications." Azure Kubernetes Service（AKS）是一项托管 Kubernetes 服务，用于运行容器化应用程序。 Microsoft, 2026a, "Understand the basic features" section, list item 4
              Azure Kubernetes Fleet Manager
              Azure Kubernetes 舰队管理器              		 "Azure Kubernetes Fleet Manager enables at-scale management of multiple supported Kubernetes clusters." Azure Kubernetes 舰队管理器支持对多个受支持的 Kubernetes 群集进行大规模管理。 Microsoft, 2026d, para. 1
              Azure Container Apps
              Azure 容器应用              		 "Azure Container Apps is a managed service built on Kubernetes, which simplifies the deployment of containerized applications in a serverless environment." Azure Container Apps 是一项基于 Kubernetes 构建的托管服务，可简化在无服务器环境中部署容器化应用程序。 Microsoft, 2026a, "Understand the basic features" section, list item 5
              Azure Container Instances
              Azure 容器实例              		 "Azure Container Instances is a service for running a single container or group of containers in Azure. Container Instances doesn't provide full container orchestration, but you can implement containers without the need to provision VMs or adopt a higher-level service." Azure Container Instances 是一项服务，用于在 Azure 中运行单个容器或一组容器。Container Instances 不提供完整的容器编排，但你可以无需预配 VM 或采用更高层级的服务就实现容器。 Microsoft, 2026a, "Understand the basic features" section, list item 6
              Azure Red Hat OpenShift
              Azure Red Hat OpenShift              		 "Azure Red Hat OpenShift is a fully managed OpenShift cluster for running containers in production with Kubernetes." Azure Red Hat OpenShift 是一个完全托管的 OpenShift 群集，用于借助 Kubernetes 在生产环境中运行容器。 Microsoft, 2026a, "Understand the basic features" section, list item 7
              Azure Batch
              Azure 批处理              		 "Azure Batch is a managed service for running large-scale parallel and high-performance computing (HPC) applications." Azure Batch 是一项托管服务，用于运行大规模并行和高性能计算（HPC）应用程序。 Microsoft, 2026a, "Understand the basic features" section, list item 8
              Azure Static Web Apps
              Azure 静态 Web 应用              		 "Azure Static Web Apps is a service that automatically deploys full stack web apps to Azure from a code repository." Azure 静态 Web 应用是一种服务，它从代码存储库把全栈 Web 应用自动部署到 Azure。 Microsoft, 2024b, para. 1
              Azure Spring Apps
              Azure Spring Apps              		 "Azure Spring Apps makes it easy to deploy Spring Boot applications to Azure without any code changes." Azure Spring Apps 让你可以轻松地把 Spring Boot 应用程序部署到 Azure，无需任何代码更改。 Microsoft, 2025, para. 1
              Azure Cloud Services (extended support)
              Azure 云服务（扩展支持）              		 "Cloud Services (extended support) is a new Azure Resource Manager based deployment model for Azure Cloud Services product and is now generally available." Cloud Services（扩展支持）是 Azure Cloud Services 产品的一种新的基于 Azure 资源管理器的部署模型，现已正式发布。 Microsoft, 2024a, para. 1
