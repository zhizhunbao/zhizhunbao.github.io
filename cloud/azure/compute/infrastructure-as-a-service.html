              4.1 Infrastructure as a Service (IaaS)

              Classification

              Glossary

              Term Definition 中文翻译 Source
              Virtual Machines
              虚拟机              		 "Azure Virtual Machines is a service that you can use to deploy and manage virtual machines (VMs) inside an Azure virtual network." Azure Virtual Machines 是一项服务，可用来部署和管理虚拟机（VM），这些虚拟机位于 Azure 虚拟网络中。 Microsoft, 2026c, "Understand the basic features" section, list item 1
              General purpose
              通用型              		 "General purpose VM sizes provide balanced CPU-to-memory ratio. Ideal for testing and development, small to medium databases, and low to medium traffic web servers." 通用型 VM 大小提供均衡的 CPU 与内存比例。适合测试和开发、中小型数据库，以及中低流量的 Web 服务器。 Microsoft, 2026d, "General purpose" section, para. 1
              Compute optimized
              计算优化型              		 "Compute optimized VM sizes have a high CPU-to-memory ratio. These sizes are good for medium traffic web servers, network appliances, batch processes, and application servers." 计算优化型 VM 大小具有较高的 CPU 与内存比例。这些大小适合中等流量的 Web 服务器、网络设备、批处理和应用程序服务器。 Microsoft, 2026d, "Compute optimized" section, para. 1
              Memory optimized
              内存优化型              		 "Memory optimized VM sizes offer a high memory-to-CPU ratio that is great for relational database servers, medium to large caches, and in-memory analytics." 内存优化型 VM 大小提供较高的内存与 CPU 比例，非常适合关系数据库服务器、中大型缓存和内存中分析。 Microsoft, 2026d, "Memory optimized" section, para. 1
              Storage optimized
              存储优化型              		 "Storage optimized virtual machine (VM) sizes offer high disk throughput and IO, and are ideal for Big Data, SQL, NoSQL databases, data warehousing, and large transactional databases." 存储优化型虚拟机（VM）大小提供高磁盘吞吐量和 IO，适合大数据、SQL、NoSQL 数据库、数据仓库和大型事务数据库。 Microsoft, 2026d, "Storage optimized" section, para. 1
              GPU accelerated
              GPU 加速型              		 "GPU optimized VM sizes are specialized virtual machines available with single, multiple, or fractional GPUs. These sizes are designed for compute-intensive, graphics-intensive, and visualization workloads." GPU 优化型 VM 大小是配有单个、多个或部分 GPU 的专用虚拟机。这些大小为计算密集型、图形密集型和可视化工作负载而设计。 Microsoft, 2026d, "GPU accelerated" section, para. 1
              FPGA accelerated
              FPGA 加速型              		 "FPGA optimized VM sizes are specialized virtual machines available with single or multiple FPGAs. These sizes are designed for compute-intensive workloads." FPGA 优化型 VM 大小是配有单个或多个 FPGA 的专用虚拟机。这些大小为计算密集型工作负载而设计。 Microsoft, 2026d, "FPGA accelerated" section, para. 1
              High performance compute
              高性能计算              		 "Azure High Performance Compute VMs are optimized for various HPC workloads such as computational fluid dynamics, finite element analysis, frontend and backend EDA, rendering, molecular dynamics, computational geoscience, weather simulation, and financial risk analysis." Azure 高性能计算 VM 针对各种 HPC 工作负载进行了优化，例如计算流体动力学、有限元分析、前端和后端 EDA、渲染、分子动力学、计算地球科学、天气模拟和金融风险分析。 Microsoft, 2026d, "High performance compute" section, para. 1
              Temporary disk
              临时磁盘              		 "Most VMs contain a temporary disk, which isn't a managed disk. The temporary disk provides short-term storage for applications and processes. It's intended for storing only data such as page files, swap files, or SQL Server tempdb files." 大多数 VM 都包含一个临时磁盘，它不是托管磁盘。临时磁盘为应用程序和进程提供短期存储。它只用于存储页面文件、交换文件或 SQL Server tempdb 文件之类的数据。 Microsoft, 2026a, "Temporary disk" section, para. 1
              Virtual Machine Scale Sets
              虚拟机规模集              		 "Azure Virtual Machine Scale Sets let you create and manage a group of load balanced virtual machines (VM) instances. The number of VM instances can automatically increase or decrease in response to demand or a defined schedule." Azure 虚拟机规模集让你创建和管理一组负载均衡的虚拟机（VM）实例。VM 实例的数量可以根据需求或设定的计划自动增加或减少。 Microsoft, 2026e, para. 1
              Azure Spot Virtual Machines
              Azure 竞价虚拟机              		 "Using Azure Spot Virtual Machines allows you to take advantage of our unused capacity at a significant cost savings. At any point in time when Azure needs the capacity back, the Azure infrastructure will evict Azure Spot Virtual Machines." 使用 Azure 竞价虚拟机，你可以利用 Azure 未使用的容量，从而大幅节省成本。每当 Azure 需要收回容量时，Azure 基础结构就会逐出 Azure 竞价虚拟机。 Microsoft, 2026b, para. 1
              Azure VMware Solution
              Azure VMware 解决方案              		 "Azure VMware Solution is a managed service for running VMware workloads natively on Azure." Azure VMware Solution 是一项托管服务，用于在 Azure 上原生运行 VMware 工作负载。 Microsoft, 2026c, "Understand the basic features" section, list item 9
