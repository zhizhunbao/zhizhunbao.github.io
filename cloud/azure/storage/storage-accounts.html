              8.1 Storage Accounts

              Classification

              Glossary

              Term Definition 中文翻译 Source
              Standard general-purpose v2
              标准常规用途 v2              		 "Standard storage account type for blobs, file shares, queues, and tables. Recommended for most scenarios that use Azure Storage." 标准存储帐户类型，用于 Blob、文件共享、队列和表。推荐用于使用 Azure 存储的大多数场景。 Microsoft, 2026, "Types of storage accounts" section, table row 1
              Premium block blobs
              高级块 Blob              		 "Premium storage account type for block blobs and append blobs. Recommended for scenarios with high transaction rates or that use smaller objects or require consistently low storage latency." 高级存储帐户类型，用于块 Blob 和追加 Blob。推荐用于事务率高、使用较小对象或需要持续低存储延迟的场景。 Microsoft, 2026, "Types of storage accounts" section, table row 2
              Premium file shares
              高级文件共享              		 "Premium storage account type for file shares only. Recommended for enterprise or high-performance scale applications." 高级存储帐户类型，仅用于文件共享。推荐用于企业级或高性能规模的应用程序。 Microsoft, 2026, "Types of storage accounts" section, table row 3
              Premium page blobs
              高级页 Blob              		 "Premium storage account type for page blobs only." 高级存储帐户类型，仅用于页 Blob。 Microsoft, 2026, "Types of storage accounts" section, table row 4
              Storage account endpoints
              存储帐户终结点              		 "Every object that you store in Azure Storage has a URL address that includes your unique account name. The combination of the account name and the service endpoint forms the endpoints for your storage account." 你存储在 Azure 存储中的每个对象都有一个包含唯一帐户名的 URL 地址。帐户名和服务终结点的组合构成存储帐户的终结点。 Microsoft, 2026, "Storage account endpoints" section, para. 1
