              5. Containers

              Classification

              Glossary

              Term Definition 中文翻译 Source
              Containers
              容器              		 "A container is a standardized package of software that can be quickly and reliably deployed across cloud and other environments to support fast, efficient innovation." 容器是一种标准化的软件包，可以快速、可靠地部署到云和其他环境中，从而支持快速、高效的创新。 Microsoft, n.d.-b, para. 1
              Docker
              Docker              		 "Docker is an open-source project for automating the deployment of applications as portable, self-sufficient containers that can run on the cloud or on-premises." Docker 是一个开源项目，用于自动完成应用程序的部署，把它们部署成可移植、自给自足的容器，这些容器可以在云中或本地运行。 Microsoft, 2018, para. 1
              Kubernetes
              Kubernetes              		 "Kubernetes is an open-source container orchestration platform for automating the deployment, scaling, and management of containerized applications." Kubernetes 是一个开源的容器编排平台，用于自动部署、扩缩和管理各类容器化应用程序。 Microsoft, 2026a, "What is Kubernetes?" section, para. 1
              Azure container services
              Azure 容器服务              		 "Azure provides several container-related services. These include Azure Kubernetes Service, Azure Container Apps, Azure Red Hat OpenShift, Azure Container Registry, and Azure Container Storage." Azure 提供多种与容器相关的服务，包括 Azure Kubernetes Service、Azure Container Apps、Azure Red Hat OpenShift、Azure Container Registry 和 Azure Container Storage。 Microsoft, n.d.-a, "Frequently asked questions" section, question 1
