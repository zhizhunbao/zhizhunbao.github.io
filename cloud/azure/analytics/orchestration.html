              11.8 Orchestration

              Classification

              Glossary

              Term Definition 中文翻译 Source
              Azure Data Factory
              Azure 数据工厂              		 "Azure Data Factory is a managed cloud service that's built for these complex hybrid extract-transform-load (ETL), extract-load-transform (ELT), and data integration projects." Azure 数据工厂是一项托管云服务，专为这些复杂的混合提取-转换-加载 (ETL)、提取-加载-转换 (ELT) 和数据集成项目而构建。 Microsoft, 2026a, para. 2
              Data Factory in Microsoft Fabric
              Microsoft Fabric 中的数据工厂              		 (context) "Data Factory in Microsoft Fabric helps you solve one of business's toughest challenges: turning scattered data into useful insights." （语境）Microsoft Fabric 中的数据工厂帮助你解决业务中最棘手的挑战之一：把分散的数据转化为有用的见解。 Microsoft, 2026b, para. 1
              Apache Oozie
              Apache Oozie              		 "Oozie is a workflow scheduler system to manage Apache Hadoop jobs." Oozie 是一个工作流调度系统，用于管理 Apache Hadoop 作业。 Apache Software Foundation, n.d.-a, para. 1
              Apache Sqoop
              Apache Sqoop              		 "Apache Sqoop(TM) is a tool designed for efficiently transferring bulk data between Apache Hadoop and structured datastores such as relational databases." Apache Sqoop(TM) 是一种专为高效传输批量数据而设计的工具，在 Apache Hadoop 与结构化数据存储（例如关系数据库）之间传输。 Apache Software Foundation, n.d.-b, para. 1
