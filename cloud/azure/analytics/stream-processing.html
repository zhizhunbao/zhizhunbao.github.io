              11.5 Stream Processing

              Classification

              Glossary

              Term Definition 中文翻译 Source
              Output sink
              输出接收器              		 (context) "The processed stream data is then written to an output sink." （语境）处理后的流数据随后写入一个输出接收器。 Microsoft, 2025, "Components of a big data architecture" section, list item 5
              Spark Streaming
              Spark Streaming              		 "Spark Streaming is an extension of the core Spark API that enables scalable, high-throughput, fault-tolerant stream processing of live data streams." Spark Streaming 是核心 Spark API 的扩展，能够对实时数据流进行可扩展、高吞吐量、容错的流处理。 Apache Software Foundation, n.d., "Overview" section, para. 2
              Azure Databricks
              Azure Databricks              		 "Azure Databricks is a unified, open analytics platform for building, deploying, sharing, and maintaining enterprise-grade data, analytics, and AI solutions at scale." Azure Databricks 是一个统一、开放的分析平台，用于大规模构建、部署、共享和维护企业级数据、分析和 AI 解决方案。 Microsoft, 2026d, para. 1
              Structured Streaming
              结构化流              		 (context) "Azure Databricks leverages Apache Spark Structured Streaming to work with streaming data and incremental data changes." （语境）Azure Databricks 利用 Apache Spark 结构化流来处理流数据和增量数据变更。 Microsoft, 2026d, "Real-time and streaming analytics" section, para. 1
              Delta Lake
              Delta Lake              		 (context) "Structured Streaming integrates tightly with Delta Lake, and these technologies provide the foundations for both Lakeflow pipelines and Auto Loader." （语境）结构化流与 Delta Lake 紧密集成，这些技术为 Lakeflow 管道和 Auto Loader 提供基础。 Microsoft, 2026d, "Real-time and streaming analytics" section, para. 1
              Lakeflow pipelines
              Lakeflow 管道              		 (context) "Structured Streaming integrates tightly with Delta Lake, and these technologies provide the foundations for both Lakeflow pipelines and Auto Loader." （语境）结构化流与 Delta Lake 紧密集成，这些技术为 Lakeflow 管道和 Auto Loader 提供基础。 Microsoft, 2026d, "Real-time and streaming analytics" section, para. 1
              Auto Loader
              自动加载器              		 (context) "Structured Streaming integrates tightly with Delta Lake, and these technologies provide the foundations for both Lakeflow pipelines and Auto Loader." （语境）结构化流与 Delta Lake 紧密集成，这些技术为 Lakeflow 管道和自动加载器（Auto Loader）提供基础。 Microsoft, 2026d, "Real-time and streaming analytics" section, para. 1
              Azure Functions
              Azure Functions              		 "Azure Functions is a serverless solution that allows you to build robust apps while using less code, and with less infrastructure and lower costs." Azure Functions 是一种无服务器解决方案，让你可以用更少的代码构建可靠的应用，同时使用更少的基础结构，成本也更低。 Microsoft, 2026e, para. 1
              Fabric eventstreams
              Fabric 事件流              		 (context) "Use the eventstreams feature in Microsoft Fabric Real-Time Intelligence to bring real-time events into Fabric, transform them, and then send them to various destinations without writing any code." （语境）使用 Microsoft Fabric 实时智能中的事件流功能，把实时事件引入 Fabric、转换它们，然后无需编写任何代码就把它们发送到各种目标。 Microsoft, 2026b, para. 1
              Azure Stream Analytics
              Azure 流分析              		 "Azure Stream Analytics is a fully managed stream processing engine that analyzes and processes large volumes of streaming data with submillisecond latencies." Azure 流分析是一种完全托管的流处理引擎，以亚毫秒级延迟分析和处理大量流数据。 Microsoft, 2026c, para. 1
              Inputs
              输入              		 (context) "You can create a Stream Analytics job that connects to Azure Event Hubs and Azure IoT Hub for streaming data ingestion, and Azure Blob storage or Azure Data Lake Storage Gen2 to ingest historical data." （语境）你可以创建一个流分析作业，连接 Azure 事件中心和 Azure IoT 中心进行流数据引入，并连接 Azure Blob 存储或 Azure Data Lake Storage Gen2 来引入历史数据。 Microsoft, 2026c, "Ease of use" section, para. 2
              Reference data
              参考数据              		 (context) "The input for the Stream Analytics job can also include static or slow-changing reference data from Azure Blob storage or SQL Database that you can join with streaming data to perform lookup operations." （语境）流分析作业的输入还可以包括来自 Azure Blob 存储或 SQL 数据库的静态或缓慢变化的参考数据，你可以把它与流数据联接来执行查找操作。 Microsoft, 2026c, "Ease of use" section, para. 2
              Outputs
              输出              		 (context) "You can route output from a Stream Analytics job to many storage systems such as Azure Blob storage, Azure SQL Database, Azure Data Lake Store, and Azure Cosmos DB." （语境）你可以把流分析作业的输出路由到多种存储系统，例如 Azure Blob 存储、Azure SQL 数据库、Azure Data Lake Store 和 Azure Cosmos DB。 Microsoft, 2026c, "Ease of use" section, para. 3
              Stream Analytics query language
              流分析查询语言              		 (context) "The Stream Analytics query language allows you to perform Complex Event Processing (CEP) by offering a wide array of functions for analyzing streaming data." （语境）流分析查询语言通过提供大量用于分析流数据的函数，让你可以执行复杂事件处理（CEP）。 Microsoft, 2026c, "Programmer productivity" section, para. 3
              Windowing functions
              窗口函数              		 (context) "Stream Analytics has native support for windowing functions, so you can create complex stream processing jobs with minimal effort." （语境）流分析原生支持窗口函数，因此你可以用极少的工作量创建复杂的流处理作业。 Microsoft, 2026a, para. 1
              Tumbling window
              翻转窗口              		 "Use Tumbling window functions to segment a data stream into distinct time segments, and perform a function against them." 使用翻转窗口函数把数据流分割成互不相同的时间段，并对它们执行一个函数。 Microsoft, 2026a, "Tumbling window" section, para. 1
              Hopping window
              跳跃窗口              		 "Hopping window functions hop forward in time by a fixed period." 跳跃窗口函数按固定周期在时间上向前跳跃。 Microsoft, 2026a, "Hopping window" section, para. 1
              Sliding window
              滑动窗口              		 "Sliding windows, unlike tumbling or hopping windows, output events only for points in time when the content of the window actually changes." 与翻转窗口或跳跃窗口不同，滑动窗口只在某些时间点输出事件，即窗口内容实际发生变化的时候。 Microsoft, 2026a, "Sliding window" section, para. 1
              Session window
              会话窗口              		 "Session window functions group events that arrive at similar times. They filter out periods of time where there's no data." 会话窗口函数把在相近时间到达的事件分为一组。它们过滤掉没有数据的时间段。 Microsoft, 2026a, "Session window" section, para. 1
              Snapshot window
              快照窗口              		 "Snapshot windows group events that have the same timestamp." 快照窗口把时间戳相同的事件分为一组。 Microsoft, 2026a, "Snapshot window" section, para. 1
              Streaming units
              流式处理单元              		 (context) "There are no upfront costs - you only pay for the streaming units you consume." （语境）没有预付费用，你只为消耗的流式处理单元付费。 Microsoft, 2026c, "Low total cost of ownership" section, para. 1
              Exactly once event processing
              恰好一次事件处理              		 (context) "Stream Analytics guarantees exactly once event processing and at-least-once delivery of events, so events are never lost." （语境）流分析保证恰好一次的事件处理和至少一次的事件传递，因此事件永远不会丢失。 Microsoft, 2026c, "Reliability" section, para. 1
