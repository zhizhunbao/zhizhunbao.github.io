              11.4 Real-Time Message Ingestion

              Classification

              Glossary

              Term Definition 中文翻译 Source
              Azure Event Hubs
              Azure 事件中心              		 "Azure Event Hubs is a fully managed, real-time data streaming platform that can ingest millions of events per second with low latency." Azure 事件中心是一个完全托管的实时数据流式处理平台，能够以低延迟每秒引入数百万个事件。 Microsoft, 2026a, para. 1
              Azure IoT Hub
              Azure IoT 中心              		 "Azure IoT Hub is a managed service that acts as a central message hub in a cloud-based IoT solution." Azure IoT 中心是一项托管服务，充当基于云的 IoT 解决方案中的中央消息中心。 Microsoft, 2026b, para. 2
              Apache Kafka
              Apache Kafka              		 "Apache Kafka® is an event streaming platform." Apache Kafka® 是一个事件流平台。 Apache Software Foundation, n.d., "Apache Kafka® is an event streaming platform. What does that mean?" section heading
