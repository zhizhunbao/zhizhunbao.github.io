              10. Integration

              Classification

              Glossary

              Term Definition 中文翻译 Source
              Integration
              集成              		 "... integrating services, systems, apps, and data across cloud, on-premises, and hybrid environments ..." ……把服务、系统、应用和数据集成起来，范围涵盖云端、本地和混合环境…… Microsoft, 2026c, para. 1
              Workflows
              工作流              		 "In Azure Logic Apps, a workflow coordinates operations called actions." 在 Azure Logic Apps 中，工作流负责协调称为操作（action）的各项操作。 Microsoft, 2026d, "Compare Azure Functions and Azure Logic Apps" section, para. 1
              API management
              API 管理              		 "Azure API Management is a hybrid, multicloud management platform for APIs across all environments." Azure API Management 是一个混合、多云的管理平台，用于管理所有环境中的 API。 Microsoft, 2025, para. 1
              Messages
              消息              		 "Message: Raw data produced by a service to be consumed or stored elsewhere." 消息：由一个服务产生、要在别处被使用或存储的原始数据。 Microsoft, 2026b, "Events vs. messages in Azure messaging services" section, para. 3
              Events
              事件              		 "Event: A lightweight notification of a condition or state change." 事件：关于某个状况或状态变化的轻量级通知。 Microsoft, 2026b, "Events vs. messages in Azure messaging services" section, para. 2
