              20. Management and Governance

              Classification

              Glossary

              Term Definition 中文翻译 Source
              Management and Governance
              管理和治理              		 "Cloud governance is how an organization controls its use of cloud services by establishing guardrails." 云治理是组织通过建立护栏来控制自己如何使用云服务的方式。 Microsoft, 2025, para. 1
              Cost management
              成本管理              		 "This module explores methods to estimate, track, and manage costs in Azure." 本模块探讨在 Azure 中估算、跟踪和管理成本的方法。 Microsoft, 2026a, "Describe cost management in Azure" module
              Governance and compliance
              治理和合规              		 "This module introduces you to tools that can help with governance and compliance within Azure." 本模块介绍能在 Azure 中帮助实现治理和合规的工具。 Microsoft, 2026a, "Describe features and tools in Azure for governance and compliance" module
              Managing and deploying resources
              管理和部署资源              		 "This module covers tools that help you manage your Azure and on-premises resources." 本模块介绍帮助你管理 Azure 资源和本地资源的工具。 Microsoft, 2026a, "Describe features and tools for managing and deploying Azure resources" module
              Monitoring tools
              监视工具              		 "This module covers tools that you can use to monitor your Azure environment." 本模块介绍可以用来监视你的 Azure 环境的工具。 Microsoft, 2026a, "Describe monitoring tools in Azure" module
