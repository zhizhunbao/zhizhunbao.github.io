              26.5 Govern

              Classification

              Glossary

              Term Definition 中文解释 Source
              Govern
              治理
              (retired 2019–2023: the Five Disciplines of Cloud Governance: Cost Management, Security Baseline, Identity Baseline, Resource Consistency, Deployment Acceleration; Microsoft, 2022)              		 "Cloud governance is how an organization controls its use of cloud services by establishing guardrails." 云治理是组织通过建立防护措施来控制其云服务使用的方式。 Microsoft, 2026b, para. 1
              Build governance team
              组建治理团队              		 (context) "The first step is to establish a dedicated cloud governance team to oversee cloud governance across the organization." （语境）第一步是建立专门的云治理团队，在整个组织中监督云治理。 Microsoft, 2026b, para. 4
              Assess risks
              评估风险              		 "A "risk" in this context is any potential unwanted outcome, such as a security breach, compliance violation, service outage, or cost overrun, that could result from how the cloud is used." 此处的"风险"指任何潜在的不良后果，例如安全漏洞、合规违规、服务中断或成本超支，这些后果可能源于云的使用方式。 Microsoft, 2026a, para. 1
              Document policies
              记录策略              		 (context) "For each significant risk or group of risks, there should be one or more corresponding governance policies." （语境）对于每个重大风险或每组风险，都应有一个或多个相应的治理策略。 Microsoft, 2026c, para. 1
              Enforce policies
              执行策略              		 "Cloud governance enforcement means implementing controls, processes, and tools so that cloud usage adheres to the governance policies." 云治理执行是指实施控制、流程和工具，使云的使用遵守治理策略。 Microsoft, 2026d, para. 1
              Monitor compliance
              监视合规性              		 "Monitoring is about continuously measuring how well the cloud environment complies with your governance policies and detecting when it becomes noncompliant with those policies." 监视就是持续衡量云环境遵守治理策略的程度，并检测它何时变得不合规。 Microsoft, 2026e, para. 1
