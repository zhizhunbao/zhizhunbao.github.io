              26.3 Ready

              Classification

              Glossary

              Term Definition 中文解释 Source
              Ready
              就绪              		 "The Ready phase of the Cloud Adoption Framework helps you design your Azure landing zone to meet your organization's requirements. An Azure landing zone is a proven and flexible architecture for governing, securing, and scaling a multi-subscription Azure environment." Cloud Adoption Framework 的就绪阶段帮助你设计 Azure 登陆区，以满足组织的要求。Azure 登陆区是一种经过验证且灵活的体系结构，用于治理、保护和扩展多订阅的 Azure 环境。 Microsoft, 2026d, para. 1
              Platform landing zone
              平台登陆区              		 "The centralized foundation that establishes governance, security, and shared resources for all your Azure workloads." 集中式基础，用于为你的所有 Azure 工作负载建立治理、安全和共享资源。 Microsoft, 2026d, para. 1, item 1
              Workload landing zones
              工作负载登陆区
              (retired 2026: Application landing zones; Microsoft, 2025e)              		 "The environments where workload teams deploy and operate workload resources within the guardrails of the platform landing zone." 工作负载团队部署和运行工作负载资源的环境，位于平台登陆区的防护措施之内。 Microsoft, 2026d, para. 1, item 2
              Accelerators
              加速器              		 "Microsoft-provided accelerators for both platform landing zone and workload landing zone scenarios use infrastructure as code to deploy Azure environments based on recommended practices." Microsoft 提供的加速器适用于平台登陆区和工作负载登陆区两种场景，基于推荐做法，使用基础结构即代码部署 Azure 环境。 Microsoft, 2026d, para. 2, item 1
              Custom build
              自定义构建              		 "You design and build the solution internally or with support from Microsoft or Microsoft partners." 你在内部设计和构建解决方案，或在 Microsoft 或 Microsoft 合作伙伴的支持下完成。 Microsoft, 2026d, para. 2, item 2
              Design principles
              设计原则              		 "At the foundation of the architecture, a set of core design principles serve as a compass for subsequent design decisions across critical technical domains." 在该体系结构的基础上，一组核心设计原则充当后续设计决策的指南针，覆盖各个关键技术领域。 Microsoft, 2026b, para. 1
              Journey to the target architecture
              迈向目标体系结构的历程              		 (context) "Adopting cloud technologies is a journey. Business priorities and the need to bring new technologies online to unlock capabilities or features influence the speed at which an organization deploys and scales out a cloud environment." （语境）采用云技术是一段历程。业务优先级，以及为解锁能力或功能而上线新技术的需要，会影响组织部署和横向扩展云环境的速度。 Microsoft, 2025b, para. 1
              Design areas
              设计领域              		 (context) "Whatever the deployment option, you should carefully consider each design area. Your decisions affect the platform foundation on which each landing zone depends." （语境）无论采用哪种部署选项，都应仔细考虑每个设计领域。你的决策会影响每个登陆区所依赖的平台基础。 Microsoft, 2026a, "Environment design areas" section, para. 1
              Azure billing and Active Directory tenant
              Azure 计费和 Active Directory 租户              		 (context) "Proper tenant creation, enrollment, and billing setup are important early steps." （语境）正确的租户创建、注册和计费设置是重要的早期步骤。 Microsoft, 2026a, "Environment design areas" section, table, row 1
              Identity and access management
              身份和访问管理              		 "Identity and access management is a primary security boundary in the public cloud. It's the foundation for any secure and fully compliant architecture." 身份和访问管理是公有云中的主要安全边界。它是任何安全且完全合规的体系结构的基础。 Microsoft, 2026a, "Environment design areas" section, table, row 2
              Resource organization
              资源组织              		 (context) "As cloud adoption scales, considerations for subscription design and management group hierarchy have an impact on governance, operations management, and adoption patterns." （语境）随着云采用规模的扩大，订阅设计和管理组层次结构方面的考虑会影响治理、运营管理和采用模式。 Microsoft, 2026a, "Environment design areas" section, table, row 3
              Network topology and connectivity
              网络拓扑和连接              		 (context) "Networking and connectivity decisions are an equally important foundational aspect of any cloud architecture." （语境）网络和连接决策同样是任何云体系结构的重要基础方面。 Microsoft, 2026a, "Environment design areas" section, table, row 4
              Security
              安全              		 (context) "Implement controls and processes to protect your cloud environments." （语境）实施控制措施和流程，以保护你的云环境。 Microsoft, 2026a, "Compliance design areas" section, table, row 1
              Management
              管理              		 (context) "For stable, ongoing operations in the cloud, a management baseline is required to provide visibility, operations compliance, and protect and recover capabilities." （语境）为了在云中稳定、持续地运营，需要一个管理基线，以提供可见性、运营合规性以及保护和恢复能力。 Microsoft, 2026a, "Compliance design areas" section, table, row 2
              Governance
              治理              		 (context) "Automate auditing and enforcement of governance policies." （语境）自动审核和强制执行各项治理策略。 Microsoft, 2026a, "Compliance design areas" section, table, row 3
              Platform automation and DevOps
              平台自动化和 DevOps              		 (context) "Align the best tools and templates to deploy your landing zones and supporting resources." （语境）协调最合适的工具和模板，以部署你的登陆区和支持资源。 Microsoft, 2026a, "Compliance design areas" section, table, row 4
              Implementation options
              实现选项              		 (context) "This article describes options to deploy and manage the platform landing zone, which is part of Azure landing zone." （语境）本文介绍部署和管理平台登陆区的选项，平台登陆区是 Azure 登陆区的一部分。 Microsoft, 2026c, para. 1
              Azure Landing Zones IaC Accelerator
              Infrastructure-as-Code
              Azure 登陆区 IaC 加速器              		 "The Azure Landing Zones IaC Accelerator provides an automated approach to deploy and manage the platform landing zone." Azure Landing Zones IaC Accelerator 提供一种自动化方法，用来部署和管理平台登陆区。 Microsoft, 2026c, "Azure landing zone Infrastructure-as-Code (IaC) accelerator" section, para. 1
              Azure platform landing zone portal accelerator
              Azure 平台登陆区门户加速器              		 "The Azure platform landing zone portal accelerator provides a graphical interface to deploy the reference architecture." Azure 平台登陆区门户加速器提供图形界面，用来部署参考体系结构。 Microsoft, 2026c, "Azure platform landing zone portal accelerator" section, para. 1
              Align
              对齐              		 (context) "This article provides recommendations to help your organization navigate changes based on your existing Azure environment that's transitioning into the Azure landing zone reference architecture." （语境）本文提供建议，帮助你的组织根据现有 Azure 环境应对变化，这个环境正在过渡到 Azure 登陆区参考体系结构。 Microsoft, 2025d, para. 2
              Enhance
              增强              		 (context) "This series of articles assumes that you deployed your first landing zone and want to expand that landing zone to meet enterprise requirements." （语境）本系列文章假设你已经部署了第一个登陆区，并希望扩展该登陆区以满足企业要求。 Microsoft, 2025a, para. 1
              Prepare your landing zone for migration
              为迁移准备登陆区              		 (context) "This article describes how to get your Azure landing zone ready for a migration." （语境）本文介绍如何让你的 Azure 登陆区为迁移做好准备。 Microsoft, 2025c, para. 1
