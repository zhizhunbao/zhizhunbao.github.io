              24.4 Execute

              Classification

              Glossary

              Term Definition 中文解释 Source
              Execute
              执行              		 "In the execution phase, you perform the migration or modernization of your workloads to move to Azure." 在执行阶段，你对工作负载进行迁移或现代化，以便转移到 Azure。 Microsoft, n.d., "Execute" section, para. 1
              Azure Migrate
              Azure Migrate              		 "Azure Migrate is a service that helps you decide on, plan, and execute your migration to Azure." Azure Migrate 是一项服务，帮助你决定、规划和执行自己的到 Azure 的迁移。 Microsoft, n.d., para. 1
              Azure Migrate and Modernize
              Azure Migrate 迁移和现代化              		 "Migrate VMware VMs, Hyper-V VMs, physical servers, other virtualized servers, and public cloud VMs to Azure." 把 VMware VM、Hyper-V VM、物理服务器、其他虚拟化服务器和公有云 VM 迁移到 Azure。 Microsoft, n.d., "Integrated tools and features" section, "Migrate and Modernize" row, Details
              Agentless migration
              无代理迁移              		 "For agentless migration, the Azure Migrate and Modernize tool uses the same appliance that's used for discovery and assessment of servers." 对于无代理迁移，Azure Migrate 迁移和现代化工具使用与服务器发现和评估所用的同一个设备。 Microsoft, n.d., "Execute" section, "On-premises VMware VMs" row, Details
              Agent-based migration
              基于代理的迁移              		 "For agent-based migration, the Azure Migrate and Modernize tool uses a replication appliance." 对于基于代理的迁移，Azure Migrate 迁移和现代化工具使用复制设备。 Microsoft, n.d., "Execute" section, "On-premises VMware VMs" row, Details
              Azure Database Migration Service
              Azure 数据库迁移服务              		 "Migrate on-premises databases to Azure VMs running SQL Server, Azure SQL Database, or Azure SQL Managed Instance." 把本地数据库迁移到运行 SQL Server 的 Azure VM、Azure SQL 数据库或 Azure SQL 托管实例。 Microsoft, n.d., "Integrated tools and features" section, "Azure Database Migration Service" row, Function
              Data Migration Assistant
              数据迁移助手              		 "Data Migration Assistant is a standalone tool to assess SQL servers. It helps pinpoint potential problems that block migration." 数据迁移助手是用于评估 SQL 服务器的独立工具。它帮助找出阻碍迁移的潜在问题。 Microsoft, n.d., "Integrated tools and features" section, "Data Migration Assistant" row, Details
              Azure App Service Migration Assistant
              Azure App Service 迁移助手              		 "Azure App Service Migration Assistant is a standalone tool to assess on-premises websites for migration to Azure App Service." Azure App Service 迁移助手是评估本地网站的独立工具，用于迁移到 Azure App Service。 Microsoft, n.d., "Integrated tools and features" section, "Azure App Service Migration Assistant" row, Details
              Azure Data Box
              Azure Data Box              		 "Use Azure Data Box products to move large amounts of offline data to Azure." 使用 Azure Data Box 产品把大量离线数据转移到 Azure。 Microsoft, n.d., "Integrated tools and features" section, "Azure Data Box" row, Details

              References

              Microsoft. (n.d.). About Azure Migrate. Microsoft Learn. Retrieved October 18, 2026, from https://learn.microsoft.com/en-us/azure/migrate/migrate-services-overview
