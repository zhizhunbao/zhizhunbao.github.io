              9. Databases

              Classification

              Glossary

              Term Definition 中文翻译 Source
              Databases
              数据库              		 "A database is a structured system for storing, managing, and retrieving data, enabling everything from simple recordkeeping to powering complex applications and services." 数据库是一种结构化系统，用于存储、管理和检索数据，用途从简单的记录保存到驱动复杂的应用程序和服务。 Microsoft, n.d., para. 1
              Relational data stores
              关系数据存储              		 "Relational database management systems organize data into normalized tables by using schema-on-write." 关系数据库管理系统使用写入时架构，把数据组织成规范化的表。 Microsoft, 2025, "Relational data stores" section, para. 1
              Document data stores
              文档数据存储              		 "Use document data stores to store semi-structured documents, often in JSON format, where each document includes named fields and data." 使用文档数据存储来存放半结构化文档，通常是 JSON 格式，每个文档都包含命名字段和数据。 Microsoft, 2025, "Document data stores" section, para. 1
              Column-family data stores
              列族数据存储              		 "A column-family database, also known as a wide-column database, stores sparse data into rows and organizes dynamic columns into column families to support co-access." 列族数据库也叫宽列数据库，它把稀疏数据存成行，并把动态列组织成列族，以便一起访问。 Microsoft, 2025, "Column-family data stores" section, para. 1
              Key-value data stores
              键值数据存储              		 "A key-value data store associates each data value with a unique key." 键值数据存储把每个数据值和一个唯一的键关联起来。 Microsoft, 2025, "Key-value data stores" section, para. 1
              Graph data stores
              图数据存储              		 "A graph database stores information as nodes and edges." 图数据库把信息存成节点和边。 Microsoft, 2025, "Graph data stores" section, para. 1
              Time-series data stores
              时间序列数据存储              		 "Time-series data stores manage a set of values organized by time." 时间序列数据存储管理一组按时间组织的值。 Microsoft, 2025, "Time-series data stores" section, para. 1
