              27. Azure Architecture Center

              Classification

              Glossary

              Term Definition 中文翻译 Source
              Azure Architecture Center
              Azure 体系结构中心              		 "The Azure Architecture Center provides guidance for designing and building solutions on Azure by using established patterns and practices." Azure 体系结构中心通过成熟的模式和做法，提供在 Azure 上设计和构建解决方案的指导。 Microsoft, 2026b, para. 1
              Architecture styles
              体系结构样式              		 "An architecture style is a family of architectures that share specific characteristics." 体系结构样式是具有某些共同特征的一类架构。 Microsoft, 2025, para. 1
              Best practices
              最佳做法              		 "The best practices in this article provide guidance for common concerns that arise in distributed systems, such as caching, data partitioning, API design, and transient fault handling." 本文中的最佳做法为分布式系统中常见的问题提供指导，例如缓存、数据分区、API 设计和暂时性故障处理。 Microsoft, 2026c, para. 1
              Cloud design patterns
              云设计模式              		 "Software design patterns are named and repeatable approaches that you can apply to processing or data storage." 软件设计模式是有名称、可重复使用的方法，可以用于处理或数据存储。 Microsoft, 2026a, "Use design patterns to solve common problems and introduce strategic tradeoffs" section, para. 1
              Technology choices
              技术选择              		 "... you can choose the main technology components for the architecture." ……你可以为架构选择主要的技术组件。 Microsoft, 2026a, "Make informed technology choices" section, para. 1
              Architectures
              架构              		 "Azure Architecture Center is home to articles about solution ideas, example workloads, and reference architectures." Azure 体系结构中心收录了关于解决方案构想、示例工作负载和参考体系结构的文章。 Microsoft, 2026a, "Evaluate reference architectures" section, para. 1
