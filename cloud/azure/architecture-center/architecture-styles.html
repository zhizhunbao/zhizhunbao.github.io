              27.1 Architecture Styles

              Classification

              Glossary

              Term Definition 中文翻译 Source
              N-tier
              N 层              		 "N-tier is a traditional architecture for enterprise applications that divides an application into logical layers and physical tiers." N 层是一种面向企业应用程序的传统体系结构，它把应用程序划分为逻辑层和物理层级。 Microsoft, 2025, "A quick tour of the styles" section, "N-tier", para. 1
              Web-Queue-Worker
              Web-队列-辅助角色              		 "Web-Queue-Worker is an architecture that consists of a web front end, a message queue, and a back-end worker." Web-队列-辅助角色是一种体系结构，由 Web 前端、消息队列和后端辅助角色组成。 Microsoft, 2025, "A quick tour of the styles" section, "Web-Queue-Worker", para. 1
              Microservices
              微服务              		 "The Microservices architecture decomposes applications into a collection of small, autonomous services." 微服务体系结构把应用程序分解为一组小型的自治服务。 Microsoft, 2025, "A quick tour of the styles" section, "Microservices", para. 1
              Event-driven architecture
              事件驱动体系结构              		 "Event-driven architectures use a publish-subscribe model where event producers generate streams of events, and event consumers respond to those events in near real time." 事件驱动体系结构使用发布-订阅模型，其中事件生成者生成事件流，事件使用者近实时地响应这些事件。 Microsoft, 2025, "A quick tour of the styles" section, "Event-driven architecture", para. 1
              Event producers
              事件生成者              		 "event producers that generate a stream of events" 事件生成者，它们生成事件流 Microsoft, 2026, para. 1
              Event consumers
              事件使用者              		 "event consumers that listen for these events" 事件使用者，它们侦听这些事件 Microsoft, 2026, para. 1
              Event channels
              事件通道              		 "event channels (often implemented as event brokers or ingestion services) that transfer events from producers to consumers" 事件通道，通常实现为事件代理或引入服务，负责把事件从生成者传送到使用者 Microsoft, 2026, para. 1
              Publish-subscribe
              发布-订阅              		 "The publish-subscribe messaging infrastructure tracks subscriptions. When an event is published, it sends the event to each subscriber." 发布-订阅消息传送基础结构跟踪订阅。发布事件时，它把事件发送给每个订阅者。 Microsoft, 2026, "Architecture" section, "Publish-subscribe" item
              Event streaming
              事件流式处理              		 "Events are written to a log. Events are strictly ordered within a partition and are durable." 事件被写入日志。事件在分区内严格有序，并且是持久的。 Microsoft, 2026, "Architecture" section, "Event streaming" item
              Simple event processing
              简单事件处理              		 "An event immediately triggers an action in the consumer." 事件立即触发位于使用者中的操作。 Microsoft, 2026, "Architecture" section, "Simple event processing" item
              Basic event correlation
              基本事件关联              		 "A consumer processes a few discrete business events, correlates them by an identifier, and persists information from earlier events to use when it processes later events." 使用者处理几个离散的业务事件，按标识符将它们关联起来，并保存早先事件的信息，供处理后续事件时使用。 Microsoft, 2026, "Architecture" section, "Basic event correlation" item
              Complex event processing
              复杂事件处理              		 "A consumer uses a technology like Azure Stream Analytics to analyze a series of events and identify patterns in the event data." 使用者借助 Azure 流分析之类的技术来分析一系列事件，并识别事件数据中的模式。 Microsoft, 2026, "Architecture" section, "Complex event processing" item
              Event stream processing
              事件流处理              		 "Use a data streaming platform, such as Azure IoT Hub, Event Hubs, or Event Hubs for Apache Kafka, as a pipeline to ingest events and feed them to stream processors." 使用数据流式处理平台，例如 Azure IoT 中心、事件中心或适用于 Apache Kafka 的事件中心，作为管道，引入事件并把它们馈送给流处理器。 Microsoft, 2026, "Architecture" section, "Event stream processing" item
              Include all required attributes in the payload
              在有效负载中包含所有必需属性              		 "Use this approach when you want consumers to have all available information without needing to query an external data source." 当你希望使用者拥有所有可用信息、无需查询外部数据源时，使用此方法。 Microsoft, 2026, "Architecture" section, "Include all required attributes in the payload" item
              Include only keys in the payload
              仅在有效负载中包含键              		 "In this approach, consumers retrieve the necessary attributes, such as a primary key, to independently fetch the remaining data from a data source." 在此方法中，使用者检索必要的属性，例如主键，以便独立地从数据源获取其余数据。 Microsoft, 2026, "Architecture" section, "Include only keys in the payload" item
              Broker topology
              代理拓扑              		 "Components broadcast events to the entire system. Other components either act on the event or ignore the event." 组件把事件广播到整个系统。其他组件要么对事件采取行动，要么忽略该事件。 Microsoft, 2026, "Architecture" section, "Broker topology" item
              Mediator topology
              中介拓扑              		 "There's an event mediator that manages and controls the flow of events." 有一个事件中介，它管理并控制事件流。 Microsoft, 2026, "Architecture" section, "Mediator topology" item
              Big data
              大数据              		 "Big data architectures handle the ingestion, processing, and analysis of data that's too large or complex for traditional database systems." 大数据体系结构负责数据的引入、处理和分析，这些数据对传统数据库系统来说过于庞大或复杂。 Microsoft, 2025, "A quick tour of the styles" section, "Big data", para. 1
              Big compute
              大计算              		 "Big compute architectures support large-scale workloads that require hundreds or thousands of cores for computationally intensive operations." 大计算体系结构支持大规模工作负载，这些工作负载需要数百或数千个核心来执行计算密集型操作。 Microsoft, 2025, "A quick tour of the styles" section, "Big compute", para. 1
