              9 Policies
              策略              		 (context) "Manage security and best-practices with policies." （语境）管理安全和最佳实践，靠的是策略。 The Kubernetes Authors, n.d.-b, "Policies", para. 1
              9.1 Limit Ranges
              限制范围              		 "A LimitRange is a policy to constrain the resource allocations (limits and requests) that you can specify for each applicable object kind (such as Pod or PersistentVolumeClaim) in a namespace." LimitRange 是一种策略，用来约束资源分配（限制和请求），这些分配是你可以为每种适用对象类型指定的（例如命名空间中的 Pod 或 PersistentVolumeClaim）。 The Kubernetes Authors, n.d.-a, "Limit Ranges", para. 2
              9.2 Resource Quotas
              资源配额              		 (context) "Resource quotas are a tool for administrators to address this concern." （语境）资源配额是管理员的一种工具，用来解决这一问题。 The Kubernetes Authors, n.d.-d, "Resource Quotas", para. 2
              9.3 Process ID Limits And Reservations
              进程 ID 限制与预留              		 (context) "Kubernetes allow you to limit the number of process IDs (PIDs) that a Pod can use." （语境）Kubernetes 允许你限制进程 ID（PID）的数量，即一个 Pod 可使用的数量。 The Kubernetes Authors, n.d.-c, "Process ID Limits And Reservations", para. 1
