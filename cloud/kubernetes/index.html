              Term Definition 中文翻译 Source
              Kubernetes
              Kubernetes              		 "Kubernetes is a portable, extensible, open source platform for managing containerized workloads and services that facilitate both declarative configuration and automation." Kubernetes 是一个可移植、可扩展的开源平台，用于管理容器化的工作负载和服务，可促进声明式配置和自动化。 The Kubernetes Authors, n.d.-f, "Overview", para. 1
              1 Overview
              概述              		 (No definition) （无定义） The Kubernetes Authors, n.d.-f, "Overview", documentation menu
              2 Cluster Architecture
              集群架构              		 (context) "The architectural concepts behind Kubernetes." （语境）Kubernetes 背后的架构概念。 The Kubernetes Authors, n.d.-b, "Cluster Architecture", para. 1
              3 Containers
              容器              		 "Technology for packaging an application along with its runtime dependencies." 技术，用于打包应用程序及其运行时依赖。 The Kubernetes Authors, n.d.-d, "Containers", para. 1
              4 Workloads
              工作负载              		 "A workload is an application running on Kubernetes." 工作负载是运行在 Kubernetes 上的应用程序。 The Kubernetes Authors, n.d.-n, "Workloads", para. 2
              5 Services, Load Balancing, and Networking
              服务、负载均衡与网络              		 (context) "Concepts and resources behind networking in Kubernetes." （语境）概念和资源，支撑 Kubernetes 中的网络。 The Kubernetes Authors, n.d.-k, "Services, Load Balancing, and Networking", para. 1
              6 Storage
              存储              		 "Ways to provide both long-term and temporary storage to Pods in your cluster." 各种方式，把长期和临时存储提供给集群中的 Pod。 The Kubernetes Authors, n.d.-l, "Storage", para. 1
              7 Configuration
              配置              		 "Configuration mechanisms within Kubernetes." Kubernetes 内部的配置机制。 The Kubernetes Authors, n.d.-c, "Configuration", para. 1
              8 Security
              安全              		 (context) "Concepts for keeping your cloud-native workload secure." （语境）概念，用于保障云原生工作负载的安全。 The Kubernetes Authors, n.d.-j, "Security", para. 1
              9 Policies
              策略              		 (context) "Manage security and best-practices with policies." （语境）管理安全和最佳实践，手段是策略。 The Kubernetes Authors, n.d.-g, "Policies", para. 1
              10 Scheduling, Preemption and Eviction
              调度、抢占与驱逐              		 (context) "In Kubernetes, scheduling refers to making sure that Pods are matched to Nodes so that the kubelet can run them." （语境）在 Kubernetes 中，调度是指确保 Pod 被匹配到 Node，以便 kubelet 能够运行它们。 The Kubernetes Authors, n.d.-i, "Scheduling, Preemption and Eviction", para. 1
              11 Resource Management
              资源管理              		 "How Kubernetes represents, requests, allocates, and constrains the resources that workloads consume." Kubernetes 如何表示、请求、分配和约束那些工作负载所消耗的资源。 The Kubernetes Authors, n.d.-h, "Resource Management", para. 1
              12 Cluster Administration
              集群管理              		 "Lower-level detail relevant to creating or administering a Kubernetes cluster." 底层细节，与创建或管理 Kubernetes 集群相关。 The Kubernetes Authors, n.d.-a, "Cluster Administration", para. 1
              13 Windows in Kubernetes
              Kubernetes 中的 Windows              		 (context) "Kubernetes supports nodes that run Microsoft Windows." （语境）Kubernetes 支持节点，这些节点运行 Microsoft Windows。 The Kubernetes Authors, n.d.-m, "Windows in Kubernetes", para. 1
              14 Extending Kubernetes
              扩展 Kubernetes              		 "Different ways to change the behavior of your Kubernetes cluster." 不同方式，用来改变 Kubernetes 集群的行为。 The Kubernetes Authors, n.d.-e, "Extending Kubernetes", para. 1
