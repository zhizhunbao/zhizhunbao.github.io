              10.3 Assigning Pods to Nodes
              将 Pod 分配给节点              		 (context) "You can constrain a Pod so that it is restricted to run on particular node(s), or to prefer to run on particular nodes." （语境）你可以约束一个 Pod，使它被限制在特定节点上运行，或优先在特定节点上运行。 The Kubernetes Authors, n.d., "Assigning Pods to Nodes", para. 1
              10.3.1 Node labels
              节点标签              		 "Like many other Kubernetes objects, nodes have labels." 与许多其他 Kubernetes 对象一样，节点也有标签。 The Kubernetes Authors, n.d., "Node labels", para. 1
              10.3.2 nodeSelector
              nodeSelector              		 "nodeSelector is the simplest recommended form of node selection constraint." nodeSelector 是最简单的推荐形式，属于节点选择约束。 The Kubernetes Authors, n.d., "nodeSelector", para. 1
              10.3.3 Affinity and anti-affinity
              亲和性与反亲和性              		 (No definition) （无定义） The Kubernetes Authors, n.d., "Affinity and anti-affinity"
              soft rules
              软规则              		 (context) "You can indicate that a rule is soft or preferred, so that the scheduler still schedules the Pod even if it can't find a matching node." （语境）你可以把一条规则标记为软或首选，这样调度器仍会调度该 Pod，即使它找不到匹配的节点。 The Kubernetes Authors, n.d., "Affinity and anti-affinity", para. 3
              Node affinity
              节点亲和性              		 "Node affinity functions like the nodeSelector field but is more expressive and allows you to specify soft rules." 节点亲和性的作用类似 nodeSelector 字段，但表达能力更强，并允许你指定软规则。 The Kubernetes Authors, n.d., "Affinity and anti-affinity", para. 6
              Inter-pod affinity/anti-affinity
              Pod 间亲和性/反亲和性              		 "Inter-pod affinity/anti-affinity allows you to constrain Pods against labels on other Pods." Pod 间亲和性/反亲和性让你约束 Pod，依据是其他 Pod 上的标签。 The Kubernetes Authors, n.d., "Affinity and anti-affinity", para. 7
              10.3.4 nodeName
              nodeName              		 "nodeName is a more direct form of node selection than affinity or nodeSelector." nodeName 是更直接的节点选择形式，相比亲和性或 nodeSelector。 The Kubernetes Authors, n.d., "nodeName", para. 1
              10.3.5 nominatedNodeName
              nominatedNodeName              		 "nominatedNodeName can be used for external components to nominate node for a pending pod." nominatedNodeName 可供外部组件用来为待调度的 Pod 提名节点。 The Kubernetes Authors, n.d., "nominatedNodeName", para. 1

              References

              The Kubernetes Authors. (n.d.). Assigning Pods to Nodes. Kubernetes Documentation. Retrieved October 31, 2026, from https://kubernetes.io/docs/concepts/scheduling-eviction/assign-pod-node/
