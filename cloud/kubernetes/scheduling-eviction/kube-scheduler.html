              10.1 Kubernetes Scheduler
              Kubernetes 调度器              		 "A scheduler watches for newly created Pods that have no Node assigned." 调度器监视尚未分配节点的新建 Pod。 The Kubernetes Authors, n.d., "Scheduling overview", para. 1
              10.1.1 kube-scheduler
              kube-scheduler              		 "kube-scheduler is the default scheduler for Kubernetes and runs as part of the control plane." kube-scheduler 是 Kubernetes 的默认调度器，作为控制平面的一部分运行。 The Kubernetes Authors, n.d., "kube-scheduler", para. 1
              feasible nodes
              可行节点              		 "In a cluster, Nodes that meet the scheduling requirements for a Pod are called feasible nodes." 在集群中，满足某个 Pod 调度要求的节点称为可行节点。 The Kubernetes Authors, n.d., "kube-scheduler", para. 3
              binding
              绑定              		 "The scheduler then notifies the API server about this decision in a process called binding." 随后调度器把这一决定通知 API 服务器，这个过程称为绑定。 The Kubernetes Authors, n.d., "kube-scheduler", para. 4
              filtering
              过滤              		 "The filtering step finds the set of Nodes where it's feasible to schedule the Pod." 过滤步骤找出可以调度该 Pod 的节点集合。 The Kubernetes Authors, n.d., "Node selection in kube-scheduler", para. 4
              scoring
              打分              		 "In the scoring step, the scheduler ranks the remaining nodes to choose the most suitable Pod placement." 在打分步骤中，调度器对剩下的节点排序，以选择最合适的 Pod 放置。 The Kubernetes Authors, n.d., "Node selection in kube-scheduler", para. 5
              Predicates
              断言              		 (context) "Scheduling Policies allow you to configure Predicates for filtering and Priorities for scoring." （语境）调度策略让你配置用于过滤的断言和用于打分的优先级。 The Kubernetes Authors, n.d., "Node selection in kube-scheduler", para. 8

              References

              The Kubernetes Authors. (n.d.). Kubernetes Scheduler. Kubernetes Documentation. Retrieved October 31, 2026, from https://kubernetes.io/docs/concepts/scheduling-eviction/kube-scheduler/
