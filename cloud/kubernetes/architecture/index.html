              2 Cluster Architecture
              集群架构              		 (context) "The architectural concepts behind Kubernetes." （语境）Kubernetes 背后的架构概念。 The Kubernetes Authors, n.d.-c, "Cluster Architecture", para. 1
              2.0 Cluster Architecture
              集群架构              		 "A Kubernetes cluster consists of a control plane plus a set of worker machines, called nodes, that run containerized applications." Kubernetes 集群由一个控制平面加上一组称为节点的工作机器组成，它们运行容器化应用。 The Kubernetes Authors, n.d.-c, "Cluster Architecture", para. 2
              2.1 Nodes
              节点              		 "A node may be a virtual or physical machine, depending on the cluster." 节点可以是虚拟机或物理机，取决于集群。 The Kubernetes Authors, n.d.-j, "Nodes", para. 1
              2.2 Communication between Nodes and the Control Plane
              节点与控制平面之间的通信              		 (context) "Kubernetes has a "hub-and-spoke" API pattern." （语境）Kubernetes 采用 “中心辐射”式的 API 模式。 The Kubernetes Authors, n.d.-d, "Node to Control Plane", para. 1
              2.3 Controllers
              控制器              		 (context) "In robotics and automation, a control loop is a non-terminating loop that regulates the state of a system." （语境）在机器人和自动化领域，控制回路是一个非终止循环，调节系统的状态。 The Kubernetes Authors, n.d.-e, "Controllers", para. 1
              2.4 Leases
              租约              		 "Distributed systems often have a need for leases, which provide a mechanism to lock shared resources and coordinate activity between members of a set." 分布式系统常常需要租约，它提供一种机制来锁定共享资源，并协调一组成员之间的活动。 The Kubernetes Authors, n.d.-h, "Leases", para. 1
              2.5 Cloud Controller Manager
              云控制器管理器              		 "The cloud-controller-manager is a Kubernetes control plane component that embeds cloud-specific control logic." 云控制器管理器是一个 Kubernetes 控制平面组件，嵌入了云平台特定的控制逻辑。 The Kubernetes Authors, n.d.-b, "Cloud Controller Manager", para. 2
              2.6 About cgroup v2
              关于 cgroup v2              		 (context) "On Linux, control groups constrain resources that are allocated to processes." （语境）在 Linux 上，控制组约束资源，这些资源分配给进程。 The Kubernetes Authors, n.d.-a, "About cgroup v2", para. 1
              2.7 Kubernetes Self-Healing
              Kubernetes 自我修复              		 "Kubernetes is designed with self-healing capabilities that help maintain the health and availability of workloads." Kubernetes 设计有自我修复能力，帮助维持工作负载的健康和可用性。 The Kubernetes Authors, n.d.-g, "Kubernetes Self-Healing", para. 1
              2.8 Garbage Collection
              垃圾回收              		 "Garbage collection is a collective term for the various mechanisms Kubernetes uses to clean up cluster resources." 垃圾回收是一个统称，指各种机制，Kubernetes 用它们来清理集群资源。 The Kubernetes Authors, n.d.-f, "Garbage Collection", para. 1
              2.9 Mixed Version Proxy
              混合版本代理              		 "Kubernetes 1.37 includes a beta feature that lets an API Server proxy resource requests to other peer API servers." Kubernetes 1.37 包含一项 beta 功能，让一个 API 服务器 把资源请求代理给其他对等 API 服务器。 The Kubernetes Authors, n.d.-i, "Mixed Version Proxy", para. 1
