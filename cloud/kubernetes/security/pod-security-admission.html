              8.3 Pod Security Admission
              Pod 安全准入              		 (context) "The Kubernetes Pod Security Standards define different isolation levels for Pods." （语境）Kubernetes Pod 安全标准定义了不同的隔离级别，适用于 Pod。 The Kubernetes Authors, n.d., "Pod Security Admission", para. 2
              8.3.0 Pod Security Admission
              Pod 安全准入              		 (No definition) （无定义） The Kubernetes Authors, n.d., "Pod Security Admission"
              Pod Security admission controller
              Pod 安全准入控制器              		 "Kubernetes offers a built-in Pod Security admission controller to enforce the Pod Security Standards." Kubernetes 提供一个内置的 Pod 安全准入控制器，用来执行 Pod 安全标准。 The Kubernetes Authors, n.d., "Pod Security Admission", para. 3
              8.3.1 Exemptions
              豁免              		 "You can define exemptions from pod security enforcement in order to allow the creation of pods that would have otherwise been prohibited due to the policy associated with a given namespace." 你可以定义豁免，免于 Pod 安全执行，以允许创建一些 Pod，这些 Pod 本来会被禁止，依据的是与给定命名空间关联的策略。 The Kubernetes Authors, n.d., "Exemptions", para. 1
