              云原生安全              		 (context) "Concepts for keeping your cloud native workload secure." （语境）一组概念，用于保障云原生工作负载安全。 The Kubernetes Authors, n.d.-a, "Cloud Native Security", para. 1
              8.2 Pod Security Standards
              Pod 安全标准              		 "The Pod Security Standards define three different policies to broadly cover the security spectrum." Pod 安全标准定义了三种不同的策略级别，以广泛覆盖安全范围。 The Kubernetes Authors, n.d.-g, "Pod Security Standards", para. 2
              8.3 Pod Security Admission
              Pod 安全准入              		 (context) "The Kubernetes Pod Security Standards define different isolation levels for Pods." （语境）Kubernetes Pod 安全标准定义了不同的隔离级别，适用于 Pod。 The Kubernetes Authors, n.d.-f, "Pod Security Admission", para. 2
              8.4 Service Accounts
              服务账号              		 (context) "Learn about ServiceAccount objects in Kubernetes." （语境）了解 ServiceAccount 对象在 Kubernetes 中的用法。 The Kubernetes Authors, n.d.-k, "Service Accounts", para. 1
              8.5 Security For Linux Nodes
              Linux 节点的安全              		 (context) "This page describes security considerations and best practices specific to the Linux operating system." （语境）本页介绍安全注意事项和最佳实践，专属于 Linux 操作系统。 The Kubernetes Authors, n.d.-i, "Security For Linux Nodes", para. 1
              8.6 Security For Windows Nodes
              Windows 节点的安全              		 (context) "This page describes security considerations and best practices specific to the Windows operating system." （语境）本页介绍安全注意事项和最佳实践，专属于 Windows 操作系统。 The Kubernetes Authors, n.d.-j, "Security For Windows Nodes", para. 1
              8.7 Controlling Access to the Kubernetes API
              控制对 Kubernetes API 的访问              		 (context) "Users access the Kubernetes API using kubectl, client libraries, or by making REST requests." （语境）用户访问 Kubernetes API，方式是 kubectl、客户端库或发送 REST 请求。 The Kubernetes Authors, n.d.-b, "Controlling Access to the Kubernetes API", para. 2
              8.8 Multi-tenancy
              多租户              		 (context) "Sharing clusters saves costs and simplifies administration." （语境）共享集群可以节省成本，并简化管理。 The Kubernetes Authors, n.d.-e, "Multi-tenancy", para. 2
              8.9 Kubernetes API Server Bypass Risks
              Kubernetes API 服务器旁路风险              		 (context) "The Kubernetes API server is the main point of entry to a cluster for external parties (users and services) interacting with it." （语境）Kubernetes API 服务器是集群的主要入口，供与之交互的外部各方（用户和服务）。 The Kubernetes Authors, n.d.-c, "Kubernetes API Server Bypass Risks", para. 2
              8.10 Linux kernel security constraints for Pods and containers
              Pod 和容器的 Linux 内核安全约束              		 (context) "Overview of Linux kernel security modules and constraints that you can use to harden your Pods and containers." （语境）概述 Linux 内核安全模块与约束，可用来加固 Pod 和容器。 The Kubernetes Authors, n.d.-d, "Linux kernel security constraints for Pods and containers", para. 1
