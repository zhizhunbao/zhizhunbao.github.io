              8.4 Service Accounts

              8.4.1 Service accounts
              服务账号              		 "A service account is a type of non-human account that, in Kubernetes, provides a distinct identity in a Kubernetes cluster." 服务账号是一种非人类账号，在 Kubernetes 中提供集群内的一个独立身份。 The Kubernetes Authors, n.d., "What are service accounts?", para. 1
              Default service accounts
              默认服务账号              		 "When you create a cluster, Kubernetes automatically creates a ServiceAccount object named default for every namespace in your cluster." 当你创建集群时，Kubernetes 自动创建一个名为 default 的 ServiceAccount 对象，为集群中的每个命名空间各建一个。 The Kubernetes Authors, n.d., "Default service accounts", para. 1
              8.4.2 How to use service accounts
              如何使用服务账号              		 (No definition) （无定义） The Kubernetes Authors, n.d., "How to use service accounts"
              role
              角色              		 (context) "You create a role, which grants access, and then bind the role to your ServiceAccount." （语境）你创建一个角色，由它授予访问权，再把该角色绑定到 ServiceAccount。 The Kubernetes Authors, n.d., "Grant permissions to a ServiceAccount", para. 1
              8.4.3 Authenticating service account credentials
              验证服务账号凭据              		 "ServiceAccounts use signed JSON Web Tokens (JWTs) to authenticate to the Kubernetes API server, and to any other system where a trust relationship exists." ServiceAccount 使用签名的 JSON Web Token（JWT），以此向 Kubernetes API 服务器认证，也向任何存在信任关系的其他系统认证。 The Kubernetes Authors, n.d., "Authenticating service account credentials", para. 1
              bound tokens
              绑定令牌              		 "The TokenRequest API produces bound tokens for a ServiceAccount." TokenRequest API 生成绑定令牌，供一个 ServiceAccount 使用。 The Kubernetes Authors, n.d., "Authenticating service account credentials", para. 7
