              6.11 Dialog

              Glossary

              Term Definition 中文翻译 Source
              Dialog
              对话框              		 "A dialog is a supplemental surface that can provide helpful interactions or require someone to take an action before they can continue their task, like confirming a deletion." 对话框是一个补充界面，可以提供有用的交互，或要求用户先做一个操作才能继续手头的任务，比如确认删除。 Microsoft, n.d., "Dialog"
              Modal
              模态              		 "A modal dialog disables the page content behind it and usually obscures or dims it to surface its content. Use it when someone needs to perform a focused task, like signing into an app." 模态对话框会让后面的页面内容不可操作，通常还会遮住或调暗页面来突出自己的内容。当用户需要完成一项专注的任务时使用，比如登录应用。 Microsoft, n.d., "Dialog", Types
              Non-modal
              非模态              		 "A non-modal dialog allows someone to continue interacting with the page content behind the window and aids in their workflow, like find and replace. Use it as a helper in a task." 非模态对话框允许用户继续操作窗口后面的页面内容，辅助他们的工作流程，比如查找和替换。把它当作任务中的助手使用。 Microsoft, n.d., "Dialog", Types
              Alert
              警告              		 "An alert dialog is a modal that requires someone to make a decision. Alert dialogs have a special role that allows assistive technologies to treat them more urgently than other dialogs, like playing a system alert sound." 警告对话框是一种要求用户做出决定的模态框。它有特殊的角色，让辅助技术比对待其他对话框更紧急地处理它，比如播放系统提示音。 Microsoft, n.d., "Dialog", Types
              Dismissal
              关闭方式              		 (context) "Someone can dismiss a modal dialog by selecting an area outside of the container, using the Esc key, or selecting a footer button." （语境）用户可以通过点击容器外的区域、按 Esc 键或点击底部按钮来关闭模态对话框。 Microsoft, n.d., "Dialog", Behavior
              Forms in dialogs
              对话框中的表单              		 (context) "Fields can be placed in dialogs to ask people for information that’s related to their current task." （语境）可以在对话框里放字段，向用户收集信息，且信息与他们当前的任务相关。 Microsoft, n.d., "Dialog", Behavior
              Header
              标题栏              		 (context) "A header, which can contain a title and a dismiss icon" （语境）标题栏，可以包含标题和关闭图标 Microsoft, n.d., "Dialog", Layout
              Body
              正文              		 (context) "Use the body content area for additional info or instructions, if needed. Don’t restate the title in the body." （语境）需要时用正文区放补充信息或说明。不要在正文里重复标题。 Microsoft, n.d., "Dialog", Content
              Footer
              底部              		 (context) "Optional footer, which can contain up to three actions." （语境）可选的底部，最多可以放三个操作。 Microsoft, n.d., "Dialog", Layout
              Dialog focus
              对话框焦点              		 (context) "When a dialog is opened, keyboard focus should go to the first interactive element within the container." （语境）对话框打开时，键盘焦点应移到容器内第一个可交互的元素上。 Microsoft, n.d., "Dialog", Accessibility

              References

              Microsoft. (n.d.). Fluent 2 Design System. Retrieved November 6, 2026, from https://fluent2.microsoft.design/
