              2.6 Wait UX

              Glossary

              Term Definition 中文翻译 Source
              Wait UX
              等待体验（Wait UX）              		 "Wait UX refers to the design of user experiences during moments of delay—when a system is processing, loading, or retrieving data." 等待体验指用户体验的设计，针对的是延迟的时刻，即系统正在处理、加载或获取数据的时候。 Microsoft, n.d., "Wait UX"
              Determinate indicators
              确定型指示器              		 (context) "When possible, use determinate indicators to show actual progress." （语境）尽可能使用确定型指示器来显示实际进度。 Microsoft, n.d., "Wait UX", Principles
              Indeterminate indicators
              不确定型指示器              		 (context) "If progress cannot be measured, use indeterminate indicators only for short waits." （语境）如果进度无法衡量，就用不确定型指示器，但只用于短暂等待。 Microsoft, n.d., "Wait UX", Principles
              Perceived performance
              感知性能              		 (context) "Visual feedback can reduce the perceived duration of a delay." （语境）视觉反馈可以缩短用户感觉到的延迟时长。 Microsoft, n.d., "Wait UX", Principles
              Spinner
              旋转指示器              		 "Spinners are best used for short, indeterminate waits—typically under three seconds." 旋转指示器最适合短暂、无法确定时长的等待，通常不到三秒。 Microsoft, n.d., "Wait UX", Visual patterns
              Progress bar
              进度条              		 "Progress bars are ideal for longer waits where progress can be tracked." 进度条最适合较长的等待，且进度可以追踪。 Microsoft, n.d., "Wait UX", Visual patterns
              Skeleton
              骨架屏              		 "Skeleton screens are useful for content rendering delays. In AI-first experiences like Copilot, use the Copilot gradient shimmer to reinforce the theme and reassure users that content is loading." 骨架屏适用于内容渲染的延迟。在 Copilot 这类以 AI 为主的体验里，用 Copilot 渐变微光效果来强化主题，并让用户放心内容正在加载。 Microsoft, n.d., "Wait UX", Visual patterns
              Progress toast
              进度通知              		 "Progress toasts are appropriate for long back-end processes that affect current content." 进度通知适用于耗时较长的后台处理，且这些处理会影响当前内容。 Microsoft, n.d., "Wait UX", Visual patterns
              Morse code
              摩斯码动画              		 "The morse code animation is used specifically in AI-forward, Copilot scenarios. It mimics the typing dots animation in human to human chat experiences" 摩斯码动画专用于以 AI 为主的 Copilot 场景。它模仿人与人聊天里正在输入的点点动画 Microsoft, n.d., "Wait UX", Visual patterns
              Pulsing dot
              脉冲圆点              		 "The pulsing dot animation is used in Chain of Thought as a lighter-weight wait animation." 脉冲圆点动画用在思维链（Chain of Thought）中，作为较轻量的等待动画。 Microsoft, n.d., "Wait UX", Visual patterns
              Timing thresholds
              时间阈值              		 (context) "For waits between one and three seconds, a spinner is appropriate. If the wait exceeds three seconds, switch to a progress bar or display a content string to reassure users that the process is active." （语境）等待在一到三秒之间时，用旋转指示器合适。等待超过三秒，就换成进度条，或显示一段文字，让用户放心处理仍在进行。 Microsoft, n.d., "Wait UX", Behavior
              Fallback messaging
              兜底提示              		 "When progress details are unavailable, fallback messages should still offer reassurance." 当拿不到进度细节时，兜底提示也应当让用户安心。 Microsoft, n.d., "Wait UX", Behavior
              Hardcoded vs. generated strings
              固定文案与生成文案              		 "In productivity apps like Outlook, hardcoded strings ensure consistency and clarity. In AI chat experiences, dynamically generated strings allow for more personalized and context-aware feedback." 在 Outlook 这类办公应用里，固定文案保证一致和清楚。在 AI 聊天体验里，动态生成的文案能给出更个性化、更贴合情境的反馈。 Microsoft, n.d., "Wait UX", Behavior

              References

              Microsoft. (n.d.). Fluent 2 Design System. Retrieved November 6, 2026, from https://fluent2.microsoft.design/
