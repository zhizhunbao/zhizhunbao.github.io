              9.3.44 Table

              Glossary

              Term Definition 中文翻译 Source
              Table
              表格              		 "A Table displays sets of two-dimensional data. The primitive components can be fully customized to support different feature sets." 表格显示成组的二维数据。它的基本组件可以完全自定义，以支持不同的功能组合。 Microsoft, n.d., "Table", para. 1
              useTableFeatures
              useTableFeatures 钩子              		 "The library provides a default useTableFeatures hook that handles the business logic and state management of common features." 库提供了一个默认的 useTableFeatures 钩子，用来处理常用功能的业务逻辑和状态管理。 Microsoft, n.d., "Table", para. 1
              Non Native Elements
              非原生元素              		 (context) "Using the noNativeElements prop will ensure that all components are rendered as divs while ensuring a layout experience similar to semantic table elements." （语境）使用 noNativeElements 属性，可以让所有组件都渲染为 div，同时保证布局体验与语义化的表格元素相似。 Microsoft, n.d., "Table", Stories, "Non Native Elements"
              Cell Actions
              单元格操作              		 "TableCellActions is a container that is visible when the TableRowis hovered or when the current focused element is within the row." TableCellActions 是一个容器，在鼠标悬停于 TableRow 上、或当前获得焦点的元素位于该行内时可见。 Microsoft, n.d., "Table", Stories, "Cell Actions"
              Primary Cell
              主单元格              		 "A primary cell creates emphasis by increasing icon size and font weight for the main text." 主单元格形成强调的方式是加大主文本的图标尺寸和字重。 Microsoft, n.d., "Table", Stories, "Primary Cell"
              Cell Navigation
              单元格导航              		 (context) "Cell navigation can be achieved simply using the useArrowNavigationGroup utility provided by the Library." （语境）使用 useArrowNavigationGroup 工具就能简单地实现单元格导航，这个工具由库提供。 Microsoft, n.d., "Table", Stories, "Cell Navigation"
              Composite Navigation
              复合导航              		 "Composite navigation combines row focus and cell focus. By default the user navigates the table by row." 复合导航结合了行焦点和单元格焦点。默认情况下，用户按行浏览表格。 Microsoft, n.d., "Table", Stories, "Composite Navigation"
              Sort
              排序              		 (context) "Using the sortable prop will configure all header cells to be buttons and add extra styles." （语境）使用 sortable 属性，会把所有表头单元格设置为按钮，并添加额外的样式。 Microsoft, n.d., "Table", Stories, "Sort"
              Resizable Columns (preview)
              可调整宽度的列（预览）              		 (context) "The Table component contains logic to support column resizing. To enable resizing, use the useTableFeatures hook in combination with the useTableColumnSizing_unstable plugin." （语境）Table 组件包含支持调整列宽的逻辑。要启用调整列宽，请把 useTableFeatures 钩子与 useTableColumnSizing_unstable 插件结合使用。 Microsoft, n.d., "Table", Stories, "Resizable Columns (preview)"
              Multiple Select
              多选              		 (context) "Selection can be achieved easily by combining the TableSelectionCell component along with other primitive components." （语境）把 TableSelectionCell 组件与其他基本组件组合起来，就能轻松实现选择。 Microsoft, n.d., "Table", Stories, "Multiple Select"
              Single Select
              单选              		 (context) "The single selection scenario is similar to the multiple selection scenario." （语境）单选场景类似于多选场景。 Microsoft, n.d., "Table", Stories, "Single Select"
              Subtle Selection
              低调选择              		 (context) "By setting the subtle prop on the TableSelectionCell component, the selection indicator will only appear when:" （语境）在 TableSelectionCell 组件上设置 subtle 属性后，选择指示器只会在以下情况下出现： Microsoft, n.d., "Table", Stories, "Subtle Selection"
              Virtualization
              虚拟化              		 (context) "The Table primitive components are unopinionated with respect to virtualization." （语境）Table 基本组件不预设任何立场，对虚拟化也是如此。 Microsoft, n.d., "Table", Stories, "Virtualization"
              Data Grid
              数据网格              		 "The DataGrid component is a composition of the useTableFeatures hook and primitive Table components along with some convenience features such as accessible markup and event handlers." DataGrid 组件是由 useTableFeatures 钩子与 Table 基本组件构成的组合，并带有一些便利功能，例如无障碍标记和事件处理程序。 Microsoft, n.d., "Table", Stories, "Data Grid"

              References

              Microsoft. (n.d.). Fluent UI React v9. Retrieved November 19, 2026, from https://storybooks.fluentui.dev/react/
