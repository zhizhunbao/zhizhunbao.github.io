              9.4.2 DatePicker

              Glossary

              Term Definition 中文翻译 Source
              DatePicker
              日期选择器              		 "A date picker (DatePicker) offers a popup control that’s optimized for picking a single date from a calendar view where contextual information like the day of the week or fullness of the calendar is important." 日期选择器（DatePicker）提供一个弹出控件，专为从日历视图中挑选单个日期而优化，适用于星期几或日历繁忙程度等上下文信息很重要的场合。 Microsoft, n.d., "DatePicker", para. 1
              Text Input
              文本输入              		 "A DatePicker supports user input. Clicking the input field will open the DatePicker, and clicking the field again will dismiss the DatePicker and allow text input." DatePicker 支持用户输入。点击输入框会打开 DatePicker，再次点击输入框会关闭 DatePicker 并允许输入文本。 Microsoft, n.d., "DatePicker", Stories, "Text Input"
              First Day Of The Week
              每周第一天              		 "A DatePicker allows you to set the first day of the week." DatePicker 允许你设置每周的第一天。 Microsoft, n.d., "DatePicker", Stories, "First Day Of The Week"
              Week Numbers
              周数              		 "A DatePicker allows you to show the number of the week on the left when showWeekNumbers is set to true." DatePicker 允许你在左侧显示周数，条件是 showWeekNumbers 设为 true。 Microsoft, n.d., "DatePicker", Stories, "Week Numbers"
              Date Range
              日期范围              		 "DatePicker allows you to set the selection range type. The range can be Day, Month, Week, and WorkWeek." DatePicker 允许你设置选择范围的类型。范围可以是 Day、Month、Week 和 WorkWeek。 Microsoft, n.d., "DatePicker", Stories, "Date Range"
              Date Boundaries
              日期边界              		 "A DatePicker allows setting date boundaries. To set a max boundary, use the maxDate prop." DatePicker 允许设置日期边界。要设置最大边界，请使用 maxDate 属性。 Microsoft, n.d., "DatePicker", Stories, "Date Boundaries"
              Custom Date Formatting
              自定义日期格式              		 "Applications can customize how dates are formatted and parsed. Formatted dates can be ambiguous, so the control will avoid parsing the formatted strings of dates selected using the UI when text input is allowed." 应用程序可以自定义日期的格式化和解析方式。格式化后的日期可能有歧义，所以在允许文本输入时，控件不会去解析通过界面选中的日期的格式化字符串。 Microsoft, n.d., "DatePicker", Stories, "Custom Date Formatting"
              Localized
              本地化              		 "DatePicker accepts a strings prop that allows custom localization." DatePicker 接受一个 strings 属性，用来实现自定义本地化。 Microsoft, n.d., "DatePicker", Stories, "Localized"
              Error Handling
              错误处理              		 (context) "To add error handling to a DatePicker, use onValidationResult along with Field." （语境）要给 DatePicker 加上错误处理，请把 onValidationResult 与 Field 一起使用。 Microsoft, n.d., "DatePicker", Stories, "Error Handling"
              Controlled
              受控              		 "A DatePicker can be controlled by manually keeping track of the state and updating it." DatePicker 可以通过手动跟踪状态并更新它来实现受控。 Microsoft, n.d., "DatePicker", Stories, "Controlled"
              Required
              必填              		 "DatePicker supports required validation. The validation will happen when the DatePicker loses focus." DatePicker 支持必填校验。校验会在 DatePicker 失去焦点时进行。 Microsoft, n.d., "DatePicker", Stories, "Required"
              Disabled
              禁用              		 "DatePicker can be disabled to restrict user interaction." DatePicker 可以被禁用，以限制用户交互。 Microsoft, n.d., "DatePicker", Stories, "Disabled"

              References
