              9.4.1 Calendar

              Glossary

              Term Definition 中文翻译 Source
              Calendar
              日历              		 "The calendar control lets people select and view a single date or a range of dates in their calendar." 日历控件让人们在日历中选择和查看单个日期或一段日期范围。 Microsoft, n.d., "Calendar", para. 1
              Month view
              月视图              		 "made up of 3 separate views: the month view, year view, and decade view" 由 3 个独立视图组成：月视图、年视图和十年视图 Microsoft, n.d., "Calendar", para. 1
              Year view
              年视图              		 "made up of 3 separate views: the month view, year view, and decade view" 由 3 个独立视图组成：月视图、年视图和十年视图 Microsoft, n.d., "Calendar", para. 1
              Decade view
              十年视图              		 "made up of 3 separate views: the month view, year view, and decade view" 由 3 个独立视图组成：月视图、年视图和十年视图 Microsoft, n.d., "Calendar", para. 1
              Calendar Month Only
              仅月份日历              		 "A Calendar Compat allows you to only show the month and year picker leaving the day picker hidden." Calendar Compat 允许你只显示月份和年份选择器，而让日期选择器隐藏。 Microsoft, n.d., "Calendar", Stories, "Calendar Month Only"
              Calendar Overlaid Month
              月份叠加日历              		 "A Calendar Compat allows you to render the month picker over the day picker. This is useful when there are width constraints and the month picker is needed." Calendar Compat 允许你把月份选择器叠加在日期选择器之上。当存在宽度限制又需要月份选择器时，这很有用。 Microsoft, n.d., "Calendar", Stories, "Calendar Overlaid Month"
              Calendar Date Boundaries
              日期边界日历              		 "A Calendar Compat can be modified to set a minDate and maxDate in order to restrict the dates that can be selected." Calendar Compat 可以通过设置 minDate 和 maxDate 来限制可选的日期。 Microsoft, n.d., "Calendar", Stories, "Calendar Date Boundaries"
              Calendar Six Weeks
              六周日历              		 "A Calendar Compat allows you to set a six week month." Calendar Compat 允许你把一个月设为六周。 Microsoft, n.d., "Calendar", Stories, "Calendar Six Weeks"
              Calendar Week Numbers
              周数日历              		 "A Calendar Compat allows you to show the week numbers next to the day grid for their respective week." Calendar Compat 允许你显示各周的周数，位置在日期网格旁边。 Microsoft, n.d., "Calendar", Stories, "Calendar Week Numbers"
              Calendar Week Selection
              按周选择日历              		 "A Calendar Compat allows you to set a selection range of weeks instead of selecting a single day." Calendar Compat 允许你设置按周的选择范围，而不是只选单独一天。 Microsoft, n.d., "Calendar", Stories, "Calendar Week Selection"
              Calendar Marked Days
              标记日期日历              		 "A Calendar Compat allows you to pass a callback that returns an array of number that should bemarked. This callback provides a starting date and an ending date." Calendar Compat 允许你传入一个回调，返回应被标记的数字数组。这个回调会提供开始日期和结束日期。 Microsoft, n.d., "Calendar", Stories, "Calendar Marked Days"
              Calendar Month Selection
              按月选择日历              		 "A Calendar Compat allows you to set a selection range of months instead of selecting a single day." Calendar Compat 允许你设置按月的选择范围，而不是只选单独一天。 Microsoft, n.d., "Calendar", Stories, "Calendar Month Selection"
              Calendar Multiday Day View
              多日日视图日历              		 "A Calendar Compat allows you to pass a number of days that will be highlighted from the selected date and forward." Calendar Compat 允许你传入一个天数，从所选日期起往后的这些天会被高亮。 Microsoft, n.d., "Calendar", Stories, "Calendar Multiday Day View"
              Calendar Contiguous Work Week Days
              连续工作周日历              		 "A Calendar Compat can be modified to allow selecting a contiguous (5 day) work week." Calendar Compat 可以修改为允许选择一个连续的（5 天）工作周。 Microsoft, n.d., "Calendar", Stories, "Calendar Contiguous Work Week Days"
              Calendar Non Contiguous Work Week Days
              非连续工作周日历              		 "A Calendar Compat can be modified to allow selecting a non contiguous (7 day) week." Calendar Compat 可以修改为允许选择一个非连续的（7 天）周。 Microsoft, n.d., "Calendar", Stories, "Calendar Non Contiguous Work Week Days"

              References

              Microsoft. (n.d.). Fluent UI React v9. Retrieved November 19, 2026, from https://storybooks.fluentui.dev/react/
