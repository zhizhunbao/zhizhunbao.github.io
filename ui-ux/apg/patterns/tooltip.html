              1.23 Tooltip
              工具提示              		 "A tooltip is a popup that displays information related to an element when the element receives keyboard focus or the mouse hovers over it. It typically appears after a small delay and disappears when Escape is pressed or on mouse out." 工具提示是一种弹出层，当某个元素获得键盘焦点或鼠标悬停在其上时，显示与该元素相关的信息。它通常在短暂延迟后出现，在按下 Escape 或鼠标移出时消失。 W3C Web Accessibility Initiative, n.d., "About This Pattern"
              non-modal dialog
              非模态对话框              		 (context) "Tooltip widgets do not receive focus. A hover that contains focusable elements can be made using a non-modal dialog." （语境）工具提示控件不会获得焦点。包含可聚焦元素的悬停内容可以用非模态对话框来实现。 W3C Web Accessibility Initiative, n.d., "About This Pattern"
              Escape
              Esc 键              		 "Dismisses the Tooltip." 关闭这个工具提示。 W3C Web Accessibility Initiative, n.d., "Keyboard Interaction"
              tooltip
              工具提示角色              		 "The element that serves as the tooltip container has role tooltip." 充当工具提示容器的元素具有 tooltip 角色。 W3C Web Accessibility Initiative, n.d., "WAI-ARIA Roles, States, and Properties"
              aria-describedby
              由谁描述              		 "The element that triggers the tooltip references the tooltip element with aria-describedby." 触发工具提示的元素通过 aria-describedby 引用工具提示元素。 W3C Web Accessibility Initiative, n.d., "WAI-ARIA Roles, States, and Properties"

              References
