              1.6 Slider
              滑块              		 "A slider is an input where the user selects a value from within a given range." 滑块是一种输入，用户在其中从给定范围内选择一个值。 W3C Web Accessibility Initiative, n.d., "About This Pattern"
              slider thumb
              滑块手柄              		 "Sliders typically have a slider thumb that can be moved along a bar, rail, or track to change the value of the slider." 滑块通常有一个滑块手柄，它可以沿着条、轨道或滑道移动，以改变滑块的值。 W3C Web Accessibility Initiative, n.d., "About This Pattern"
              Right Arrow
              右方向键              		 "Increase the value of the slider by one step." 把滑块的值增加，幅度为一步。 W3C Web Accessibility Initiative, n.d., "Keyboard Interaction"
              Up Arrow
              上方向键              		 "Increase the value of the slider by one step." 把滑块的值增加，幅度为一步。 W3C Web Accessibility Initiative, n.d., "Keyboard Interaction"
              Left Arrow
              左方向键              		 "Decrease the value of the slider by one step." 把滑块的值减少，幅度为一步。 W3C Web Accessibility Initiative, n.d., "Keyboard Interaction"
              Down Arrow
              下方向键              		 "Decrease the value of the slider by one step." 把滑块的值减少，幅度为一步。 W3C Web Accessibility Initiative, n.d., "Keyboard Interaction"
              Home
              Home 键              		 "Set the slider to the first allowed value in its range." 把滑块设为其范围内的第一个允许值，即范围的起点。 W3C Web Accessibility Initiative, n.d., "Keyboard Interaction"
              End
              End 键              		 "Set the slider to the last allowed value in its range." 把滑块设为其范围内的最后一个允许值，即范围的终点。 W3C Web Accessibility Initiative, n.d., "Keyboard Interaction"
              Page Up (Optional)
              Page Up 键（可选）              		 "Increase the slider value by an amount larger than the step change made by Up Arrow." 增加滑块的值，增加量大于上方向键每次的步长。 W3C Web Accessibility Initiative, n.d., "Keyboard Interaction"
              Page Down (Optional)
              Page Down 键（可选）              		 "Decrease the slider value by an amount larger than the step change made by Down Arrow." 减少滑块的值，减少量大于下方向键每次的步长。 W3C Web Accessibility Initiative, n.d., "Keyboard Interaction"
              slider
              滑块角色              		 "The element serving as the focusable slider control has role slider." 充当可聚焦滑块控件的元素具有 slider 角色。 W3C Web Accessibility Initiative, n.d., "WAI-ARIA Roles, States, and Properties"
              aria-valuenow
              当前值              		 "The slider element has the aria-valuenow property set to a decimal value representing the current value of the slider." 滑块元素的 aria-valuenow 属性设为一个十进制数值，表示滑块的当前值。 W3C Web Accessibility Initiative, n.d., "WAI-ARIA Roles, States, and Properties"
              aria-valuemin
              最小值              		 "The slider element has the aria-valuemin property set to a decimal value representing the minimum allowed value of the slider." 滑块元素的 aria-valuemin 属性设为一个十进制数值，表示滑块的最小允许值。 W3C Web Accessibility Initiative, n.d., "WAI-ARIA Roles, States, and Properties"
              aria-valuemax
              最大值              		 "The slider element has the aria-valuemax property set to a decimal value representing the maximum allowed value of the slider." 滑块元素的 aria-valuemax 属性设为一个十进制数值，表示滑块的最大允许值。 W3C Web Accessibility Initiative, n.d., "WAI-ARIA Roles, States, and Properties"
              aria-valuetext
              值的文字              		 "If the value of aria-valuenow is not user-friendly, e.g., the day of the week is represented by a number, the aria-valuetext property is set to a string that makes the slider value understandable, e.g., "Monday"." 如果 aria-valuenow 的值对用户不友好，例如星期几用数字表示，就把 aria-valuetext 属性设为一个让滑块的值易于理解的字符串，例如 "Monday"。 W3C Web Accessibility Initiative, n.d., "WAI-ARIA Roles, States, and Properties"
              aria-labelledby
              由谁标注              		 "If the slider has a visible label, it is referenced by aria-labelledby on the slider element." 如果滑块有可见的标签，滑块元素上的 aria-labelledby 会引用这个标签。 W3C Web Accessibility Initiative, n.d., "WAI-ARIA Roles, States, and Properties"
              aria-label
              标签              		 "Otherwise, the slider element has a label provided by aria-label." 否则，滑块元素的标签由 aria-label 提供。 W3C Web Accessibility Initiative, n.d., "WAI-ARIA Roles, States, and Properties"
              aria-orientation
              方向              		 "If the slider is vertically oriented, it has aria-orientation set to vertical. The default value of aria-orientation for a slider is horizontal." 如果滑块是竖直方向的，它的 aria-orientation 设为 vertical。滑块的 aria-orientation 默认值是 horizontal。 W3C Web Accessibility Initiative, n.d., "WAI-ARIA Roles, States, and Properties"

              References
