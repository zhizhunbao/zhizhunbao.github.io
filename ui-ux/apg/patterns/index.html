              1. Patterns

              Order: the APG Patterns page lists the patterns alphabetically, as an index. Here they go from simple to complex, with related patterns next to each other: basic controls (Button to Switch), value controls (Slider to Meter), selection (Listbox, Combobox), show and hide containers (Disclosure to Feed), menus and toolbars, dialogs and messages (Alert to Tooltip), page navigation and structure (Breadcrumb to Window Splitter), and data (Table to Treegrid). The groups only set the order; they are not a level of the menu.

              Glossary

              Term Definition 中文翻译 Source
              1. Patterns
              模式              		 "Learn how to make accessible web components and widgets with ARIA roles, states and properties and by implementing keyboard support." 学习如何制作无障碍的网页组件和控件，方法是使用 ARIA 角色、状态和属性，并实现键盘支持。 W3C Web Accessibility Initiative, n.d., "Design Patterns and Examples"
              1.1 Button
              按钮              		 "A button is a widget that enables users to trigger an action or event, such as submitting a form, opening a dialog, canceling an action, or performing a delete operation." 按钮是一种控件，让用户能够触发一个动作或事件，例如提交表单、打开对话框、取消操作或执行删除。 W3C Web Accessibility Initiative, n.d., "Button"
              1.2 Link
              链接              		 "A link widget provides an interactive reference to a resource." 链接控件提供一个交互式引用，指向某个资源。 W3C Web Accessibility Initiative, n.d., "Link"
              1.3 Checkbox
              复选框              		 "WAI-ARIA supports two types of checkbox widgets: dual-state checkboxes toggle between two choices -- checked and not checked -- and tri-state checkboxes, which allow an additional third state known as partially checked." WAI-ARIA 支持两类复选框控件：双态复选框在两个选项（选中和未选中）之间切换，三态复选框则多出第三种状态，称为部分选中。 W3C Web Accessibility Initiative, n.d., "Checkbox"
              1.4 Radio Group
              单选组              		 "A radio group is a set of checkable buttons, known as radio buttons, where no more than one of the buttons can be checked at a time." 单选组是一组可勾选的按钮，称为单选按钮，同一时间最多只能有一个按钮被选中。 W3C Web Accessibility Initiative, n.d., "Radio Group"
              1.5 Switch
              开关              		 "A switch is an input widget that allows users to choose one of two values: on or off." 开关是一种输入控件，让用户在开或关两个值中选择一个。 W3C Web Accessibility Initiative, n.d., "Switch"
              1.6 Slider
              滑块              		 "A slider is an input where the user selects a value from within a given range." 滑块是一种输入，用户在其中从给定范围内选择一个值。 W3C Web Accessibility Initiative, n.d., "Slider"
              1.7 Slider (Multi-Thumb)
              多手柄滑块              		 "A multi-thumb slider implements the Slider Pattern but includes two or more thumbs, often on a single rail." 多手柄滑块实现了滑块模式，但包含两个或更多手柄，它们通常在同一条轨道上。 W3C Web Accessibility Initiative, n.d., "Slider (Multi-Thumb)"
              1.8 Spinbutton
              数值调节按钮              		 "A spinbutton is an input widget that restricts its value to a set or range of discrete values." 数值调节按钮是一种输入控件，它把值限制在一组或一个范围的离散值之内。 W3C Web Accessibility Initiative, n.d., "Spinbutton"
              1.9 Meter
              计量器              		 "A meter is a graphical display of a numeric value that varies within a defined range." 计量器是一种图形化显示，展示一个在规定范围内变化的数值。 W3C Web Accessibility Initiative, n.d., "Meter"
              1.10 Listbox
              列表框              		 "A listbox widget presents a list of options and allows a user to select one or more of them." 列表框控件呈现一个选项列表，并允许用户选择其中一个或多个。 W3C Web Accessibility Initiative, n.d., "Listbox"
              1.11 Combobox
              组合框              		 "A combobox is an input widget that has an associated popup." 组合框是一种输入控件，带有一个关联的弹出层。 W3C Web Accessibility Initiative, n.d., "Combobox"
              1.12 Disclosure (Show/Hide)
              展开收起（显示/隐藏）              		 "A disclosure is a widget that enables content to be either collapsed (hidden) or expanded (visible)." 展开收起控件让内容可以被折叠（隐藏）或展开（可见）。 W3C Web Accessibility Initiative, n.d., "Disclosure (Show/Hide)"
              1.13 Accordion (Sections With Show/Hide Functionality)
              手风琴（带显示/隐藏功能的区块）              		 "An accordion is a vertically stacked set of interactive headings that each contain a title, content snippet, or thumbnail representing a section of content." 手风琴是垂直堆叠的一组交互式标题，每个标题包含代表一段内容的标题文字、内容片段或缩略图。 W3C Web Accessibility Initiative, n.d., "Accordion (Sections With Show/Hide Functionality)"
              1.14 Tabs
              选项卡              		 "Tabs are a set of layered sections of content, known as tab panels, that display one panel of content at a time." 选项卡是一组分层的内容区块，称为选项卡面板，一次只显示一个面板的内容。 W3C Web Accessibility Initiative, n.d., "Tabs"
              1.15 Carousel (Slide Show or Image Rotator)
              轮播（幻灯片放映或图片轮换）              		 "A carousel presents a set of items, referred to as slides, by sequentially displaying a subset of one or more slides." 轮播呈现一组称为幻灯片的项目，方式是依次显示其中一张或多张。 W3C Web Accessibility Initiative, n.d., "Carousel (Slide Show or Image Rotator)"
              1.16 Feed
              信息流              		 "A feed is a section of a page that automatically loads new sections of content as the user scrolls." 信息流是页面中的一个区域，它会自动加载新的内容区块，时机是用户滚动时。 W3C Web Accessibility Initiative, n.d., "Feed"
              1.17 Menu Button
              菜单按钮              		 "A menu button is a button that opens a menu as described in the Menu and Menubar Pattern." 菜单按钮是一个打开菜单的按钮，菜单的行为见菜单与菜单栏模式。 W3C Web Accessibility Initiative, n.d., "Menu Button"
              1.18 Menu and Menubar
              菜单与菜单栏              		 "A menu is a widget that offers a list of choices to the user, such as a set of actions or functions." 菜单是一种控件，向用户提供一个选项列表，例如一组操作或功能。 W3C Web Accessibility Initiative, n.d., "Menu and Menubar"
              1.19 Toolbar
              工具栏              		 "A toolbar is a container for grouping a set of controls, such as buttons, menubuttons, or checkboxes." 工具栏是一个用于组合一组控件的容器，例如按钮、菜单按钮或复选框。 W3C Web Accessibility Initiative, n.d., "Toolbar"
              1.20 Alert
              警报              		 "An alert is an element that displays a brief, important message in a way that attracts the user's attention without interrupting the user's task." 警报是一种元素，它以吸引用户注意的方式显示一条简短而重要的消息，同时不打断用户的任务。 W3C Web Accessibility Initiative, n.d., "Alert"
              1.21 Alert and Message Dialogs
              警报与消息对话框              		 "An alert dialog is a modal dialog that interrupts the user's workflow to communicate an important message and acquire a response." 警报对话框是一种模态对话框，它打断用户的工作流程，以传达重要消息并获取回应。 W3C Web Accessibility Initiative, n.d., "Alert and Message Dialogs"
              1.22 Dialog (Modal)
              对话框（模态）              		 "A dialog is a window overlaid on either the primary window or another dialog window." 对话框是一个覆盖在上层的窗口，它下面是主窗口或另一个对话框窗口。 W3C Web Accessibility Initiative, n.d., "Dialog (Modal)"
              1.23 Tooltip
              工具提示              		 "A tooltip is a popup that displays information related to an element when the element receives keyboard focus or the mouse hovers over it." 工具提示是一种弹出层，当某个元素获得键盘焦点或鼠标悬停在其上时，显示与该元素相关的信息。 W3C Web Accessibility Initiative, n.d., "Tooltip"
              1.24 Breadcrumb
              面包屑导航              		 "A breadcrumb trail consists of a list of links to the parent pages of the current page in hierarchical order." 面包屑导航由一个链接列表组成，按层级顺序指向当前页面的各级父页面。 W3C Web Accessibility Initiative, n.d., "Breadcrumb"
              1.25 Landmarks
              地标              		 "Landmarks are a set of eight roles that identify the major sections of a page." 地标是一组八个角色，用来标识页面的主要区域。 W3C Web Accessibility Initiative, n.d., "Landmarks"
              1.26 Window Splitter
              窗口分隔条              		 "A window splitter is a moveable separator between two sections, or panes, of a window that enables users to change the relative size of the panes." 窗口分隔条是窗口两个区域（窗格）之间的可移动分隔条，让用户能够改变窗格的相对大小。 W3C Web Accessibility Initiative, n.d., "Window Splitter"
              1.27 Table
              表格              		 "Like an HTML table element, a WAI-ARIA table is a static tabular structure containing one or more rows that each contain one or more cells; it is not an interactive widget." 与 HTML table 元素一样，WAI-ARIA 表格是一种静态的表格结构，包含一行或多行，每行包含一个或多个单元格；它不是交互式控件。 W3C Web Accessibility Initiative, n.d., "Table"
              1.28 Grid (Interactive Tabular Data and Layout Containers)
              网格（交互式表格数据与布局容器）              		 "A grid widget is a container that enables users to navigate the information or interactive elements it contains using directional navigation keys, such as arrow keys, Home, and End." 网格控件是一个容器，让用户能够浏览其中的信息或交互元素，方式是使用方向导航键，例如方向键、Home 和 End。 W3C Web Accessibility Initiative, n.d., "Grid (Interactive Tabular Data and Layout Containers)"
              1.29 Tree View
              树视图              		 "A tree view widget presents a hierarchical list." 树视图控件呈现一个分层列表。 W3C Web Accessibility Initiative, n.d., "Tree View"
              1.30 Treegrid
              树形网格              		 "A treegrid widget presents a hierarchical data grid consisting of tabular information that is editable or interactive." 树形网格控件呈现一个分层的数据网格，由可编辑或可交互的表格信息组成。 W3C Web Accessibility Initiative, n.d., "Treegrid"
