              1.13 Accordion (Sections With Show/Hide Functionality)
              手风琴（带显示/隐藏功能的区块）              		 "An accordion is a vertically stacked set of interactive headings that each contain a title, content snippet, or thumbnail representing a section of content. The headings function as controls that enable users to reveal or hide their associated sections of content." 手风琴是垂直堆叠的一组交互式标题，每个标题包含代表一段内容的标题文字、内容片段或缩略图。这些标题充当控件，让用户显示或隐藏与之关联的内容区块。 W3C Web Accessibility Initiative, n.d., "About This Pattern"
              Accordion Header
              手风琴标题              		 "Label for or thumbnail representing a section of content that also serves as a control for showing, and in some implementations, hiding the section of content." 代表一段内容的标签或缩略图，它同时充当显示该内容的控件，在某些实现中也用来隐藏该内容。 W3C Web Accessibility Initiative, n.d., "About This Pattern"
              Accordion Panel
              手风琴面板              		 "Section of content associated with an accordion header." 内容区块，与某个手风琴标题相关联。 W3C Web Accessibility Initiative, n.d., "About This Pattern"
              Enter or Space
              Enter 或空格              		 "When focus is on the accordion header for a collapsed panel, expands the associated panel. If the implementation allows only one panel to be expanded, and if another panel is expanded, collapses that panel. When focus is on the accordion header for an expanded panel, collapses the panel if the implementation supports collapsing." 当焦点位于某个已折叠面板的手风琴标题上时，展开关联的面板。如果实现只允许展开一个面板，而另一个面板已展开，则折叠那个面板。当焦点位于已展开面板的手风琴标题上时，如果实现支持折叠，则折叠该面板。 W3C Web Accessibility Initiative, n.d., "Keyboard Interaction"
              Tab
              Tab 键              		 "Moves focus to the next focusable element; all focusable elements in the accordion are included in the page Tab sequence." 把焦点移到下一个可聚焦元素；手风琴中所有可聚焦元素都包含在页面的 Tab 顺序中。 W3C Web Accessibility Initiative, n.d., "Keyboard Interaction"
              Shift + Tab
              Shift + Tab 键              		 "Moves focus to the previous focusable element; all focusable elements in the accordion are included in the page Tab sequence." 把焦点移到上一个可聚焦元素；手风琴中所有可聚焦元素都包含在页面的 Tab 顺序中。 W3C Web Accessibility Initiative, n.d., "Keyboard Interaction"
              button
              按钮角色              		 "The title of each accordion header is contained in an element with role button." 每个手风琴标题的标题文字包含在一个角色为 button 的元素中。 W3C Web Accessibility Initiative, n.d., "WAI-ARIA Roles, States, and Properties"
              heading
              标题角色              		 "Each accordion header button is wrapped in an element with role heading that has a value set for aria-level that is appropriate for the information architecture of the page. The button element is the only element inside the heading element." 每个手风琴标题按钮都被包在一个角色为 heading 的元素中，该元素的 aria-level 值要与页面的信息架构相符。button 元素是 heading 元素内唯一的元素。 W3C Web Accessibility Initiative, n.d., "WAI-ARIA Roles, States, and Properties"
              aria-level
              标题层级              		 "If the native host language has an element with an implicit heading and aria-level, such as an HTML heading tag, a native host language element may be used." 如果原生宿主语言有一个隐含 heading 角色和 aria-level 的元素，例如 HTML 标题标签，可以使用该原生宿主语言元素。 W3C Web Accessibility Initiative, n.d., "WAI-ARIA Roles, States, and Properties"
              aria-expanded
              展开状态              		 "If the accordion panel associated with an accordion header is visible, the header button element has aria-expanded set to true. If the panel is not visible, aria-expanded is set to false." 如果与手风琴标题关联的面板可见，标题按钮元素的 aria-expanded 设为 true。如果面板不可见，aria-expanded 设为 false。 W3C Web Accessibility Initiative, n.d., "WAI-ARIA Roles, States, and Properties"
              aria-controls
              控制对象              		 "The accordion header button element has aria-controls set to the ID of the element containing the accordion panel content." 手风琴标题按钮元素的 aria-controls 设为某个 ID，这个 ID 属于包含手风琴面板内容的元素。 W3C Web Accessibility Initiative, n.d., "WAI-ARIA Roles, States, and Properties"
              aria-disabled
              禁用状态              		 "If the accordion panel associated with an accordion header is visible, and if the accordion does not permit the panel to be collapsed, the header button element has aria-disabled set to true." 如果与手风琴标题关联的面板可见，并且手风琴不允许折叠该面板，标题按钮元素的 aria-disabled 设为 true。 W3C Web Accessibility Initiative, n.d., "WAI-ARIA Roles, States, and Properties"
              region
              区域角色              		 "Optionally, each element that serves as a container for panel content has role region and aria-labelledby with a value that refers to the button that controls display of the panel." 可选地，每个充当面板内容容器的元素具有 region 角色，并带有 aria-labelledby，其值指向控制该面板显示的按钮。 W3C Web Accessibility Initiative, n.d., "WAI-ARIA Roles, States, and Properties"
