| **Homoscedasticity**<br>同方差性 | "In linear regression, the assumption that **the variance around the regression line is the same for all values of the predictor variable**." | 在线性回归中，指**回归线周围的方差对预测变量的所有取值都相同**的假设。 | [Online Statistics Education, n.d., glossary](https://onlinestatbook.com/2/glossary/homoscedasticity.html) |
| **14.5 Influential Observations**<br>强影响观测 | (No definition) | （无定义） | [Online Statistics Education, n.d., section 14.5](https://onlinestatbook.com/2/regression/influential.html) |
| **Cook's D**<br>库克距离 | "**Cook's D** is a measure of the influence of an observation in regression and is proportional to the sum of the squared differences between predictions made with all observations in the analysis and predictions made leaving out the observation in question." | **库克距离 D** 是衡量回归中某个观测的影响的指标，它与分析中使用全部观测所作预测和剔除所讨论观测后所作预测之间的平方差之和成正比。 | [Online Statistics Education, n.d., glossary](https://onlinestatbook.com/2/glossary/cooks_d.html) |
| **Influence**<br>影响 | "**Influence** refers to the degree to which a single observation in regression influences the estimation of the regression parameters. It is often measured in terms how much the predicted scores for other observations would differ if the observation in question were not included." | **影响**指回归中单个观测对回归参数估计的影响程度。它通常用如果不包含所讨论的观测，其他观测的预测得分会有多大差异来衡量。 | [Online Statistics Education, n.d., glossary](https://onlinestatbook.com/2/glossary/influence.html) |
| **Leverage**<br>杠杆值 | "**Leverage** is a factor affecting the influence of an observation in regression. Leverage is based on how much the observation's value on the predictor variable differs from the mean of the predictor variable. The greater an observation's leverage, the more potential it has to be an influential observation." | **杠杆值**是影响回归中某个观测值影响力的一个因素。杠杆值取决于该观测值在预测变量上的取值与预测变量均值的差异有多大。观测值的杠杆值越大，它成为强影响观测值的可能性就越大。 | [Online Statistics Education, n.d., glossary](https://onlinestatbook.com/2/glossary/leverage.html) |

| **Beta Weight**<br>贝塔权重 | "A **standardized regression coefficient**." | **标准化回归系数**。 | [Online Statistics Education, n.d., glossary](https://onlinestatbook.com/2/glossary/beta_weight.html) |
| **Criterion Variable**<br>效标变量 | "In regression analysis (such as linear regression) the **criterion variable** is the variable being predicted. In general, the criterion variable is the dependent variable." | 在回归分析（如线性回归）中，**效标变量**是被预测的变量。一般而言，效标变量就是因变量。 | [Online Statistics Education, n.d., glossary](https://onlinestatbook.com/2/glossary/criterion_variable.html) |
| **Multiple Regression**<br>多元回归 | "**Multiple regression** is linear regression in which **two or more predictor variables** are used to predict the criterion." | **多元回归**是使用**两个或多个预测变量**来预测效标的线性回归。 | [Online Statistics Education, n.d., glossary](https://onlinestatbook.com/2/glossary/multiple_regression.html) |
| **Partial Slope**<br>偏斜率 | "The **partial slope** in multiple regression is the slope of the relationship between a predictor variable that is independent of the other predictor variables and the criterion. It is also the regression coefficient for the predictor variable in question." | 多元回归中的**偏斜率**是某个与其他预测变量无关的预测变量同效标之间关系的斜率。它也是所讨论预测变量的回归系数。 | [Online Statistics Education, n.d., glossary](https://onlinestatbook.com/2/glossary/partial_slope.html) |
| **Predictor**<br>预测变量 | "A **predictor variable** is a **variable used in regression to predict another variable**. | **Regression Coefficient**<br>回归系数 | "A **regression coefficient** is the **slope of the regression line in simple regression or the partial slope in multiple regression**." | **回归系数**是**简单回归中回归线的斜率或多元回归中的偏斜率**。 | [Online Statistics Education, n.d., glossary](https://onlinestatbook.com/2/glossary/regression_coefficient.html) |
| **Simple Regression**<br>简单回归 | "**Simple regression** is **linear regression in which one more predictor variable is used to predict the criterion**." | **简单回归**是**使用一个以上预测变量来预测效标的线性回归**。 | [Online Statistics Education, n.d., glossary](https://onlinestatbook.com/2/glossary/simple_regression.html) |
| **Slope**<br>斜率 | "The **slope** of a line is the change in $Y$ for each change of one unit of $X$. It is sometimes defined as "rise over run" which is the same thing.
