# 3. Statistics: term checklist

Not built (README). Source: Çetinkaya-Rundel and Hardin, *Introduction to Modern Statistics* (2e, openintro-ims.netlify.app, version of March 31, 2026; the chapter pages cached 2026-10-28 in `design-refs/official-docs/cache/data/ims-raw/`). The terms are the book's own: every chapter ends with a table "Terms introduced in this chapter", which says each term is bolded where the text introduces it. The six Applications chapters (3, 6, 10, 15, 23, 27) have no such table, so they have no page. Each term's definition is the sentence where it is bolded (or the closest sentence where the book never defines it, noted below); every quote was checked to be a contiguous part of the chapter text. Terms introduced before a chapter's first section are in a group named after the chapter.
