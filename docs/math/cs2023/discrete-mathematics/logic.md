# 1.6 Logic

Tier: CS Core.

## Classification

![Logic: its 6 terms in one column, in the order CS2023 names them: Truth table, Connective (operator), Inference rule, Formula, Normal form, Predicate logic.](media/logic.png)

## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **Truth table**<br>真值表 | "A truth table is a **two-dimensional array** with n+1 columns. The first n columns correspond to the possible values of n inputs, and the last column to the operation being performed. The rows list **all possible combinations of inputs** together with the corresponding outputs." | 真值表是一个有 n+1 列的**二维数组**。前 n 列对应 n 个输入的可能取值，最后一列对应所执行的运算。各行列出**所有可能的输入组合**以及对应的输出。 | [Weisstein, n.d.-f, "Truth table" entry, para. 1](https://mathworld.wolfram.com/TruthTable.html#:~:text=A%20truth%20table%20is%20a%20two%2Ddimensional%20array) |
| **Connective (operator)**<br>联结词（运算符） | "A function, or the symbol representing a function, which corresponds to English conjunctions such as 'and,' 'or,' 'not,' etc. that **takes one or more truth values as input** and **returns a single truth value as output**." | 一种函数（或表示该函数的符号），对应英语中的 and、or、not 等连词，它**以一个或多个真值为输入**，并**输出单个真值**。 | [Weisstein, n.d.-a, "Connective" entry, para. 1](https://mathworld.wolfram.com/Connective.html#:~:text=takes%20one%20or%20more%20truth%20values%20as%20input) |
| **Inference rule**<br>推理规则 | "A syllogism, also known as a rule of inference, is a **formal logical scheme** used to **draw a conclusion from a set of premises**." | 三段论也称为推理规则，是一种**形式逻辑格式**，用于**从一组前提得出结论**。 | [Weisstein, n.d.-e, "Syllogism" entry, para. 1](https://mathworld.wolfram.com/Syllogism.html#:~:text=also%20known%20as%20a%20rule%20of%20inference) |
| **Formula**<br>公式 | "The term 'formula' is also commonly used in the theory of logic to mean **sentential formula** (also called a propositional formula), i.e., **a formula in propositional calculus**." | “公式”一词在逻辑理论中也常用来指**语句公式**（也称为命题公式），即**命题演算中的公式**。 | [Weisstein, n.d.-b, "Formula" entry, para. 2](https://mathworld.wolfram.com/Formula.html#:~:text=is%20also%20commonly%20used%20in%20the%20theory%20of%20logic) |
| **Normal form**<br>范式 | "In general, it refers to a **way of representing objects** so that, although each may have many different names, **every possible name corresponds to exactly one object** ..." | 一般来说，它指一种**表示对象的方式**，使得尽管每个对象可能有许多不同的名称，**每个可能的名称都恰好对应一个对象**…… | [Weisstein, n.d.-c, "Normal form" entry, para. 1](https://mathworld.wolfram.com/NormalForm.html#:~:text=it%20refers%20to%20a%20way%20of%20representing%20objects) |
| **Predicate logic**<br>谓词逻辑 | "Predicate calculus, also called predicate logic or functional calculus, is the **branch of formal logic** that deals with **representing the logical connections between statements** as well as the statements themselves." | 谓词演算也称为谓词逻辑或函数演算，是**形式逻辑的一个分支**，研究**表示陈述之间的逻辑联系**以及陈述本身。 | [Weisstein, n.d.-d, "Predicate calculus" entry, para. 1](https://mathworld.wolfram.com/PredicateCalculus.html#:~:text=also%20called%20predicate%20logic) |
