## Classification

![Discrete random variables and distributions: its 2 terms in one column, in the order CS2023 names them: Discrete random variable, Discrete distribution.](media/discrete-random-variables-and-distributions.png)

## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **Discrete random variable**<br>离散随机变量 | (context) "A random variable is a **measurable function from a probability space** ... into **a measurable space** ... known as the state space ..." | （语境）随机变量是**从概率空间到可测空间的可测函数**……后者称为**状态空间**…… | [Weisstein, n.d.-b, "Random variable" entry, para. 1](https://mathworld.wolfram.com/RandomVariable.html#:~:text=A%20random%20variable%20is%20a%20measurable%20function) |
| **Discrete distribution**<br>离散分布 | "A discrete distribution is a statistical distribution whose random variable takes values in a **countable set** almost surely." | 离散分布是一种统计分布，它的随机变量几乎必然在一个**可数集合**中取值。 | [Weisstein, n.d.-a, "Discrete distribution" entry, para. 1](https://mathworld.wolfram.com/DiscreteDistribution.html#:~:text=A%20discrete%20distribution%20is%20a%20statistical%20distribution) |
