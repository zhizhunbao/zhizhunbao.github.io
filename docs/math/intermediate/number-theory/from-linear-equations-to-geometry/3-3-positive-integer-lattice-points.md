| **3.3 Positive Integer Lattice Points**<br>正整数格点 | "Assume there exists a solution (hence infinitely many) to $ax+by=c$. | **Greatest Integer Function**<br>最大整数函数 | "The ***greatest integer function*** (also called the ***floor*** function) is **the function which takes a real number $x$ and returns the largest integer below it (or equal to it)**. We notate it $\lfloor x\rfloor$." | ***最大整数函数***（也称***下取整***函数）是**把实数 $x$ 映到不超过它的最大整数的函数**。记作 $\lfloor x\rfloor$。 | [Crisman, 2024, Definition 3.3.3](https://math.gordon.edu/ntic/ntic/section-positive-lattice.html#definition-greatest-integer) |
