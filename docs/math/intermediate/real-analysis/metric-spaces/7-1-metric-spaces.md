| **Metric Space**<br>度量空间 | "Let $X$ be a set, and let $d \colon X \times X \to \mathbb{R}$ be a function such that for all $x,y,z \in X$ $d(x,y) \geq 0$. (nonnegativity) $d(x,y) = 0$ if and only if $x = y$. (identity of indiscernibles) $d(x,y) = d(y,x)$. (symmetry) $d(x,z) \leq d(x,y)+ d(y,z)$. (triangle inequality) **The pair $(X,d)$** is called a **metric space**." | 设 $X$ 是集合，$d \colon X \times X \to \mathbb{R}$ 是函数，使得对所有 $x,y,z \in X$：$d(x,y) \geq 0$（非负性）；$d(x,y) = 0$ 当且仅当 $x = y$（不可分辨者的同一性）；$d(x,y) = d(y,x)$（对称性）；$d(x,z) \leq d(x,y)+ d(y,z)$（三角不等式）。**二元组 $(X,d)$** 称为**度量空间**。 | [Lebl, 2026, Definition 7.1.1](https://www.jirka.org/ra/html/sec_metric.html#sec_metric-6) |

| **Cauchy–Schwarz Inequality**<br>柯西–施瓦茨不等式 | "Suppose $x =(x_1,x_2,\ldots,x_n) \in \mathbb{R}^n$, $y =(y_1,y_2,\ldots,y_n) \in \mathbb{R}^n$. Then **${\biggl( \sum_{k=1}^n x_k y_k \biggr)}^2 \leq \biggl(\sum_{k=1}^n x_k^2 \biggr) \biggl(\sum_{k=1}^n y_k^2 \biggr)$**." | 设 $x =(x_1,x_2,\ldots,x_n) \in \mathbb{R}^n$，$y =(y_1,y_2,\ldots,y_n) \in \mathbb{R}^n$，则 **${\biggl( \sum_{k=1}^n x_k y_k \biggr)}^2 \leq \biggl(\sum_{k=1}^n x_k^2 \biggr) \biggl(\sum_{k=1}^n y_k^2 \biggr)$**。 | [Lebl, 2026, Lemma 7.1.4](https://www.jirka.org/ra/html/sec_metric.html#sec_metric-16) |
| **Standard Metric on ℝⁿ**<br>ℝⁿ 上的标准度量 | "Let us construct the **standard metric for $\mathbb{R}^n$**. | **Complex Conjugate**<br>共轭复数 | "Furthermore, when working with complex numbers it is often convenient to write the metric in terms of the **complex conjugate**: The conjugate of $z=x+iy$ is **$\bar{z} := x-iy$**." | 此外，处理复数时，常常用**共轭复数**来写度量较为方便：$z=x+iy$ 的共轭是 **$\bar{z} := x-iy$**。 | [Lebl, 2026, Example 7.1.6](https://www.jirka.org/ra/html/sec_metric.html#sec_metric-19) |
| **Discrete Metric**<br>离散度量 | "An example to keep in mind is the **discrete metric**. For any set $X$, define **$d(x,y) := \begin{cases} 1 & \text{if } x \neq y, \\ 0 & \text{if } x = y. \end{cases}$** That is, all points are equally distant from each other." | 值得记住的一个例子是**离散度量**。对任意集合 $X$，定义 **$d(x,y) := \begin{cases} 1 & \text{if } x \neq y, \\ 0 & \text{if } x = y. \end{cases}$** 也就是说，所有点彼此等距。 | [Lebl, 2026, Example 7.1.7](https://www.jirka.org/ra/html/sec_metric.html#sec_metric-20) |
| **Unit Sphere**<br>单位球面 | "Let $S^2$ be the **unit sphere** in $\mathbb{R}^3$, that is **$S^2 := \{ x \in \mathbb{R}^3 : x_1^2+x_2^2+x_3^2 = 1 \}$**." | 设 $S^2$ 是 $\mathbb{R}^3$ 中的**单位球面**，即 **$S^2 := \{ x \in \mathbb{R}^3 : x_1^2+x_2^2+x_3^2 = 1 \}$**。 | [Lebl, 2026, Example 7.1.9](https://www.jirka.org/ra/html/sec_metric.html#sec_metric-22) |
| **Great Circle Distance**<br>大圆距离 | "Another useful example of a metric space is the sphere with a metric usually called the **great circle distance**. Take $x$ and $y$ in $S^2$, draw a line through the origin and $x$, and another line through the origin and $y$, and let $\theta$ be **the angle that the two lines make**. Then define **$d(x,y) := \theta$**." | 度量空间的另一个有用例子是球面，配以通常称为**大圆距离**的度量。在 $S^2$ 中取 $x$ 与 $y$，作过原点和 $x$ 的直线，再作过原点和 $y$ 的直线，令 $\theta$ 为**两直线所成的角**，然后定义 **$d(x,y) := \theta$**。 | [Lebl, 2026, Example 7.1.9](https://www.jirka.org/ra/html/sec_metric.html#sec_metric-22) |
| **Subspace**<br>子空间 | "If $(X,d)$ is a metric space, **$Y \subset X$, and $d' := d|_{Y \times Y}$**, then $(Y,d')$ is said to be a **subspace** of $(X,d)$." | 若 $(X,d)$ 是度量空间，**$Y \subset X$，且 $d' := d|_{Y \times Y}$**，则称 $(Y,d')$ 是 $(X,d)$ 的**子空间**。 | [Lebl, 2026, Definition 7.1.11](https://www.jirka.org/ra/html/sec_metric.html#sec_metric-25) |
| **Subspace Metric**<br>子空间度量 | "It is common to simply write $d$ for the metric on $Y$, as it is **the restriction of the metric on $X$**. | **Subspace Topology**<br>子空间拓扑 | "Sometimes we say $d'$ is the subspace metric and **$Y$** has the **subspace topology**." | 有时说 $d'$ 是子空间度量，**$Y$** 具有**子空间拓扑**。 | [Lebl, 2026, section 7.1](https://www.jirka.org/ra/html/sec_metric.html#sec_metric-26) |
| **Diameter**<br>直径 | "**$\operatorname{diam}(S) := \sup \bigl\{ d(x,y) : x,y \in S \bigr\} < \infty$**. | **Hausdorff Metric**<br>豪斯多夫度量 | "Let $(X,d)$ be a metric space.
