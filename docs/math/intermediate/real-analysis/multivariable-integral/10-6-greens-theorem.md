| **Green’s Theorem**<br>格林定理 | "Suppose $U \subset \mathbb{R}^2$ is a bounded domain with piecewise smooth boundary with the boundary positively oriented. Suppose $P$ and $Q$ are continuously differentiable functions defined on some open set that contains the closure $\overline{U}$. Then **$\int_{\partial U} P \, dx + Q\, dy = \int_{U} \left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} \right)$**." | 设 $U \subset \mathbb{R}^2$ 是具有分段光滑边界、边界为正定向的有界区域，$P$ 与 $Q$ 是定义在某个包含闭包 $\overline{U}$ 的开集上的连续可微函数，则 **$\int_{\partial U} P \, dx + Q\, dy = \int_{U} \left(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y} \right)$**。 | [Lebl, 2026, Theorem 10.6.4](https://www.jirka.org/ra/html/sec_mvgreenstheorem.html#sec_mvgreenstheorem-13) |
| **Type I Domain**<br>I 型区域 | "Let $U \subset \mathbb{R}^2$ be a bounded domain with piecewise smooth boundary. We say $U$ is of **type I** if **there exist numbers $a < b$, and continuous functions $f \colon [a,b] \to \mathbb{R}$ and $g \colon [a,b] \to \mathbb{R}$, such that $U := \bigl\{ (x,y) \in \mathbb{R}^2 : a < x < b \text{ and } f(x) < y < g(x) \bigr\}$**." | 设 $U \subset \mathbb{R}^2$ 是具有分段光滑边界的有界区域。若**存在数 $a < b$ 和连续函数 $f \colon [a,b] \to \mathbb{R}$、$g \colon [a,b] \to \mathbb{R}$，使得 $U := \bigl\{ (x,y) \in \mathbb{R}^2 : a < x < b \text{ and } f(x) < y < g(x) \bigr\}$**，则称 $U$ 是 **I 型**的。 | [Lebl, 2026, section 10.6](https://www.jirka.org/ra/html/sec_mvgreenstheorem.html#sec_mvgreenstheorem-15) |
| **Type II Domain**<br>II 型区域 | "Similarly, $U$ is of **type II** if **there exist numbers $c < d$, and continuous functions $h \colon [c,d] \to \mathbb{R}$ and $k \colon [c,d] \to \mathbb{R}$, such that $U := \bigl\{ (x,y) \in \mathbb{R}^2 : c < y < d \text{ and } h(y) < x < k(y) \bigr\}$**." | 类似地，若**存在数 $c < d$ 和连续函数 $h \colon [c,d] \to \mathbb{R}$、$k \colon [c,d] \to \mathbb{R}$，使得 $U := \bigl\{ (x,y) \in \mathbb{R}^2 : c < y < d \text{ and } h(y) < x < k(y) \bigr\}$**，则称 $U$ 是 **II 型**的。 | [Lebl, 2026, section 10.6](https://www.jirka.org/ra/html/sec_mvgreenstheorem.html#sec_mvgreenstheorem-15) |
| **Type III Domain**<br>III 型区域 | "Finally, $U \subset \mathbb{R}^2$ is of **type III** if **it is both of type I and type II**." | 最后，若 $U \subset \mathbb{R}^2$ **既是 I 型又是 II 型**，则称它是 **III 型**的。 | [Lebl, 2026, section 10.6](https://www.jirka.org/ra/html/sec_mvgreenstheorem.html#sec_mvgreenstheorem-15) |
| **Vortex Vector Field**<br>涡旋向量场 | "Suppose $P(x,y) = \frac{-y}{x^2+y^2}$, $Q(x,y) = \frac{x}{x^2+y^2}$. If we think of $(P,Q)$ as a vector, so that we have a vector field, $(P,Q)$ is called the **vortex vector field**, as it **gives the velocity of particles traveling in a vortex around the origin**." | 设 $P(x,y) = \frac{-y}{x^2+y^2}$，$Q(x,y) = \frac{x}{x^2+y^2}$。把 $(P,Q)$ 看作向量，就得到一个向量场；$(P,Q)$ 称为**涡旋向量场**，因为它**给出绕原点涡旋运动的粒子的速度**。 | [Lebl, 2026, Example 10.6.5](https://www.jirka.org/ra/html/sec_mvgreenstheorem.html#sec_mvgreenstheorem-22) |
| **Laplace Equation**<br>拉普拉斯方程 | "Suppose $U \subset \mathbb{R}^2$ is open and $f \colon U \to \mathbb{R}$ is harmonic, that is, $f$ is twice continuously differentiable and satisfies the **Laplace equation**, **$\frac{\partial^2 f}{\partial x^2} + \frac{\partial^2 f}{\partial y^2} = 0$**." | 设 $U \subset \mathbb{R}^2$ 是开集，$f \colon U \to \mathbb{R}$ 是调和函数，即 $f$ 二次连续可微且满足**拉普拉斯方程** **$\frac{\partial^2 f}{\partial x^2} + \frac{\partial^2 f}{\partial y^2} = 0$**。 | [Lebl, 2026, Example 10.6.6](https://www.jirka.org/ra/html/sec_mvgreenstheorem.html#sec_mvgreenstheorem-24) |
