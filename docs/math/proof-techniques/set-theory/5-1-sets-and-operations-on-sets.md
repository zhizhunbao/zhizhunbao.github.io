| **Complement of a Set**<br>集合的补集 | "The complement of the set $A\text{,}$ written $A^c$ and read “the complement of $A\text{,}$” is **the set of all elements of** $U$ **that are not in** $A\text{.}$" | 集合 $A$ 的补集，记作 $A^c$，读作“$A$ 的补集”，是**全集** $U$ **中不属于** $A$ 的所有元素组成的集合。 | [Sundstrom, 2022, section 5.1](https://gvsuoer.github.io/sundstrom-textbook/S_setoperations.html#setdiff) |
