# 8. Software Requirements Tools

## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **Software Requirements Tools**<br>软件需求工具 | "Tools that help software engineers deal with software requirements fall broadly into three categories: **requirements management tools**, **requirements modeling tools** and **functional test case generation tools**, as discussed below." | 帮助软件工程师处理软件需求的工具大致分为三类：**需求管理工具**、**需求建模工具**和**功能测试用例生成工具**，下文分别讨论。 | [Washizaki, 2026, Chapter 1, section 8, para. 1, p. 1-20](https://www.computer.org/education/bodies-of-knowledge/software-engineering/v4) |
| **Requirements Management Tools**<br>需求管理工具 | "**Requirements management tools** support various activities, including **storing requirements attributes, tracing, document generation and change control**." | **需求管理工具**支持多种活动，包括**存储需求属性、追踪、生成文档和变更控制**。 | [Washizaki, 2026, Chapter 1, section 8.1, para. 1, p. 1-20](https://www.computer.org/education/bodies-of-knowledge/software-engineering/v4) |
| **Requirements Modeling Tools**<br>需求建模工具 | "At a minimum, a **requirements modeling tool** supports **visually creating, modifying and publishing model-based requirements specifications**." | **需求建模工具**至少支持**以可视化方式创建、修改和发布基于模型的需求规格说明**。 | [Washizaki, 2026, Chapter 1, section 8.2, para. 1, p. 1-20](https://www.computer.org/education/bodies-of-knowledge/software-engineering/v4) |
| **Functional Test Case Generation Tools**<br>功能测试用例生成工具 | "The more formally defined a requirements specification language is, the more likely it is that **functional test cases** can be at least **partially derived mechanically**." | 需求规格说明语言定义得越形式化，**功能测试用例**就越有可能至少**部分地被机械推导出来**。 | [Washizaki, 2026, Chapter 1, section 8.3, para. 1, p. 1-20](https://www.computer.org/education/bodies-of-knowledge/software-engineering/v4) |
