# Dictionary of Algorithms and Data Structures

Planned, no content yet. The pages under this one take two of the types of the NIST Dictionary of Algorithms and Data Structures (DADS), data structures and then algorithms, and under each the DADS areas that have entries of that type, in the order of its index by area. Each area page lists those entries with links to their definitions. The dictionary is the reference for definitions, quoted with an APA reference when a topic of the CS2023 knowledge units is written. The other types (38 algorithmic techniques, 79 classic problems, 636 definitions) are not listed, nor are entries with no area. The source leaves out algorithms specific to business data processing, communications, operating systems or distributed algorithms, programming languages, AI, graphics, and numerical analysis.
