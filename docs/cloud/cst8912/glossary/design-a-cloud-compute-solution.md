# Design a cloud compute solution

Terms from week 2 of CST8912 Cloud Solution Architecture (Algonquin College, Fall 2026), grouped under the Microsoft Learn modules and documentation sets they belong to. Each definition is quoted from official documentation, mostly Microsoft Learn, and each citation names the section and paragraph and links to that passage. Where no official definition exists, the definition is my own.

## 1. Describe the core architectural components of Azure

### 1.1 Resources, resource groups and regions

| Term | Definition | 中文解释 | Source |
|---|---|---|---|
| **resource** (资源) | "A manageable item that's available through Azure. Examples of resources include virtual machines, storage accounts, web apps, databases, and virtual networks." | 资源是你在 Azure 里建出来、能单独管理的每一样东西，比如一台虚拟机、一块磁盘、一个虚拟网络、一个公共 IP 或一个 Log Analytics 工作区。 | [Microsoft, n.d., "Terminology" section, bullet 1](https://learn.microsoft.com/en-us/azure/azure-resource-manager/management/overview#terminology:~:text=A%20manageable%20item%20that%27s%20available%20through%20Azure.%20Examples) |
| **resource group** (资源组) | "A container that holds related resources for an Azure solution. The resource group includes those resources that you want to manage as a group." | 资源组是装相关资源的「文件夹」：同一个项目的资源放在一起，可以一起管理、一起删除。比如做完一个实验，删掉整个资源组就能把里面的资源一次清理干净。 | [Microsoft, n.d., "Terminology" section, bullet 2](https://learn.microsoft.com/en-us/azure/azure-resource-manager/management/overview#terminology:~:text=A%20container%20that%20holds%20related%20resources%20for%20an) |
| **region** (区域) | "Each region is a set of physical facilities that include datacenters and networking infrastructure." | 区域是 Azure 机房所在的地理位置：一个区域是同一地区的一组数据中心，建资源时要选放在哪个区域，比如 Canada Central 在多伦多。资源组的区域只存它的元数据，组里的资源可以放在别的区域。 | [Microsoft, n.d., para. 1](https://learn.microsoft.com/en-us/azure/reliability/regions-overview#:~:text=Each%20region%20is%20a%20set%20of%20physical%20facilities) |
| **quota** (配额) | "Many Azure services have quotas, which are the assigned number of resources for your Azure subscription." | 配额是一个订阅在一个区域里最多能用多少某种资源的上限，比如最多同时开几个 CPU 核，像手机套餐的流量上限。可以用 `az vm list-usage -l <region>` 查看用量和上限；型号没被限制但配额为 0，同样建不了。 | [Microsoft, n.d., para. 1](https://learn.microsoft.com/en-us/azure/quotas/quotas-overview#:~:text=Many%20Azure%20services%20have%20quotas%2C%20which%20are%20the) |
| **availability zone** (可用性区域) | "An availability zone is a logical grouping of one or more physically separate datacenters within a region. Each availability zone is built in a way that if something goes wrong in one (like a power outage or network issue), the others keep working." | 可用性区域是同一个 Azure 区域里物理上分开的几处机房，各自有独立的电源、空调和网络，一处出事不会连累另一处。门户新建 VM 时可能默认选 Zone 1；某个型号在所有区域都受限时，只有选「不需要基础结构冗余」才能建。 | [Microsoft, n.d., "Datacenters and availability zones" section, para. 1](https://learn.microsoft.com/en-us/azure/reliability/availability-zones-overview#datacenters-and-availability-zones:~:text=An%20availability%20zone%20is%20a%20logical%20grouping%20of) |
| **delete a resource group** (删除资源组) | "When no longer needed, you can delete the resource group, virtual machine, and all related resources." *Note: A deleted resource group can't be recovered (see the FAQ in Microsoft's article on resource group and resource deletion).* | 把资源组连同里面的所有资源一起删掉，删了就找不回来，所以删之前要确认里面没有还要用的资源。 | [Microsoft, 2026, February 6, "Delete resources" section, para. 1](https://learn.microsoft.com/en-us/azure/virtual-machines/linux/quick-create-portal#delete-resources:~:text=When%20no%20longer%20needed%2C%20you%20can%20delete%20the) |
| **subscription ID** (订阅 ID) | "Each subscription has an ID associated with it, as does the tenant to which a subscription belongs." | 你的 Azure 订阅独一无二的编号，是一长串字母和数字；ID 是 identifier（标识符）的缩写。公开分享截图时要遮住。 | [Microsoft, 2026, January 21, para. 2](https://learn.microsoft.com/en-us/azure/azure-portal/get-subscription-tenant-id#:~:text=Each%20subscription%20has%20an%20ID%20associated%20with%20it) |

## 2. Describe Azure compute services

### 2.1 Azure Virtual Machines

| Term | Definition | 中文解释 | Source |
|---|---|---|---|
| **Azure Virtual Machines** (Azure 虚拟机) | "Azure virtual machines (VMs) are one of several types of on-demand, scalable computing resources that Azure offers. | **custom image** (自定义映像) | "Custom images are like marketplace images, but you create them yourself. | **gateway** (网关) | "An intermediate system (interface, relay) that attaches to two (or more) computer networks that have similar functions but dissimilar implementations and that enables either one-way or two-way communication between the networks." | 连接两个网络、在它们之间转发数据的机器或服务，像两个网络之间的大门，比如公司内网通往互联网的那道门。 | [National Institute of Standards and Technology, n.d., definition 1](https://csrc.nist.gov/glossary/term/gateway#:~:text=An%20intermediate%20system%20%28interface%2C%20relay%29%20that%20attaches%20to) |
| **web app** (Web 应用) | A web app is an application that people use through a web browser. | 用浏览器打开就能用的应用程序，比如网上银行、网上商城。 | My own words |

### 2.2 Virtual Machine Scale Sets

| Term | Definition | 中文解释 | Source |
|---|---|---|---|
| **Virtual Machine Scale Sets (VMSS)** (虚拟机规模集) | "Azure Virtual Machine Scale Sets let you create and manage a group of load balanced virtual machines (VM) instances. The number of VM instances can automatically increase or decrease in response to demand or a defined schedule." *Note: A common short description is "a set of identical VMs with built-in autoscaling"; identical VMs match the Uniform mode, while the Flexible mode can mix VM sizes.* | 把一群虚拟机当成一个整体来管的服务，台数可以随访问量或按时间表自动增减，访问请求会平均分给它们。 | [Microsoft, 2026, May 19, para. 1](https://learn.microsoft.com/en-us/azure/virtual-machine-scale-sets/overview#:~:text=Azure%20Virtual%20Machine%20Scale%20Sets%20let%20you%20create) |
| **autoscale** (自动缩放) | "Autoscale is a service that automatically adds and removes resources according to the load on your application." | 按 CPU 忙不忙等指标或者按时间表，自动增加或减少机器（实例）的数量，比如 CPU 超过 70% 就自动加一台。 | [Microsoft, 2026, August 7, "What is autoscale" section, para. 1](https://learn.microsoft.com/en-us/azure/azure-monitor/autoscale/autoscale-overview#what-is-autoscale:~:text=Autoscale%20is%20a%20service%20that%20automatically%20adds%20and%20removes) |
| **instance** (实例) | An instance is one running copy of a virtual machine, container, or app. | 正在运行的一份副本，比如同一个网站同时跑在 3 台虚拟机上，就是 3 个实例；规模集里的每台虚拟机也叫一个实例。 | My own words |
| **batch processing** (批处理) | Batch processing means running a large set of jobs together without user interaction, often on a schedule. | 把一大堆任务攒在一起集中处理，中间不用人操作，常常定时跑，比如每天半夜统一算一次全公司的工资。 | My own words |

### 2.3 Containers and container images

| Term | Definition | 中文解释 | Source |

### 2.7 Azure Functions

| Term | Definition | 中文解释 | Source |
|---|---|---|---|
| **Azure Functions** (Azure Functions) | "Azure Functions is a serverless solution that allows you to build robust apps while using less code, and with less infrastructure and lower costs." | Azure 上运行一小段代码的服务：你写好一个函数（完成单一功能的一小段代码），再指定什么事发生时运行它，比如收到一个网页请求；服务器完全不用你管。 | [Microsoft, 2026, September 4, para. 1](https://learn.microsoft.com/en-us/azure/azure-functions/functions-overview#:~:text=Azure%20Functions%20is%20a%20serverless%20solution%20that%20allows) |
