# Amazon Web Services

Order: the AWS Documentation home page lists its product categories alphabetically, as an index. Here they follow the learning order of the Microsoft Azure entry (compute, containers, web, networking, storage, databases, integration, analytics, IoT, machine learning, media, security, end user computing, management, developer tools, migration), so the two clouds read side by side. A category with no Azure counterpart sits after its nearest one (Compute HPC, Serverless, Cryptography & PKI, AWS Management Console, Cloud Financial Management) or at the end: Business Applications to Satellite, then Customer Enablement Services, Marketplace and Partner Central.
