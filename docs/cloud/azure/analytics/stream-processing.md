# 11.5 Stream Processing

## Classification

![Stream processing, the output sink that the processed stream data is written to, then the 4 options that Big data architectures names for this component, in its order: Spark Streaming, Azure Databricks, Azure Functions, Fabric eventstreams; then Azure Stream Analytics, placed here by their own overviews. Azure Databricks expands into the technologies its overview names for real-time and streaming analytics (Structured Streaming, Delta Lake, Lakeflow pipelines, Auto Loader); Azure Stream Analytics expands into what its overview names (Inputs, Reference data, Outputs, Stream Analytics query language, Windowing functions, Streaming units, Exactly once event processing), and Windowing functions into the five kinds of temporal windows (Tumbling, Hopping, Sliding, Session, Snapshot).](media/stream-processing.png)

| **Azure Stream Analytics**<br>Azure 流分析 | "Azure Stream Analytics is a **fully managed stream processing engine** that **analyzes and processes large volumes of streaming data** with submillisecond latencies." | Azure 流分析是一种**完全托管的流处理引擎**，以亚毫秒级延迟**分析和处理大量流数据**。 | [Microsoft, 2026c, para. 1](https://learn.microsoft.com/en-us/azure/stream-analytics/stream-analytics-introduction#:~:text=is%20a%20fully%20managed%20stream%20processing%20engine) |
| **Inputs**<br>输入 | (context) "You can create a Stream Analytics job that connects to **Azure Event Hubs and Azure IoT Hub** for **streaming data ingestion**, and Azure Blob storage or Azure Data Lake Storage Gen2 to ingest historical data." | （语境）你可以创建一个流分析作业，连接 **Azure 事件中心和 Azure IoT 中心**进行**流数据引入**，并连接 Azure Blob 存储或 Azure Data Lake Storage Gen2 来引入历史数据。 | [Microsoft, 2026c, "Ease of use" section, para. 2](https://learn.microsoft.com/en-us/azure/stream-analytics/stream-analytics-introduction#:~:text=for%20streaming%20data%20ingestion) |

| **Stream Analytics query language**<br>流分析查询语言 | (context) "The Stream Analytics query language allows you to **perform Complex Event Processing (CEP)** by offering a **wide array of functions for analyzing streaming data**." | （语境）流分析查询语言通过提供**大量用于分析流数据的函数**，让你可以**执行复杂事件处理**（CEP）。 | [Microsoft, 2026c, "Programmer productivity" section, para. 3](https://learn.microsoft.com/en-us/azure/stream-analytics/stream-analytics-introduction#:~:text=The%20Stream%20Analytics%20query%20language%20allows%20you%20to%20perform%20Complex%20Event%20Processing) |
| **Windowing functions**<br>窗口函数 | (context) "Stream Analytics has **native support for windowing functions**, so you can **create complex stream processing jobs with minimal effort**." | （语境）流分析**原生支持窗口函数**，因此你可以**用极少的工作量创建复杂的流处理作业**。 | [Microsoft, 2026a, para. 1](https://learn.microsoft.com/en-us/azure/stream-analytics/stream-analytics-window-functions#:~:text=Stream%20Analytics%20has%20native%20support%20for%20windowing%20functions) |
| **Tumbling window**<br>翻转窗口 | "Use Tumbling window functions to **segment a data stream into distinct time segments**, and **perform a function against them**." | 使用翻转窗口函数把**数据流分割成互不相同的时间段**，并**对它们执行一个函数**。 | [Microsoft, 2026a, "Tumbling window" section, para. 1](https://learn.microsoft.com/en-us/azure/stream-analytics/stream-analytics-window-functions#:~:text=segment%20a%20data%20stream%20into%20distinct%20time%20segments) |
| **Hopping window**<br>跳跃窗口 | "Hopping window functions **hop forward in time** by a **fixed period**." | 跳跃窗口函数按**固定周期**在**时间上向前跳跃**。 | [Microsoft, 2026a, "Hopping window" section, para. 1](https://learn.microsoft.com/en-us/azure/stream-analytics/stream-analytics-window-functions#:~:text=window%20functions%20hop%20forward%20in%20time%20by%20a%20fixed%20period) |
| **Sliding window**<br>滑动窗口 | "Sliding windows, unlike tumbling or hopping windows, **output events only for points in time** when the **content of the window actually changes**." | 与翻转窗口或跳跃窗口不同，滑动窗口**只在某些时间点输出事件**，即**窗口内容实际发生变化**的时候。 | [Microsoft, 2026a, "Sliding window" section, para. 1](https://learn.microsoft.com/en-us/azure/stream-analytics/stream-analytics-window-functions#:~:text=output%20events%20only%20for%20points%20in%20time%20when%20the%20content%20of%20the%20window%20actually%20changes) |
| **Session window**<br>会话窗口 | "Session window functions **group events that arrive at similar times**. They **filter out periods of time where there's no data**." | 会话窗口函数**把在相近时间到达的事件分为一组**。它们**过滤掉没有数据的时间段**。 | [Microsoft, 2026a, "Session window" section, para. 1](https://learn.microsoft.com/en-us/azure/stream-analytics/stream-analytics-window-functions#:~:text=group%20events%20that%20arrive%20at%20similar%20times) |
| **Snapshot window**<br>快照窗口 | "Snapshot windows **group events that have the same timestamp**." | 快照窗口**把时间戳相同的事件分为一组**。 | [Microsoft, 2026a, "Snapshot window" section, para. 1](https://learn.microsoft.com/en-us/azure/stream-analytics/stream-analytics-window-functions#:~:text=group%20events%20that%20have%20the%20same%20timestamp) |
| **Streaming units**<br>流式处理单元 | (context) "There are **no upfront costs** - you **only pay for the streaming units you consume**." | （语境）**没有预付费用**，你**只为消耗的流式处理单元付费**。 | [Microsoft, 2026c, "Low total cost of ownership" section, para. 1](https://learn.microsoft.com/en-us/azure/stream-analytics/stream-analytics-introduction#:~:text=you%20only%20pay%20for%20the%20streaming%20units%20you%20consume) |
| **Exactly once event processing**<br>恰好一次事件处理 | (context) "Stream Analytics guarantees **exactly once event processing** and **at-least-once delivery of events**, so events are never lost." | （语境）流分析保证**恰好一次的事件处理**和**至少一次的事件传递**，因此事件永远不会丢失。 | [Microsoft, 2026c, "Reliability" section, para. 1](https://learn.microsoft.com/en-us/azure/stream-analytics/stream-analytics-introduction#:~:text=Stream%20Analytics%20guarantees%20exactly%20once%20event%20processing) |
