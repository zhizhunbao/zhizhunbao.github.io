## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **Power BI semantic models**<br>Power BI 语义模型 | "Power BI semantic models represent a **source of data** that's **ready for reporting and visualization**." | Power BI 语义模型代表一种**数据源**，这种数据源**已可用于报告和可视化**。 | [Microsoft, 2026a, para. 2](https://learn.microsoft.com/en-us/power-bi/connect-data/service-datasets-understand#:~:text=semantic%20models%20represent%20a%20source%20of%20data) |
| **Power BI**<br>Power BI | "Power BI is Microsoft's **business analytics platform** that helps you **turn data into actionable insights**." | Power BI 是 Microsoft 的**业务分析平台**，帮助你**把数据转化为可操作的见解**。 | [Microsoft, 2026e, para. 1](https://learn.microsoft.com/en-us/power-bi/fundamentals/power-bi-overview#:~:text=business%20analytics%20platform%20that%20helps%20you%20turn%20data%20into%20actionable%20insights) |
| **Azure Databricks**<br>Azure Databricks | "Azure Databricks is a **unified, open analytics platform** for **building, deploying, sharing, and maintaining enterprise-grade data, analytics, and AI solutions at scale**." | Azure Databricks 是一个**统一、开放的分析平台**，用于**大规模构建、部署、共享和维护企业级数据、分析和 AI 解决方案**。 | [Microsoft, 2026b, para. 1](https://learn.microsoft.com/en-us/azure/databricks/introduction/#:~:text=is%20a%20unified%2C%20open%20analytics%20platform) |
| **Fabric Data Science**<br>Fabric 数据科学 | (context) "For data enrichment and business insights, Microsoft Fabric offers **Data Science experiences** that empower users to **build end-to-end data science workflows**." | （语境）为了丰富数据和获取业务见解，Microsoft Fabric 提供**数据科学体验**，让用户能够**构建端到端的数据科学工作流**。 | [Microsoft, 2026c, para. 1](https://learn.microsoft.com/en-us/fabric/data-science/data-science-overview#:~:text=Microsoft%20Fabric%20offers%20Data%20Science%20experiences) |
| **Azure Analysis Services**<br>Azure Analysis Services | "Azure Analysis Services is a **fully managed platform as a service (PaaS)** that provides **enterprise-grade data models in the cloud**." | Azure Analysis Services 是一种**完全托管的平台即服务 (PaaS)**，在云中提供**企业级数据模型**。 | [Microsoft, 2025, para. 1](https://learn.microsoft.com/en-us/analysis-services/azure-analysis-services/analysis-services-overview?view=sql-analysis-services-2025#:~:text=provides%20enterprise-grade%20data%20models%20in%20the%20cloud) |
| **Power BI Embedded**<br>Power BI Embedded | "Power BI embedded analytics enables you to **embed Power BI content**, such as **reports, dashboards, and tiles**, into **websites and web applications** running in supported web browsers." | Power BI 嵌入式分析让你可以**嵌入 Power BI 内容**，例如**报表、仪表板和磁贴**，把它们嵌入到在受支持的 Web 浏览器中运行的**网站和 Web 应用程序**。 | [Microsoft, 2026d, para. 1](https://learn.microsoft.com/en-us/power-bi/developer/azure-pbie-what-is-power-bi-embedded#:~:text=embedded%20analytics%20enables%20you%20to%20embed%20Power%20BI%20content) |
