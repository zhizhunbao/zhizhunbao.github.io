Boxes follow the options that the current Big data architectures guide names for each component (checked 2026-10-27); each row quotes the product's own overview. A service named under several components (Azure Databricks) has a full row in each. Lambda, Kappa and Lakehouse architectures, from the same guide, are architecture figures on 11.4 and 11.5.

Products of the Analytics category that the guide does not name are placed by their own overviews, after the guide's options: Azure Data Lake Analytics (an "analytics job service", retired 29 February 2024) in 11.2, Azure Stream Analytics in 11.4, Azure Synapse Analytics in 11.5, Azure Analysis Services and Power BI Embedded in 11.6. Azure Data Share (data sharing) fits none of the components, and Azure Chaos Studio (resilience testing) belongs with reliability, not analytics.
