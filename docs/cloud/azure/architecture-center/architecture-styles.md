## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **N-tier**<br>N 层 | "N-tier is a **traditional architecture for enterprise applications** that **divides an application into logical layers and physical tiers**." | N 层是一种**面向企业应用程序的传统体系结构**，它**把应用程序划分为逻辑层和物理层级**。 | [Microsoft, 2025, "A quick tour of the styles" section, "N-tier", para. 1](https://learn.microsoft.com/en-us/azure/architecture/guide/architecture-styles/#:~:text=is%20a%20traditional%20architecture%20for%20enterprise%20applications) |
| **Web-Queue-Worker**<br>Web-队列-辅助角色 | "Web-Queue-Worker is an architecture that consists of a **web front end, a message queue, and a back-end worker**." | Web-队列-辅助角色是一种体系结构，由 **Web 前端、消息队列和后端辅助角色**组成。 | [Microsoft, 2025, "A quick tour of the styles" section, "Web-Queue-Worker", para. 1](https://learn.microsoft.com/en-us/azure/architecture/guide/architecture-styles/#:~:text=is%20an%20architecture%20that%20consists%20of%20a%20web%20front%20end) |
| **Microservices**<br>微服务 | "The Microservices architecture **decomposes applications into a collection of small, autonomous services**." | 微服务体系结构**把应用程序分解为一组小型的自治服务**。 | [Microsoft, 2025, "A quick tour of the styles" section, "Microservices", para. 1](https://learn.microsoft.com/en-us/azure/architecture/guide/architecture-styles/#:~:text=architecture%20decomposes%20applications%20into%20a%20collection%20of%20small%2C%20autonomous%20services) |
| **Event-driven architecture**<br>事件驱动体系结构 | "Event-driven architectures use a **publish-subscribe model** where **event producers generate streams of events**, and **event consumers respond to those events** in near real time." | 事件驱动体系结构使用**发布-订阅模型**，其中**事件生成者生成事件流**，**事件使用者近实时地响应这些事件**。 | [Microsoft, 2025, "A quick tour of the styles" section, "Event-driven architecture", para. 1](https://learn.microsoft.com/en-us/azure/architecture/guide/architecture-styles/#:~:text=architectures%20use%20a) |
| **Event producers**<br>事件生成者 | "**event producers** that **generate a stream of events**" | **事件生成者**，它们**生成事件流** | [Microsoft, 2026, para. 1](https://learn.microsoft.com/en-us/azure/architecture/guide/architecture-styles/event-driven#:~:text=event%20producers%20that%20generate%20a%20stream%20of%20events) |
| **Event consumers**<br>事件使用者 | "**event consumers** that **listen for these events**" | **事件使用者**，它们**侦听这些事件** | [Microsoft, 2026, para. 1](https://learn.microsoft.com/en-us/azure/architecture/guide/architecture-styles/event-driven#:~:text=event%20consumers%20that%20listen%20for%20these%20events) |
| **Event channels**<br>事件通道 | "**event channels** (often implemented as **event brokers or ingestion services**) that transfer events from producers to consumers" | **事件通道**，通常实现为**事件代理或引入服务**，负责把事件从生成者传送到使用者 | [Microsoft, 2026, para. 1](https://learn.microsoft.com/en-us/azure/architecture/guide/architecture-styles/event-driven#:~:text=that%20transfer%20events%20from%20producers%20to%20consumers) |
| **Publish-subscribe**<br>发布-订阅 | "The publish-subscribe messaging infrastructure **tracks subscriptions**. When an event is published, it **sends the event to each subscriber**." | 发布-订阅消息传送基础结构**跟踪订阅**。发布事件时，它**把事件发送给每个订阅者**。 | [Microsoft, 2026, "Architecture" section, "Publish-subscribe" item](https://learn.microsoft.com/en-us/azure/architecture/guide/architecture-styles/event-driven#:~:text=messaging%20infrastructure%20tracks%20subscriptions) |
| **Event streaming**<br>事件流式处理 | "**Events are written to a log**. Events are **strictly ordered within a partition** and are durable." | **事件被写入日志**。事件**在分区内严格有序**，并且是持久的。 | [Microsoft, 2026, "Architecture" section, "Event streaming" item](https://learn.microsoft.com/en-us/azure/architecture/guide/architecture-styles/event-driven#:~:text=Events%20are%20written%20to%20a%20log) |
| **Simple event processing**<br>简单事件处理 | "An event **immediately triggers an action** in **the consumer**." | 事件**立即触发**位于**使用者中的操作**。 | [Microsoft, 2026, "Architecture" section, "Simple event processing" item](https://learn.microsoft.com/en-us/azure/architecture/guide/architecture-styles/event-driven#:~:text=immediately%20triggers%20an%20action%20in%20the%20consumer) |
| **Basic event correlation**<br>基本事件关联 | "A consumer **processes a few discrete business events**, **correlates them by an identifier**, and persists information from earlier events to use when it processes later events." | 使用者**处理几个离散的业务事件**，**按标识符将它们关联起来**，并保存早先事件的信息，供处理后续事件时使用。 | [Microsoft, 2026, "Architecture" section, "Basic event correlation" item](https://learn.microsoft.com/en-us/azure/architecture/guide/architecture-styles/event-driven#:~:text=processes%20a%20few%20discrete%20business%20events) |
| **Complex event processing**<br>复杂事件处理 | "A consumer uses a technology like Azure Stream Analytics to **analyze a series of events** and **identify patterns in the event data**." | 使用者借助 Azure 流分析之类的技术来**分析一系列事件**，并**识别事件数据中的模式**。 | [Microsoft, 2026, "Architecture" section, "Complex event processing" item](https://learn.microsoft.com/en-us/azure/architecture/guide/architecture-styles/event-driven#:~:text=to%20analyze%20a%20series%20of%20events%20and%20identify%20patterns) |
| **Event stream processing**<br>事件流处理 | "Use a **data streaming platform**, such as Azure IoT Hub, Event Hubs, or Event Hubs for Apache Kafka, as a pipeline to **ingest events and feed them to stream processors**." | 使用**数据流式处理平台**，例如 Azure IoT 中心、事件中心或适用于 Apache Kafka 的事件中心，作为管道，**引入事件并把它们馈送给流处理器**。 | [Microsoft, 2026, "Architecture" section, "Event stream processing" item](https://learn.microsoft.com/en-us/azure/architecture/guide/architecture-styles/event-driven#:~:text=as%20a%20pipeline%20to%20ingest%20events%20and%20feed%20them%20to%20stream%20processors) |
| **Include all required attributes in the payload**<br>在有效负载中包含所有必需属性 | "Use this approach when you want consumers to have **all available information** **without needing to query an external data source**." | 当你希望使用者拥有**所有可用信息**、**无需查询外部数据源**时，使用此方法。 | [Microsoft, 2026, "Architecture" section, "Include all required attributes in the payload" item](https://learn.microsoft.com/en-us/azure/architecture/guide/architecture-styles/event-driven#:~:text=without%20needing%20to%20query%20an%20external%20data%20source) |
| **Include only keys in the payload**<br>仅在有效负载中包含键 | "In this approach, consumers **retrieve the necessary attributes**, such as a primary key, to **independently fetch the remaining data from a data source**." | 在此方法中，使用者**检索必要的属性**，例如主键，以便**独立地从数据源获取其余数据**。 | [Microsoft, 2026, "Architecture" section, "Include only keys in the payload" item](https://learn.microsoft.com/en-us/azure/architecture/guide/architecture-styles/event-driven#:~:text=to%20independently%20fetch%20the%20remaining%20data%20from%20a%20data%20source) |
| **Broker topology**<br>代理拓扑 | "Components **broadcast events to the entire system**. Other components **either act on the event or ignore the event**." | 组件**把事件广播到整个系统**。其他组件**要么对事件采取行动，要么忽略该事件**。 | [Microsoft, 2026, "Architecture" section, "Broker topology" item](https://learn.microsoft.com/en-us/azure/architecture/guide/architecture-styles/event-driven#:~:text=Components%20broadcast%20events%20to%20the%20entire%20system) |
| **Mediator topology**<br>中介拓扑 | "There's an **event mediator** that **manages and controls the flow of events**." | 有一个**事件中介**，它**管理并控制事件流**。 | [Microsoft, 2026, "Architecture" section, "Mediator topology" item](https://learn.microsoft.com/en-us/azure/architecture/guide/architecture-styles/event-driven#:~:text=that%20manages%20and%20controls%20the%20flow%20of%20events) |
| **Big data**<br>大数据 | "Big data architectures handle the **ingestion, processing, and analysis of data** that's **too large or complex for traditional database systems**." | 大数据体系结构负责**数据的引入、处理和分析**，这些数据**对传统数据库系统来说过于庞大或复杂**。 | [Microsoft, 2025, "A quick tour of the styles" section, "Big data", para. 1](https://learn.microsoft.com/en-us/azure/architecture/guide/architecture-styles/#:~:text=architectures%20handle%20the%20ingestion%2C%20processing%2C%20and%20analysis%20of%20data) |
| **Big compute**<br>大计算 | "Big compute architectures support **large-scale workloads** that require **hundreds or thousands of cores** for computationally intensive operations." | 大计算体系结构支持**大规模工作负载**，这些工作负载需要**数百或数千个核心**来执行计算密集型操作。 | [Microsoft, 2025, "A quick tour of the styles" section, "Big compute", para. 1](https://learn.microsoft.com/en-us/azure/architecture/guide/architecture-styles/#:~:text=architectures%20support%20large-scale%20workloads) |
