# 9.1 Relational Data Stores

## Classification

![Relational data stores, 6 Azure services from "Select an Azure service for relational data stores" in Understand data models: SQL Database, Azure SQL Managed Instance, SQL Database (Hyperscale), Azure Database for PostgreSQL, Azure Database for MySQL, SQL Database in Fabric. SQL Database expands to Dynamic data masking, which expands to its six masking functions: Default, Credit card, Email, Random number, Custom text, Datetime.](media/relational-data-stores.png)

## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **SQL Database**<br>SQL 数据库 | "SQL Database is a **managed relational database** for **modern cloud applications** that use the **SQL Server engine**." | SQL 数据库是一种**托管关系数据库**，面向**现代云应用程序**，使用的是 **SQL Server 引擎**。 | [Microsoft, 2025, "Select an Azure service for relational data stores" section, list item 1](https://learn.microsoft.com/en-us/azure/architecture/data-guide/technology-choices/understand-data-store-models#:~:text=is%20a%20managed%20relational%20database%20for%20modern%20cloud%20applications) |
| **Dynamic data masking**<br>动态数据掩码 | "Azure SQL Database, SQL database in Microsoft Fabric, and Azure SQL Managed Instance support dynamic data masking (DDM). Dynamic data masking **limits sensitive data exposure by masking it to nonprivileged users**." | Azure SQL 数据库、Microsoft Fabric 中的 SQL 数据库和 Azure SQL 托管实例都支持动态数据掩码（DDM）。动态数据掩码**通过对非特权用户掩盖敏感数据来减少敏感数据的暴露**。 | [Microsoft, 2026, para. 1](https://learn.microsoft.com/en-us/azure/azure-sql/database/dynamic-data-masking-overview#:~:text=limits%20sensitive%20data%20exposure%20by%20masking%20it) |
| **Default**<br>默认 | "**Default** **Full masking according to the data types of the designated fields**" | **默认**：**按指定字段的数据类型进行完全掩码**。 | [Microsoft, 2026, "Dynamic data masking policy" section, "Masking functions" table, row 1](https://learn.microsoft.com/en-us/azure/azure-sql/database/dynamic-data-masking-overview#:~:text=Full%20masking%20according%20to%20the%20data%20types) |
| **Credit card**<br>信用卡 | "**Credit card** **Masking method, which exposes the last four digits of the designated fields** and adds a constant string as a prefix in the form of a credit card." | **信用卡**：**只露出指定字段的最后四位**，并在前面加一个信用卡格式的固定字符串。 | [Microsoft, 2026, "Dynamic data masking policy" section, "Masking functions" table, row 2](https://learn.microsoft.com/en-us/azure/azure-sql/database/dynamic-data-masking-overview#:~:text=exposes%20the%20last%20four%20digits%20of%20the%20designated%20fields) |
| **Email**<br>电子邮件 | "**Email** **Masking method, which exposes the first letter and replaces the domain with XXXX.com** using a constant string prefix in the form of an email address." | **电子邮件**：**只露出第一个字母，并把域名替换成 XXXX.com**，前缀是电子邮件格式的固定字符串。 | [Microsoft, 2026, "Dynamic data masking policy" section, "Masking functions" table, row 3](https://learn.microsoft.com/en-us/azure/azure-sql/database/dynamic-data-masking-overview#:~:text=exposes%20the%20first%20letter%20and%20replaces%20the%20domain) |
| **Random number**<br>随机数 | "**Random number** **Masking method, which generates a random number** according to the selected boundaries and actual data types." | **随机数**：**生成一个随机数**，范围按所选的边界和实际数据类型决定。 | [Microsoft, 2026, "Dynamic data masking policy" section, "Masking functions" table, row 4](https://learn.microsoft.com/en-us/azure/azure-sql/database/dynamic-data-masking-overview#:~:text=which%20generates%20a%20random%20number%20according%20to%20the%20selected%20boundaries) |
| **Custom text**<br>自定义文本 | "**Custom text** **Masking method, which exposes the first and last characters** and adds a custom padding string in the middle." | **自定义文本**：**只露出首尾字符**，中间加一段自定义的填充字符串。 | [Microsoft, 2026, "Dynamic data masking policy" section, "Masking functions" table, row 5](https://learn.microsoft.com/en-us/azure/azure-sql/database/dynamic-data-masking-overview#:~:text=exposes%20the%20first%20and%20last%20characters) |
| **Datetime**<br>日期时间 | "**Datetime** **Enables granular masking for date/time columns**, namely **datetime**, **datetime2**, **date**, **time**, **datetimeoffset**, and **smalldatetime**." | **日期时间**：**对日期/时间列做细粒度掩码**，即 **datetime**、**datetime2**、**date**、**time**、**datetimeoffset** 和 **smalldatetime**。 | [Microsoft, 2026, "Dynamic data masking policy" section, "Masking functions" table, row 6](https://learn.microsoft.com/en-us/azure/azure-sql/database/dynamic-data-masking-overview#:~:text=Enables%20granular%20masking%20for%20date%2Ftime%20columns) |
| **Azure SQL Managed Instance**<br>Azure SQL 托管实例 | "Azure SQL Managed Instance is a **near-complete SQL Server environment in the cloud** that's ideal for **lift-and-shift migrations**." | Azure SQL 托管实例是**云中近乎完整的 SQL Server 环境**，非常适合**直接迁移**（lift-and-shift）。 | [Microsoft, 2025, "Select an Azure service for relational data stores" section, list item 2](https://learn.microsoft.com/en-us/azure/architecture/data-guide/technology-choices/understand-data-store-models#:~:text=is%20a%20near-complete%20SQL%20Server%20environment%20in%20the%20cloud) |
| **SQL Database (Hyperscale)**<br>SQL 数据库（超大规模） | "SQL Database (Hyperscale) is a **highly scalable SQL tier** designed for **massive workloads** with fast autoscaling and rapid backups." | SQL 数据库（超大规模）是一种**高度可扩展的 SQL 层级**，专为**海量工作负载**设计，具有快速自动缩放和快速备份能力。 | [Microsoft, 2025, "Select an Azure service for relational data stores" section, list item 3](https://learn.microsoft.com/en-us/azure/architecture/data-guide/technology-choices/understand-data-store-models#:~:text=is%20a%20highly%20scalable%20SQL%20tier%20designed%20for%20massive%20workloads) |
| **Azure Database for PostgreSQL**<br>Azure Database for PostgreSQL | "Azure Database for PostgreSQL is a **managed PostgreSQL service** that supports **open-source extensions** and **flexible deployment options**." | Azure Database for PostgreSQL 是一种**托管 PostgreSQL 服务**，支持**开源扩展**和**灵活的部署选项**。 | [Microsoft, 2025, "Select an Azure service for relational data stores" section, list item 4](https://learn.microsoft.com/en-us/azure/architecture/data-guide/technology-choices/understand-data-store-models#:~:text=is%20a%20managed%20PostgreSQL%20service%20that%20supports%20open-source%20extensions) |
| **Azure Database for MySQL**<br>Azure Database for MySQL | "Azure Database for MySQL is a **managed MySQL database** for **web apps and open-source workloads**." | Azure Database for MySQL 是一种**托管 MySQL 数据库**，用于 **Web 应用和开源工作负载**。 | [Microsoft, 2025, "Select an Azure service for relational data stores" section, list item 5](https://learn.microsoft.com/en-us/azure/architecture/data-guide/technology-choices/understand-data-store-models#:~:text=is%20a%20managed%20MySQL%20database%20for%20web%20apps) |
| **SQL Database in Fabric**<br>Fabric 中的 SQL 数据库 | "SQL Database in Fabric is a **developer-friendly transactional database**, based on SQL Database, that you can use to **easily create an operational database in Fabric**." | Fabric 中的 SQL 数据库是一种**对开发人员友好的事务数据库**，基于 SQL 数据库，你可以用它**在 Fabric 中轻松创建操作数据库**。 | [Microsoft, 2025, "Select an Azure service for relational data stores" section, list item 6](https://learn.microsoft.com/en-us/azure/architecture/data-guide/technology-choices/understand-data-store-models#:~:text=is%20a%20developer-friendly%20transactional%20database) |
