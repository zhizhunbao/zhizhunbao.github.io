# 4.1 Infrastructure as a Service (IaaS)

## Classification

![Infrastructure as a service (IaaS), four terms: Virtual Machines and Azure VMware Solution, defined in Choose an Azure compute service, and Virtual Machine Scale Sets and Azure Spot Virtual Machines, described in the Compute list of the Azure documentation; Virtual Machines expanded into the seven VM size types of Sizes for virtual machines in Azure (General purpose, Compute optimized, Memory optimized, Storage optimized, GPU accelerated, FPGA accelerated, High performance compute) and the temporary disk of Azure managed disks overview.](media/infrastructure-as-a-service.png)

## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **Virtual Machines**<br>虚拟机 | "Azure Virtual Machines is a service that you can use to **deploy and manage virtual machines** (VMs) inside an **Azure virtual network**." | Azure Virtual Machines 是一项服务，可用来**部署和管理虚拟机**（VM），这些虚拟机位于 **Azure 虚拟网络**中。 | [Microsoft, 2026c, "Understand the basic features" section, list item 1](https://learn.microsoft.com/en-us/azure/architecture/guide/technology-choices/compute-decision-tree#:~:text=is%20a%20service%20that%20you%20can%20use%20to%20deploy%20and%20manage%20virtual%20machines) |
| **General purpose**<br>通用型 | "General purpose VM sizes provide **balanced CPU-to-memory ratio**. Ideal for **testing and development, small to medium databases, and low to medium traffic web servers**." | 通用型 VM 大小提供**均衡的 CPU 与内存比例**。适合**测试和开发、中小型数据库，以及中低流量的 Web 服务器**。 | [Microsoft, 2026d, "General purpose" section, para. 1](https://learn.microsoft.com/en-us/azure/virtual-machines/sizes/overview#:~:text=General%20purpose%20VM%20sizes%20provide%20balanced%20CPU%2Dto%2Dmemory%20ratio) |
| **Compute optimized**<br>计算优化型 | "Compute optimized VM sizes have a **high CPU-to-memory ratio**. These sizes are good for **medium traffic web servers, network appliances, batch processes, and application servers**." | 计算优化型 VM 大小具有**较高的 CPU 与内存比例**。这些大小适合**中等流量的 Web 服务器、网络设备、批处理和应用程序服务器**。 | [Microsoft, 2026d, "Compute optimized" section, para. 1](https://learn.microsoft.com/en-us/azure/virtual-machines/sizes/overview#:~:text=Compute%20optimized%20VM%20sizes%20have%20a%20high%20CPU%2Dto%2Dmemory%20ratio) |
| **Memory optimized**<br>内存优化型 | "Memory optimized VM sizes offer a **high memory-to-CPU ratio** that is great for **relational database servers, medium to large caches, and in-memory analytics**." | 内存优化型 VM 大小提供**较高的内存与 CPU 比例**，非常适合**关系数据库服务器、中大型缓存和内存中分析**。 | [Microsoft, 2026d, "Memory optimized" section, para. 1](https://learn.microsoft.com/en-us/azure/virtual-machines/sizes/overview#:~:text=Memory%20optimized%20VM%20sizes%20offer%20a%20high%20memory%2Dto%2DCPU%20ratio) |
| **Storage optimized**<br>存储优化型 | "Storage optimized virtual machine (VM) sizes offer **high disk throughput and IO**, and are ideal for **Big Data, SQL, NoSQL databases, data warehousing, and large transactional databases**." | 存储优化型虚拟机（VM）大小提供**高磁盘吞吐量和 IO**，适合**大数据、SQL、NoSQL 数据库、数据仓库和大型事务数据库**。 | [Microsoft, 2026d, "Storage optimized" section, para. 1](https://learn.microsoft.com/en-us/azure/virtual-machines/sizes/overview#:~:text=Storage%20optimized%20virtual%20machine%20(VM)%20sizes%20offer%20high%20disk%20throughput%20and%20IO) |
| **GPU accelerated**<br>GPU 加速型 | "GPU optimized VM sizes are specialized virtual machines available with **single, multiple, or fractional GPUs**. These sizes are designed for **compute-intensive, graphics-intensive, and visualization workloads**." | GPU 优化型 VM 大小是配有**单个、多个或部分 GPU** 的专用虚拟机。这些大小为**计算密集型、图形密集型和可视化工作负载**而设计。 | [Microsoft, 2026d, "GPU accelerated" section, para. 1](https://learn.microsoft.com/en-us/azure/virtual-machines/sizes/overview#:~:text=GPU%20optimized%20VM%20sizes%20are%20specialized%20virtual%20machines) |
| **FPGA accelerated**<br>FPGA 加速型 | "FPGA optimized VM sizes are specialized virtual machines available with **single or multiple FPGAs**. These sizes are designed for **compute-intensive workloads**." | FPGA 优化型 VM 大小是配有**单个或多个 FPGA** 的专用虚拟机。这些大小为**计算密集型工作负载**而设计。 | [Microsoft, 2026d, "FPGA accelerated" section, para. 1](https://learn.microsoft.com/en-us/azure/virtual-machines/sizes/overview#:~:text=FPGA%20optimized%20VM%20sizes%20are%20specialized%20virtual%20machines) |
| **High performance compute**<br>高性能计算 | "Azure High Performance Compute VMs are **optimized for various HPC workloads** such as computational fluid dynamics, finite element analysis, frontend and backend EDA, rendering, molecular dynamics, computational geoscience, weather simulation, and financial risk analysis." | Azure 高性能计算 VM **针对各种 HPC 工作负载进行了优化**，例如计算流体动力学、有限元分析、前端和后端 EDA、渲染、分子动力学、计算地球科学、天气模拟和金融风险分析。 | [Microsoft, 2026d, "High performance compute" section, para. 1](https://learn.microsoft.com/en-us/azure/virtual-machines/sizes/overview#:~:text=Azure%20High%20Performance%20Compute%20VMs%20are%20optimized%20for%20various%20HPC%20workloads) |
| **Temporary disk**<br>临时磁盘 | "Most VMs contain a temporary disk, which **isn't a managed disk**. The temporary disk provides **short-term storage for applications and processes**. It's intended for storing only data such as **page files, swap files, or SQL Server tempdb files**." | 大多数 VM 都包含一个临时磁盘，它**不是托管磁盘**。临时磁盘**为应用程序和进程提供短期存储**。它只用于存储**页面文件、交换文件或 SQL Server tempdb 文件**之类的数据。 | [Microsoft, 2026a, "Temporary disk" section, para. 1](https://learn.microsoft.com/en-us/azure/virtual-machines/managed-disks-overview#:~:text=Most%20VMs%20contain%20a%20temporary%20disk) |
| **Virtual Machine Scale Sets**<br>虚拟机规模集 | "Azure Virtual Machine Scale Sets let you **create and manage a group of load balanced virtual machines** (VM) instances. The number of VM instances can **automatically increase or decrease** in response to demand or a defined schedule." | Azure 虚拟机规模集让你**创建和管理一组负载均衡的虚拟机**（VM）实例。VM 实例的数量可以根据需求或设定的计划**自动增加或减少**。 | [Microsoft, 2026e, para. 1](https://learn.microsoft.com/en-us/azure/virtual-machine-scale-sets/overview#:~:text=let%20you%20create%20and%20manage%20a%20group%20of%20load%20balanced) |
| **Azure Spot Virtual Machines**<br>Azure 竞价虚拟机 | "Using Azure Spot Virtual Machines allows you to **take advantage of our unused capacity** at a **significant cost savings**. At any point in time when Azure needs the capacity back, the Azure infrastructure will **evict Azure Spot Virtual Machines**." | 使用 Azure 竞价虚拟机，你可以**利用 Azure 未使用的容量**，从而**大幅节省成本**。每当 Azure 需要收回容量时，Azure 基础结构就会**逐出 Azure 竞价虚拟机**。 | [Microsoft, 2026b, para. 1](https://learn.microsoft.com/en-us/azure/virtual-machines/spot-vms#:~:text=allows%20you%20to%20take%20advantage%20of%20our%20unused%20capacity) |
| **Azure VMware Solution**<br>Azure VMware 解决方案 | "Azure VMware Solution is a **managed service** for **running VMware workloads natively on Azure**." | Azure VMware Solution 是一项**托管服务**，用于**在 Azure 上原生运行 VMware 工作负载**。 | [Microsoft, 2026c, "Understand the basic features" section, list item 9](https://learn.microsoft.com/en-us/azure/architecture/guide/technology-choices/compute-decision-tree#:~:text=is%20a%20managed%20service%20for%20running%20VMware%20workloads) |
