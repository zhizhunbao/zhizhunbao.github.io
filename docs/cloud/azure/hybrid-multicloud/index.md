## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **Hybrid + multicloud**<br>混合 + 多云 | "**Hybrid cloud computing** combines **public cloud computing with on-premises infrastructure, or the private cloud**, into an **integrated environment**." "**Multicloud** refers to the **use of cloud services from multiple cloud providers** to manage the demands of different workloads." | **混合云计算**把**公有云计算与本地基础结构**（或私有云）结合成一个**集成环境**。**多云**指**使用多个云提供商的云服务**来满足不同工作负载的需求。 | [Microsoft, n.d.-b, "Hybrid cloud definition" section, para. 1; FAQ 03](https://azure.microsoft.com/en-us/resources/cloud-computing-dictionary/what-is-hybrid-cloud-computing#:~:text=Hybrid%20cloud%20computing%20combines) |
| **Azure Arc**<br>Azure Arc | "Azure Arc simplifies governance and management by delivering a **consistent multicloud and on-premises management platform**." | Azure Arc 通过提供**一致的多云和本地管理平台**来简化治理和管理。 | [Microsoft, 2025a, para. 2](https://learn.microsoft.com/en-us/azure/azure-arc/overview#:~:text=consistent%20multicloud%20and%20on-premises%20management%20platform) |
| **Azure Database for PostgreSQL**<br>Azure PostgreSQL 数据库 | "Azure Database for PostgreSQL is a **fully managed database service** that gives you **granular control and flexibility** over database management functions and configuration settings." | Azure Database for PostgreSQL 是一种**完全托管的数据库服务**，让你对数据库管理功能和配置设置拥有**精细的控制和灵活性**。 | [Microsoft, 2026b, para. 2](https://learn.microsoft.com/en-us/azure/postgresql/overview#:~:text=is%20a%20fully%20managed%20database%20service%20that%20gives%20you%20granular%20control) |
| **Azure DevOps**<br>Azure DevOps | "Azure DevOps is a **cloud-based platform** that provides **integrated tools for software development teams**." | Azure DevOps 是一个**基于云的平台**，为**软件开发团队提供集成工具**。 | [Microsoft, 2026c, para. 1](https://learn.microsoft.com/en-us/azure/devops/user-guide/what-is-azure-devops?view=azure-devops#:~:text=is%20a%20cloud-based%20platform%20that%20provides%20integrated%20tools) |
| **Azure ExpressRoute**<br>Azure ExpressRoute | "ExpressRoute lets you **extend your on-premises networks into the Microsoft cloud** over a **private connection** with the help of a connectivity provider." | ExpressRoute 让你借助连接服务提供商，通过**专用连接**把**本地网络扩展到 Microsoft 云**中。 | [Microsoft, 2026d, para. 1](https://learn.microsoft.com/en-us/azure/expressroute/expressroute-introduction#:~:text=lets%20you%20extend%20your%20on-premises%20networks%20into%20the%20Microsoft%20cloud) |
| **Azure IoT Edge**<br>Azure IoT 边缘 | "Azure IoT Edge is a **device-focused runtime** that enables you to **deploy, run, and monitor containerized Linux applications**, bringing analytics closer to your devices for faster insights and offline decision-making." | Azure IoT Edge 是一个**面向设备的运行时**，让你可以**部署、运行和监视容器化的 Linux 应用程序**，把分析带到更靠近设备的地方，以便更快地获得见解并离线做出决策。 | [Microsoft, 2026e, para. 1](https://learn.microsoft.com/en-us/azure/iot-edge/about-iot-edge#:~:text=is%20a%20device-focused%20runtime) |
| **Azure Kubernetes Service Edge Essentials**<br>Azure Kubernetes 服务 Edge Essentials | "Azure Kubernetes Service Edge Essentials is an **on-premises Kubernetes implementation** of Azure Kubernetes Service (AKS) that **automates running containerized applications at scale**." | Azure Kubernetes Service Edge Essentials 是 Azure Kubernetes Service（AKS）的一种**本地 Kubernetes 实现**，它**自动化大规模运行容器化应用程序**。 | [Microsoft, 2026a, para. 1](https://learn.microsoft.com/en-us/azure/aks/hybrid/aks-edge-overview#:~:text=is%20an%20on-premises%20Kubernetes%20implementation) |
| **Azure Local**<br>Azure 本地 | "Azure Local is Microsoft's **distributed infrastructure solution** that **extends Azure capabilities to customer-owned environments**." | Azure Local 是 Microsoft 的**分布式基础结构解决方案**，它**把 Azure 功能扩展到客户自有的环境**中。 | [Microsoft, 2026f, para. 1](https://learn.microsoft.com/en-us/azure/azure-local/overview#:~:text=distributed%20infrastructure%20solution%20that%20extends%20Azure%20capabilities) |
| **Azure Operator Nexus**<br>Azure 运营商关系 | "Azure Operator Nexus is a **carrier-grade, next-generation hybrid cloud platform** for **telecommunication operators**." | Azure Operator Nexus 是一个面向**电信运营商**的**运营商级下一代混合云平台**。 | [Microsoft, 2025c, para. 1](https://learn.microsoft.com/en-us/azure/operator-nexus/overview#:~:text=is%20a%20carrier-grade%2C%20next-generation%20hybrid%20cloud%20platform) |
| **Azure Operator Service Manager**<br>Azure 操作员服务管理器 | "Azure Operator Service Manager is a **cloud orchestration service** designed to **automate lifecycle management of complex mobility workloads** hosted on Azure Operator Nexus." | Azure Operator Service Manager 是一项**云编排服务**，旨在**自动化复杂移动工作负载的生命周期管理**，这些工作负载托管在 Azure Operator Nexus 上。 | [Microsoft, 2025d, para. 1](https://learn.microsoft.com/en-us/azure/operator-service-manager/azure-operator-service-manager-overview#:~:text=is%20a%20cloud%20orchestration%20service%20designed%20to%20automate) |
| **Azure SQL Database**<br>Azure SQL 数据库 | (context) "This article provides an overview of Azure SQL Database, a **fully managed platform as a service (PaaS) database engine** that **handles most of the database management functions** such as upgrading, patching, backups, and monitoring without user involvement." | （语境）本文概述 Azure SQL Database，它是一个**完全托管的平台即服务（PaaS）数据库引擎**，无需用户参与就能**处理大部分数据库管理功能**，例如升级、修补、备份和监视。 | [Microsoft, 2026g, para. 1](https://learn.microsoft.com/en-us/azure/azure-sql/database/sql-database-paas-overview?view=azuresql#:~:text=a%20fully%20managed%20platform%20as%20a%20service%20%28PaaS%29%20database%20engine) |
| **Azure Stack Edge**<br>Azure Stack 边缘 | (context) "Azure Stack Edge Pro with GPU is an **AI-enabled edge computing device** with **network data transfer capabilities**." | （语境）Azure Stack Edge Pro with GPU 是一种**支持 AI 的边缘计算设备**，具有**网络数据传输功能**。 | [Microsoft, 2025e, para. 1](https://learn.microsoft.com/en-us/azure/databox-online/azure-stack-edge-gpu-overview#:~:text=is%20an%20AI-enabled%20edge%20computing%20device) |
| **Azure Stack Hub**<br>Azure Stack Hub | "Azure Stack Hub is an **extension of Azure** that provides a way to **run apps in an on-premises environment** and deliver Azure services in your datacenter." | Azure Stack Hub 是 **Azure 的扩展**，它提供一种方式，让你**在本地环境中运行应用**，并在你的数据中心提供 Azure 服务。 | [Microsoft, 2025b, para. 1](https://learn.microsoft.com/en-us/azure-stack/operator/azure-stack-overview#:~:text=is%20an%20extension%20of%20Azure%20that%20provides%20a%20way%20to%20run%20apps) |
| **Microsoft Defender for Cloud**<br>Microsoft Defender for Cloud | "Microsoft Defender for Cloud is a **Cloud Native Application Protection Platform (CNAPP)**, which is a unified solution that **combines multiple cloud security tools** to protect applications across their entire lifecycle." | Microsoft Defender for Cloud 是一个**云原生应用程序保护平台（CNAPP）**，这是一种统一的解决方案，它**结合多种云安全工具**，在应用程序的整个生命周期中保护应用程序。 | [Microsoft, 2026h, para. 1](https://learn.microsoft.com/en-us/azure/defender-for-cloud/defender-for-cloud-introduction#:~:text=which%20is%20a%20unified%20solution%20that%20combines%20multiple%20cloud%20security%20tools) |
| **Microsoft Sentinel**<br>Microsoft Sentinel | "Microsoft Sentinel is a **cloud-native SIEM solution** that delivers **scalable, cost-efficient security** across multicloud and multiplatform environments." | Microsoft Sentinel 是一种**云原生 SIEM 解决方案**，在多云和多平台环境中提供**可扩展、经济高效的安全性**。 | [Microsoft, 2026i, para. 1](https://learn.microsoft.com/en-us/azure/sentinel/overview#:~:text=is%20a%20cloud-native%20SIEM%20solution) |
