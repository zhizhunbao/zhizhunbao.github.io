## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **Virtual Desktop Infrastructure**<br>虚拟桌面基础结构 | "**VDI** is an **IT infrastructure** that enables employees to **access virtual desktops hosted on centralized servers** from almost any device." | **VDI** 是一种 **IT 基础结构**，让员工几乎可以从任何设备**访问托管在集中式服务器上的虚拟桌面**。 | [Microsoft, n.d.-b, para. 1](https://azure.microsoft.com/en-us/resources/cloud-computing-dictionary/what-is-virtual-desktop-infrastructure-vdi#:~:text=VDI%20is%20an%20IT%20infrastructure) |
| **Azure Lab Services**<br>Azure 实验室服务 | "Azure Lab Services enables you to **create labs with infrastructure managed by Azure**." | Azure 实验室服务让你可以**创建由 Azure 管理基础结构的实验室**。 | [Microsoft, 2024, para. 1](https://learn.microsoft.com/en-us/azure/lab-services/lab-services-overview#:~:text=enables%20you%20to%20create%20labs%20with%20infrastructure%20managed%20by%20Azure) |
| **Azure Virtual Desktop**<br>Azure 虚拟桌面 | "Azure Virtual Desktop is a **desktop and app virtualization service** that **runs on Azure**." | Azure 虚拟桌面是一种**桌面和应用虚拟化服务**，它**运行在 Azure 上**。 | [Microsoft, 2026a, para. 1](https://learn.microsoft.com/en-us/azure/virtual-desktop/overview#:~:text=is%20a%20desktop%20and%20app%20virtualization%20service) |
