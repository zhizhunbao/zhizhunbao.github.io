## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **Mobile**<br>移动 | "abbreviation for application: a **computer program or piece of software** designed for a particular purpose that you can **download onto a mobile phone or other mobile device**" | application（应用程序）的缩写：为特定目的设计、可以**下载到手机或其他移动设备上**的**计算机程序或软件**。 | [Cambridge University Press & Assessment, n.d., "app" noun (COMPUTING), sense 2](https://dictionary.cambridge.org/dictionary/english/app) |
| **API Management**<br>API 管理 | "Azure API Management is a **hybrid, multicloud management platform for APIs** across **all environments**." | Azure API 管理是一个**混合、多云的 API 管理平台**，适用于**所有环境**。 | [Microsoft, 2025b, para. 1](https://learn.microsoft.com/en-us/azure/api-management/api-management-key-concepts#:~:text=is%20a%20hybrid%2C%20multicloud%20management%20platform%20for%20APIs) |
| **App Configuration**<br>应用程序配置 | "Azure App Configuration provides a service to **centrally manage application settings and feature flags**." | Azure 应用程序配置提供一项服务，用于**集中管理应用程序设置和功能标志**。 | [Microsoft, 2025c, para. 1](https://learn.microsoft.com/en-us/azure/azure-app-configuration/overview#:~:text=provides%20a%20service%20to%20centrally%20manage%20application%20settings) |
| **App Service**<br>应用服务 | "Azure App Service is a **platform that lets you run web applications, mobile back ends, and RESTful APIs** **without worrying about managing the underlying infrastructure**." | Azure 应用服务是一个**让你运行 Web 应用程序、移动后端和 RESTful API 的平台**，**无需操心管理底层基础结构**。 | [Microsoft, 2026a, para. 1](https://learn.microsoft.com/en-us/azure/app-service/overview#:~:text=is%20a%20platform%20that%20lets%20you%20run%20web%20applications) |
| **Azure AI Search**<br>Azure AI 搜索 | "Azure AI Search is a **fully managed, cloud-hosted service** that **connects your data to AI**." | Azure AI 搜索是一种**完全托管、云托管的服务**，它**把你的数据连接到 AI**。 | [Microsoft, 2026b, para. 1](https://learn.microsoft.com/en-us/azure/search/search-what-is-azure-search#:~:text=is%20a%20fully%20managed%2C%20cloud-hosted%20service%20that%20connects%20your%20data%20to%20AI) |
| **Azure Communication Services**<br>Azure 通信服务 | "Azure Communication Services offers **multichannel communication APIs** for **adding voice, video, chat, text messaging/SMS, email, and more** to all your applications." | Azure 通信服务提供**多渠道通信 API**，用于向你的所有应用程序**添加语音、视频、聊天、短信/SMS、电子邮件等功能**。 | [Microsoft, 2024, para. 1](https://learn.microsoft.com/en-us/azure/communication-services/overview#:~:text=offers%20multichannel%20communication%20APIs) |
| **Azure Maps**<br>Azure 地图 | "Azure Maps is a **collection of geospatial services and SDKs** that use fresh mapping data to **provide geographic context to web and mobile applications**." | Azure 地图是**地理空间服务和 SDK 的集合**，它们使用最新的地图数据，**为 Web 和移动应用程序提供地理上下文**。 | [Microsoft, 2026c, para. 1](https://learn.microsoft.com/en-us/azure/azure-maps/about-azure-maps#:~:text=is%20a%20collection%20of%20geospatial%20services%20and%20SDKs) |
| **Microsoft Foundry**<br>Microsoft Foundry | "Microsoft Foundry **unifies agents, models, and tools** under a **single management grouping** with built-in enterprise-readiness capabilities including tracing, monitoring, evaluations, and customizable enterprise setup configurations." | Microsoft Foundry 把**智能体、模型和工具统一**在**单个管理分组**下，并内置企业就绪功能，包括跟踪、监视、评估和可自定义的企业设置配置。 | [Microsoft, 2026d, para. 1](https://learn.microsoft.com/en-us/azure/ai-foundry/what-is-foundry#:~:text=unifies%20agents%2C%20models%2C%20and%20tools) |
| **Notification Hubs**<br>通知中心 | "Azure Notification Hubs provides an easy-to-use and scaled-out **push engine** that enables you to **send notifications to any platform** (iOS, Android, Windows, etc.) **from any back-end** (cloud or on-premises)." | Azure 通知中心提供一个易于使用、可横向扩展的**推送引擎**，让你可以**从任意后端**（云或本地）**向任意平台**（iOS、Android、Windows 等）**发送通知**。 | [Microsoft, 2025d, para. 1](https://learn.microsoft.com/en-us/azure/notification-hubs/notification-hubs-push-notification-overview#:~:text=provides%20an%20easy-to-use%20and%20scaled-out%20push%20engine) |
| **Visual Studio App Center**<br>Visual Studio 应用中心 | "Visual Studio App Center **brings together multiple common services** into a **DevOps cloud solution**." | Visual Studio App Center 把**多种常用服务整合**到一个 **DevOps 云解决方案**中。 | [Microsoft, 2025a, para. 1](https://learn.microsoft.com/en-us/appcenter/dashboard/#:~:text=brings%20together%20multiple%20common%20services%20into%20a%20DevOps%20cloud%20solution) |
