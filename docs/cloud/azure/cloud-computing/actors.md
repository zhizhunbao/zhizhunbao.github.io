# 1.3 Actors

Sources: [NIST SP 500-292, NIST Cloud Computing Reference Architecture](https://doi.org/10.6028/NIST.SP.500-292).

## Classification

![Actors sorted into five groups: cloud consumer (SaaS, PaaS and IaaS consumers), cloud provider (service deployment, service orchestration, cloud service management, security, privacy), cloud auditor (security controls, privacy impact, performance), cloud broker (service intermediation, service aggregation, service arbitrage) and cloud carrier (network and telecommunication carriers, transport agent).](media/actors.png)

## Glossary

| Term | Definition | 中文解释 | Source |
|---|---|---|---|
| **Actors**<br>参与者 | "... the NIST cloud computing reference architecture defines **five major actors**: cloud consumer, cloud provider, cloud carrier, cloud auditor and cloud broker. Each actor is an **entity (a person or an organization)** that **participates in a transaction or process** and/or performs tasks in cloud computing." | ……NIST 云计算参考架构定义了**五个主要参与者**：云使用者、云提供者、云运营商、云审计者和云代理。每个参与者都是一个**实体（个人或组织）**，它**参与事务或流程**，和/或在云计算中执行任务。 | [Liu et al., 2011, Section 2.1, para. 2](https://doi.org/10.6028/NIST.SP.500-292) |
| **Cloud consumer**<br>云使用者 | "A cloud consumer represents a **person or organization** that **maintains a business relationship with**, and **uses the service from** a cloud provider." | 云使用者是一个**个人或组织**，它与云提供者**保持业务关系**，并**使用其服务**。 | [Liu et al., 2011, Section 2.2, para. 1](https://doi.org/10.6028/NIST.SP.500-292) |
| **SaaS consumers**<br>SaaS 使用者 | "The consumers of SaaS can be **organizations** that provide their members with access to software applications, **end users** who directly use software applications, or **software application administrators** who configure applications for end users." | SaaS 的使用者可以是为成员提供软件应用程序访问权限的**组织**、直接使用软件应用程序的**最终用户**，或为最终用户配置应用程序的**软件应用程序管理员**。 | [Liu et al., 2011, Section 2.2, para. 4](https://doi.org/10.6028/NIST.SP.500-292) |
| **PaaS consumers**<br>PaaS 使用者 | "Cloud consumers of PaaS can employ the **tools and execution resources** provided by cloud providers to **develop, test, deploy and manage the applications** hosted in a cloud environment." | PaaS 的云使用者可以利用云提供者提供的**工具和执行资源**，来**开发、测试、部署和管理应用程序**（这些应用程序托管在云环境中）。 | [Liu et al., 2011, Section 2.2, para. 5](https://doi.org/10.6028/NIST.SP.500-292) |
| **IaaS consumers**<br>IaaS 使用者 | "Consumers of IaaS have access to **virtual computers, network-accessible storage, network infrastructure components**, and other **fundamental computing resources** on which they can **deploy and run arbitrary software**." | IaaS 的使用者可以访问**虚拟计算机、可通过网络访问的存储、网络基础结构组件**以及其他**基本计算资源**，并在其上**部署和运行任意软件**。 | [Liu et al., 2011, Section 2.2, para. 6](https://doi.org/10.6028/NIST.SP.500-292) |
| **Cloud provider**<br>云提供者 | "A cloud provider is a person, an organization; it is the **entity responsible for making a service available** to **interested parties**." | 云提供者是一个人或一个组织；它是**负责提供服务的实体**，服务对象是**相关方**。 | [Liu et al., 2011, Section 2.3, para. 1](https://doi.org/10.6028/NIST.SP.500-292) |
| **Service deployment**<br>服务部署 | (context) "As identified in the NIST cloud computing definition [1], a cloud infrastructure may be operated in one of the following **deployment models**: public cloud, private cloud, community cloud, or hybrid cloud." | （语境）正如 NIST 云计算定义 [1] 所指出的，云基础结构可以按以下**部署模型**之一运营：公有云、私有云、社区云或混合云。 | [Liu et al., 2011, Section 3.1, para. 1](https://doi.org/10.6028/NIST.SP.500-292) |
| **Service orchestration**<br>服务编排 | "Service Orchestration refers to the **composition of system components** to support the Cloud Providers activities in **arrangement, coordination and management of computing resources** in order to **provide cloud services** to Cloud Consumers." | 服务编排是指**系统组件的组合**，用来支持云提供者在**计算资源的安排、协调和管理**方面的活动，以便向云使用者**提供云服务**。 | [Liu et al., 2011, Section 3.2, para. 1](https://doi.org/10.6028/NIST.SP.500-292) |
| **Cloud service management**<br>云服务管理 | "Cloud Service Management includes **all of the service-related functions** that are necessary for the **management and operation** of those services required by or proposed to cloud consumers." | 云服务管理包括**所有与服务相关的功能**，这些功能是云使用者所需或向其提议的服务的**管理和运营**所必需的。 | [Liu et al., 2011, Section 3.3, para. 1](https://doi.org/10.6028/NIST.SP.500-292) |
| **Security**<br>安全 | "It is critical to recognize that security is a **cross-cutting aspect** of the architecture that **spans across all layers** of the reference model, ranging from **physical security to application security**." | 必须认识到，安全是架构的一个**横切方面**，它**贯穿参考模型的所有层**，从**物理安全到应用程序安全**。 | [Liu et al., 2011, Section 3.4, para. 1](https://doi.org/10.6028/NIST.SP.500-292) |
| **Privacy**<br>隐私 | (context) "Cloud providers should **protect** the assured, proper, and consistent collection, processing, communication, use and disposition of **personal information (PI)** and **personally identifiable information (PII)** in the cloud [14]." | （语境）云提供者应当**保护**云中**个人信息 (PI)** 和**个人身份信息 (PII)** 的收集、处理、通信、使用和处置，使其有保障、恰当且一致。 | [Liu et al., 2011, Section 3.5, para. 1](https://doi.org/10.6028/NIST.SP.500-292) |
| **Cloud auditor**<br>云审计者 | "A cloud auditor is a party that can perform an **independent examination of cloud service controls** with the intent to **express an opinion** thereon." | 云审计者是一方，它能够对**云服务控制措施进行独立检查**，目的是对其**发表意见**。 | [Liu et al., 2011, Section 2.4, para. 1](https://doi.org/10.6028/NIST.SP.500-292) |
| **Security controls**<br>安全控制措施 | "Security controls [3] are the **management, operational, and technical safeguards or countermeasures** employed within an organizational information system to **protect the confidentiality, integrity, and availability** of the system and its information." | 安全控制措施 [3] 是组织的信息系统中采用的**管理、运营和技术保护措施或对策**，用于**保护机密性、完整性和可用性**，对象是系统及其信息。 | [Liu et al., 2011, Section 2.4, para. 2](https://doi.org/10.6028/NIST.SP.500-292) |
| **Privacy impact**<br>隐私影响 | "A **privacy impact audit** can help Federal agencies **comply with applicable privacy laws and regulations** governing an individuals privacy, and to ensure **confidentiality, integrity, and availability** of an individuals **personal information** at every stage of development and operation." | **隐私影响审计**可以帮助联邦机构**遵守适用的隐私法律法规**（这些法律法规管理个人隐私），并在开发和运营的每个阶段确保**机密性、完整性和可用性**，对象是个人的**个人信息**。 | [Liu et al., 2011, Section 2.4, para. 3](https://doi.org/10.6028/NIST.SP.500-292) |
| **Performance**<br>性能 | (context) "A cloud auditor can **evaluate the services** provided by a cloud provider in terms of security controls, privacy impact, **performance**, etc." | （语境）云审计者可以**评估云提供者所提供的服务**，评估方面包括安全控制措施、隐私影响、**性能**等。 | [Liu et al., 2011, Section 2.4, para. 1](https://doi.org/10.6028/NIST.SP.500-292) |
| **Cloud broker**<br>云代理 | "A cloud broker is an entity that **manages the use, performance and delivery of cloud services** and **negotiates relationships** between cloud providers and cloud consumers." | 云代理是一个实体，它**管理云服务的使用、性能和交付**，并在云提供者和云使用者之间**协商关系**。 | [Liu et al., 2011, Section 2.5, para. 1](https://doi.org/10.6028/NIST.SP.500-292) |
| **Service intermediation**<br>服务中介 | "Service Intermediation: A cloud broker **enhances a given service** by **improving some specific capability** and providing **value-added services** to cloud consumers." | 服务中介：云代理**增强某项服务**，方法是**改进某些特定能力**并向云使用者提供**增值服务**。 | [Liu et al., 2011, Section 2.5, list item 1](https://doi.org/10.6028/NIST.SP.500-292) |
| **Service aggregation**<br>服务聚合 | "Service Aggregation: A cloud broker **combines and integrates multiple services** into **one or more new services**." | 服务聚合：云代理把**多个服务组合并集成**为**一个或多个新服务**。 | [Liu et al., 2011, Section 2.5, list item 2](https://doi.org/10.6028/NIST.SP.500-292) |
| **Service arbitrage**<br>服务套利 | "Service Arbitrage: Service arbitrage is **similar to service aggregation** except that the services being aggregated are **not fixed**." | 服务套利：服务套利**与服务聚合类似**，区别在于被聚合的服务**不是固定的**。 | [Liu et al., 2011, Section 2.5, list item 3](https://doi.org/10.6028/NIST.SP.500-292) |
| **Cloud carrier**<br>云运营商 | "A cloud carrier acts as an **intermediary** that provides **connectivity and transport of cloud services** between cloud consumers and cloud providers." | 云运营商充当**中介**，在云使用者和云提供者之间提供**云服务的连接和传输**。 | [Liu et al., 2011, Section 2.6, para. 1](https://doi.org/10.6028/NIST.SP.500-292) |
| **Network and telecommunication carriers**<br>网络和电信运营商 | (context) "The **distribution of cloud services** is normally provided by **network and telecommunication carriers** or a transport agent [8] ..." | （语境）**云服务的分发**通常由**网络和电信运营商**或传输代理 [8] 提供…… | [Liu et al., 2011, Section 2.6, para. 1](https://doi.org/10.6028/NIST.SP.500-292) |
| **Transport agent**<br>传输代理 | "... a transport agent refers to a **business organization** that provides **physical transport of storage media** such as high-capacity hard drives." | ……传输代理是指一个**商业组织**，它提供**存储介质的实体运输**，例如大容量硬盘。 | [Liu et al., 2011, Section 2.6, para. 1](https://doi.org/10.6028/NIST.SP.500-292) |
