| **Reservations**<br>预留 | "Reservations are best for **stable, predictable workloads**. You **commit to specific resource capacity for a one-year or three-year term**, and Azure applies **discounted pricing to matching usage**." | 预留最适合**稳定、可预测的工作负载**。你**承诺在一年或三年期限内使用特定的资源容量**，Azure 则对**匹配的用量应用折扣价格**。 | [Microsoft, n.d.-a, "Reservations" section, para. 1](https://learn.microsoft.com/en-us/training/modules/describe-cost-management-azure/7a-describe-cost-optimization-options#:~:text=Reservations%20are%20best%20for%20stable%2C%20predictable%20workloads) |
| **Azure savings plan for compute**<br>Azure 计算节省计划 | "Azure savings plan for compute is another **commitment-based option for compute services**. Instead of committing to a specific VM family or instance type, you **commit to an hourly spend amount for one or three years**, and savings are applied to eligible compute usage." | Azure 计算节省计划是另一种**基于承诺的计算服务选项**。你不是承诺某个特定的 VM 系列或实例类型，而是**承诺一年或三年内每小时的支出金额**，节省会应用到符合条件的计算用量上。 | [Microsoft, n.d.-a, "Azure savings plan for compute" section, para. 1](https://learn.microsoft.com/en-us/training/modules/describe-cost-management-azure/7a-describe-cost-optimization-options#:~:text=Azure%20savings%20plan%20for%20compute%20is%20another%20commitment%2Dbased%20option) |
| **Spot pricing**<br>现成定价 | "Spot Virtual Machines use **unused Azure capacity at reduced prices**. Spot is most appropriate for **interruptible workloads** because Azure can **reclaim that capacity when needed**." | 现成虚拟机以**更低的价格使用 Azure 未使用的容量**。现成定价最适合**可中断的工作负载**，因为 Azure 可以**在需要时收回这些容量**。 | [Microsoft, n.d.-a, "Spot pricing" section, para. 1](https://learn.microsoft.com/en-us/training/modules/describe-cost-management-azure/7a-describe-cost-optimization-options#:~:text=Spot%20Virtual%20Machines%20use%20unused%20Azure%20capacity%20at%20reduced%20prices) |
| **Azure Hybrid Benefit**<br>Azure 混合权益 | "Azure Hybrid Benefit an Azure **discount** that helps you to **significantly reduce the costs of running your workloads in the cloud**. It works by letting you **use your on-premises Software Assurance or subscription-enabled Windows Server and SQL Server licenses on Azure**." | Azure 混合权益是一种 Azure **折扣**，帮助你**大幅降低在云中运行工作负载的成本**。它的做法是让你**在 Azure 上使用本地带 Software Assurance 或已启用订阅的 Windows Server 和 SQL Server 许可证**。 | [Microsoft, 2026b, para. 1](https://learn.microsoft.com/en-us/azure/cost-management-billing/scope-level/overview-azure-hybrid-benefit-scope#:~:text=Azure%20Hybrid%20Benefit%20an%20Azure%20discount%20that%20helps%20you) |
