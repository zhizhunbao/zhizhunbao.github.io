Management groups, subscriptions and resource groups are 2.2 Management infrastructure. Total cost of ownership (taught in CST8913 and CST8912) is H3 inside 20.1.1 Factors that affect costs. Azure Monitor also appears in 5. Networking (7.5); it is defined here (20.4.3).

Product rows in 20.1, 20.3 and 20.4 quote each product's own documentation (2026-10-27). "Factors that affect costs" and "Cost optimization options" are AZ-900 unit topics with no product page, so those two rows quote the units as context.

The sub-terms of 20.1.3 (Cost Analysis, Budgets, Exports) and 20.1.5 (Reservations, Azure savings plan for compute, Spot pricing, Azure Hybrid Benefit) were added on 2026-11-03 for CST8913 W9 (Pricing and costing). The three Cost Management features quote their own Learn pages; the three pricing options quote the AZ-900 unit "Describe cost optimization options in Azure", which defines them; Azure Hybrid Benefit is not in that unit, so it quotes the Cost Management page that defines it. The W9 slides also list the retired Cloud Adoption Framework page "Best practices for costing and sizing resources hosted in Azure" (tagging, licensing alignment, right-sizing, shutting down unused resources, horizontal over vertical scale, auto-shutdown, orphaned disks, right-size redundancy, autoscale parameters); no current official page lists them, so they are not boxed here.
