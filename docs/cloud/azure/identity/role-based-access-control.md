# 17.5 Role-Based Access Control

## Classification

![Role-based access control, 6 terms: Security principal, Role definition, Scope, Role assignment, Azure roles (Owner, Contributor, Reader, Role Based Access Control Administrator, User Access Administrator), Microsoft Entra roles (Global Administrator, User Administrator, Billing Administrator).](media/role-based-access-control.png)

## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **Security principal**<br>安全主体 | "A security principal is an **object that represents a user, group, service principal, or managed identity** that is **requesting access to Azure resources**." | 安全主体是一个**代表用户、组、服务主体或托管标识的对象**，该对象**正在请求访问 Azure 资源**。 | [Microsoft, 2024, "Security principal" section, para. 1](https://learn.microsoft.com/en-us/azure/role-based-access-control/overview#:~:text=is%20an%20object%20that%20represents%20a%20user%2C%20group%2C%20service%20principal%2C%20or%20managed%20identity) |
| **Role definition**<br>角色定义 | "A role definition is a **collection of permissions**." | 角色定义是**权限的集合**。 | [Microsoft, 2024, "Role definition" section, para. 1](https://learn.microsoft.com/en-us/azure/role-based-access-control/overview#:~:text=is%20a%20collection%20of%20permissions) |
| **Scope**<br>作用域 | "Scope is the **set of resources** that the **access applies to**." | 作用域是**资源集合**，即**访问权限所适用的**范围。 | [Microsoft, 2024, "Scope" section, para. 1](https://learn.microsoft.com/en-us/azure/role-based-access-control/overview#:~:text=is%20the%20set%20of%20resources%20that%20the%20access%20applies%20to) |
| **Role assignment**<br>角色分配 | "A role assignment is the process of **attaching a role definition** to a user, group, service principal, or managed identity **at a particular scope** for the purpose of **granting access**." | 角色分配是把**角色定义附加**到用户、组、服务主体或托管标识上、范围是**特定作用域**、以**授予访问权限**的过程。 | [Microsoft, 2024, "Role assignments" section, para. 1](https://learn.microsoft.com/en-us/azure/role-based-access-control/overview#:~:text=is%20the%20process%20of%20attaching%20a%20role%20definition) |
| **Azure roles**<br>Azure 角色 | "**Azure roles control permissions** to **manage Azure resources**" | **Azure 角色控制权限**，用于**管理 Azure 资源** | [Microsoft, 2026, "Differences between Azure roles and Microsoft Entra roles" section, para. 1](https://learn.microsoft.com/en-us/azure/role-based-access-control/rbac-and-directory-admin-roles#:~:text=Azure%20roles%20control%20permissions%20to%20manage%20Azure%20resources) |
| **Owner**<br>所有者<br>(retired August 31, 2024: Service Administrator, Co-Administrator; [Microsoft, 2026, "Classic subscription administrator roles" section, para. 1](https://learn.microsoft.com/en-us/azure/role-based-access-control/rbac-and-directory-admin-roles#:~:text=Azure%20classic%20administrator%20roles)) | "**Grants full access** to manage all resources"; "**Assign roles** in Azure RBAC" | **授予完全访问权限**，以管理所有资源；在 Azure RBAC 中**分配角色** | [Microsoft, 2026, "Azure roles" section, table, Owner row](https://learn.microsoft.com/en-us/azure/role-based-access-control/rbac-and-directory-admin-roles#:~:text=Grants%20full%20access%20to%20manage%20all%20resources) |
| **Contributor**<br>参与者 | "**Grants full access** to manage all resources"; "**Can't assign roles** in Azure RBAC"; "Can't manage assignments in Azure Blueprints or share image galleries" | **授予完全访问权限**，以管理所有资源；在 Azure RBAC 中**不能分配角色**；不能管理 Azure Blueprints 中的分配，也不能共享映像库 | [Microsoft, 2026, "Azure roles" section, table, Contributor row](https://learn.microsoft.com/en-us/azure/role-based-access-control/rbac-and-directory-admin-roles#:~:text=Can%27t%20assign%20roles%20in%20Azure%20RBAC) |
| **Reader**<br>读者 | "**View** Azure resources"; "Applies to **all resource types**" | **查看** Azure 资源；适用于**所有资源类型** | [Microsoft, 2026, "Azure roles" section, table, Reader row](https://learn.microsoft.com/en-us/azure/role-based-access-control/rbac-and-directory-admin-roles#:~:text=View%20Azure%20resources) |
| **Role Based Access Control Administrator**<br>基于角色的访问控制管理员 | "**Manage user access** to Azure resources"; "Assign roles in Azure RBAC"; "Assign themselves or others the Owner role"; "**Can't manage access using other ways**, such as Azure Policy" | **管理用户访问** Azure 资源；在 Azure RBAC 中分配角色；给自己或他人分配所有者角色；**不能用其他方式管理访问**，例如 Azure Policy | [Microsoft, 2026, "Azure roles" section, table, Role Based Access Control Administrator row](https://learn.microsoft.com/en-us/azure/role-based-access-control/rbac-and-directory-admin-roles#:~:text=Can%27t%20manage%20access%20using%20other%20ways) |
| **User Access Administrator**<br>用户访问管理员 | "The **User Access Administrator role** enables the user to **grant other users access** to Azure resources." | **用户访问管理员角色**让用户能够**授予其他用户访问** Azure 资源的权限。 | [Microsoft, 2026, "Do Azure roles and Microsoft Entra roles overlap?" subsection, para. 1](https://learn.microsoft.com/en-us/azure/role-based-access-control/rbac-and-directory-admin-roles#:~:text=The%20User%20Access%20Administrator%20role%20enables) |
| **Microsoft Entra roles**<br>Microsoft Entra 角色 | "**Microsoft Entra roles** are used to **manage Microsoft Entra resources in a directory** such as create or edit users, assign administrative roles to others, reset user passwords, manage user licenses, and manage domains." | **Microsoft Entra 角色**用于**管理目录中的 Microsoft Entra 资源**，例如创建或编辑用户、给他人分配管理角色、重置用户密码、管理用户许可证和管理域。 | [Microsoft, 2026, "Microsoft Entra roles" section, para. 1](https://learn.microsoft.com/en-us/azure/role-based-access-control/rbac-and-directory-admin-roles#:~:text=are%20used%20to%20manage%20Microsoft%20Entra%20resources) |
| **Global Administrator**<br>全局管理员 | "**Manage access to all administrative features** in Microsoft Entra ID, as well as services that federate to Microsoft Entra ID"; "Assign administrator roles to others"; "**Reset the password** for any user and all other administrators" | **管理所有管理功能的访问**（范围是 Microsoft Entra ID 以及与其联合的服务）；给他人分配管理员角色；**重置密码**（任何用户和所有其他管理员） | [Microsoft, 2026, "Microsoft Entra roles" section, table, Global Administrator row](https://learn.microsoft.com/en-us/azure/role-based-access-control/rbac-and-directory-admin-roles#:~:text=Manage%20access%20to%20all%20administrative%20features) |
| **User Administrator**<br>用户管理员 | "**Create and manage all aspects of users and groups**"; "Manage support tickets"; "Monitor service health"; "**Change passwords** for users, Helpdesk administrators, and other User Administrators" | **创建和管理用户和组的各个方面**；管理支持工单；监视服务运行状况；**更改密码**（用户、支持人员管理员和其他用户管理员） | [Microsoft, 2026, "Microsoft Entra roles" section, table, User Administrator row](https://learn.microsoft.com/en-us/azure/role-based-access-control/rbac-and-directory-admin-roles#:~:text=Create%20and%20manage%20all%20aspects%20of%20users%20and%20groups) |
| **Billing Administrator**<br>计费管理员 | "**Make purchases**"; "**Manage subscriptions**"; "Manage support tickets"; "Monitors service health" | **进行购买**；**管理订阅**；管理支持工单；监视服务运行状况 | [Microsoft, 2026, "Microsoft Entra roles" section, table, Billing Administrator row](https://learn.microsoft.com/en-us/azure/role-based-access-control/rbac-and-directory-admin-roles#:~:text=Make%20purchases) |
