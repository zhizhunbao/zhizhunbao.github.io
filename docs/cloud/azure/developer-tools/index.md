| **Azure DevTest Labs**<br>Azure 开发测试实验室 | "Azure DevTest Labs is a service that enables developers and testers to **quickly create and manage Azure virtual machines** **for development and testing**." | Azure 开发测试实验室是一项服务，让开发人员和测试人员可以**快速创建和管理 Azure 虚拟机**，**用于开发和测试**。 | [Microsoft, 2025c, para. 1](https://learn.microsoft.com/en-us/azure/devtest-labs/devtest-lab-overview#:~:text=enables%20developers%20and%20testers%20to%20quickly%20create%20and%20manage) |
| **Azure Pipelines**<br>Azure 管道 | "Azure Pipelines is the part of Azure DevOps that combines **continuous integration, continuous testing, and continuous delivery** to **automatically build, test, and deploy code projects** to any destination." | Azure Pipelines 是 Azure DevOps 的一部分，它结合**持续集成、持续测试和持续交付**，**自动构建、测试和部署代码项目**到任何目标。 | [Microsoft, 2026c, para. 1](https://learn.microsoft.com/en-us/azure/devops/pipelines/get-started/what-is-azure-pipelines?view=azure-devops#:~:text=is%20the%20part%20of%20Azure%20DevOps%20that%20combines) |
| **Microsoft Dev Box**<br>Microsoft 开发箱 | "Microsoft Dev Box gives developers **self-service access** to **ready-to-code cloud workstations** called dev boxes." | Microsoft Dev Box 为开发人员提供**自助访问**，可以使用称为 dev box 的**随时可编码的云工作站**。 | [Microsoft, 2026d, para. 1](https://learn.microsoft.com/en-us/azure/dev-box/overview-what-is-microsoft-dev-box#:~:text=gives%20developers%20self-service%20access%20to%20ready-to-code) |
| **Microsoft Playwright Testing (Preview)**<br>Microsoft Playwright Testing（预览版） | "Playwright Workspaces is a **fully managed cloud browser platform** for **testing applications**, automating browser workflows, and powering AI agents through browser interactions." | Playwright Workspaces 是一个**完全托管的云浏览器平台**，用于**测试应用程序**、自动化浏览器工作流，以及通过浏览器交互为 AI 智能体提供支持。 | [Microsoft, 2026e, para. 1](https://learn.microsoft.com/en-us/azure/app-testing/playwright-workspaces/overview-what-is-microsoft-playwright-workspaces#:~:text=is%20a%20fully%20managed%20cloud%20browser%20platform) |
| **Visual Studio**<br>Visual Studio | "Visual Studio is a powerful **integrated development environment (IDE)** for Windows where you can **develop, build, debug, test, and deploy your apps**, all in one place." | Visual Studio 是一个功能强大的 Windows **集成开发环境（IDE）**，你可以在同一个地方**开发、构建、调试、测试和部署你的应用**。 | [Microsoft, 2026f, para. 1](https://learn.microsoft.com/en-us/visualstudio/get-started/visual-studio-ide?view=visualstudio#:~:text=is%20a%20powerful%20integrated%20development%20environment) |
| **Visual Studio Code**<br>Visual Studio Code | "Visual Studio Code combines the **simplicity of a source code editor** with **powerful developer tooling**, like IntelliSense code completion and debugging." | Visual Studio Code 把**源代码编辑器的简洁**和**强大的开发者工具**结合在一起，例如 IntelliSense 代码补全和调试。 | [Microsoft, n.d.-b, para. 1](https://code.visualstudio.com/docs/editor/whyvscode#:~:text=combines%20the%20simplicity%20of%20a%20source%20code%20editor) |
