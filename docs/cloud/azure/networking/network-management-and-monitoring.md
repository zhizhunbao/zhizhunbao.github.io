| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **Azure Network Watcher**<br>Azure 网络观察程序 | "Azure Network Watcher provides tools to **monitor, diagnose, view metrics, and enable or disable logs** for **resources in an Azure virtual network**." | Azure 网络观察程序提供工具，用于**监视、诊断、查看指标以及启用或禁用日志**，对象是 **Azure 虚拟网络中的资源**。 | [Microsoft, 2026, "Azure Network Watcher" section, para. 1](https://learn.microsoft.com/en-us/azure/networking/fundamentals/networking-overview#:~:text=provides%20tools%20to%20monitor%2C%20diagnose%2C%20view%20metrics) |
| **Azure Monitor**<br>Azure Monitor | "Azure Monitor **maximizes the availability and performance of your applications** by delivering a comprehensive solution for **collecting, analyzing, and acting on telemetry** from your cloud and on-premises environments." | Azure Monitor **最大限度地提高应用程序的可用性和性能**，方法是提供一个全面的解决方案，用于**收集、分析来自云和本地环境的遥测数据并据此采取行动**。 | [Microsoft, 2026, "Azure Monitor" section, para. 1](https://learn.microsoft.com/en-us/azure/networking/fundamentals/networking-overview#:~:text=maximizes%20the%20availability%20and%20performance%20of%20your%20applications) |
