# 8.3 Focus Navigation

## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **8.3 Focus Navigation**<br>焦点导航 | "An implementing host language MUST provide support for the author to **make all interactive elements focusable**, that is, any renderable or event-receiving elements." | 实现方宿主语言必须支持作者**使所有交互元素可聚焦**，即任何可呈现或接收事件的元素。 | [World Wide Web Consortium, 2023, section 8.3](https://www.w3.org/TR/wai-aria-1.2/) |
