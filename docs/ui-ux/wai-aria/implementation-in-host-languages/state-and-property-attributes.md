# 8.2 State and Property Attributes

## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **8.2 State and Property Attributes**<br>状态和属性的 attribute | (context) "The attribute name is the **name of any state or property** identified in the Supported States and Properties section, such as aria-busy, aria-selected, aria-activedescendant, aria-valuetext;" | （语境）属性名是“支持的状态和属性”一节中标识的**任何状态或属性的名称**，例如 aria-busy、aria-selected、aria-activedescendant、aria-valuetext； | [World Wide Web Consortium, 2023, section 8.2](https://www.w3.org/TR/wai-aria-1.2/) |
