|---|---|---|---|
| **6.7 Definitions of States and Properties (All aria-\* Attributes)**<br>状态和属性的定义（所有 aria-* 属性） | "Below is an **alphabetical list of WAI-ARIA states and properties** to be used by rich internet application authors." | 下面是供富互联网应用作者使用的 **WAI-ARIA 状态和属性的字母顺序列表**。 | [World Wide Web Consortium, 2023, section 6.7](https://www.w3.org/TR/wai-aria-1.2/) |
| **aria-activedescendant**<br>当前活动后代 | "Identifies the **currently active element** when DOM focus is on a composite widget, combobox, textbox, group, or application." | 当 DOM 焦点在复合控件、组合框、文本框、组或应用上时，标识**当前活动的元素**。 | [World Wide Web Consortium, 2023, section 6.7, aria-activedescendant](https://www.w3.org/TR/wai-aria-1.2/#aria-activedescendant) |
| **aria-atomic**<br>整体呈现 | "Indicates whether assistive technologies will present **all, or only parts of, the changed region** based on the change notifications defined by the aria-relevant attribute." | 指示辅助技术将根据 aria-relevant 属性定义的变化通知，呈现**整个变化区域还是只呈现其中一部分**。 | [World Wide Web Consortium, 2023, section 6.7, aria-atomic](https://www.w3.org/TR/wai-aria-1.2/#aria-atomic) |
| **aria-autocomplete**<br>自动补全 | "Indicates whether inputting text could **trigger display of one or more predictions** of the user's intended value for a combobox, searchbox, or textbox and specifies **how predictions would be presented** if they were made." | 指示在组合框、搜索框或文本框中输入文本是否会**触发显示一个或多个对用户意图值的预测**，并指定**预测将如何呈现**。 | [World Wide Web Consortium, 2023, section 6.7, aria-autocomplete](https://www.w3.org/TR/wai-aria-1.2/#aria-autocomplete) |
| **aria-busy**<br>忙碌 | "Indicates an element is **being modified** and that assistive technologies MAY want to **wait until the modifications are complete** before exposing them to the user." | 指示元素**正在被修改**，辅助技术可以**等修改完成后**再向用户公开。 | [World Wide Web Consortium, 2023, section 6.7, aria-busy](https://www.w3.org/TR/wai-aria-1.2/#aria-busy) |
| **aria-checked**<br>选中状态 | "Indicates the current "**checked**" state of checkboxes, radio buttons, and other widgets." | 指示复选框、单选按钮和其他控件当前的“**选中**”状态。 | [World Wide Web Consortium, 2023, section 6.7, aria-checked](https://www.w3.org/TR/wai-aria-1.2/#aria-checked) |
| **aria-colcount**<br>列总数 | "Defines the **total number of columns** in a table, grid, or treegrid." | 定义表格、网格或树形网格中的**列总数**。 | [World Wide Web Consortium, 2023, section 6.7, aria-colcount](https://www.w3.org/TR/wai-aria-1.2/#aria-colcount) |
| **aria-colindex**<br>列索引 | "Defines an element's **column index or position** with respect to the total number of columns within a table, grid, or treegrid." | 定义元素相对于表格、网格或树形网格列总数的**列索引或位置**。 | [World Wide Web Consortium, 2023, section 6.7, aria-colindex](https://www.w3.org/TR/wai-aria-1.2/#aria-colindex) |
| **aria-colspan**<br>跨列数 | "Defines the **number of columns spanned by a cell or gridcell** within a table, grid, or treegrid." | 定义表格、网格或树形网格中**单元格或网格单元格所跨的列数**。 | [World Wide Web Consortium, 2023, section 6.7, aria-colspan](https://www.w3.org/TR/wai-aria-1.2/#aria-colspan) |
| **aria-controls**<br>控制对象 | "Identifies the element (or elements) whose **contents or presence are controlled by the current element**." | 标识**内容或存在由当前元素控制**的元素。 | [World Wide Web Consortium, 2023, section 6.7, aria-controls](https://www.w3.org/TR/wai-aria-1.2/#aria-controls) |
| **aria-current**<br>当前项 | "Indicates the element that represents the **current item within a container or set of related elements**." | 指示代表**容器或一组相关元素中的当前项**的元素。 | [World Wide Web Consortium, 2023, section 6.7, aria-current](https://www.w3.org/TR/wai-aria-1.2/#aria-current) |
| **aria-describedby**<br>描述来源 | "Identifies the element (or elements) that **describes the object**." | 标识**描述该对象**的元素。 | [World Wide Web Consortium, 2023, section 6.7, aria-describedby](https://www.w3.org/TR/wai-aria-1.2/#aria-describedby) |
| **aria-details**<br>详细描述来源 | "Identifies the element that provides a **detailed, extended description** for the object." | 标识为该对象提供**详细、扩展描述**的元素。 | [World Wide Web Consortium, 2023, section 6.7, aria-details](https://www.w3.org/TR/wai-aria-1.2/#aria-details) |
| **aria-disabled**<br>禁用 | "Indicates that the element is **perceivable but disabled**, so it is **not editable or otherwise operable**." | 指示元素**可感知但已禁用**，因此**不可编辑或以其他方式操作**。 | [World Wide Web Consortium, 2023, section 6.7, aria-disabled](https://www.w3.org/TR/wai-aria-1.2/#aria-disabled) |
| **aria-dropeffect**<br>放置效果 | "[Deprecated in ARIA 1.1] Indicates **what functions can be performed when a dragged object is released on the drop target**." | [在 ARIA 1.1 中已弃用] 指示**被拖动的对象释放到放置目标上时可以执行哪些功能**。 | [World Wide Web Consortium, 2023, section 6.7, aria-dropeffect](https://www.w3.org/TR/wai-aria-1.2/#aria-dropeffect) |
| **aria-errormessage**<br>错误消息来源 | "Identifies the element that provides an **error message for an object**." | 标识为对象提供**错误消息**的元素。 | [World Wide Web Consortium, 2023, section 6.7, aria-errormessage](https://www.w3.org/TR/wai-aria-1.2/#aria-errormessage) |
| **aria-expanded**<br>展开状态 | "Indicates whether a **grouping element owned or controlled by this element** is **expanded or collapsed**." | 指示**此元素拥有或控制的分组元素**是**展开还是折叠**。 | [World Wide Web Consortium, 2023, section 6.7, aria-expanded](https://www.w3.org/TR/wai-aria-1.2/#aria-expanded) |
| **aria-flowto**<br>阅读流向 | "Identifies the next element (or elements) in an **alternate reading order of content** which, at the user's discretion, allows assistive technology to override the general default of reading in document source order." | 标识**替代阅读顺序**中的下一个元素，由用户决定，让辅助技术可以不按文档源顺序朗读的默认方式。 | [World Wide Web Consortium, 2023, section 6.7, aria-flowto](https://www.w3.org/TR/wai-aria-1.2/#aria-flowto) |
| **aria-grabbed**<br>抓取状态 | "[Deprecated in ARIA 1.1] Indicates an element's "**grabbed**" state in a drag-and-drop operation." | [在 ARIA 1.1 中已弃用] 指示元素在拖放操作中的“**被抓取**”状态。 | [World Wide Web Consortium, 2023, section 6.7, aria-grabbed](https://www.w3.org/TR/wai-aria-1.2/#aria-grabbed) |
| **aria-haspopup**<br>有弹出层 | "Indicates the **availability and type of interactive popup element**, such as menu or dialog, that can be triggered by an element." | 指示元素可以触发的**交互式弹出元素是否存在及其类型**，例如菜单或对话框。 | [World Wide Web Consortium, 2023, section 6.7, aria-haspopup](https://www.w3.org/TR/wai-aria-1.2/#aria-haspopup) |
| **aria-hidden**<br>隐藏 | "Indicates whether the element is **exposed to an accessibility API**." | 指示元素是否**向无障碍 API 公开**。 | [World Wide Web Consortium, 2023, section 6.7, aria-hidden](https://www.w3.org/TR/wai-aria-1.2/#aria-hidden) |
| **aria-invalid**<br>无效 | "Indicates the entered value **does not conform to the format expected by the application**." | 指示输入的值**不符合应用所期望的格式**。 | [World Wide Web Consortium, 2023, section 6.7, aria-invalid](https://www.w3.org/TR/wai-aria-1.2/#aria-invalid) |
| **aria-keyshortcuts**<br>键盘快捷键 | "Indicates **keyboard shortcuts** that an author has implemented to **activate or give focus to an element**." | 指示作者实现的、用来**激活元素或使其获得焦点**的**键盘快捷键**。 | [World Wide Web Consortium, 2023, section 6.7, aria-keyshortcuts](https://www.w3.org/TR/wai-aria-1.2/#aria-keyshortcuts) |
| **aria-label**<br>标签 | "Defines a **string value that labels the current element**." | 定义**标注当前元素的字符串值**。 | [World Wide Web Consortium, 2023, section 6.7, aria-label](https://www.w3.org/TR/wai-aria-1.2/#aria-label) |
| **aria-labelledby**<br>标签来源 | "Identifies the element (or elements) that **labels the current element**." | 标识**标注当前元素**的元素。 | [World Wide Web Consortium, 2023, section 6.7, aria-labelledby](https://www.w3.org/TR/wai-aria-1.2/#aria-labelledby) |
| **aria-level**<br>层级 | "Defines the **hierarchical level of an element within a structure**." | 定义**元素在结构中的层级**。 | [World Wide Web Consortium, 2023, section 6.7, aria-level](https://www.w3.org/TR/wai-aria-1.2/#aria-level) |
| **aria-live**<br>实时 | "Indicates that an element **will be updated**, and describes the **types of updates** the user agents, assistive technologies, and user can expect from the live region." | 指示元素**将会更新**，并描述用户代理、辅助技术和用户可以从该实时区域预期的**更新类型**。 | [World Wide Web Consortium, 2023, section 6.7, aria-live](https://www.w3.org/TR/wai-aria-1.2/#aria-live) |
| **aria-modal**<br>模态 | "Indicates whether an element is **modal when displayed**." | 指示元素在**显示时是否为模态**。 | [World Wide Web Consortium, 2023, section 6.7, aria-modal](https://www.w3.org/TR/wai-aria-1.2/#aria-modal) |
| **aria-multiline**<br>多行 | "Indicates whether a text box accepts **multiple lines of input or only a single line**." | 指示文本框接受**多行输入还是只接受单行**。 | [World Wide Web Consortium, 2023, section 6.7, aria-multiline](https://www.w3.org/TR/wai-aria-1.2/#aria-multiline) |
| **aria-multiselectable**<br>可多选 | "Indicates that the user may **select more than one item** from the current selectable descendants." | 指示用户可以从当前可选的后代中**选择多于一项**。 | [World Wide Web Consortium, 2023, section 6.7, aria-multiselectable](https://www.w3.org/TR/wai-aria-1.2/#aria-multiselectable) |
| **aria-orientation**<br>方向 | "Indicates whether the element's orientation is **horizontal, vertical, or unknown/ambiguous**." | 指示元素的方向是**水平、垂直，还是未知/不明确**。 | [World Wide Web Consortium, 2023, section 6.7, aria-orientation](https://www.w3.org/TR/wai-aria-1.2/#aria-orientation) |
| **aria-owns**<br>拥有对象 | "Identifies an element (or elements) in order to define a **visual, functional, or contextual parent/child relationship** between DOM elements where the DOM hierarchy cannot be used to represent the relationship." | 标识元素，以在 DOM 层次无法表示该关系时，定义 DOM 元素之间**视觉上、功能上或上下文上的父子关系**。 | [World Wide Web Consortium, 2023, section 6.7, aria-owns](https://www.w3.org/TR/wai-aria-1.2/#aria-owns) |
| **aria-placeholder**<br>占位提示 | "Defines a **short hint** (a word or short phrase) intended to **aid the user with data entry** when the control has no value." | 定义一个**简短提示**（一个词或短语），在控件没有值时**帮助用户输入数据**。 | [World Wide Web Consortium, 2023, section 6.7, aria-placeholder](https://www.w3.org/TR/wai-aria-1.2/#aria-placeholder) |
| **aria-posinset**<br>集合中的位置 | "Defines an element's **number or position in the current set** of listitems or treeitems." | 定义元素在当前列表项或树项**集合中的序号或位置**。 | [World Wide Web Consortium, 2023, section 6.7, aria-posinset](https://www.w3.org/TR/wai-aria-1.2/#aria-posinset) |
| **aria-pressed**<br>按下状态 | "Indicates the current "**pressed**" state of **toggle buttons**." | 指示**切换按钮**当前的“**按下**”状态。 | [World Wide Web Consortium, 2023, section 6.7, aria-pressed](https://www.w3.org/TR/wai-aria-1.2/#aria-pressed) |
| **aria-readonly**<br>只读 | "Indicates that the element is **not editable, but is otherwise operable**." | 指示元素**不可编辑，但其他方面可操作**。 | [World Wide Web Consortium, 2023, section 6.7, aria-readonly](https://www.w3.org/TR/wai-aria-1.2/#aria-readonly) |
| **aria-relevant**<br>相关变化 | "Indicates **what notifications the user agent will trigger** when the accessibility tree within a live region is modified." | 指示实时区域内的无障碍树被修改时，**用户代理将触发哪些通知**。 | [World Wide Web Consortium, 2023, section 6.7, aria-relevant](https://www.w3.org/TR/wai-aria-1.2/#aria-relevant) |
| **aria-required**<br>必填 | "Indicates that **user input is required** on the element before a form may be submitted." | 指示在表单可以提交之前，该元素上**需要用户输入**。 | [World Wide Web Consortium, 2023, section 6.7, aria-required](https://www.w3.org/TR/wai-aria-1.2/#aria-required) |
| **aria-roledescription**<br>角色描述 | "Defines a **human-readable, author-localized description for the role** of an element." | 定义元素**角色的人类可读、由作者本地化的描述**。 | [World Wide Web Consortium, 2023, section 6.7, aria-roledescription](https://www.w3.org/TR/wai-aria-1.2/#aria-roledescription) |
| **aria-rowcount**<br>行总数 | "Defines the **total number of rows** in a table, grid, or treegrid." | 定义表格、网格或树形网格中的**行总数**。 | [World Wide Web Consortium, 2023, section 6.7, aria-rowcount](https://www.w3.org/TR/wai-aria-1.2/#aria-rowcount) |
| **aria-rowindex**<br>行索引 | "Defines an element's **row index or position** with respect to the total number of rows within a table, grid, or treegrid." | 定义元素相对于表格、网格或树形网格行总数的**行索引或位置**。 | [World Wide Web Consortium, 2023, section 6.7, aria-rowindex](https://www.w3.org/TR/wai-aria-1.2/#aria-rowindex) |
| **aria-rowspan**<br>跨行数 | "Defines the **number of rows spanned by a cell or gridcell** within a table, grid, or treegrid." | 定义表格、网格或树形网格中**单元格或网格单元格所跨的行数**。 | [World Wide Web Consortium, 2023, section 6.7, aria-rowspan](https://www.w3.org/TR/wai-aria-1.2/#aria-rowspan) |
| **aria-selected**<br>选定状态 | "Indicates the current "**selected**" state of **various widgets**." | 指示**各种控件**当前的“**选定**”状态。 | [World Wide Web Consortium, 2023, section 6.7, aria-selected](https://www.w3.org/TR/wai-aria-1.2/#aria-selected) |
| **aria-setsize**<br>集合大小 | "Defines the **number of items in the current set** of listitems or treeitems." | 定义当前列表项或树项**集合中的项目数**。 | [World Wide Web Consortium, 2023, section 6.7, aria-setsize](https://www.w3.org/TR/wai-aria-1.2/#aria-setsize) |
| **aria-sort**<br>排序 | "Indicates if items in a table or grid are **sorted in ascending or descending order**." | 指示表格或网格中的项目是**按升序还是降序排序**。 | [World Wide Web Consortium, 2023, section 6.7, aria-sort](https://www.w3.org/TR/wai-aria-1.2/#aria-sort) |
| **aria-valuemax**<br>最大值 | "Defines the **maximum allowed value** for a range widget." | 定义范围控件**允许的最大值**。 | [World Wide Web Consortium, 2023, section 6.7, aria-valuemax](https://www.w3.org/TR/wai-aria-1.2/#aria-valuemax) |
| **aria-valuemin**<br>最小值 | "Defines the **minimum allowed value** for a range widget." | 定义范围控件**允许的最小值**。 | [World Wide Web Consortium, 2023, section 6.7, aria-valuemin](https://www.w3.org/TR/wai-aria-1.2/#aria-valuemin) |
| **aria-valuenow**<br>当前值 | "Defines the **current value** for a range widget." | 定义范围控件的**当前值**。 | [World Wide Web Consortium, 2023, section 6.7, aria-valuenow](https://www.w3.org/TR/wai-aria-1.2/#aria-valuenow) |
| **aria-valuetext**<br>值的文本 | "Defines the **human readable text alternative of aria-valuenow** for a range widget." | 定义范围控件 **aria-valuenow 的人类可读文本替代**。 | [World Wide Web Consortium, 2023, section 6.7, aria-valuetext](https://www.w3.org/TR/wai-aria-1.2/#aria-valuetext) |
