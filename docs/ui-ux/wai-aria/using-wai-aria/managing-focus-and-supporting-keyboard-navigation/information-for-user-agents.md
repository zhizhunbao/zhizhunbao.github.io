# 4.3.2 Information for User Agents

| **4.3.2 Information for User Agents**<br>给用户代理的信息 | (context) "Implement the host language method for keyboard navigation so that **widgets that support aria-activedescendant may be included in the tab order**." | （语境）实现宿主语言的键盘导航方法，使**支持 aria-activedescendant 的控件可以进入 Tab 顺序**。 | [World Wide Web Consortium, 2023, section 4.3.2](https://www.w3.org/TR/wai-aria-1.2/) |
