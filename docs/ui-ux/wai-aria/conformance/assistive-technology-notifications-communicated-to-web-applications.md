# 3.3 Assistive Technology Notifications Communicated to Web Applications

## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **3.3 Assistive Technology Notifications Communicated to Web Applications**<br>传达给 Web 应用的辅助技术通知 | "Assistive technologies, such as speech recognition systems and alternate input devices for users with mobility impairments, require the ability to **control a web application in a device-independent way**." | 辅助技术（例如语音识别系统和供行动障碍用户使用的替代输入设备）需要能够**以与设备无关的方式控制 Web 应用**。 | [World Wide Web Consortium, 2023, section 3.3](https://www.w3.org/TR/wai-aria-1.2/) |
