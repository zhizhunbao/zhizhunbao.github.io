# 3.1 Non-interference with the Host Language

## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **3.1 Non-interference with the Host Language**<br>不干扰宿主语言 | "WAI-ARIA processing by the user agent MUST NOT **interfere with the normal operation of the built-in features of the host language**." | 用户代理对 WAI-ARIA 的处理不得**干扰宿主语言内置特性的正常运作**。 | [World Wide Web Consortium, 2023, section 3.1](https://www.w3.org/TR/wai-aria-1.2/) |
