# 5.2.8 Accessible Name Calculation

## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **5.2.8 Accessible Name Calculation**<br>可访问名称计算 | (context) "author: **name comes from values provided by the author** in explicit markup features such as the aria-label attribute, the aria-labelledby attribute, or the host language labeling mechanism, such as the alt or title attributes in HTML, with HTML title attribute having the lowest precedence for specifying a text alternative." | （语境）author：**名称来自作者提供的值**，通过显式标记特性给出，例如 aria-label 属性、aria-labelledby 属性，或宿主语言的标注机制（如 HTML 的 alt 或 title 属性），其中 HTML 的 title 属性在指定文本替代时优先级最低。 | [World Wide Web Consortium, 2023, section 5.2.8](https://www.w3.org/TR/wai-aria-1.2/) |
