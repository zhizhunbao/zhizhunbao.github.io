# 1.5.1 Authoring Tools

## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **1.5.1 Authoring Tools**<br>编写工具 | "To assist authors who are creating custom widgets, **authoring tools may compare widget roles, states, and properties** to those supported in WAI-ARIA as well as those supported in related and cross-referenced roles, states, and properties." | 为了帮助创建自定义控件的作者，**编写工具可以把控件的角色、状态和属性**与 WAI-ARIA 支持的，以及相关和交叉引用的角色、状态和属性所支持的进行比较。 | [World Wide Web Consortium, 2023, section 1.5.1](https://www.w3.org/TR/wai-aria-1.2/) |
