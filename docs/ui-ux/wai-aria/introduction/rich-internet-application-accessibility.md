# 1.1 Rich Internet Application Accessibility

## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **1.1 Rich Internet Application Accessibility**<br>富互联网应用无障碍 | "The incorporation of WAI-ARIA is a way for an author to **provide proper semantics for custom widgets** to make these widgets **accessible, usable, and interoperable with assistive technologies**." | 引入 WAI-ARIA 是作者**为自定义控件提供恰当语义**的一种方式，使这些控件**无障碍、可用，并能与辅助技术互操作**。 | [World Wide Web Consortium, 2023, section 1.1](https://www.w3.org/TR/wai-aria-1.2/) |
