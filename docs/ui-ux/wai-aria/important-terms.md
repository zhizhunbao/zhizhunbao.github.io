# 2. Important Terms

## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **2. Important Terms**<br>重要术语 | (context) "While some terms are defined in place, the following **definitions** are **used throughout this document**." | （语境）虽然有些术语就地定义，但下列**定义**，**在整份文档中通用**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Accessibility API**<br>无障碍 API | "Operating systems and other platforms provide a **set of interfaces** that **expose information about objects and events** to assistive technologies." | 操作系统和其他平台提供一组**接口**，它们向辅助技术**公开对象和事件的信息**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Accessibility Subtree**<br>无障碍子树 | "An **accessible object** in the accessibility tree and **its descendants** in that tree." | 无障碍树中的一个**可访问对象**，以及它在该树中的**后代**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Accessibility Tree**<br>无障碍树 | "**Tree of accessible objects** that **represents the structure of the user interface** (UI)." | **由可访问对象组成的树**，它**表示用户界面（UI）的结构**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Accessible Description**<br>可访问描述 | "An accessible description provides **additional information**, related to an interface element, that **complements the accessible name**." | 可访问描述提供与界面元素相关的**附加信息**，用来**补充可访问名称**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Accessible Name**<br>可访问名称 | "The accessible name is the **name of a user interface element**." | 可访问名称是**用户界面元素的名称**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Accessible object**<br>可访问对象 | "A **node in the accessibility tree** of a platform accessibility API." | 平台无障碍 API 的**无障碍树中的一个节点**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Activation behavior**<br>激活行为 | "The **action taken** when an event, typically initiated by users through an input device, causes an element to **fulfill a defined role**." | 当一个事件（通常由用户通过输入设备发起）使元素**履行既定角色**时**所采取的动作**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Assistive Technologies**<br>辅助技术 | "Hardware and/or software that: **relies on services provided by a user agent** to retrieve and render Web content **works with a user agent or web content itself** through the use of APIs, and **provides services beyond those offered by the user agent** to facilitate user interaction with web content by people with disabilities" | 满足以下条件的硬件和/或软件：**依靠用户代理提供的服务**来获取和呈现网络内容；通过 API **与用户代理或网络内容本身协同工作**；并**提供用户代理之外的服务**，以便利残障人士与网络内容交互 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Attribute**<br>属性（attribute） | "Attributes are **structural features added to elements** to provide **information about the states and properties** of the object represented by the element." | 属性是**添加到元素上的结构特征**，用来提供元素所代表对象的**状态和属性信息**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Class**<br>类 | "A **set of instance objects** that **share similar characteristics**." | 一组**实例对象**，它们**具有相似的特征**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Deprecated**<br>已弃用 | "A deprecated role, state, or property is one which has been **outdated by newer constructs or changed circumstances**, and which **may be removed in future versions** of the WAI-ARIA specification." | 已弃用的角色、状态或属性，是指**因新结构或情况变化而过时**，并**可能在未来版本中移除**的项，针对 WAI-ARIA 规范而言。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Desktop focus event**<br>桌面焦点事件 | "Event from/to the host operating system via the accessibility API, **notifying of a change of input focus**." | 通过无障碍 API 来自或发往宿主操作系统的事件，**通知输入焦点发生变化**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **DOMString**<br>DOM 字符串 | "**Sequence of 16-bit unsigned integers**, typically interpreted as **UTF-16 code units**." | **16 位无符号整数的序列**，通常解释为 **UTF-16 码元**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Element**<br>元素 | "Elements are the **structural elements in markup language** that **contains the data profile for objects**." | 元素是**标记语言中的结构元素**，它**包含对象的数据概况**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Event**<br>事件 | "A **programmatic message** used to **communicate discrete changes in the state of an object** to other objects in a computational system." | 一种**程序化消息**，用来向计算系统中的其他对象**传达对象状态的离散变化**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Expose**<br>公开 | "**Translated to platform-specific accessibility APIs** as defined in the Core Accessibility API Mappings." | 按 Core Accessibility API Mappings 的定义，**转换为特定平台的无障碍 API**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Graphical Document**<br>图形文档 | "A document containing **graphic representations** with **user-navigable parts**." | 一种文档，包含带有**用户可导航部分**的**图形表示**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Hidden**<br>隐藏 | "Indicates that the element is **not visible, perceivable, or interactive** to any user." | 表示该元素对任何用户都**不可见、不可感知、不可交互**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Informative**<br>信息性 | "Content provided for **information purposes** and **not required for conformance**." | 为**提供信息**而给出、**不是一致性所必需**的内容。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Keyboard Accessible**<br>键盘可访问 | "Accessible to the user using a **keyboard** or **assistive technologies that mimic keyboard input**, such as a sip and puff tube." | 用户可以通过**键盘**或**模拟键盘输入的辅助技术**（如吸吹管）访问。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Landmark**<br>地标 | "A **type of region on a page** to which the user may want **quick access**." | **页面上的一种区域**，用户可能希望**快速访问**它。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Live Region**<br>实时区域 | "Live regions are **perceivable regions of a web page** that are typically **updated as a result of an external event** when user focus may be elsewhere." | 实时区域是**网页中可感知的区域**，通常**因外部事件而更新**，此时用户焦点可能在别处。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Primary Content Element**<br>主要内容元素 | "An implementing host language's **primary content element**, such as the **body element in HTML**." | 实现方宿主语言的**主要内容元素**，例如 **HTML 中的 body 元素**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Managed State**<br>托管状态 | "Accessibility API state that is **controlled by the user agent**, such as **focus and selection**." | **由用户代理控制**的无障碍 API 状态，例如**焦点和选择**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Nemeth Braille**<br>Nemeth 盲文 | "The Nemeth Braille Code for Mathematics is a **braille code** for encoding **mathematical and scientific notation**." | Nemeth 数学盲文码是一种**盲文编码**，用来编码**数学和科学记号**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Node**<br>节点 | "**Basic type of object** in the **DOM tree or accessibility tree**." | **DOM 树或无障碍树**中**对象的基本类型**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Normative**<br>规范性 | "**Required for conformance**." | **一致性所必需**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Object**<br>对象 | "In the context of user interfaces, an **item in the perceptual user experience**, represented in markup languages by **one or more elements**, and **rendered by user agents**." | 在用户界面语境中，指**感知性用户体验中的一项**，在标记语言中由**一个或多个元素**表示，并**由用户代理呈现**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Ontology**<br>本体 | "A **description of the characteristics of classes** and **how they relate to each other**." | 对**类的特征**及其**相互关系**的描述。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Operable**<br>可操作 | "**Usable by users** in ways **they can control**." | **用户可以使用**，方式是**他们能够控制**的。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Owned Element**<br>从属元素 | "An 'owned element' is **any DOM descendant of the element**, **any element specified as a child via aria-owns**, or any DOM descendant of the owned child." | “从属元素”是**该元素的任何 DOM 后代**、**通过 aria-owns 指定为子元素的任何元素**，或该从属子元素的任何 DOM 后代。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Owning Element**<br>拥有元素 | "An 'owning element' is **any DOM ancestor of the element**, or **any element with an aria-owns attribute** which references the ID of the element." | “拥有元素”是**该元素的任何 DOM 祖先**，或**任何带 aria-owns 属性**并引用该元素 ID 的元素。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Perceivable**<br>可感知 | "**Presentable to users** in ways **they can sense**." | **可以呈现给用户**，方式是**他们能够感知**的。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Property**<br>属性（property） | "Attributes that are **essential to the nature of a given object**, or that **represent a data value** associated with the object." | **对给定对象的性质至关重要**，或**表示与对象相关的数据值**的属性（attribute）。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Relationship**<br>关系 | "A **connection between two distinct things**." | **两个不同事物之间的联系**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Role**<br>角色 | "**Main indicator of type**." | **类型的主要标识**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Root WAI-ARIA node**<br>WAI-ARIA 根节点 | "The **primary element** containing **non-metadata content**." | 包含**非元数据内容**的**主要元素**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Semantics**<br>语义 | "The **meaning of something as understood by a human**, defined in a way that **computers can process a representation of an object**, such as elements and attributes, and reliably represent the object in a way that various humans will achieve a mutually consistent understanding of the object." | **人所理解的事物含义**，其定义方式使**计算机能够处理对象的表示**（如元素和属性），并可靠地表示该对象，让不同的人对它达成一致的理解。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **State**<br>状态 | "A state is a **dynamic property** expressing characteristics of an object that **may change in response to user action or automated processes**." | 状态是一种**动态属性**，表达对象的特征，这些特征**可能因用户操作或自动过程而改变**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Sub-document**<br>子文档 | "A sub-document may contain **a document, an application or any widget** such as a calendar pulled in from another server." | 子文档可以包含**一个文档、一个应用或任何控件**，例如从另一台服务器拉取的日历。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Target Element**<br>目标元素 | "An element **specified in a WAI-ARIA relation**." | **在 WAI-ARIA 关系中指定**的元素。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Taxonomy**<br>分类法 | "A **hierarchical definition** of how the **characteristics of various classes relate to each other**, in which classes inherit the properties of superclasses in the hierarchy." | 一种**层次化定义**，说明**各个类的特征如何相互关联**，其中类继承层次结构中超类的属性。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Text node**<br>文本节点 | "Type of DOM node that **represents the textual content** of an attribute or an element." | 一种 DOM 节点，**表示属性或元素的文本内容**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Tooltip attribute**<br>工具提示属性 | "Any **host language attribute** that would result in a user agent **generating a tooltip** such as in response to a mouse hover in desktop user agents." | 任何**宿主语言属性**，它会使用户代理**生成工具提示**，例如在桌面用户代理中响应鼠标悬停。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Understandable**<br>可理解 | "**Presentable to users** in ways they can **construct an appropriate meaning**." | **可以呈现给用户**，方式使他们能够**建立恰当的含义**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Unicode Braille Patterns**<br>Unicode 盲文图案 | "In Unicode, braille is represented in a **block called Braille Patterns** (U+2800..U+28FF)." | 在 Unicode 中，盲文由**名为 Braille Patterns 的区块**（U+2800..U+28FF）表示。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **User Agent**<br>用户代理 | "Any software that **retrieves, renders and facilitates end user interaction** with Web content." | 任何**获取、呈现网络内容并便利最终用户与之交互**的软件。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Valid IDREF**<br>有效 IDREF | "A **reference to a target element** in the same document that has a **matching ID**" | 对同一文档中**具有匹配 ID** 的**目标元素的引用** | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
| **Widget**<br>控件 | "Discrete **user interface object** with which the user **can interact**." | 用户**可以与之交互**的独立**用户界面对象**。 | [World Wide Web Consortium, 2023, section 2](https://www.w3.org/TR/wai-aria-1.2/) |
