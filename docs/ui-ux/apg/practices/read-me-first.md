# 2.1 Read Me First

## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **2.1 Read Me First**<br>请先阅读 | (No definition) | （无定义） | [W3C Web Accessibility Initiative, n.d., "Read Me First"](https://www.w3.org/WAI/ARIA/apg/practices/read-me-first/) |
| **No ARIA is better than Bad ARIA**<br>没有 ARIA 好过错误的 ARIA | "**Incorrect ARIA** misrepresents visual experiences, with **potentially devastating effects** on their corresponding non-visual experiences." | **错误的 ARIA** 歪曲视觉体验，并可能对相应的非视觉体验造成**毁灭性的影响**。 | [W3C Web Accessibility Initiative, n.d., "No ARIA is better than Bad ARIA"](https://www.w3.org/WAI/ARIA/apg/practices/read-me-first/#:~:text=Incorrect%20ARIA%20misrepresents) |
| **Principle 1: A role is a promise**<br>原则 1：角色是一个承诺 | "Is a promise that the author of that `<div>` has also **incorporated JavaScript** that provides the **keyboard interactions expected for a button**. Unlike HTML input elements, ARIA roles **do not cause browsers to provide** keyboard behaviors or styling." | 是一个承诺：该 `<div>` 的作者还**加入了 JavaScript**，用来提供**按钮应有的键盘交互**。与 HTML input 元素不同，ARIA 角色**不会让浏览器提供**键盘行为或样式。 | [W3C Web Accessibility Initiative, n.d., "Principle 1: A role is a promise"](https://www.w3.org/WAI/ARIA/apg/practices/read-me-first/#:~:text=Is%20a%20promise%20that) |
| **Principle 2: ARIA Can Both Cloak and Enhance, Creating Both Power and Danger**<br>原则 2：ARIA 既能遮盖也能增强，同时带来力量和危险 | (context) "From the perspective of assistive technologies, ARIA gives authors the ability to **dress up HTML and SVG elements** with **critical accessibility semantics** that the assistive technologies would not otherwise be able to reliably derive." | （语境）从辅助技术的角度看，ARIA 让作者能够用**关键的无障碍语义**来**装扮 HTML 和 SVG 元素**，否则辅助技术无法可靠地推断出这些语义。 | [W3C Web Accessibility Initiative, n.d., "Principle 2"](https://www.w3.org/WAI/ARIA/apg/practices/read-me-first/#:~:text=From%20the%20perspective%20of%20assistive) |
| **accessibility semantics**<br>无障碍语义 | "The information assistive technologies need about the **meaning and purpose** of user interface elements is called **accessibility semantics**." | 辅助技术所需要的、关于用户界面元素**含义和用途**的信息，称为**无障碍语义**。 | [W3C Web Accessibility Initiative, n.d., "Principle 2"](https://www.w3.org/WAI/ARIA/apg/practices/read-me-first/#:~:text=is%20called%20accessibility%20semantics) |
| **Cloak**<br>遮盖 | "Some of ARIA is like a cloak; it **covers up, or overrides**, the **original semantics or content**." | 有些 ARIA 像斗篷一样，会**遮盖或覆盖**掉**原有的语义或内容**。 | [W3C Web Accessibility Initiative, n.d., "Principle 2"](https://www.w3.org/WAI/ARIA/apg/practices/read-me-first/#:~:text=Some%20of%20ARIA%20is%20like%20a%20cloak) |
| **Enhance**<br>增强 | "On the other hand, some uses of ARIA are more like suspenders or belts; they **add meaning** that provides **essential support** to the original content." | 另一方面，有些 ARIA 用法更像背带或腰带，它们**增加含义**，为原有内容提供**必要的支持**。 | [W3C Web Accessibility Initiative, n.d., "Principle 2"](https://www.w3.org/WAI/ARIA/apg/practices/read-me-first/#:~:text=some%20uses%20of%20ARIA%20are%20more%20like) |
| **Power**<br>力量 | "It enables authors to **describe nearly any user interface component** in ways that **assistive technologies can reliably interpret**, thus making components accessible to assistive technology users." | 它让作者能够以**辅助技术可以可靠解读**的方式**描述几乎任何用户界面组件**，从而让辅助技术用户能够访问这些组件。 | [W3C Web Accessibility Initiative, n.d., "Principle 2"](https://www.w3.org/WAI/ARIA/apg/practices/read-me-first/#:~:text=It%20enables%20authors%20to%20describe) |
| **Danger**<br>危险 | "Authors can **inadvertently override** accessibility semantics." | 作者可能**无意中覆盖**无障碍语义。 | [W3C Web Accessibility Initiative, n.d., "Principle 2"](https://www.w3.org/WAI/ARIA/apg/practices/read-me-first/#:~:text=Authors%20can%20inadvertently%20override) |
