# 1. Patterns

Order: the APG Patterns page lists the patterns alphabetically, as an index. Here they go from simple to complex, with related patterns next to each other: basic controls (Button to Switch), value controls (Slider to Meter), selection (Listbox, Combobox), show and hide containers (Disclosure to Feed), menus and toolbars, dialogs and messages (Alert to Tooltip), page navigation and structure (Breadcrumb to Window Splitter), and data (Table to Treegrid). The groups only set the order; they are not a level of the menu.

| **[1.9 Meter](meter.md)**<br>计量器 | "A meter is a **graphical display** of a **numeric value** that varies within a defined range." | 计量器是一种**图形化显示**，展示一个在规定范围内变化的**数值**。 | [W3C Web Accessibility Initiative, n.d., "Meter"](https://www.w3.org/WAI/ARIA/apg/patterns/#:~:text=A%20meter%20is%20a%20graphical%20display) |
| **[1.10 Listbox](listbox.md)**<br>列表框 | "A listbox widget presents a **list of options** and allows a user to **select one or more** of them." | 列表框控件呈现一个**选项列表**，并允许用户**选择其中一个或多个**。 | [W3C Web Accessibility Initiative, n.d., "Listbox"](https://www.w3.org/WAI/ARIA/apg/patterns/#:~:text=A%20listbox%20widget%20presents) |
| **[1.11 Combobox](combobox.md)**<br>组合框 | "A combobox is an **input widget** that has an **associated popup**." | 组合框是一种**输入控件**，带有一个**关联的弹出层**。 | [W3C Web Accessibility Initiative, n.d., "Combobox"](https://www.w3.org/WAI/ARIA/apg/patterns/#:~:text=A%20combobox%20is%20an%20input%20widget) |
| **[1.12 Disclosure (Show/Hide)](disclosure.md)**<br>展开收起（显示/隐藏） | "A disclosure is a widget that enables content to be either **collapsed** (hidden) or **expanded** (visible)." | 展开收起控件让内容可以被**折叠**（隐藏）或**展开**（可见）。 | [W3C Web Accessibility Initiative, n.d., "Disclosure (Show/Hide)"](https://www.w3.org/WAI/ARIA/apg/patterns/#:~:text=A%20disclosure%20is%20a%20widget) |

| **[1.15 Carousel (Slide Show or Image Rotator)](carousel.md)**<br>轮播（幻灯片放映或图片轮换） | "A carousel presents a set of items, referred to as **slides**, by **sequentially displaying** a subset of one or more slides." | 轮播呈现一组称为**幻灯片**的项目，方式是**依次显示**其中一张或多张。 | [W3C Web Accessibility Initiative, n.d., "Carousel (Slide Show or Image Rotator)"](https://www.w3.org/WAI/ARIA/apg/patterns/#:~:text=A%20carousel%20presents%20a%20set) |
| **[1.16 Feed](feed.md)**<br>信息流 | "A feed is a section of a page that **automatically loads new sections** of content **as the user scrolls**." | 信息流是页面中的一个区域，它会**自动加载新的内容区块**，时机是**用户滚动时**。 | [W3C Web Accessibility Initiative, n.d., "Feed"](https://www.w3.org/WAI/ARIA/apg/patterns/#:~:text=A%20feed%20is%20a%20section) |
| **[1.17 Menu Button](menu-button.md)**<br>菜单按钮 | "A menu button is a **button that opens a menu** as described in the **Menu and Menubar Pattern**." | 菜单按钮是一个**打开菜单的按钮**，菜单的行为见**菜单与菜单栏模式**。 | [W3C Web Accessibility Initiative, n.d., "Menu Button"](https://www.w3.org/WAI/ARIA/apg/patterns/#:~:text=A%20menu%20button%20is%20a%20button) |
| **[1.18 Menu and Menubar](menubar.md)**<br>菜单与菜单栏 | "A menu is a widget that offers a **list of choices** to the user, such as a set of **actions or functions**." | 菜单是一种控件，向用户提供一个**选项列表**，例如一组**操作或功能**。 | [W3C Web Accessibility Initiative, n.d., "Menu and Menubar"](https://www.w3.org/WAI/ARIA/apg/patterns/#:~:text=A%20menu%20is%20a%20widget) |
| **[1.19 Toolbar](toolbar.md)**<br>工具栏 | "A toolbar is a **container for grouping a set of controls**, such as **buttons, menubuttons, or checkboxes**." | 工具栏是一个**用于组合一组控件的容器**，例如**按钮、菜单按钮或复选框**。 | [W3C Web Accessibility Initiative, n.d., "Toolbar"](https://www.w3.org/WAI/ARIA/apg/patterns/#:~:text=A%20toolbar%20is%20a%20container) |
| **[1.20 Alert](alert.md)**<br>警报 | "An alert is an element that displays a **brief, important message** in a way that attracts the user's attention **without interrupting the user's task**." | 警报是一种元素，它以吸引用户注意的方式显示一条**简短而重要的消息**，同时**不打断用户的任务**。 | [W3C Web Accessibility Initiative, n.d., "Alert"](https://www.w3.org/WAI/ARIA/apg/patterns/#:~:text=An%20alert%20is%20an%20element) |
| **[1.21 Alert and Message Dialogs](alertdialog.md)**<br>警报与消息对话框 | "An alert dialog is a **modal dialog** that **interrupts the user's workflow** to communicate an important message and acquire a response." | 警报对话框是一种**模态对话框**，它**打断用户的工作流程**，以传达重要消息并获取回应。 | [W3C Web Accessibility Initiative, n.d., "Alert and Message Dialogs"](https://www.w3.org/WAI/ARIA/apg/patterns/#:~:text=An%20alert%20dialog%20is%20a%20modal) |

| **[1.23 Tooltip](tooltip.md)**<br>工具提示 | "A tooltip is a **popup** that displays information related to an element when the element **receives keyboard focus** or the mouse hovers over it." | 工具提示是一种**弹出层**，当某个元素**获得键盘焦点**或鼠标悬停在其上时，显示与该元素相关的信息。 | [W3C Web Accessibility Initiative, n.d., "Tooltip"](https://www.w3.org/WAI/ARIA/apg/patterns/#:~:text=A%20tooltip%20is%20a%20popup) |
| **[1.24 Breadcrumb](breadcrumb.md)**<br>面包屑导航 | "A breadcrumb trail consists of a **list of links** to the **parent pages** of the current page in hierarchical order." | 面包屑导航由一个**链接列表**组成，按层级顺序指向当前页面的各级**父页面**。 | [W3C Web Accessibility Initiative, n.d., "Breadcrumb"](https://www.w3.org/WAI/ARIA/apg/patterns/#:~:text=A%20breadcrumb%20trail%20consists) |
| **[1.25 Landmarks](landmarks.md)**<br>地标 | "Landmarks are a set of **eight roles** that identify the **major sections** of a page." | 地标是一组**八个角色**，用来标识页面的**主要区域**。 | [W3C Web Accessibility Initiative, n.d., "Landmarks"](https://www.w3.org/WAI/ARIA/apg/patterns/#:~:text=Landmarks%20are%20a%20set%20of%20eight) |
| **[1.26 Window Splitter](windowsplitter.md)**<br>窗口分隔条 | "A window splitter is a **moveable separator** between two sections, or panes, of a window that enables users to **change the relative size** of the panes." | 窗口分隔条是窗口两个区域（窗格）之间的**可移动分隔条**，让用户能够**改变窗格的相对大小**。 | [W3C Web Accessibility Initiative, n.d., "Window Splitter"](https://www.w3.org/WAI/ARIA/apg/patterns/#:~:text=A%20window%20splitter%20is%20a%20moveable) |
| **[1.27 Table](table.md)**<br>表格 | "Like an HTML table element, a WAI-ARIA table is a **static tabular structure** containing one or more rows that each contain one or more cells; it is **not an interactive widget**." | 与 HTML table 元素一样，WAI-ARIA 表格是一种**静态的表格结构**，包含一行或多行，每行包含一个或多个单元格；它**不是交互式控件**。 | [W3C Web Accessibility Initiative, n.d., "Table"](https://www.w3.org/WAI/ARIA/apg/patterns/#:~:text=Like%20an%20HTML%20table%20element) |
| **[1.28 Grid (Interactive Tabular Data and Layout Containers)](grid.md)**<br>网格（交互式表格数据与布局容器） | "A grid widget is a container that enables users to **navigate the information** or interactive elements it contains using **directional navigation keys**, such as arrow keys, Home, and End." | 网格控件是一个容器，让用户能够**浏览其中的信息**或交互元素，方式是使用**方向导航键**，例如方向键、Home 和 End。 | [W3C Web Accessibility Initiative, n.d., "Grid (Interactive Tabular Data and Layout Containers)"](https://www.w3.org/WAI/ARIA/apg/patterns/#:~:text=A%20grid%20widget%20is%20a%20container) |
| **[1.29 Tree View](treeview.md)**<br>树视图 | "A **tree view widget** presents a **hierarchical list**." | **树视图控件**呈现一个**分层列表**。 | [W3C Web Accessibility Initiative, n.d., "Tree View"](https://www.w3.org/WAI/ARIA/apg/patterns/#:~:text=A%20tree%20view%20widget%20presents) |
| **[1.30 Treegrid](treegrid.md)**<br>树形网格 | "A treegrid widget presents a **hierarchical data grid** consisting of tabular information that is **editable or interactive**." | 树形网格控件呈现一个**分层的数据网格**，由**可编辑或可交互**的表格信息组成。 | [W3C Web Accessibility Initiative, n.d., "Treegrid"](https://www.w3.org/WAI/ARIA/apg/patterns/#:~:text=A%20treegrid%20widget%20presents) |
