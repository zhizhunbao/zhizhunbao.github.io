# 1. Patterns

Sources: [ARIA Authoring Practices Guide: Patterns](https://www.w3.org/WAI/ARIA/apg/patterns/).

Order: the APG Patterns page lists the patterns alphabetically, as an index. Here they go from simple to complex, with related patterns next to each other: basic controls (Button to Switch), value controls (Slider to Meter), selection (Listbox, Combobox), show and hide containers (Disclosure to Feed), menus and toolbars, dialogs and messages (Alert to Tooltip), page navigation and structure (Breadcrumb to Window Splitter), and data (Table to Treegrid). The groups only set the order; they are not a level of the menu.
