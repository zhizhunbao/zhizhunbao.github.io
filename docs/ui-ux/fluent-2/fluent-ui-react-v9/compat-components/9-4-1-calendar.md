# 9.4.1 Calendar

## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **Calendar**<br>日历 | "The calendar control lets people **select and view a single date** or **a range of dates** in their calendar." | 日历控件让人们在日历中**选择和查看单个日期**或**一段日期范围**。 | [Microsoft, n.d., "Calendar", para. 1](https://storybooks.fluentui.dev/react/?path=/docs/compat-components-calendar--docs) |
| **Month view**<br>月视图 | "made up of **3 separate views**: **the month view**, year view, and decade view" | 由 **3 个独立视图**组成：**月视图**、年视图和十年视图 | [Microsoft, n.d., "Calendar", para. 1](https://storybooks.fluentui.dev/react/?path=/docs/compat-components-calendar--docs) |
| **Year view**<br>年视图 | "made up of **3 separate views**: the month view, **year view**, and decade view" | 由 **3 个独立视图**组成：月视图、**年视图**和十年视图 | [Microsoft, n.d., "Calendar", para. 1](https://storybooks.fluentui.dev/react/?path=/docs/compat-components-calendar--docs) |
| **Decade view**<br>十年视图 | "made up of **3 separate views**: the month view, year view, and **decade view**" | 由 **3 个独立视图**组成：月视图、年视图和**十年视图** | [Microsoft, n.d., "Calendar", para. 1](https://storybooks.fluentui.dev/react/?path=/docs/compat-components-calendar--docs) |
| **Calendar Month Only**<br>仅月份日历 | "A Calendar Compat allows you to **only show the month and year picker** leaving **the day picker hidden**." | Calendar Compat 允许你**只显示月份和年份选择器**，而让**日期选择器隐藏**。 | [Microsoft, n.d., "Calendar", Stories, "Calendar Month Only"](https://storybooks.fluentui.dev/react/?path=/docs/compat-components-calendar--docs) |
| **Calendar Overlaid Month**<br>月份叠加日历 | "A Calendar Compat allows you to render **the month picker over the day picker**. This is useful when there are **width constraints** and the month picker is needed." | Calendar Compat 允许你把**月份选择器叠加在日期选择器之上**。当存在**宽度限制**又需要月份选择器时，这很有用。 | [Microsoft, n.d., "Calendar", Stories, "Calendar Overlaid Month"](https://storybooks.fluentui.dev/react/?path=/docs/compat-components-calendar--docs) |
| **Calendar Date Boundaries**<br>日期边界日历 | "A Calendar Compat can be modified to set **a minDate and maxDate** in order to **restrict the dates that can be selected**." | Calendar Compat 可以通过设置 **minDate 和 maxDate** 来**限制可选的日期**。 | [Microsoft, n.d., "Calendar", Stories, "Calendar Date Boundaries"](https://storybooks.fluentui.dev/react/?path=/docs/compat-components-calendar--docs) |
| **Calendar Six Weeks**<br>六周日历 | "A Calendar Compat allows you to **set a six week month**." | Calendar Compat 允许你**把一个月设为六周**。 | [Microsoft, n.d., "Calendar", Stories, "Calendar Six Weeks"](https://storybooks.fluentui.dev/react/?path=/docs/compat-components-calendar--docs) |
| **Calendar Week Numbers**<br>周数日历 | "A Calendar Compat allows you to **show the week numbers** next to **the day grid** for their respective week." | Calendar Compat 允许你**显示各周的周数**，位置在**日期网格**旁边。 | [Microsoft, n.d., "Calendar", Stories, "Calendar Week Numbers"](https://storybooks.fluentui.dev/react/?path=/docs/compat-components-calendar--docs) |
| **Calendar Week Selection**<br>按周选择日历 | "A Calendar Compat allows you to set **a selection range of weeks** instead of **selecting a single day**." | Calendar Compat 允许你设置**按周的选择范围**，而不是**只选单独一天**。 | [Microsoft, n.d., "Calendar", Stories, "Calendar Week Selection"](https://storybooks.fluentui.dev/react/?path=/docs/compat-components-calendar--docs) |
| **Calendar Marked Days**<br>标记日期日历 | "A Calendar Compat allows you to pass **a callback that returns an array of number** that should bemarked. This callback provides **a starting date and an ending date**." | Calendar Compat 允许你传入**一个回调，返回应被标记的数字数组**。这个回调会提供**开始日期和结束日期**。 | [Microsoft, n.d., "Calendar", Stories, "Calendar Marked Days"](https://storybooks.fluentui.dev/react/?path=/docs/compat-components-calendar--docs) |
| **Calendar Month Selection**<br>按月选择日历 | "A Calendar Compat allows you to set **a selection range of months** instead of **selecting a single day**." | Calendar Compat 允许你设置**按月的选择范围**，而不是**只选单独一天**。 | [Microsoft, n.d., "Calendar", Stories, "Calendar Month Selection"](https://storybooks.fluentui.dev/react/?path=/docs/compat-components-calendar--docs) |
| **Calendar Multiday Day View**<br>多日日视图日历 | "A Calendar Compat allows you to pass **a number of days** that will be **highlighted from the selected date and forward**." | Calendar Compat 允许你传入**一个天数**，**从所选日期起往后**的这些天会被高亮。 | [Microsoft, n.d., "Calendar", Stories, "Calendar Multiday Day View"](https://storybooks.fluentui.dev/react/?path=/docs/compat-components-calendar--docs) |
| **Calendar Contiguous Work Week Days**<br>连续工作周日历 | "A Calendar Compat can be modified to allow selecting **a contiguous (5 day) work week**." | Calendar Compat 可以修改为允许选择**一个连续的（5 天）工作周**。 | [Microsoft, n.d., "Calendar", Stories, "Calendar Contiguous Work Week Days"](https://storybooks.fluentui.dev/react/?path=/docs/compat-components-calendar--docs) |
| **Calendar Non Contiguous Work Week Days**<br>非连续工作周日历 | "A Calendar Compat can be modified to allow selecting **a non contiguous (7 day) week**." | Calendar Compat 可以修改为允许选择**一个非连续的（7 天）周**。 | [Microsoft, n.d., "Calendar", Stories, "Calendar Non Contiguous Work Week Days"](https://storybooks.fluentui.dev/react/?path=/docs/compat-components-calendar--docs) |
