# 9.4.2 DatePicker

## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **DatePicker**<br>日期选择器 | "A date picker (DatePicker) offers **a popup control** that’s optimized for **picking a single date from a calendar view** where contextual information like the day of the week or fullness of the calendar is important." | 日期选择器（DatePicker）提供**一个弹出控件**，专为**从日历视图中挑选单个日期**而优化，适用于星期几或日历繁忙程度等上下文信息很重要的场合。 | [Microsoft, n.d., "DatePicker", para. 1](https://storybooks.fluentui.dev/react/?path=/docs/compat-components-datepicker--docs) |
| **Text Input**<br>文本输入 | "A DatePicker **supports user input**. Clicking the input field will **open the DatePicker**, and clicking the field again will dismiss the DatePicker and allow text input." | DatePicker **支持用户输入**。点击输入框会**打开 DatePicker**，再次点击输入框会关闭 DatePicker 并允许输入文本。 | [Microsoft, n.d., "DatePicker", Stories, "Text Input"](https://storybooks.fluentui.dev/react/?path=/docs/compat-components-datepicker--docs) |
| **First Day Of The Week**<br>每周第一天 | "A DatePicker allows you to **set the first day of the week**." | DatePicker 允许你**设置每周的第一天**。 | [Microsoft, n.d., "DatePicker", Stories, "First Day Of The Week"](https://storybooks.fluentui.dev/react/?path=/docs/compat-components-datepicker--docs) |
| **Week Numbers**<br>周数 | "A DatePicker allows you to **show the number of the week** on the left when `showWeekNumbers` is **set to true**." | DatePicker 允许你在左侧**显示周数**，条件是 `showWeekNumbers` **设为 true**。 | [Microsoft, n.d., "DatePicker", Stories, "Week Numbers"](https://storybooks.fluentui.dev/react/?path=/docs/compat-components-datepicker--docs) |
| **Date Range**<br>日期范围 | "DatePicker allows you to **set the selection range type**. The range can be **`Day`, `Month`, `Week`, and `WorkWeek`**." | DatePicker 允许你**设置选择范围的类型**。范围可以是 **`Day`、`Month`、`Week` 和 `WorkWeek`**。 | [Microsoft, n.d., "DatePicker", Stories, "Date Range"](https://storybooks.fluentui.dev/react/?path=/docs/compat-components-datepicker--docs) |
| **Date Boundaries**<br>日期边界 | "A DatePicker allows **setting date boundaries**. To set a max boundary, use **the `maxDate` prop**." | DatePicker 允许**设置日期边界**。要设置最大边界，请使用 **`maxDate` 属性**。 | [Microsoft, n.d., "DatePicker", Stories, "Date Boundaries"](https://storybooks.fluentui.dev/react/?path=/docs/compat-components-datepicker--docs) |
| **Custom Date Formatting**<br>自定义日期格式 | "Applications can **customize how dates are formatted and parsed**. Formatted dates can be ambiguous, so **the control will avoid parsing the formatted strings** of dates selected using the UI when text input is allowed." | 应用程序可以**自定义日期的格式化和解析方式**。格式化后的日期可能有歧义，所以在允许文本输入时，**控件不会去解析通过界面选中的日期的格式化字符串**。 | [Microsoft, n.d., "DatePicker", Stories, "Custom Date Formatting"](https://storybooks.fluentui.dev/react/?path=/docs/compat-components-datepicker--docs) |
| **Localized**<br>本地化 | "DatePicker accepts **a `strings` prop** that allows **custom localization**." | DatePicker 接受**一个 `strings` 属性**，用来实现**自定义本地化**。 | [Microsoft, n.d., "DatePicker", Stories, "Localized"](https://storybooks.fluentui.dev/react/?path=/docs/compat-components-datepicker--docs) |
| **Error Handling**<br>错误处理 | (context) "To add error handling to a DatePicker, use **`onValidationResult`** along with **Field**." | （语境）要给 DatePicker 加上错误处理，请把 **`onValidationResult`** 与 **Field** 一起使用。 | [Microsoft, n.d., "DatePicker", Stories, "Error Handling"](https://storybooks.fluentui.dev/react/?path=/docs/compat-components-datepicker--docs) |
| **Controlled**<br>受控 | "A DatePicker can be controlled by **manually keeping track of the state** and **updating it**." | DatePicker 可以通过**手动跟踪状态**并**更新它**来实现受控。 | [Microsoft, n.d., "DatePicker", Stories, "Controlled"](https://storybooks.fluentui.dev/react/?path=/docs/compat-components-datepicker--docs) |
| **Required**<br>必填 | "DatePicker supports **required validation**. The validation will happen when **the DatePicker loses focus**." | DatePicker 支持**必填校验**。校验会在 **DatePicker 失去焦点**时进行。 | [Microsoft, n.d., "DatePicker", Stories, "Required"](https://storybooks.fluentui.dev/react/?path=/docs/compat-components-datepicker--docs) |
| **Disabled**<br>禁用 | "DatePicker can be disabled to **restrict user interaction**." | DatePicker 可以被禁用，以**限制用户交互**。 | [Microsoft, n.d., "DatePicker", Stories, "Disabled"](https://storybooks.fluentui.dev/react/?path=/docs/compat-components-datepicker--docs) |
