# 9.3.12 DataGrid

## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **DataGrid**<br>数据网格 | "This component is **a higher level extension** of the `Table` primitive components and **the `useTableFeatures` hook**." | 这个组件是**更高层的扩展**，扩展的是 `Table` 基本组件和 **`useTableFeatures` 钩子**。 | [Microsoft, n.d., "DataGrid", note](https://storybooks.fluentui.dev/react/?path=/docs/components-datagrid--docs) |
| **Sort**<br>排序 | (context) "To **enable sorting**, **the `sortable` prop** needs to be set." | （语境）要**启用排序**，需要设置 **`sortable` 属性**。 | [Microsoft, n.d., "DataGrid", Stories, "Sort"](https://storybooks.fluentui.dev/react/?path=/docs/components-datagrid--docs) |
| **Multiple Select**<br>多选 | (context) "In order to **enable this feature** the **`selectionMode` prop** needs to be set." | （语境）要**启用这一功能**，需要设置 **`selectionMode` 属性**。 | [Microsoft, n.d., "DataGrid", Stories, "Multiple Select"](https://storybooks.fluentui.dev/react/?path=/docs/components-datagrid--docs) |
| **Single Select**<br>单选 | (context) "To **enable selection**, **the `selectionMode` prop** needs to be set." | （语境）要**启用选择**，需要设置 **`selectionMode` 属性**。 | [Microsoft, n.d., "DataGrid", Stories, "Single Select"](https://storybooks.fluentui.dev/react/?path=/docs/components-datagrid--docs) |
| **Subtle Selection**<br>低调选择 | (context) "To **enable subtle selection mode**, **the `subtleSelection`** should be set." | （语境）要**启用低调选择模式**，应当设置 **`subtleSelection`**。 | [Microsoft, n.d., "DataGrid", Stories, "Subtle Selection"](https://storybooks.fluentui.dev/react/?path=/docs/components-datagrid--docs) |
| **Selection Appearance**<br>选中外观 | "The `selectionAppearance` prop will **vary the appearance of selected rows**. The default appearance is **a brand background color**." | `selectionAppearance` 属性会**改变选中行的外观**。默认外观是**品牌背景色**。 | [Microsoft, n.d., "DataGrid", Stories, "Selection Appearance"](https://storybooks.fluentui.dev/react/?path=/docs/components-datagrid--docs) |
| **Resizable Columns (preview)**<br>可调整宽度的列（预览） | (context) "Columns can be **made resizable** by passing **a prop `resizableColumns`**." | （语境）列可以**设为可调整宽度**，方法是传入 **`resizableColumns` 属性**。 | [Microsoft, n.d., "DataGrid", Stories, "Resizable Columns (preview)"](https://storybooks.fluentui.dev/react/?path=/docs/components-datagrid--docs) |
| **Virtualization**<br>虚拟化 | "Virtualizating the DataGrid component involves **recomposing components** to use **a virtualized container**." | 对 DataGrid 组件做虚拟化，需要**重新组合组件**，以使用**虚拟化容器**。 | [Microsoft, n.d., "DataGrid", Stories, "Virtualization"](https://storybooks.fluentui.dev/react/?path=/docs/components-datagrid--docs) |
| **Custom Row Id**<br>自定义行 ID | "By default row Ids are **the index of the item** in the collection. In order to use a row Id based on the data use **the `getRowId` prop**." | 默认情况下，行 ID 是**该项在集合中的索引**。要使用基于数据的行 ID，请使用 **`getRowId` 属性**。 | [Microsoft, n.d., "DataGrid", Stories, "Custom Row Id"](https://storybooks.fluentui.dev/react/?path=/docs/components-datagrid--docs) |
