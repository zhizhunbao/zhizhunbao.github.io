# 9.3.44 Table

## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **Table**<br>表格 | "A Table displays **sets of two-dimensional data**. The primitive components can be **fully customized** to support different feature sets." | 表格显示**成组的二维数据**。它的基本组件可以**完全自定义**，以支持不同的功能组合。 | [Microsoft, n.d., "Table", para. 1](https://storybooks.fluentui.dev/react/?path=/docs/components-table--docs) |
| **useTableFeatures**<br>useTableFeatures 钩子 | "The library provides **a default `useTableFeatures` hook** that handles **the business logic and state management** of common features." | 库提供了**一个默认的 `useTableFeatures` 钩子**，用来处理常用功能的**业务逻辑和状态管理**。 | [Microsoft, n.d., "Table", para. 1](https://storybooks.fluentui.dev/react/?path=/docs/components-table--docs) |
| **Non Native Elements**<br>非原生元素 | (context) "Using **the `noNativeElements` prop** will ensure that all components are **rendered as divs** while ensuring a layout experience similar to semantic table elements." | （语境）使用 **`noNativeElements` 属性**，可以让所有组件都**渲染为 div**，同时保证布局体验与语义化的表格元素相似。 | [Microsoft, n.d., "Table", Stories, "Non Native Elements"](https://storybooks.fluentui.dev/react/?path=/docs/components-table--docs) |
| **Cell Actions**<br>单元格操作 | "`TableCellActions` is **a container** that is visible when the `TableRow`is hovered or when **the current focused element is within the row**." | `TableCellActions` 是**一个容器**，在鼠标悬停于 `TableRow` 上、或**当前获得焦点的元素位于该行内**时可见。 | [Microsoft, n.d., "Table", Stories, "Cell Actions"](https://storybooks.fluentui.dev/react/?path=/docs/components-table--docs) |
| **Primary Cell**<br>主单元格 | "A primary cell **creates emphasis** by **increasing icon size and font weight** for the main text." | 主单元格**形成强调**的方式是**加大主文本的图标尺寸和字重**。 | [Microsoft, n.d., "Table", Stories, "Primary Cell"](https://storybooks.fluentui.dev/react/?path=/docs/components-table--docs) |
| **Cell Navigation**<br>单元格导航 | (context) "Cell navigation can be achieved simply using **the `useArrowNavigationGroup` utility** provided by **the Library**." | （语境）使用 **`useArrowNavigationGroup` 工具**就能简单地实现单元格导航，这个工具由**库**提供。 | [Microsoft, n.d., "Table", Stories, "Cell Navigation"](https://storybooks.fluentui.dev/react/?path=/docs/components-table--docs) |
| **Composite Navigation**<br>复合导航 | "Composite navigation **combines row focus and cell focus**. By default the user **navigates the table by row**." | 复合导航**结合了行焦点和单元格焦点**。默认情况下，用户**按行浏览表格**。 | [Microsoft, n.d., "Table", Stories, "Composite Navigation"](https://storybooks.fluentui.dev/react/?path=/docs/components-table--docs) |
| **Sort**<br>排序 | (context) "Using the `sortable` prop will configure **all header cells to be buttons** and **add extra styles**." | （语境）使用 `sortable` 属性，会把**所有表头单元格设置为按钮**，并**添加额外的样式**。 | [Microsoft, n.d., "Table", Stories, "Sort"](https://storybooks.fluentui.dev/react/?path=/docs/components-table--docs) |
| **Resizable Columns (preview)**<br>可调整宽度的列（预览） | (context) "The Table component contains **logic to support column resizing**. To enable resizing, use **the `useTableFeatures` hook** in combination with the `useTableColumnSizing_unstable` plugin." | （语境）Table 组件包含**支持调整列宽的逻辑**。要启用调整列宽，请把 **`useTableFeatures` 钩子**与 `useTableColumnSizing_unstable` 插件结合使用。 | [Microsoft, n.d., "Table", Stories, "Resizable Columns (preview)"](https://storybooks.fluentui.dev/react/?path=/docs/components-table--docs) |
| **Multiple Select**<br>多选 | (context) "Selection can be achieved easily by combining **the `TableSelectionCell` component** along with **other primitive components**." | （语境）把 **`TableSelectionCell` 组件**与**其他基本组件**组合起来，就能轻松实现选择。 | [Microsoft, n.d., "Table", Stories, "Multiple Select"](https://storybooks.fluentui.dev/react/?path=/docs/components-table--docs) |
| **Single Select**<br>单选 | (context) "The single selection scenario is **similar to the multiple selection scenario**." | （语境）单选场景**类似于多选场景**。 | [Microsoft, n.d., "Table", Stories, "Single Select"](https://storybooks.fluentui.dev/react/?path=/docs/components-table--docs) |
| **Subtle Selection**<br>低调选择 | (context) "By setting **the `subtle` prop** on the `TableSelectionCell` component, **the selection indicator will only appear** when:" | （语境）在 `TableSelectionCell` 组件上设置 **`subtle` 属性**后，**选择指示器只会在以下情况下出现**： | [Microsoft, n.d., "Table", Stories, "Subtle Selection"](https://storybooks.fluentui.dev/react/?path=/docs/components-table--docs) |
| **Virtualization**<br>虚拟化 | (context) "The `Table` primitive components are **unopinionated** with respect to **virtualization**." | （语境）`Table` 基本组件**不预设任何立场**，对**虚拟化**也是如此。 | [Microsoft, n.d., "Table", Stories, "Virtualization"](https://storybooks.fluentui.dev/react/?path=/docs/components-table--docs) |
| **Data Grid**<br>数据网格 | "The `DataGrid` component is **a composition of the `useTableFeatures` hook and primitive `Table` components** along with **some convenience features** such as accessible markup and event handlers." | `DataGrid` 组件是**由 `useTableFeatures` 钩子与 `Table` 基本组件构成的组合**，并带有**一些便利功能**，例如无障碍标记和事件处理程序。 | [Microsoft, n.d., "Table", Stories, "Data Grid"](https://storybooks.fluentui.dev/react/?path=/docs/components-table--docs) |
