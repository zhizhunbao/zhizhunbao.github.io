# 6.11 Dialog

## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **Dialog**<br>对话框 | "A dialog is **a supplemental surface** that can provide helpful interactions or **require someone to take an action** before they can continue their task, like confirming a deletion." | 对话框是**一个补充界面**，可以提供有用的交互，或**要求用户先做一个操作**才能继续手头的任务，比如确认删除。 | [Microsoft, n.d., "Dialog"](https://fluent2.microsoft.design/components/web/react/core/dialog/usage#:~:text=A%20dialog%20is%20a%20supplemental%20surface) |
| **Modal**<br>模态 | "A modal dialog **disables the page content behind it** and usually obscures or dims it to surface its content. Use it when someone needs to perform **a focused task**, like signing into an app." | 模态对话框会**让后面的页面内容不可操作**，通常还会遮住或调暗页面来突出自己的内容。当用户需要完成**一项专注的任务**时使用，比如登录应用。 | [Microsoft, n.d., "Dialog", Types](https://fluent2.microsoft.design/components/web/react/core/dialog/usage#:~:text=A%20modal%20dialog%20disables%20the%20page) |
| **Non-modal**<br>非模态 | "A non-modal dialog allows someone to **continue interacting with the page content** behind the window and aids in their workflow, like find and replace. Use it as **a helper in a task**." | 非模态对话框允许用户**继续操作窗口后面的页面内容**，辅助他们的工作流程，比如查找和替换。把它当作**任务中的助手**使用。 | [Microsoft, n.d., "Dialog", Types](https://fluent2.microsoft.design/components/web/react/core/dialog/usage#:~:text=A%20non-modal%20dialog%20allows%20someone%20to) |
| **Alert**<br>警告 | "An alert dialog is a modal that **requires someone to make a decision**. Alert dialogs have a special role that allows **assistive technologies** to treat them more urgently than other dialogs, like playing a system alert sound." | 警告对话框是一种**要求用户做出决定**的模态框。它有特殊的角色，让**辅助技术**比对待其他对话框更紧急地处理它，比如播放系统提示音。 | [Microsoft, n.d., "Dialog", Types](https://fluent2.microsoft.design/components/web/react/core/dialog/usage#:~:text=An%20alert%20dialog%20is%20a%20modal) |
| **Dismissal**<br>关闭方式 | (context) "Someone can dismiss a modal dialog by **selecting an area outside of the container**, using the Esc key, or **selecting a footer button**." | （语境）用户可以通过**点击容器外的区域**、按 Esc 键或**点击底部按钮**来关闭模态对话框。 | [Microsoft, n.d., "Dialog", Behavior](https://fluent2.microsoft.design/components/web/react/core/dialog/usage#:~:text=Someone%20can%20dismiss%20a%20modal%20dialog) |
| **Forms in dialogs**<br>对话框中的表单 | (context) "Fields can be placed in dialogs to **ask people for information** that’s related to **their current task**." | （语境）可以在对话框里放字段，**向用户收集信息**，且信息与**他们当前的任务**相关。 | [Microsoft, n.d., "Dialog", Behavior](https://fluent2.microsoft.design/components/web/react/core/dialog/usage#:~:text=Fields%20can%20be%20placed%20in%20dialogs) |
| **Header**<br>标题栏 | (context) "A header, which can contain **a title** and **a dismiss icon**" | （语境）标题栏，可以包含**标题**和**关闭图标** | [Microsoft, n.d., "Dialog", Layout](https://fluent2.microsoft.design/components/web/react/core/dialog/usage#:~:text=A%20header%2C%20which%20can%20contain%20a) |
| **Body**<br>正文 | (context) "Use the body content area for **additional info or instructions**, if needed. Don’t **restate the title** in the body." | （语境）需要时用正文区放**补充信息或说明**。不要在正文里**重复标题**。 | [Microsoft, n.d., "Dialog", Content](https://fluent2.microsoft.design/components/web/react/core/dialog/usage#:~:text=Use%20the%20body%20content%20area%20for) |
| **Footer**<br>底部 | (context) "**Optional footer**, which can contain **up to three actions**." | （语境）**可选的底部**，最多可以放**三个操作**。 | [Microsoft, n.d., "Dialog", Layout](https://fluent2.microsoft.design/components/web/react/core/dialog/usage#:~:text=Optional%20footer%2C%20which%20can%20contain%20up) |
| **Dialog focus**<br>对话框焦点 | (context) "When a dialog is opened, **keyboard focus** should go to **the first interactive element** within the container." | （语境）对话框打开时，**键盘焦点**应移到容器内**第一个可交互的元素**上。 | [Microsoft, n.d., "Dialog", Accessibility](https://fluent2.microsoft.design/components/web/react/core/dialog/usage#:~:text=When%20a%20dialog%20is%20opened%2C%20keyboard) |
