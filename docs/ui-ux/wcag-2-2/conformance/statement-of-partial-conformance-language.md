# 5.5 Statement of Partial Conformance - Language

## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **5.5 Statement of Partial Conformance - Language**<br>部分一致性声明：语言 | "A "statement of partial conformance due to language" **may be made when the page does not conform, but would conform if accessibility support existed** for (all of) the language(s) used on the page. The form of that statement would be, "This page does not conform, but would conform to WCAG 2.2 at level X if accessibility support existed for the following language(s):"" | “因语言而作的部分一致性声明”**可以在页面不符合、但如果页面所用（全部）语言有无障碍支持就会符合的情况下作出**。该声明的形式是：“本页面不符合，但如果下列语言有无障碍支持，就会在 X 级符合 WCAG 2.2：” | [World Wide Web Consortium, 2024, section 5.5](https://www.w3.org/TR/WCAG22/#conformance) |
