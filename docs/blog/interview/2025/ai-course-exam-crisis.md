# Interview: The AI Course Exam Crisis

The full story is in [The AI Course Exam Crisis](../../learning/2025/ai-course-exam-crisis.md).

## Interview Version

| Step | Description | 中文翻译 |
|---|---|---|
| **Problem** | In my AI program, the machine learning course was very hard. The exams were **on paper**, with math and handwritten definitions, and the material was huge: slides, labs and many long readings. After the midterm, the **class average was only about 50 to 60 percent**. This course is a prerequisite and only runs once a year, so failing it would cost a full year. | 在我的 AI 专业里，机器学习这门课非常难。考试是**纸笔考试**，有数学计算和手写定义，资料又非常多：课件、实验，还有大量很长的阅读材料。期中考试后，**全班平均分只有 50 到 60 分左右**。这门课是下学期的前置课，一年只开一次，挂科就要损失整整一年。 |
| **What I did** | The professor agreed to change the final to multiple choice, but the scope was still very large. So **I built a quiz system by myself**, using AI coding tools. It covered **all the course materials**, the key concepts and the formulas. I practised with it again and again, some topics more than five times. | 老师同意把期末改成选择题，但考试范围仍然很大。所以**我自己做了一个答题系统**，用的是 AI 编程工具。它覆盖了**全部课程资料**、重点概念和公式。我用它一遍又一遍地练，有些内容练了五遍以上。 |
| **Result** | In the end, **almost everyone in the class passed**. I learned that under pressure, **building the right tool** is better than just working harder. | 最后，**全班几乎所有人都通过了**。我学到的是：压力大的时候，**做出合适的工具**比单纯更努力更有效。 |
| **Answers** | Questions about **pressure**, a difficult challenge, problem solving and **using technology to solve a problem**. | 用来回答关于**压力**、困难挑战、解决问题，以及**用技术解决问题**的提问。 |
