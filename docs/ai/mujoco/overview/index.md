| **Reconfigurable computation pipeline**<br>可重新配置的计算流水线 | "To this end MuJoCo provides **a large number of flags which can be set in any combination, allowing the user to reconfigure the pipeline as needed**, beyond the selection of algorithms and algorithm parameters via options." | 为此 MuJoCo 提供了**大量可以任意组合设置的标志，让用户按需重新配置流水线**，这超出了通过选项选择算法和算法参数的范围。 | [Google DeepMind, n.d., "Key features", item 5](https://mujoco.readthedocs.io/en/stable/overview.html#key-features) |

| **MJCF**<br>MJCF | "As mentioned above, the user defines a MuJoCo model in **an XML file format called MJCF**." | 如上所述，用户用**一种名为 MJCF 的 XML 文件格式**定义 MuJoCo 模型。 | [Google DeepMind, n.d., "Key features", item 6](https://mujoco.readthedocs.io/en/stable/overview.html#key-features) |
| **MJB**<br>MJB | "The compiled model can also be saved in **a binary MJB file**." | 编译后的模型也可以保存为**二进制 MJB 文件**。 | [Google DeepMind, n.d., "Key features", item 6](https://mujoco.readthedocs.io/en/stable/overview.html#key-features) |
| **Separation of model and data**<br>模型与数据分离 | "MuJoCo separates **simulation parameters into two data structures (C structs) at runtime**:" | MuJoCo 在运行时把**仿真参数分到两个数据结构（C 结构体）中**： | [Google DeepMind, n.d., "Key features", item 7](https://mujoco.readthedocs.io/en/stable/overview.html#key-features) |
| **mjModel**<br>mjModel | "mjModel contains **the model description and is expected to remain constant**." | mjModel 包含**模型描述，预期保持不变**。 | [Google DeepMind, n.d., "Key features", item 7](https://mujoco.readthedocs.io/en/stable/overview.html#key-features) |
| **mjData**<br>mjData | "mjData contains **all dynamic variables and intermediate results**." | mjData 包含**所有动态变量和中间结果**。 | [Google DeepMind, n.d., "Key features", item 7](https://mujoco.readthedocs.io/en/stable/overview.html#key-features) |
| **Performance**<br>性能 | "MuJoCo’s runtime **performs zero memory allocations after initialization** – all working memory is preallocated in mjData." | MuJoCo 的运行时**在初始化之后不做任何内存分配**：所有工作内存都预先分配在 mjData 中。 | [Google DeepMind, n.d., "Key features", item 8](https://mujoco.readthedocs.io/en/stable/overview.html#key-features) |
| **Interactive simulation and visualization**<br>交互式仿真与可视化 | "The native 3D visualizer provides **rendering of meshes and geometric primitives, textures, reflections, shadows, fog, transparency, wireframes, skyboxes, stereoscopic visualization** (on video cards supporting quad-buffered OpenGL)." | 原生三维可视化器提供**网格和几何基元、纹理、反射、阴影、雾、透明、线框、天空盒和立体可视化的渲染**（在支持四缓冲 OpenGL 的显卡上）。 | [Google DeepMind, n.d., "Key features", item 9](https://mujoco.readthedocs.io/en/stable/overview.html#key-features) |
| **Powerful yet intuitive modeling language**<br>强大而直观的建模语言 | "MuJoCo has its own modeling language called MJCF. The goal of MJCF is **to provide access to all of MuJoCo’s compute capabilities, and at the same time enable users to develop new models quickly and experiment with them**." | MuJoCo 有自己的建模语言 MJCF。MJCF 的目标是**提供对 MuJoCo 全部计算能力的访问，同时让用户能快速开发新模型并用它们做实验**。 | [Google DeepMind, n.d., "Key features", item 10](https://mujoco.readthedocs.io/en/stable/overview.html#key-features) |
| **Automated generation of composite flexible objects**<br>复合柔性物体的自动生成 | "The modeling language has **high-level macros which are automatically expanded by the model compiler into the necessary collections of standard model elements**." | 建模语言有**高层宏，由模型编译器自动展开成所需的标准模型元素集合**。 | [Google DeepMind, n.d., "Key features", item 11](https://mujoco.readthedocs.io/en/stable/overview.html#key-features) |
| **Constraint islands and sleeping**<br>约束岛与休眠 | "The constraint solver automatically discovers **independent constraint islands – groups of bodies coupled by constraints that can be solved independently**." | 约束求解器会自动发现**独立的约束岛：由约束耦合、可以独立求解的刚体组**。 | [Google DeepMind, n.d., "Key features", item 12](https://mujoco.readthedocs.io/en/stable/overview.html#key-features) |
| **Plugin system**<br>插件系统 | "Plugins are **dynamically loaded shared libraries that register themselves with the engine and are instantiated per model element**." | 插件是**动态加载的共享库，它们向引擎注册自己，并按模型元素实例化**。 | [Google DeepMind, n.d., "Key features", item 13](https://mujoco.readthedocs.io/en/stable/overview.html#key-features) |
