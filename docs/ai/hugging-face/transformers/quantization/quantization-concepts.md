# 6.3 Quantization Concepts

## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **Quantization**<br>量化 | "Quantization reduces **the memory footprint and computational cost** of large machine learning models like those found in the Transformers library. It achieves this by representing the model’s weights and or activations with **lower-precision data types** (like 8-bit integers or int8) instead of the standard 32-bit floating-point (float32)." | 量化降低大型机器学习模型（例如 Transformers 库中的模型）的**内存占用与计算成本**。做法是用**更低精度的数据类型**（如 8 位整数，即 int8）表示模型的权重和或激活值，取代标准的 32 位浮点数（float32）。 | [Hugging Face, n.d., "Quantization concepts", para. 1](https://huggingface.co/docs/transformers/v5.20.2/en/quantization/concept_guide#quantization-concepts) |
| **Quantization Noise**<br>量化噪声 | (context) "The primary trade-off in quantization is **efficiency vs. accuracy**. Reducing precision saves resources but inevitably introduces **small errors (quantization noise)**." | （语境）量化的主要取舍是**效率与准确度**。降低精度节省资源，但不可避免地带来**小的误差（量化噪声）**。 | [Hugging Face, n.d., "Quantization concepts", para. 3](https://huggingface.co/docs/transformers/v5.20.2/en/quantization/concept_guide#quantization-concepts) |
| **Quantization Scheme**<br>量化方案 | (context) "The core idea is to **map the range of values** found in the original float32 weights and activations to **the much smaller range represented by int8**" | （语境）核心思路是把原始 float32 权重与激活值中的**取值范围映射**到 **int8 所能表示的小得多的范围**。 | [Hugging Face, n.d., "Quantization concepts", "Quantization schemes", para. 1](https://huggingface.co/docs/transformers/v5.20.2/en/quantization/concept_guide#quantization-schemes) |
| **Affine Quantization**<br>仿射量化 | (context) "There are **two main ways to perform this mapping**, symmetric and asymmetric. The choice between symmetric and asymmetric quantization determines **how the float32 range is mapped to the int8 range**." | （语境）**完成这种映射主要有两种方式**：对称与非对称。选对称还是非对称量化，决定了 **float32 范围如何映射到 int8 范围**。 | [Hugging Face, n.d., "Quantization concepts", "Affine quantization", para. 2](https://huggingface.co/docs/transformers/v5.20.2/en/quantization/concept_guide#affine-quantization) |
| **Symmetric Quantization**<br>对称量化 | (context) "It can **simplify computations**, but it might be **less accurate** if the original data distribution isn’t naturally centered around zero." | （语境）它能**简化计算**，但如果原始数据分布本来不以零为中心，可能**不够准确**。 | [Hugging Face, n.d., "Quantization concepts", "Affine quantization", list item 1](https://huggingface.co/docs/transformers/v5.20.2/en/quantization/concept_guide#affine-quantization) |
| **Asymmetric Quantization**<br>非对称量化 | (context) "This method does **not assume** the data is **centered around zero**." | （语境）这种方法**不假定**数据**以零为中心**。 | [Hugging Face, n.d., "Quantization concepts", "Affine quantization", list item 2](https://huggingface.co/docs/transformers/v5.20.2/en/quantization/concept_guide#affine-quantization) |
| **Scale**<br>缩放因子 | "A **positive float32 number** representing **the ratio between the float32 and the int8 range**." | 一个**正的 float32 数**，表示 **float32 范围与 int8 范围之比**。 | [Hugging Face, n.d., "Quantization concepts", "Affine quantization", list item 2](https://huggingface.co/docs/transformers/v5.20.2/en/quantization/concept_guide#affine-quantization) |
| **int4 Quantization**<br>int4 量化 | "int4 quantization **further reduces the model size and memory usage** (halving it compared to int8)." | int4 量化**进一步减小模型大小与内存用量**（比 int8 再减半）。 | [Hugging Face, n.d., "Quantization concepts", "int4 and weight packing", para. 1](https://huggingface.co/docs/transformers/v5.20.2/en/quantization/concept_guide#int4-and-weight-packing) |
| **int4 Accuracy Drop**<br>int4 准确度下降 | (context) "However, int4 quantization typically results in **a larger accuracy drop** compared to int8. **Advanced quantization techniques** like GPTQ or AWQ are often necessary for good performance with int4." | （语境）不过，与 int8 相比，int4 量化通常带来**更大的准确度下降**。要让 int4 表现良好，往往需要 GPTQ 或 AWQ 这类**高级量化技术**。 | [Hugging Face, n.d., "Quantization concepts", "int4 and weight packing", para. 4](https://huggingface.co/docs/transformers/v5.20.2/en/quantization/concept_guide#int4-and-weight-packing) |
| **Weight Packing**<br>权重打包 | "Since most hardware can’t natively handle **4-bit data types** in memory, two int4 values are typically **packed together into a single int8 byte** for storage and transfer." | 由于多数硬件无法在内存中原生处理 **4 位数据类型**，通常把两个 int4 值**打包进一个 int8 字节**来存储和传输。 | [Hugging Face, n.d., "Quantization concepts", "int4 and weight packing", para. 2](https://huggingface.co/docs/transformers/v5.20.2/en/quantization/concept_guide#int4-and-weight-packing) |
| **A8W8**<br>A8W8 | "FP8 is used in the A8W8 quantization scheme, which quantizes **both activations (A) and weights (W)** to **8-bit precision**." | FP8 用于 A8W8 量化方案，该方案把**激活值（A）和权重（W）两者**都量化到 **8 位精度**。 | [Hugging Face, n.d., "Quantization concepts", "FP8 Quantization (A8W8)", para. 2](https://huggingface.co/docs/transformers/v5.20.2/en/quantization/concept_guide#fp8-quantization-a8w8) |
| **E4M3**<br>E4M3 | "1 sign bit, 4 exponent bits, 3 mantissa bits. Offers **higher precision** (more mantissa bits) but **a smaller dynamic range** (fewer exponent bits)." | 1 个符号位、4 个指数位、3 个尾数位。提供**更高的精度**（尾数位更多），但**动态范围更小**（指数位更少）。 | [Hugging Face, n.d., "Quantization concepts", "FP8 Quantization (A8W8)", list item 1](https://huggingface.co/docs/transformers/v5.20.2/en/quantization/concept_guide#fp8-quantization-a8w8) |
| **E5M2**<br>E5M2 | "1 sign bit, 5 exponent bits, 2 mantissa bits. Offers **a wider dynamic range** but **lower precision**." | 1 个符号位、5 个指数位、2 个尾数位。提供**更宽的动态范围**，但**精度更低**。 | [Hugging Face, n.d., "Quantization concepts", "FP8 Quantization (A8W8)", list item 2](https://huggingface.co/docs/transformers/v5.20.2/en/quantization/concept_guide#fp8-quantization-a8w8) |
| **Per-Tensor**<br>逐张量 | (context) "**Simpler**, but **less accurate** if data values vary greatly within the tensor." | （语境）**更简单**，但如果张量内的数据值差异很大，就**不够准确**。 | [Hugging Face, n.d., "Quantization concepts", "Granularity", list item 1](https://huggingface.co/docs/transformers/v5.20.2/en/quantization/concept_guide#granularity) |
| **Per-Channel**<br>逐通道 | (context) "**More accurate and better performance** at the cost of **slightly more complexity and memory**." | （语境）**更准确、性能更好**，代价是**稍多一些复杂度与内存**。 | [Hugging Face, n.d., "Quantization concepts", "Granularity", list item 2](https://huggingface.co/docs/transformers/v5.20.2/en/quantization/concept_guide#granularity) |
| **Post-Training Quantization (PTQ)**<br>训练后量化 | "Quantization is applied **after** the model is **fully trained**." | 量化在模型**完全训练好**之**后**进行。 | [Hugging Face, n.d., "Quantization concepts", "Quantization techniques", list item 1](https://huggingface.co/docs/transformers/v5.20.2/en/quantization/concept_guide#quantization-techniques) |
| **Quantization-Aware Training (QAT)**<br>量化感知训练 | "Quantization effects are **simulated during training** by inserting “fake quantization” ops that **simulate the rounding errors of quantization**." | 量化的影响**在训练期间被模拟**，做法是插入“伪量化”算子来**模拟量化的舍入误差**。 | [Hugging Face, n.d., "Quantization concepts", "Quantization techniques", list item 2](https://huggingface.co/docs/transformers/v5.20.2/en/quantization/concept_guide#quantization-techniques) |
| **HfQuantizer**<br>HfQuantizer | (context) "All backends are **unified under the `HfQuantizer` API** and associated **`QuantizationConfig` classes**." | （语境）所有后端都**统一在 `HfQuantizer` API** 及相关的 **`QuantizationConfig` 类**之下。 | [Hugging Face, n.d., "Quantization concepts", "Quantization in Transformers", para. 2](https://huggingface.co/docs/transformers/v5.20.2/en/quantization/concept_guide#quantization-in-transformers) |
