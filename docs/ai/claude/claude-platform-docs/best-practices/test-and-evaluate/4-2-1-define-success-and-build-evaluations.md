# 4.2.1 Success Criteria and Evaluations

## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **Success Criteria and Evaluations**<br>成功标准与评估 | (Summary) The **measurable goals** for an LLM application and the **tests that check performance against them**. | （概述）LLM 应用的**可衡量目标**，以及**据此检验表现的测试**。 | [Anthropic, n.d., "Define Success and Build Evaluations"](https://platform.claude.com/docs/en/test-and-evaluate/develop-tests) |
| **Success Criteria**<br>成功标准 | (Summary) Goals for an application that are **specific and measurable**, and also **achievable and relevant** to what its users need. | （概述）应用要达到的目标，要**具体且可衡量**，同时**可实现并且切合**用户的需要。 | [Anthropic, n.d., "Define Success and Build Evaluations", "Define your success criteria"](https://platform.claude.com/docs/en/test-and-evaluate/develop-tests) |
| **Task Fidelity**<br>任务保真度 | (Summary) **How well the model must perform** the task itself, including **rare or difficult inputs**. | （概述）**模型完成任务本身要好到什么程度**，包括**少见或困难的输入**。 | [Anthropic, n.d., "Define Success and Build Evaluations", "Task fidelity"](https://platform.claude.com/docs/en/test-and-evaluate/develop-tests) |
| **Consistency**<br>一致性 | (Summary) **How similar the answers must be** when the model receives **similar inputs**, such as the same question asked twice. | （概述）**回答要相近到什么程度**，指模型收到**相似输入**时，例如同一个问题问两次。 | [Anthropic, n.d., "Define Success and Build Evaluations", "Consistency"](https://platform.claude.com/docs/en/test-and-evaluate/develop-tests) |
| **Relevance and Coherence**<br>相关性与连贯性 | (Summary) Whether the output **directly addresses the request** and presents its information in a **logical, easy-to-follow order**. | （概述）输出是否**直接回应请求**，并以**合乎逻辑、容易跟上的顺序**呈现信息。 | [Anthropic, n.d., "Define Success and Build Evaluations", "Relevance and coherence"](https://platform.claude.com/docs/en/test-and-evaluate/develop-tests) |
| **Tone and Style**<br>语气与风格 | (Summary) Whether the **style of the output** matches expectations and its language **suits the intended audience**. | （概述）**输出的风格**是否符合预期，用语是否**适合目标读者**。 | [Anthropic, n.d., "Define Success and Build Evaluations", "Tone and style"](https://platform.claude.com/docs/en/test-and-evaluate/develop-tests) |
| **Privacy Preservation**<br>隐私保护 | (Summary) How the model **handles personal or sensitive information**, and whether it **follows instructions not to use or share** certain details. | （概述）模型如何**处理个人或敏感信息**，以及是否**遵守不使用、不分享**某些细节的指示。 | [Anthropic, n.d., "Define Success and Build Evaluations", "Privacy preservation"](https://platform.claude.com/docs/en/test-and-evaluate/develop-tests) |
| **Context Utilization**<br>上下文利用 | (Summary) How effectively the model **uses the context it was given** and **builds on earlier information** in the conversation. | （概述）模型能否有效**利用给它的上下文**，并**在先前的信息之上继续**对话。 | [Anthropic, n.d., "Define Success and Build Evaluations", "Context utilization"](https://platform.claude.com/docs/en/test-and-evaluate/develop-tests) |
| **Latency**<br>延迟 | (Summary) The **response time that is acceptable**, which depends on the application's **real-time needs and user expectations**. | （概述）**可接受的响应时间**，取决于应用的**实时性需要与用户预期**。 | [Anthropic, n.d., "Define Success and Build Evaluations", "Latency"](https://platform.claude.com/docs/en/test-and-evaluate/develop-tests) |
| **Price**<br>价格 | (Summary) The **budget for running the model**, shaped by **cost per call, model size and how often** it is used. | （概述）**运行模型的预算**，由**每次调用的成本、模型大小与使用频率**决定。 | [Anthropic, n.d., "Define Success and Build Evaluations", "Price"](https://platform.claude.com/docs/en/test-and-evaluate/develop-tests) |
| **Evaluation (Eval)**<br>评估 | (Summary) A set of test cases that **mirrors the real task**, with edge cases, built so that **grading can be automated** and run in volume. | （概述）一组**贴近真实任务**的测试用例，包含边界情况，设计成**可以自动评分**并大量运行。 | [Anthropic, n.d., "Define Success and Build Evaluations", "Eval design principles"](https://platform.claude.com/docs/en/test-and-evaluate/develop-tests) |
| **Edge Case**<br>边界情况 | (Summary) An input that is **rare or hard to handle**, such as missing, overly long, harmful or **ambiguous data**. | （概述）**少见或难处理**的输入，例如缺失、过长、有害或**含糊的数据**。 | [Anthropic, n.d., "Define Success and Build Evaluations", "Eval design principles"](https://platform.claude.com/docs/en/test-and-evaluate/develop-tests) |
| **Exact Match Evaluation**<br>精确匹配评估 | (Summary) An eval that checks whether the output **equals a predefined correct answer**, usually **after normalizing** spacing and case. | （概述）检查输出是否**等于预先给定的正确答案**的评估，通常**先做规范化**（空白与大小写）。 | [Anthropic, n.d., "Define Success and Build Evaluations", "Task fidelity (sentiment analysis): exact match evaluation"](https://platform.claude.com/docs/en/test-and-evaluate/develop-tests) |
| **Cosine Similarity Evaluation**<br>余弦相似度评估 | (Summary) An eval that measures **how close two outputs are** by comparing the **vectors of their sentence embeddings**. | （概述）衡量**两段输出有多接近**的评估，做法是比较它们的**句向量**。 | [Anthropic, n.d., "Define Success and Build Evaluations", "Consistency (FAQ bot): cosine similarity evaluation"](https://platform.claude.com/docs/en/test-and-evaluate/develop-tests) |
| **ROUGE-L**<br>ROUGE-L | (Summary) A score for **generated summaries** based on the **longest common subsequence** shared with a reference summary. | （概述）给**生成的摘要**打的分，依据与参考摘要共有的**最长公共子序列**。 | [Anthropic, n.d., "Define Success and Build Evaluations", "Relevance and coherence (summarization): ROUGE-L evaluation"](https://platform.claude.com/docs/en/test-and-evaluate/develop-tests) |
| **LLM-Based Likert Scale**<br>基于 LLM 的李克特量表 | (Summary) A rating scale on which **an LLM judges a subjective quality**, such as tone, by **assigning a score**. | （概述）一种评分量表，由 **LLM 评判主观品质**（如语气）并**给出分数**。 | [Anthropic, n.d., "Define Success and Build Evaluations", "Tone and style (customer service): LLM-based Likert scale"](https://platform.claude.com/docs/en/test-and-evaluate/develop-tests) |
| **LLM-Based Binary Classification**<br>基于 LLM 的二分类 | (Summary) A check in which **an LLM sorts each output into one of two classes**, for example whether it **contains protected information**. | （概述）一种检查，由 **LLM 把每条输出分到两类之一**，例如是否**含有受保护的信息**。 | [Anthropic, n.d., "Define Success and Build Evaluations", "Privacy preservation (medical chatbot): LLM-based binary classification"](https://platform.claude.com/docs/en/test-and-evaluate/develop-tests) |
| **LLM-Based Ordinal Scale**<br>基于 LLM 的顺序量表 | (Summary) A **fixed, ordered scale** (1 to 5) on which **an LLM rates an output**, for example how well it uses context. | （概述）一个**固定且有序的量表**（1 到 5），由 **LLM 给输出评级**，例如对上下文的利用程度。 | [Anthropic, n.d., "Define Success and Build Evaluations", "Context utilization (conversation assistant): LLM-based ordinal scale"](https://platform.claude.com/docs/en/test-and-evaluate/develop-tests) |
| **Code-Based Grading**<br>基于代码的评分 | (Summary) Grading by **rules written in code**, such as exact or string match: **fastest and most reliable**, but without nuance. | （概述）用**写成代码的规则**评分，如精确匹配或字符串匹配：**最快也最可靠**，但缺少细微判断。 | [Anthropic, n.d., "Define Success and Build Evaluations", "Grade your evaluations"](https://platform.claude.com/docs/en/test-and-evaluate/develop-tests) |
| **Human Grading**<br>人工评分 | (Summary) Grading done **by people**: the most flexible and highest in quality, but **slow and expensive**. | （概述）**由人**完成的评分：最灵活、质量最高，但**慢而且贵**。 | [Anthropic, n.d., "Define Success and Build Evaluations", "Grade your evaluations"](https://platform.claude.com/docs/en/test-and-evaluate/develop-tests) |
| **LLM-Based Grading**<br>基于 LLM 的评分 | (Summary) Grading done **by a model following a rubric**: fast and scalable for complex judgments, once its **reliability has been tested**. | （概述）**由模型按评分细则**完成的评分：对复杂判断又快又可扩展，前提是**先验证过它的可靠性**。 | [Anthropic, n.d., "Define Success and Build Evaluations", "Grade your evaluations"](https://platform.claude.com/docs/en/test-and-evaluate/develop-tests) |
