# Claude Platform Docs: allowed pages and term checklist

Not published (`docfx.json` excludes `**/README.md`). Source: Claude Platform Docs (https://platform.claude.com/docs/en/home, Anthropic), its tabs and sidebar groups as the site's own sidebar serves them, the page list from `https://platform.claude.com/llms.txt` (886 English pages, saved as `design-refs/official-docs/claude_platform_llms.txt`), pages cached 2026-11-08 (`design-refs/official-docs/urls_kb_claude_platform.txt`, `--plain`).

Status (2026-11-08): skeleton. 7 top-level groups, 250 entries; every page has one row, its own subject, as a table-of-contents title; its terms are added when the page is read (repository README, "New terms from a new documentation set"). Chinese names are this site's own. Sidebar groups whose Overview page is the group's own subject (Thinking, Tools, Compaction, Images and Vision, Skills, MCP Tunnels, OpenTelemetry, Google Cloud, Self-Hosted Sandboxes, Access Transparency, Encryption Keys, Inference Hooks, Compliance API, Prompt Engineering, Models) take that page as their source, with no separate Overview entry. The collapsed groups were read from each group's own page, where the sidebar opens it; Identity Providers, Build Persistent Memory, Specialized Models and Legacy Models do not open in the served HTML, so their pages come from the page list. Claude Mythos 5 and 5.1 are put under Specialized Models from their pages ("available only to organizations verified"). The models overview lists nine legacy models "still available"; Claude Sonnet 4.5 is in the page list but not in that sentence, and is kept under Legacy Models. License: the documentation pages carry no open-license notice (checked 2026-11-08), so definitions are written in this site's own words and marked (Summary) (repository README, "Term tables"). A page marked "subject only" has its subject defined; the terms in its sections are still to be added; file names keep the table-of-contents titles after a page is renamed to its term.

Left out (no terms):

- Messages: Get your API key, Quickstart, Tutorial: Build a tool-using agent, Build an orchestration mode (how-to or tutorials); the Troubleshooting pages of Thinking, Tools and MCP Tunnels; Skills Quickstart and Best practices; MCP Tunnels Quickstart, Manage in the Console, Deploy with Helm, Deploy with Docker Compose.
- Managed Agents: Quickstart, Build in Console, Migration; Self-Hosted Sandboxes Monitor and troubleshoot.
- Admin: Identity providers, the whole group (seven WIF how-to pages, one per provider); the CMEK setup pages (AWS KMS, Azure Key Vault, Google Cloud KMS, Claude Platform on AWS, Limit key to workspaces, Admin API, Troubleshooting); Configure Inference hooks, Build an integration; Compliance API Set up, Design your integration, Errors, FAQ.
- Best practices: Use cases, the whole group (6 guides); the eight model-specific prompting pages (Prompting Claude Fable 5.1 and the others); Additional resources.
- Models & pricing: each model's sub-pages (What's new, Migration guide, System prompts and others, about 70 pages); the System prompts group; Upgrade between model versions.
- SDKs, CLI, and libraries: ant CLI Quickstart.
- Claude API skill and Release notes, whole tabs.
- API reference: the endpoint pages of both listed sections (about 580 pages; options and endpoints are not terms on this site); AWS IAM actions, Google Cloud IAM permissions, IP addresses, Migrating to API version 2026-10-21 (reference lists or migration).
- API usage primer for Claude (a primer for agents, under Other pages).
