# 7.4 Extend with Tools

## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **7.4 Extend with Tools**<br>用工具扩展 | (Summary) Ways to **give an agent more actions**, through **your own functions, MCP or subagents**. | （概述）**让代理能做更多事**的方式，包括**你自己的函数、MCP 或子代理**。 | [Anthropic, n.d., "Extend with Tools"](https://code.claude.com/docs/en/agent-sdk/custom-tools) |
| **[7.4.1 Custom Tools](7-4-1-give-claude-custom-tools.md)**<br>自定义工具 | (Summary) **Functions you write** that the agent **can call during its work**, served through an in-process MCP server. | （概述）**你编写的函数**，代理**可在工作中调用**，通过进程内 MCP 服务器提供。 | [Anthropic, n.d., "Give Claude Custom Tools"](https://code.claude.com/docs/en/agent-sdk/custom-tools) |
| **[7.4.2 Model Context Protocol](7-4-2-connect-to-external-tools-with-mcp.md)**<br>模型上下文协议 | (Summary) An **open protocol linking agents to outside systems**, so you can **reach services without writing your own tool code**. | （概述）**把代理连接到外部系统的开放协议**，让你**无需自己写工具代码就能访问服务**。 | [Anthropic, n.d., "Connect to External Tools with MCP"](https://code.claude.com/docs/en/agent-sdk/mcp) |
| **[7.4.3 Tool Search](7-4-3-scale-to-many-tools-with-tool-search.md)**<br>工具搜索 | (Summary) A way to **load tool definitions only when needed**, which **keeps very large tool sets from filling the context**. | （概述）**按需加载工具定义**的方式，**避免庞大的工具集占满上下文**。 | [Anthropic, n.d., "Scale to Many Tools with Tool Search"](https://code.claude.com/docs/en/agent-sdk/tool-search) |
| **[7.4.4 Subagents in the SDK](7-4-4-subagents-in-the-sdk.md)**<br>SDK 中的子代理 | (Summary) **Child agents started by the main agent** to **work on a narrow task in their own context**. | （概述）**由主代理启动的子代理**，**在自己的上下文中处理专门任务**。 | [Anthropic, n.d., "Subagents in the SDK"](https://code.claude.com/docs/en/agent-sdk/subagents) |
