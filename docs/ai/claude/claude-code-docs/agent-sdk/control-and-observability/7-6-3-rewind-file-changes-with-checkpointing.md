# 7.6.3 File Checkpointing

## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **File Checkpointing**<br>文件检查点 | (Summary) A record of **edits made through file tools**, from which you can **restore earlier versions**; shell edits are not covered. | （概述）对**通过文件工具所做修改**的记录，可以**恢复到之前的版本**；shell 命令的修改不在其内。 | [Anthropic, n.d., "Rewind File Changes with Checkpointing"](https://code.claude.com/docs/en/agent-sdk/file-checkpointing) |
