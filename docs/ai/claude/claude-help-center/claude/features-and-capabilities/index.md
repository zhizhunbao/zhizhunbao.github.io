# 1.2 Features and Capabilities

## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **1.2 Features and Capabilities**<br>功能与能力 | (Summary) The **things Claude can make or connect to**, from **artifacts and research to plugins**. | （概述）**Claude 能创建或连接的内容**，**从 Artifact、研究到插件**。 | [Anthropic, n.d., "Features and Capabilities"](https://support.claude.com/en/collections/18031719-features-and-capabilities) |
| **[1.2.1 Artifacts](1-2-1-artifacts.md)**<br>Artifact | (Summary) A **finished piece of work** from Claude, such as a slide deck or small app, that **sits next to the chat** and can be revised and passed on. | （概述）Claude 产出的**成品**，例如幻灯片或小应用，**显示在对话旁边**，可以继续修改并分享给别人。 | [Anthropic, n.d., "What are artifacts and how do I use them?"](https://support.claude.com/en/articles/17153992-what-are-artifacts-and-how-do-i-use-them) |

| **[1.2.4 Claude Design](1-2-4-claude-design.md)**<br>Claude Design | (Summary) An artifact template for **visual work such as mock-ups and prototypes**, made through conversation and **adjusted directly on a canvas**. | （概述）用于**样稿、原型等视觉作品**的 Artifact 模板，通过对话生成，并可**直接在画布上调整**。 | [Anthropic, n.d., "Get started with Claude Design"](https://support.claude.com/en/articles/14604416-get-started-with-claude-design) |

| **[1.2.10 Projects](1-2-10-projects.md)**<br>项目 | (Summary) **Separate workspaces** that each keep **their own chats and reference material**. | （概述）**彼此独立的工作区**，各自保存**自己的聊天和参考资料**。 | [Anthropic, n.d., "What are projects?"](https://support.claude.com/en/articles/9517075-what-are-projects) |
| **[1.2.11 Retrieval Augmented Generation (RAG) for Projects](1-2-11-retrieval-augmented-generation-rag-for-projects.md)**<br>项目的检索增强生成（RAG） | (Summary) A mode Claude **enters automatically** as project files near the context limit, so a project **can hold far more material**. | （概述）当项目文件接近上下文上限时，Claude **自动进入**的一种模式，使项目**能容纳多得多的资料**。 | [Anthropic, n.d., "Retrieval augmented generation (RAG) for projects"](https://support.claude.com/en/articles/11473015-retrieval-augmented-generation-rag-for-projects) |
