# 1.2.5 Design System

## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **Design System**<br>设计系统 | (Summary) A **stored set of brand rules** (colour, type, components, layout) that Claude **pulls from your files** and reuses in each new design. | （概述）一套**保存下来的品牌规则**（颜色、字体、组件、布局），由 Claude **从你的文件中提取**，并在每个新设计中沿用。 | [Anthropic, n.d., "Set up your design system in Claude Design"](https://support.claude.com/en/articles/14604397-set-up-your-design-system-in-claude-design) |
