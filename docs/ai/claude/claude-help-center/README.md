Status (2026-11-08): skeleton. 13 top-level groups, 136 entries; every page has one row, its own subject, as a table-of-contents title; its terms are added when the page is read (repository README, "New terms from a new documentation set"). Chinese names are this site's own. A Help Center article is mostly a how-to, so a page is kept only where its title names a feature, plan or concept. Titles phrased as questions are named by their term ("What are skills?" is Skills). Since 2026-11-08 the rows of the Overviews and of 1.2 hold definitions in this site's own words, marked (Summary), with the article's real title as the source (repository README, "Term tables"); 1.2's terms inside each article's sections are still to be added (Read column: "subject only"); file names keep the table-of-contents titles after a page is renamed to its term. Sub-collections left with one kept article are drawn as that article (Pro, Max and Ultra Plans; Mobile; API and Console). The collection order is the home page's. The site answered 429 Too Many Requests after 108 pages, so 28 pages are not cached yet; each is cached when it is read, and its Sections cell says so.
