# OpenCV: allowed pages

Source: the OpenCV-Python Tutorials, version 4.13.0 (https://docs.opencv.org/4.x/d6/d00/tutorial_py_root.html), and opencv.org/about for the product row. Each group's table-of-contents page lists its pages, so nothing here copies them.

The site lists the official tutorial tree as it stands, names and order unchanged, with the parts that hold no terms removed (the ROS 2 layout).

| No. | Folder and page | Entries (official names, menu order) | Parts |
|---|---|---|---|
| 1 | `core-operations/` Core Operations | Basic Operations on Images, Arithmetic Operations on Images | |
| 2 | `image-processing-in-opencv/` Image Processing in OpenCV | the 16 pages from Changing Colorspaces to Interactive Foreground Extraction using GrabCut Algorithm | Contours in OpenCV: its 5 pages; Histograms in OpenCV: its 4 pages |
| 3 | `feature-detection-and-description/` Feature Detection and Description | its 10 pages | |
| 4 | `camera-calibration-and-3d-reconstruction/` Camera Calibration and 3D Reconstruction | its 4 pages | |
| 5 | `machine-learning/` Machine Learning | K-Nearest Neighbour, Support Vector Machines (SVM), K-Means Clustering | each one's Understanding page |
| 6 | `computational-photography/` Computational Photography | Image Denoising, Image Inpainting, High Dynamic Range (HDR) | |
| 7 | `object-detection-objdetect-module/` Object Detection (objdetect module) | Detection of ArUco Markers, Detection of ArUco boards, Detection of ChArUco Boards, Detection of Diamond Markers | |

Left out (no terms): Introduction to OpenCV (installation guides), Gui Features in OpenCV (how-to pages on displaying images and videos, drawing, mouse and trackbars), Video Analysis (one link to other tutorials) and OpenCV-Python Bindings (a page on how the bindings are generated); Performance Measurement and Improvement Techniques, Calibration with ArUco and ChArUco and Aruco module FAQ; the OCR pages and K-Means Clustering in OpenCV under Machine Learning (applications).

Rows: the tutorials state goals rather than definitions, so an entry quotes the one-line description its group's table of contents gives under its link, marked (context); the ArUco pages, which have no such lines, quote their opening sentences. The Image Transforms in OpenCV page returns 404 on the 4.x site (2026-10-31), so its parts (Fourier Transform) are not listed.
