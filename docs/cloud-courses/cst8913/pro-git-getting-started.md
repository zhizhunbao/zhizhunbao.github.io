# Pro Git: getting started

Study notes on [Scott Chacon and Ben Straub, Pro Git, 2nd edition](https://git-scm.com/book/en/v2), which CST8913 Cloud Migration (Algonquin College, Fall 2026) uses in week 1. Each section follows one part of the source. Start from the figure: the framed terms are the ones to learn, and the table below it defines them in the same order, each with a citation linked to the passage.

## [What is Git?](https://git-scm.com/book/en/v2/Getting-Started-What-is-Git%3F)

![Diagram: What is Git?](media/pro-git-getting-started-1.png)

| Term | Definition | 中文解释 | Source |
|---|---|---|---|
| **Git** (Git 版本控制) | "Git is a free and open source distributed version control system designed to handle everything from small to very large projects with speed and efficiency." | Git 是记录文件改动历史的工具，每个人本地都有完整副本；可以回退、分支、合并。 | [Git, n.d., para. 1](https://git-scm.com/#:~:text=Git%20is%20a%20free%20and%20open%20source%20distributed%20version) |
| **working tree** (工作区) | "The working tree is a single checkout of one version of the project. These files are pulled out of the compressed database in the Git directory and placed on disk for you to use or modify." *Note: Also called the working directory.* | 工作区就是你电脑上能直接打开、修改的那份项目文件。你的改动先发生在这里，Git 还没有记录它们。 | [Chacon, 2014, "The Three States" section, para. 3](https://git-scm.com/book/en/v2/Getting-Started-What-is-Git%3F#_the_three_states:~:text=The%20working%20tree%20is%20a%20single%20checkout%20of%20one%20version) |
| **modified** (已修改) | "Modified means that you have changed the file but have not committed it to your database yet." | 已修改是文件的一种状态：你改过了，但还没放进暂存区，也没提交。这时的改动最容易丢。 | [Chacon, 2014, "The Three States" section, bullet 1](https://git-scm.com/book/en/v2/Getting-Started-What-is-Git%3F#_the_three_states:~:text=Modified%20means%20that%20you%20have%20changed%20the%20file%20but) |
| **git add** (git add 暂存) | "Add contents of new or changed files to the index. The "index" (also known as the "staging area") is what you use to prepare the contents of the next commit." | git add 把改动放进暂存区，准备下一次提交；没有 add 的改动不会进入 commit。 | [Git, n.d., "DESCRIPTION" section, para. 1](https://git-scm.com/docs/git-add#_description:~:text=Add%20contents%20of%20new%20or%20changed%20files%20to%20the%20index) |
| **staging area (index)** (暂存区) | "The staging area is a file, generally contained in your Git directory, that stores information about what will go into your next commit. Its technical name in Git parlance is the "index"..." | 暂存区是提交前的“候选清单”，用 git add 把改动放进来，下一次 commit 只记录这里的内容。 | [Chacon, 2014, "The Three States" section, para. 4](https://git-scm.com/book/en/v2/Getting-Started-What-is-Git%3F#_the_three_states:~:text=The%20staging%20area%20is%20a%20file%2C%20generally%20contained%20in%20your) |
| **staged** (已暂存) | "Staged means that you have marked a modified file in its current version to go into your next commit snapshot." | 已暂存是文件的一种状态：你用 git add 把它当前的版本选进了下一次提交。 | [Chacon, 2014, "The Three States" section, bullet 2](https://git-scm.com/book/en/v2/Getting-Started-What-is-Git%3F#_the_three_states:~:text=Staged%20means%20that%20you%20have%20marked%20a%20modified%20file) |
| **commit** (提交) | "With Git, every time you commit, or save the state of your project, Git basically takes a picture of what all your files look like at that moment and stores a reference to that snapshot." *Note: The command is git commit; it stores what is in the staging area.* | 提交就是给整个项目拍一张快照，存进本地仓库的历史里。以后可以随时查看或回到这个版本。 | [Chacon, 2014, "Snapshots, Not Differences" section, para. 2](https://git-scm.com/book/en/v2/Getting-Started-What-is-Git%3F#_snapshots_not_differences:~:text=With%20Git%2C%20every%20time%20you%20commit%2C%20or%20save%20the) |
| **Git directory** (Git 目录（本地仓库）) | "The Git directory is where Git stores the metadata and object database for your project. This is the most important part of Git, and it is what is copied when you clone a repository from another computer." *Note: Often called the local repository.* | Git 目录就是项目里的 .git 文件夹，也就是本地仓库，保存全部提交历史。不联网也能在这里提交和查看历史。 | [Chacon, 2014, "The Three States" section, para. 5](https://git-scm.com/book/en/v2/Getting-Started-What-is-Git%3F#_the_three_states:~:text=The%20Git%20directory%20is%20where%20Git%20stores%20the%20metadata) |
| **committed** (已提交) | "Committed means that the data is safely stored in your local database." | 已提交是文件的一种状态：这个版本已经安全地存进了本地仓库，很难再丢失。 | [Chacon, 2014, "The Three States" section, bullet 3](https://git-scm.com/book/en/v2/Getting-Started-What-is-Git%3F#_the_three_states:~:text=Committed%20means%20that%20the%20data%20is%20safely%20stored%20in) |
| **remote repository** (远程仓库) | "A repository which is used to track the same project but resides somewhere else. To communicate with remotes, see fetch or push." | 远程仓库是放在别处（例如 GitHub）的同一个项目仓库，用来和别人共享代码、做备份。 | [Git, n.d., "remote repository" entry](https://git-scm.com/docs/gitglossary#Documentation/gitglossary.txt-aiddefremotearemoterepository:~:text=A%20repository%20which%20is%20used%20to%20track%20the%20same%20project) |
| **push** (推送) | "When you have your project at a point that you want to share, you have to push it upstream." | 推送就是把本地已经提交的内容上传到远程仓库，这样别人才能看到。命令是 git push。 | [Chacon, 2014, "Pushing to Your Remotes" section, para. 1](https://git-scm.com/book/en/v2/Git-Basics-Working-with-Remotes#_pushing_remotes:~:text=When%20you%20have%20your%20project%20at%20a%20point%20that) |
| **pull** (拉取) | "Pulling a branch means to fetch it and merge it." | 拉取就是从远程仓库下载新改动并合并到本地分支，让本地保持最新。 | [Git, n.d., "pull" entry](https://git-scm.com/docs/gitglossary#Documentation/gitglossary.txt-aiddefpullapull:~:text=Pulling%20a%20branch%20means%20to%20fetch%20it%20and%20merge%20it) |
| **clone** (克隆) | "If you want to get a copy of an existing Git repository — for example, a project you’d like to contribute to — the command you need is git clone." *Note: Git receives a full copy of nearly all the data on the server, not just a working copy.* | 克隆就是把一个已有的仓库完整复制到自己电脑上，包括几乎全部历史，而不只是最新的文件。 | [Chacon, 2014, "Cloning an Existing Repository" section, para. 1](https://git-scm.com/book/en/v2/Git-Basics-Getting-a-Git-Repository#_git_cloning:~:text=If%20you%20want%20to%20get%20a%20copy%20of%20an%20existing) |
