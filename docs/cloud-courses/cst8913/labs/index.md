## Lab 2: Levi Strauss & Co. migration case study

| **Service types**<br>云服务类型 | Service types are the cloud service models, **IaaS**, PaaS and **SaaS**, which differ in how much of the stack the **provider** manages for you.<br><br>*In this lab:* Rehosted servers run on IaaS VMs, databases move to PaaS Azure SQL Managed Instance, and some applications could be replaced with SaaS. | 服务类型是云服务模型，即 **IaaS**、PaaS 和 **SaaS**，它们的区别在于**提供商**替你管理多少技术栈。<br><br>*本实验*：重新托管的服务器运行在 IaaS 虚拟机上，数据库迁到 PaaS 的 Azure SQL Managed Instance，部分应用可以用 SaaS 替代。 | My own words |

## Lab 3: IaaS and PaaS architecture

![Overview of lab 3: the same app on IaaS (load balancer, web, app and database VMs in two availability zones inside a VNet with subnets and NSGs; you manage the OS and up) and on PaaS (Static Web Apps, App Service, Azure Database for PostgreSQL; Azure manages the OS and runtime), with SaaS beyond](media/lab-3.png)

| Term | Definition | 中文翻译 | Source |
