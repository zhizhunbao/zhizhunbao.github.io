# Discovery and assessment

Lab 4 of CST8913 Cloud Migration (week 4), described in my own words: what it practises and which concepts it needs. The lab's questions and my answers are not published.

## What it practises

List the digital estate, choose how to discover it, map dependencies, check readiness, size and cost it, then prioritize and plan the migration.

## Concepts to understand

- digital estate
- Azure Migrate
- appliance
- dependency analysis
- readiness
- sizing
- cost estimate
- migration wave
