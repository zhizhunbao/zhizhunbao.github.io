# Cloud migration

Study notes for CST8913 Cloud Migration (Algonquin College, Fall 2026), weeks 1 to 6 (the midterm). Each week is built around its lab, so the table starts from the lab, then lists the concepts it needs and the lecture pages that explain them. The lecture pages follow the official sources the slides copy, one page per source: one figure per part with the key terms framed, and a table that defines exactly those terms in the same order.
