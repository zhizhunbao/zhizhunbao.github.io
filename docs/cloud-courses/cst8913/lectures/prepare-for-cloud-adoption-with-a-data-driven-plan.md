# Prepare for cloud adoption with a data-driven plan

Study notes on [Microsoft Learn module (retired)](https://web.archive.org/web/20220804114917/https://docs.microsoft.com/en-us/learn/modules/cloud-adoption-framework-plan/4-exercise-digital-estate-assessment), which CST8913 Cloud Migration (Algonquin College, Fall 2026) uses in week 4. Each section follows one part of the source. Start from the figure: the framed terms are the ones to learn, and the table below it defines them in the same order, each with a citation linked to the passage and a Chinese translation in which each key word has the same colour as in the English. In the English, the verb of each sentence is underlined.

## [Readiness and suitability analysis](https://web.archive.org/web/20220804114917/https://docs.microsoft.com/en-us/learn/modules/cloud-adoption-framework-plan/4-exercise-digital-estate-assessment#readiness-and-suitability-analysis)

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **Ready for Azure**<br>可迁移（Azure 就绪） | "**Ready for Azure**: Machines can be migrated **as-is** to Azure, **without any changes**." | **Azure 就绪**：计算机可以**按原样**迁移到 Azure，**无需任何更改**。 | [Microsoft, 2022, "Readiness and suitability analysis" section, bullet 1](https://web.archive.org/web/20220804114917/https://docs.microsoft.com/en-us/learn/modules/cloud-adoption-framework-plan/4-exercise-digital-estate-assessment#readiness-and-suitability-analysis:~:text=Ready%20for%20Azure%3A%20Machines%20can%20be%20migrated%20as%2Dis%20to%20Azure) |
| **Conditionally ready for Azure**<br>有条件可迁移 | "**Conditionally ready for Azure**: Machines can be migrated to Azure, but need **minor changes** in accordance with the **remediation guidance** provided in the assessment." | **有条件地为 Azure 就绪**：计算机可以迁移到 Azure，但需要进行**少量更改**，更改须遵循评估中提供的**修正指南**。 | [Microsoft, 2022, "Readiness and suitability analysis" section, bullet 2](https://web.archive.org/web/20220804114917/https://docs.microsoft.com/en-us/learn/modules/cloud-adoption-framework-plan/4-exercise-digital-estate-assessment#readiness-and-suitability-analysis:~:text=Conditionally%20ready%20for%20Azure%3A%20Machines%20can%20be%20migrated%20to) |
| **Not ready for Azure**<br>不可迁移（未就绪） | "**Not ready for Azure**: Machines **can't be migrated to Azure as-is**. Issues must be fixed in accordance with **remediation guidance** before migration." | **未为 Azure 就绪**：计算机**无法按原样迁移到 Azure**。迁移前必须按照**修正指南**修复问题。 | [Microsoft, 2022, "Readiness and suitability analysis" section, bullet 3](https://web.archive.org/web/20220804114917/https://docs.microsoft.com/en-us/learn/modules/cloud-adoption-framework-plan/4-exercise-digital-estate-assessment#readiness-and-suitability-analysis:~:text=Not%20ready%20for%20Azure%3A%20Machines%20can%27t%20be%20migrated%20to) |
| **Readiness unknown**<br>就绪性未知 | "**Readiness unknown**: Azure Migrate **can't determine machine readiness**, because of **insufficient metadata**." | **就绪性未知**：Azure Migrate **无法确定计算机的就绪性**，原因是**元数据不足**。 | [Microsoft, 2022, "Readiness and suitability analysis" section, bullet 4](https://web.archive.org/web/20220804114917/https://docs.microsoft.com/en-us/learn/modules/cloud-adoption-framework-plan/4-exercise-digital-estate-assessment#readiness-and-suitability-analysis:~:text=Readiness%20unknown%3A%20Azure%20Migrate%20can%27t%20determine%20machine%20readiness) |
| **performance-based sizing**<br>按性能定规格 | "The **performance-based sizing** option in Azure Migrate assessments helps you to **right-size VMs**, and should be used as a **best practice** for optimizing workloads in Azure." | Azure Migrate 评估中的**按性能定规格**选项可帮助你**合理调整虚拟机规格**，并且应作为在 Azure 中优化工作负载的**最佳做法**加以使用。 | [Microsoft, 2022, "Get compute costs" section, para. 1](https://web.archive.org/web/20220804114917/https://docs.microsoft.com/en-us/learn/modules/cloud-adoption-framework-plan/4-exercise-digital-estate-assessment#get-compute-costs:~:text=The%20performance%2Dbased%20sizing%20option%20in%20Azure%20Migrate%20assessments%20helps) |
| **as on-premises (as-is) sizing**<br>按本地配置定规格 | "You can get **sizing recommendations** based on **performance history** (to optimize resources as you migrate), or based on **on-premises machine settings** without performance history." | 你可以获取**规格建议**，依据可以是**性能历史记录**（以便在迁移时优化资源），也可以是不含性能历史记录的**本地计算机设置**。 | [Microsoft, 2022, "Sizing recommendations" section, para. 1, sentence 2](https://web.archive.org/web/20220804114917/https://docs.microsoft.com/en-us/learn/modules/cloud-adoption-framework-plan/4-exercise-digital-estate-assessment#sizing-recommendations:~:text=You%20can%20get%20sizing%20recommendations%20based%20on%20performance%20history) |
| **database assessment**<br>数据库评估 | "Using **database assessments**, you can assess the readiness of your **SQL Server data estate** for migration to **Azure SQL Database**, or **Azure SQL Managed Instance**." | 使用**数据库评估**，你可以评估 **SQL Server 数据资产**迁移到 **Azure SQL 数据库**或 **Azure SQL 托管实例**的就绪情况。 | [Microsoft, 2022, "Readiness and suitability analysis" section, para. 2](https://web.archive.org/web/20220804114917/https://docs.microsoft.com/en-us/learn/modules/cloud-adoption-framework-plan/4-exercise-digital-estate-assessment#readiness-and-suitability-analysis:~:text=Using%20database%20assessments%2C%20you%20can%20assess%20the%20readiness%20of) |
