# Overview of application migration examples for Azure

Study notes on [Cloud Adoption Framework, migration examples (retired)](https://github.com/MicrosoftDocs/cloud-adoption-framework/blob/cb2149769f66/docs/migrate/azure-best-practices/contoso-migration-overview.md), which CST8913 Cloud Migration (Algonquin College, Fall 2026) uses in weeks 5 and 6. Each section follows one part of the source. Start from the figure: the framed terms are the ones to learn, and the table below it defines them in the same order, each with a citation linked to the passage and a Chinese translation in which each key word has the same colour as in the English. In the English, the verb of each sentence is underlined.

## [Rehost](https://github.com/MicrosoftDocs/cloud-adoption-framework/blob/cb2149769f66/docs/migrate/azure-best-practices/contoso-migration-overview.md#migration-patterns)

![Diagram: Rehost](media/overview-of-application-migration-examples-for-azure-1.png)

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **replication**<br>复制 | "During **initial replication**, a **VM snapshot** is created. Disk data from the snapshot is replicated to **replica managed disks (seed disks**) in Azure. After initial replication finishes, **delta replication** begins." | 在**初始复制**期间，会创建**虚拟机快照**。快照中的磁盘数据会复制到 Azure 中的**副本托管磁盘（种子磁盘**）。初始复制完成后，**增量复制**开始。 | [Microsoft, n.d., "Track migrations" section, bullet 2 ("Replication occurs as follows"), sub-bullet 2](https://learn.microsoft.com/en-us/azure/migrate/tutorial-migrate-vmware#track-migrations:~:text=During%20initial%20replication%2C%20a%20VM%20snapshot%20is%20created.%20Disk%20data) |
| **test migration**<br>测试迁移 | "**Test migration** **simulates the migration** by creating an Azure VM using **replicated data** (usually migrating to a **non-production VNet** in your Azure subscription)." | **测试迁移**会**模拟迁移**，方法是使用**复制的数据**创建 Azure 虚拟机（通常迁移到你 Azure 订阅中的**非生产虚拟网络**）。 | [Microsoft, n.d., "Run a test migration" section, bullet 2](https://learn.microsoft.com/en-us/azure/migrate/tutorial-migrate-vmware#run-a-test-migration:~:text=Test%20migration%20simulates%20the%20migration%20by%20creating%20an%20Azure%20VM) |
| **cutover**<br>切换 | "You can perform **final migrations (Cutover**) for these servers. ... By default Azure Migrate **shuts down the source** (on-premises or AVS) VM, and runs an **on-demand replication** to **synchronize** any VM changes that occurred since the last replication occurred." | 你可以对这些服务器执行**最终迁移（切换**）。……默认情况下，Azure Migrate 会**关闭源**（本地或 AVS）虚拟机，并运行**按需复制**，以**同步**自上次复制以来发生的任何虚拟机更改。 | [Microsoft, n.d., "Track migrations" section, bullet 3 ("Completion"), sub-bullet 1](https://learn.microsoft.com/en-us/azure/migrate/tutorial-migrate-vmware#track-migrations:~:text=You%20can%20perform%20final%20migrations%20%28Cutover%29%20for%20these%20servers) |

## [Refactor](https://github.com/MicrosoftDocs/cloud-adoption-framework/blob/cb2149769f66/docs/migrate/azure-best-practices/contoso-migration-overview.md#migration-patterns)

![Diagram: Refactor](media/overview-of-application-migration-examples-for-azure-2.png)

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **Azure DevOps**<br>Azure DevOps | "Provides a **continuous integration and continuous deployment (CI/CD) pipeline** for app development. The pipeline starts with a **Git repository** for managing app code, a **build system** for producing packages and other build artifacts, and a **Release Management system** to deploy changes in dev, test, and production environments." | 为应用开发提供**持续集成和持续部署 (CI/CD) 管道**。该管道首先包括：用于管理应用代码的 **Git 仓库**、用于生成包和其他生成项目的**生成系统**，以及用于在开发、测试和生产环境中部署更改的 **Release Management 系统**。 | [Microsoft, 2019, "Azure services" section, table 1, row 4 (Azure DevOps), Description](https://github.com/MicrosoftDocs/cloud-adoption-framework/blob/cb2149769f66/docs/migrate/azure-best-practices/contoso-migration-refactor-web-app-sql.md#azure-services:~:text=Provides%20a%20continuous%20integration%20and%20continuous%20deployment%20%28CI%2FCD%29%20pipeline) |
| **Data Migration Assistant (DMA)**<br>数据迁移助手 | "**Data Migration Assistant** is a **standalone tool** to assess SQL servers. It helps pinpoint **potential problems** that block migration. It finds **unsupported features**, new features that can benefit you after migration, and the right path for database migration." | **数据迁移助手**是用于评估 SQL 服务器的**独立工具**。它有助于找出阻碍迁移的**潜在问题**。它会找出**不受支持的功能**、迁移后可为你带来好处的新功能，以及数据库迁移的正确路径。 | [Microsoft, n.d., "Integrated tools and features" section, table 1, row 3 (Data Migration Assistant), Details](https://learn.microsoft.com/en-us/azure/migrate/migrate-services-overview#integrated-tools-and-features:~:text=Data%20Migration%20Assistant%20is%20a%20standalone%20tool%20to%20assess) |
| **Azure SQL Managed Instance**<br>Azure SQL 托管实例 | "**Azure SQL Managed Instance** is a **PaaS service** that has **near 100% compatibility** with the latest Enterprise Edition SQL Server Database Engine. ... SQL Managed Instance enables existing SQL Server customers to **lift and shift** their on-premises applications to the cloud with minimal application and database changes." *Note: The 2019 source calls it Azure SQL Database Managed Instance.* | **Azure SQL 托管实例**是一项 **PaaS 服务**，与最新的企业版 SQL Server 数据库引擎具有**近乎 100% 的兼容性**。……SQL 托管实例使现有 SQL Server 客户能够以最少的应用程序和数据库更改，将其本地应用程序**直接迁移**到云中。 | [Microsoft, n.d., "Overview" section, para. 1](https://learn.microsoft.com/en-us/azure/azure-sql/managed-instance/sql-managed-instance-paas-overview#overview:~:text=Azure%20SQL%20Managed%20Instance%20is%20a%20PaaS%20service%20that%20has) |
| **Azure Database for MySQL**<br>Azure MySQL 数据库 | "Azure Database for MySQL **flexible server** is a **fully managed**, **production-ready** **relational database service** in the Microsoft Cloud." | Azure MySQL 数据库**灵活服务器**是一种**完全托管**的、**可用于生产**的**关系数据库服务**，位于 Microsoft 云中。 | [Microsoft, n.d., para. 1](https://learn.microsoft.com/en-us/azure/mysql/flexible-server/overview#:~:text=Azure%20Database%20for%20MySQL%20flexible%20server%20is%20a%20fully%20managed) |
| **Azure Cosmos DB**<br>Azure Cosmos DB（非关系数据库） | "**Azure Cosmos DB** is a fully managed **NoSQL and vector database**. It offers **single-digit millisecond response times**, **automatic and instant scalability**, along with guaranteed speed at any scale." | **Azure Cosmos DB** 是一种完全托管的 **NoSQL 和矢量数据库**。它提供**个位数毫秒级的响应时间**、**自动且即时的可扩展性**，以及在任何规模下都有保证的速度。 | [Microsoft, n.d., "...for free" section, para. 1](https://learn.microsoft.com/en-us/azure/cosmos-db/overview#for-free:~:text=Azure%20Cosmos%20DB%20is%20a%20fully%20managed%20NoSQL%20and%20vector%20database) |
