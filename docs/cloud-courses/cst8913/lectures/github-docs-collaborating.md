# GitHub Docs: collaborating with pull requests

Study notes on [GitHub Docs](https://docs.github.com/en/pull-requests), which CST8913 Cloud Migration (Algonquin College, Fall 2026) uses in week 1. Each section follows one part of the source. Start from the figure: the framed terms are the ones to learn, and the table below it defines them in the same order, each with a citation linked to the passage and a Chinese translation in which each key word has the same colour as in the English. The main verb of each sentence has a red wavy underline, in the English and in the Chinese.

## [About pull requests and forks](https://docs.github.com/en/pull-requests/reference/pull-requests)

![Diagram: About pull requests and forks](media/github-docs-collaborating-1.png)

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **GitHub**<br>GitHub 平台 | "**GitHub** is a **platform** that supports your **entire software development process**, from **planning work** to deploying and operating software." | **GitHub** 是一个**平台**，支持你的**整个软件开发流程**，从**规划工作**到部署和运营软件。 | [GitHub, n.d., para. 1](https://docs.github.com/en/get-started/start-your-journey/what-is-github#:~:text=GitHub%20is%20a%20platform%20that%20supports%20your%20entire%20software) |
| **fork and pull model**<br>复刻加拉取请求模式 | "In the **fork and pull model**, anyone can fork an existing ("upstream") repository if they have **read access** and the **owner of the upstream repository** allows it." | 在**复刻加拉取请求模式**中，任何人都可以复刻现有的（“上游”）仓库，前提是他们拥有**读取权限**，并且**上游仓库的所有者**允许这样做。 | [GitHub, n.d., "Fork and pull model" section, para. 1](https://docs.github.com/en/pull-requests/reference/pull-requests#fork-and-pull-model:~:text=In%20the%20fork%20and%20pull%20model%2C%20anyone%20can%20fork) |
| **upstream repository**<br>上游仓库 | "**Forks** are repositories that start as **copies** of another repository, called the **upstream repository**." | **复刻**是一些仓库，它们最初是另一个仓库的**副本**，该仓库称为**上游仓库**。 | [GitHub, n.d., para. 1](https://docs.github.com/en/pull-requests/reference/forks#:~:text=Forks%20are%20repositories%20that%20start%20as%20copies%20of%20another) |
| **fork**<br>复刻（Fork） | "A **fork** is a **separate repository** with its **own settings** and **collaboration space**." | **复刻**是一个**独立的仓库**，拥有**自己的设置**和**协作空间**。 | [GitHub, n.d., "What makes forks distinct from branches" section, para. 1](https://docs.github.com/en/pull-requests/reference/forks#what-makes-forks-distinct-from-branches:~:text=A%20fork%20is%20a%20separate%20repository%20with%20its%20own) |
| **shared repository model**<br>共享仓库模式 | "In the **shared repository model**, **collaborators** have **push access** to a single shared repository and create **topic branches** when they need to make changes." | 在**共享仓库模式**中，**协作者**对单个共享仓库拥有**推送权限**，并在需要进行更改时创建**主题分支**。 | [GitHub, n.d., "Shared repository model" section, para. 1](https://docs.github.com/en/pull-requests/reference/pull-requests#shared-repository-model:~:text=In%20the%20shared%20repository%20model%2C%20collaborators%20have%20push%20access) |
| **collaborator**<br>协作者 | "A **collaborator** is a person with **read and write access** to a repository who has been **invited to contribute** by the repository owner." | **协作者**是对某个仓库拥有**读写访问权限**的人，此人已受仓库所有者**邀请参与贡献**。 | [GitHub, n.d., "collaborator" section, para. 1](https://docs.github.com/en/get-started/learning-about-github/github-glossary#collaborator:~:text=A%20collaborator%20is%20a%20person%20with%20read%20and%20write%20access) |
| **branch**<br>分支 | "A "**branch**" is a **line of development**. The **most recent commit** on a branch is referred to as the **tip** of that branch." | “**分支**”是一条**开发线**。分支上**最近的一次提交**被称为该分支的**末端**（tip）。 | [Git, n.d., "branch" entry](https://git-scm.com/docs/gitglossary#Documentation/gitglossary.txt-aiddefbranchabranch:~:text=A%20%22branch%22%20is%20a%20line%20of%20development.%20The%20most%20recent) |
| **pull request**<br>拉取请求（PR） | "**Pull requests** are **proposals** to merge **code changes** into a **project**." | **拉取请求**是一种**提议**：将**代码更改**合并到一个**项目**中。 | [GitHub, n.d., para. 1](https://docs.github.com/en/pull-requests/reference/pull-requests#:~:text=Pull%20requests%20are%20proposals%20to%20merge%20code%20changes%20into) |
| **review**<br>代码审查 | "**Pull request reviews** let people **comment on changes**, **suggest improvements**, and **approve or request changes** before code is merged." | **拉取请求审查**让人们可以在代码合并之前**对更改发表评论**、**提出改进建议**，以及**批准或请求更改**。 | [GitHub, n.d., para. 2](https://docs.github.com/en/pull-requests/reference/pull-request-reviews#:~:text=Pull%20request%20reviews%20let%20people%20comment%20on%20changes%2C%20suggest) |
| **merge**<br>合并 | "**Merging** takes the changes from **one branch** (in the same repository or from a **fork**), and **applies them into another**." | **合并**会获取来自**一个分支**（位于同一仓库中或来自某个**复刻**）的更改，并将其**应用到另一个分支**中。 | [GitHub, n.d., "merge" section, para. 1](https://docs.github.com/en/get-started/learning-about-github/github-glossary#merge:~:text=Merging%20takes%20the%20changes%20from%20one%20branch%20%28in%20the%20same) |
| **default branch**<br>默认分支 | "The **base branch** for new pull requests and code commits in a repository. Each repository has **at least one branch**, which Git creates when you **initialize** the repository. The first branch is usually called main, and is often the **default branch**." | 仓库中新拉取请求和代码提交的**基础分支**。每个仓库**至少有一个分支**，该分支由 Git 在你**初始化**仓库时创建。第一个分支通常称为 main，并且通常是**默认分支**。 | [GitHub, n.d., "default branch" section, para. 1](https://docs.github.com/en/get-started/learning-about-github/github-glossary#default-branch:~:text=The%20base%20branch%20for%20new%20pull%20requests%20and%20code) |
