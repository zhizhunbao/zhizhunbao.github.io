# Accessible by design

Study notes for CST8914 Accessible by Design (Algonquin College, Fall 2026). The pages follow the official sources the course uses (W3C WAI tutorials, the ARIA Authoring Practices Guide, Understanding WCAG 2.2 and the WCAG techniques), one page per source: one figure per part with the key terms framed, and a table that defines exactly those terms in the same order.
