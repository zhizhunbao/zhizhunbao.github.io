# CST8914: rules and allowed topics

The course slides copy W3C pages: every slide note names the page it came from. So this folder follows **the sources the slides copied**: one page per source, not one page per week or per slide deck, the same method as `../cst8913/`. This README is the contract for the folder. `build_site_pages.py` (cloud notes repo, `courses/accessible-by-design-cst8914/review/site/`) reads it and refuses to build a page that breaks it. This README is not published (`docfx.json` excludes `**/README.md`).

## Folders

- `index.md`: the overview, pages by week.
- `lectures/`: the source pages below and their figures in `lectures/media/`. `understanding-wcag-2-2.md` and `techniques-for-wcag-2-2.md` there are redirect stubs to `wcag-2-2.md` (the pages before the merge).
- `labs/`: one page per lab: what it practises and the concepts it needs, in my own words, each linked to the lecture section that explains it (the `LABS` list in `build_site_pages.py`). CST8914 labs are AI Level 2, so these pages hold no answers, fixes or handout text; my own answers can be added after a lab is submitted.

All are generated by `build_site_pages.py`, which also writes the CST8914 part of `../toc.yml`. Assignments are not published.

## Rules

1. **One page per source.** Each page in `lectures/` is one row of the table below: its file name, title (H1) and source are fixed there. A tutorial or a guide counts as one source; its sub-pages are its parts. The WCAG 2.2 supporting documents (Understanding WCAG 2.2 and Techniques for WCAG 2.2) count as one source, WCAG 2.2: success criteria first, then techniques (merged 2026-10-19).
2. **Sections (H2) are parts of that source.** Every H2 is one of the parts listed for its page, word for word, in that order: a sub-page title of the source. Each H2 links its part. A page may leave a part out, but may not add one. A later week adds parts to an existing page instead of a new page for the same source.
3. **One figure per section.** Every part section has exactly one figure, drawn by us in draw.io (no copied images, so terms can be marked).
4. **Key terms are framed on the figure.** A term worth learning is on the figure with a thick amber frame.
5. **The table holds only framed terms.** Each section's table lists exactly the framed terms of its figure, in figure order. Each term is defined on one page only, in the first section where it is framed.
6. **Definitions are quotes from the source** (or another official W3C, WHATWG or MDN page), with an in-text citation linked to the section and paragraph. Where no official text exists: my own words, marked "My own words".
7. **No slide text and no lab or assignment text is published.** My name, student number, email and repository names never appear.
