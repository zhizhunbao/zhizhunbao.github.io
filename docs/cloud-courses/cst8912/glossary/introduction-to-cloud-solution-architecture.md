### 1.2 Core components of cloud solution architecture

| Term | Definition | 中文解释 | Source |
|---|---|---|---|
| **cloud solution architecture** (云解决方案架构) | Cloud solution architecture is the design of which cloud services a solution uses and how they connect to meet a specific business need. | 为一个具体业务需求挑选云服务、规划它们怎么组合和连接的整体设计，比如一个网上商城该用哪种服务器、数据放在哪里、各部分怎么连起来。 | My own words |
| **cloud architecture** (云架构) | "Cloud architecture refers to the design and structure of how cloud services are delivered. It includes the components that work together to run applications over the internet, such as servers, storage, networking, and software." | 一朵云是怎么搭起来的：各种软硬件部件组合在一起，把很多台机器的计算能力和存储空间集中起来，再通过网络分给很多人用。 | [Microsoft, n.d., "Cloud architecture definition" section, para. 1](https://azure.microsoft.com/en-us/resources/cloud-computing-dictionary/what-is-cloud-architecture#:~:text=Cloud%20architecture%20refers%20to%20the%20design%20and%20structure%20of%20how%20cloud%20services%20are%20delivered.%20It%20includes%20the%20components) |
| **front-end platform** (前端平台) | "This is what users or developers interact with, such as a web app, mobile app, or API client." *Note: Microsoft lists the front-end platform as a component of cloud-based architecture; the quote is its description.* | 用户这一头用来访问云的东西，比如浏览器、手机 App 或电脑本身；也简称前端。 | [Microsoft, n.d., "Components of cloud-based architecture" section, bullet 1](https://azure.microsoft.com/en-us/resources/cloud-computing-dictionary/what-is-cloud-architecture#:~:text=This%20is%20what%20users%20or%20developers%20interact%20with%2C) |
| **back-end platform** (后端平台) | "This includes the infrastructure that processes requests, like servers, databases, storage, and app logic." *Note: Microsoft lists the back-end platform as a component of cloud-based architecture; the quote is its description.* | 云服务商那一头真正干活的部分：机房里的服务器、存储设备，以及让它们运转的管理和安全措施；也简称后端。 | [Microsoft, n.d., "Components of cloud-based architecture" section, bullet 2](https://azure.microsoft.com/en-us/resources/cloud-computing-dictionary/what-is-cloud-architecture#:~:text=This%20includes%20the%20infrastructure%20that%20processes%20requests%2C) |
| **network** (网络) | "This connects all components, including users, services, and data sources. This could be the public internet, a virtual private network (VPN), or a dedicated connection." *Note: Microsoft lists the network as a component of cloud-based architecture; the quote is its description.* | 把用户、设备和云里的各种资源连在一起、让它们能互相传数据的线路和设备，比如路由器和交换机。 | [Microsoft, n.d., "Components of cloud-based architecture" section, bullet 3](https://azure.microsoft.com/en-us/resources/cloud-computing-dictionary/what-is-cloud-architecture#:~:text=This%20connects%20all%20components%2C%20including%20users%2C%20services%2C) |
| **virtualization** (虚拟化) | "Virtualization is the process of creating virtual (rather than physical) versions of resources, such as servers, storage devices, and networks. Instead of relying on a single physical piece of hardware to perform all tasks, virtualization allows multiple virtual instances (known as virtual machines, or VMs) to operate independently on the same physical machine." | 用软件把一台真实的物理机器分成好几台「虚拟」机器，每台用起来都像一台独立的电脑，这样一台硬件能同时给好几个人用。 | [Microsoft, n.d., "What is virtualization, and how does it work?" section, para. 1](https://azure.microsoft.com/en-us/resources/cloud-computing-dictionary/what-is-virtualization#:~:text=Virtualization%20is%20the%20process%20of%20creating%20virtual%20%28rather) |
| **resource pooling** (资源池化) | "The provider’s computing resources are pooled to serve multiple consumers using a multi-tenant model, with different physical and virtual resources dynamically assigned and reassigned according to consumer demand." *Note: NIST lists resource pooling as one of the five essential characteristics of cloud computing.* | 把很多台机器的计算能力和存储空间集中成一个共享的大池子，谁需要就从里面分一些，用完再还回去。 | [Mell, 2011, "Essential Characteristics" section, bullet 3](https://nvlpubs.nist.gov/nistpubs/Legacy/SP/nistspecialpublication800-145.pdf#:~:text=The%20provider%E2%80%99s%20computing%20resources%20are%20pooled%20to%20serve) |
| **cloud delivery model** (云交付模型) | "Cloud delivery models define what you manage versus what your provider handles. Infrastructure as a Service (IaaS) gives you virtualized computing resources. Platform as a Service (PaaS) adds development tools and middleware. Software as a Service (SaaS) delivers complete applications." | 云服务「以什么形式交到你手上」：只给机器、给开发平台，还是给现成软件；就是服务模型（IaaS、PaaS、SaaS）的另一种叫法。 | [Microsoft, n.d., "What are delivery models in cloud architecture?" section, para. 1](https://azure.microsoft.com/en-us/resources/cloud-computing-dictionary/what-is-cloud-infrastructure#:~:text=Cloud%20delivery%20models%20define%20what%20you%20manage%20versus%20what) |
| **internet** (互联网) | "The internet is a worldwide network of interconnected computers that allows devices to exchange data and communicate, powering services like websites and email." | 把用户这头（前端）和云服务商那头（后端）连起来的公共网络，你发出的请求和云返回的结果都经过它传递。 | [Microsoft, n.d., "The cloud and the internet" section, para. 1](https://azure.microsoft.com/en-us/resources/cloud-computing-dictionary/what-is-the-cloud#:~:text=The%20internet%20is%20a%20worldwide%20network%20of%20interconnected%20computers) |
| **client infrastructure** (客户端基础设施) | "This is what users or developers interact with, such as a web app, mobile app, or API client." *Note: Microsoft calls it the front-end platform.* | 用户这一侧用来连上云的设备和软件，比如你的笔记本电脑、手机，以及上面的浏览器和 App。 | [Microsoft, n.d., "Components of cloud-based architecture" section, bullet 1](https://azure.microsoft.com/en-us/resources/cloud-computing-dictionary/what-is-cloud-architecture#:~:text=This%20is%20what%20users%20or%20developers%20interact%20with%2C) |
| **application** (应用程序) | "A software program hosted by an information system." | 用户真正想用的那个软件本身，它放在云的后端运行，比如网上商城、在线文档。 | [National Institute of Standards and Technology, n.d., definition 2](https://csrc.nist.gov/glossary/term/application#:~:text=A%20software%20program%20hosted%20by%20an%20information%20system.) |
| **service** (服务) | In cloud architecture, the service component is the back-end part that decides which type of cloud service the user can access, such as software, a platform, or infrastructure. | 后端里决定「用户能用哪一类云服务」的部分：是现成的软件、写程序用的平台，还是只租机器。 | My own words |
| **service model** (服务模型) | "Service models describe how cloud resources are delivered to users. They determine how much control an organization has over infrastructure, platforms, or applications." | 按「服务商替你管多少、你自己管多少」给云服务分的类，一共三种：IaaS、PaaS、SaaS。 | [Microsoft, n.d., "Types of cloud service models" section, para. 1](https://azure.microsoft.com/en-us/resources/cloud-computing-dictionary/types-of-cloud-computing#:~:text=Service%20models%20describe%20how%20cloud%20resources%20are%20delivered%20to) |
| **runtime cloud** (运行时云) | The runtime cloud is the back-end part that provides the environment where virtual machines and applications actually run. | 后端里让程序真正跑起来的地方，虚拟机和应用程序都在这里运行。 | My own words |
| **storage** (存储) | "Cloud storage is a way of saving data on remote servers where it can be accessed online instead of on local computers or physical hard drives." *Note: Microsoft defines it as cloud storage.* | 云里专门存放和管理数据的部分，容量很大，比如网盘里的照片、网站用户的资料都存在这里。 | [Microsoft, n.d., "Cloud storage definition" section, para. 1](https://azure.microsoft.com/en-us/resources/cloud-computing-dictionary/what-is-cloud-storage#:~:text=Cloud%20storage%20is%20a%20way%20of%20saving%20data%20on) |
| **infrastructure** (基础设施) | "A cloud infrastructure is the collection of hardware and software that enables the five essential characteristics of cloud computing." *Note: NIST calls it cloud infrastructure.* | 撑起整个云的底层软硬件：服务器、存储设备、网络设备，以及把一台机器分成多台虚拟机的软件。 | [Mell, 2011, "2. The NIST Definition of Cloud Computing" section, footnote 2](https://nvlpubs.nist.gov/nistpubs/Legacy/SP/nistspecialpublication800-145.pdf#:~:text=A%20cloud%20infrastructure%20is%20the%20collection%20of%20hardware) |
| **management** (管理) | In cloud architecture, management is the back-end layer that coordinates the other parts, such as applications, services, runtime, storage, infrastructure, and security, so they work together. | 后端里统一调度其他各部分的那一层，让应用、服务、运行环境、存储、基础设施和安全配合着一起运转。 | My own words |
| **security** (安全) | "Cloud infrastructure often includes a variety of security measures, like encryption, authentication, access control, and monitoring, to protect your data by rapidly identifying threats." *Note: Microsoft describes security as one of the components of cloud infrastructure.* | 后端里保护云上系统、数据和设备的各种措施，比如只让有权限的人登录、防止数据被偷看或被篡改。 | [Microsoft, n.d., "Security" section, para. 1](https://azure.microsoft.com/en-us/resources/cloud-computing-dictionary/what-is-cloud-infrastructure#:~:text=Cloud%20infrastructure%20often%20includes%20a%20variety%20of%20security%20measures%2C) |

### 1.3 Cloud Service Models - IaaS

| Term | Definition | 中文解释 | Source |
|---|---|---|---|
| **Infrastructure as a Service (IaaS)** (基础设施即服务) | "Infrastructure as a service (IaaS) is the most flexible category of cloud services. It provides the maximum amount of control for your cloud resources." | 向云服务商租用机房里的硬件（服务器、存储、网络），操作系统及以上的部分都由你自己安装和管理，控制权最大，要管的事也最多。 | [Microsoft, n.d., para. 1](https://learn.microsoft.com/en-us/training/modules/describe-cloud-service-types/2-describe-infrastructure-service#:~:text=Infrastructure%20as%20a%20service%20%28IaaS%29%20is%20the%20most) |
| **workload** (工作负载) | "A workload is a collection of IT components, such as servers, virtual machines (VMs), cloud services, applications, code, data, or appliances, that support one or more business processes." | 为业务干一件具体事情的一个应用或一组资源，比如公司的网上商城、工资系统。 | [Microsoft, 2025, July 15, "Discover workload inventory" section, bullet 1](https://learn.microsoft.com/en-us/azure/cloud-adoption-framework/plan/discover-existing-workload-inventory#discover-workload-inventory:~:text=A%20workload%20is%20a%20collection%20of%20IT%20components%2C) |
| **lift and shift** (直接迁移（原样迁移）) | "Lift-and-shift migration: You set up cloud resources similar to your on-premises datacenter, and then move your workloads to the IaaS infrastructure." *Note: The Cloud Adoption Framework calls this strategy rehost.* | 把现有系统几乎原封不动地搬到云上，像搬家时把整个柜子直接抬走，不重新改造。 | [Microsoft, n.d., "Scenarios" section, bullet 1](https://learn.microsoft.com/en-us/training/modules/describe-cloud-service-types/2-describe-infrastructure-service#scenarios:~:text=Lift%2Dand%2Dshift%20migration%3A%20You%20set%20up%20cloud%20resources%20similar) |
| **legacy** (遗留（旧有）) | "Legacy: A legacy workload generally has characteristics that newer technologies or practices could improve." *Note: The Cloud Adoption Framework treats legacy as a condition to assess, not as age alone.* | 用了很多年、还在用、但可以用新技术改进的系统、做法或流程，比如十几年前写的、至今还在跑的公司内部软件。 | [Microsoft, 2026, October 16, "1.2 Modern versus legacy" section, bullet 2](https://learn.microsoft.com/en-us/azure/cloud-adoption-framework/modernize/prepare-organization-cloud-modernization#12-modern-versus-legacy:~:text=Legacy%3A%20A%20legacy%20workload%20generally%20has%20characteristics%20that) |
| **digital transformation** (数字化转型) | Digital transformation is the use of digital technology to change how a business operates and how it delivers value to customers. | 用数字技术改变公司做生意和服务客户的方式，比如银行把柜台业务搬到手机 App 上。 | My own words |

### 1.4 Cloud Service Models - PaaS

| Term | Definition | 中文解释 | Source |
|---|---|---|---|
| **Platform as a Service (PaaS)** (平台即服务) | "Platform as a service (PaaS) is a middle ground between renting space in a datacenter (infrastructure as a service) and paying for a complete and deployed solution (software as a service)." | 云服务商把服务器、操作系统、数据库和开发工具都管好，你只需要关心自己的应用和数据，适合快速开发新应用或改造旧应用。 | [Microsoft, n.d., para. 1](https://learn.microsoft.com/en-us/training/modules/describe-cloud-service-types/3-describe-platform-service#:~:text=Platform%20as%20a%20service%20%28PaaS%29%20is%20a%20middle) |
| **fully managed** (全托管) | A fully managed service is one where the provider runs and maintains everything underneath it, such as servers, patching, and updates, so you only use the service. | 服务背后的服务器、升级、维修全部由云服务商负责，你只管用，碰不到也不用管底下的机器。 | My own words |
| **refactor** (重构) | "Refactoring improves the internal structure of code without adding new features." | 把现有程序的内部结构改一改、重新组织，但不增加新功能，常常是为了让它更好地用上云平台服务。 | [Microsoft, 2025, July 15, "4. Refactor (modernize code)" section, para. 1](https://learn.microsoft.com/en-us/azure/cloud-adoption-framework/plan/select-cloud-migration-strategy#4-refactor-modernize-code:~:text=Refactoring%20improves%20the%20internal%20structure%20of%20code%20without) |
| **modernization** (现代化改造) | "Modernization improves an existing workload or workload component to better meet current or future business requirements." | 把老系统升级改造，让它更好地满足现在和以后的业务需要，比如把自己机房里的老网站改成跑在云平台上。 | [Microsoft, 2026, October 16, "1. What is modernization?" section, para. 1](https://learn.microsoft.com/en-us/azure/cloud-adoption-framework/modernize/prepare-organization-cloud-modernization#1-what-is-modernization:~:text=Modernization%20improves%20an%20existing%20workload%20or%20workload%20component) |
| **multi-tenant** (多租户) | "A multitenant solution is a solution used by multiple customers, or tenants. Tenants are distinct from users." *Note: Microsoft writes it as one word, multitenant.* | 很多客户共用同一套软件和机器，但各自的数据隔开、互相看不到，像一栋公寓楼里住着很多户人家。 | [Microsoft, 2025, April 17, para. 1](https://learn.microsoft.com/en-us/azure/architecture/guide/multitenant/overview#:~:text=A%20multitenant%20solution%20is%20a%20solution%20used%20by) |
| **economies of scale** (规模经济) | Economies of scale means that the cost per unit goes down as the size of an operation goes up. A large cloud provider buys and runs hardware cheaply and passes part of the savings to each customer. | 规模越大、单位成本越低：云服务商的客户越多，分摊到每个客户头上的成本就越少，像批发比零售便宜。 | My own words |

### 1.6 Benefits of Cloud Architecture

| Term | Definition | 中文解释 | Source |
|---|---|---|---|
| **capital expenditure (CapEx)** (资本支出) | "CapEx refers to up-front spending on physical infrastructure like servers, network hardware, and datacenter space." | 一开始就要一次性花一大笔钱买下来的东西，比如自己买服务器、建机房。 | [Microsoft, n.d., para. 2](https://learn.microsoft.com/en-us/training/modules/describe-cloud-compute/6-describe-consumption-based-model#:~:text=CapEx%20refers%20to%20up%2Dfront%20spending%20on%20physical%20infrastructure) |
| **operational expenditure (OpEx)** (运营支出) | "OpEx refers to ongoing spending on services over time. Because you pay for cloud services as you consume them, cloud computing is classified as an operational expense." | 日常持续要付的开销，比如每个月的房租和水电费；云服务按月按用量付费，就属于运营支出。 | [Microsoft, n.d., para. 2](https://learn.microsoft.com/en-us/training/modules/describe-cloud-compute/6-describe-consumption-based-model#:~:text=OpEx%20refers%20to%20ongoing%20spending%20on%20services%20over) |
| **on-premises (on-prem)** (本地部署) | On-premises means that the servers and infrastructure sit in the organization's own building or datacenter, and the organization buys and maintains them itself. | 服务器放在公司自己的办公楼或机房里，由公司自己买、自己管，而不是租用云。 | My own words |
| **latency** (延迟) | "Latency measures the time between when a request for an operation is initiated and when the result is available or the process is complete." | 从发出请求到收到回应之间要等的时间，比如点了按钮之后，网页过了多久才有反应。 | [Microsoft, 2024, August 16, "Consider common SLOs and influencing factors" section, bullet 2](https://learn.microsoft.com/en-us/azure/well-architected/reliability/metrics#consider-common-slos-and-influencing-factors:~:text=Latency%20measures%20the%20time%20between%20when%20a%20request) |
| **scalability** (可扩展性) | "Scalability refers to the ability to adjust resources to meet demand." | 用户变多、工作量变大时，系统能靠加机器或加配置跟得上的能力，比如购物节前临时多加几台服务器。 | [Microsoft, n.d., "Scalability" section, para. 1](https://learn.microsoft.com/en-us/training/modules/describe-benefits-use-cloud-services/2-high-availability-scalability-cloud#scalability:~:text=Scalability%20refers%20to%20the%20ability%20to%20adjust%20resources) |
| **scale up** (纵向扩展) | "With vertical scaling, if you were developing an app and you needed more processing power, you could vertically scale up to add more CPUs or RAM to the virtual machine." *Note: Learn files scale up and scale down under vertical scaling.* | 把同一台机器的配置调高，比如把一台虚拟机从 2 核 CPU 换成 8 核。 | [Microsoft, n.d., "Vertical scaling" section, para. 1](https://learn.microsoft.com/en-us/training/modules/describe-benefits-use-cloud-services/2-high-availability-scalability-cloud#vertical-scaling:~:text=With%20vertical%20scaling%2C%20if%20you%20were%20developing%20an) |
| **scale down** (纵向缩减) | "Conversely, if you realized you had over-specified the needs, you could vertically scale down by lowering the CPU or RAM specifications." *Note: Learn files scale up and scale down under vertical scaling.* | 把同一台机器的配置调低，比如用不了那么多资源时，把 8 核的虚拟机换回 2 核来省钱。 | [Microsoft, n.d., "Vertical scaling" section, para. 1](https://learn.microsoft.com/en-us/training/modules/describe-benefits-use-cloud-services/2-high-availability-scalability-cloud#vertical-scaling:~:text=Conversely%2C%20if%20you%20realized%20you%20had%20over%2Dspecified%20the) |
| **scale out** (横向扩展) | "With horizontal scaling, if you suddenly experienced a steep jump in demand, your deployed resources could be scaled out (either automatically or manually).
