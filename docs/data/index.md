## Glossary

| Term | Definition | 中文翻译 | Source |
|---|---|---|---|
| **Data**<br>数据 | "**Information** in a **specific representation**, usually as a **sequence of symbols** that have meaning." | **信息**，以**特定的表示形式**呈现，通常是一串有意义的**符号序列**。 | [National Institute of Standards and Technology, n.d., "data" entry, definition 1](https://csrc.nist.gov/glossary/term/data#:~:text=Information%20in%20a%20specific%20representation) |
| **[CS2023 DM](cs2023/index.md)**<br>CS2023 DM | "Today's graduates are expected to possess **DBMS user** (rather than implementor) skills. These primarily include **data modeling** and **query construction**; ability to take an unorganized collection of data, **organize it using a DBMS**, and access/update the collection via queries." | 如今的毕业生应具备**DBMS 使用者**（而非实现者）的技能。这些技能主要包括**数据建模**和**查询构建**；能够把一堆无组织的数据**用 DBMS 组织起来**，并通过查询访问和更新这些数据。 | [Joint Task Force on Computing Curricula, 2024, DM "Preamble" section, para. 2](https://csed.acm.org/wp-content/uploads/2024/04/3.1-Body-of-Knowledge-1.pdf#page=51) |
| **Analytics engines**<br>分析引擎 | "Apache Spark is a **unified analytics engine** for **large-scale data processing**." | Apache Spark 是一个**统一的分析引擎**，用于**大规模数据处理**。 | [The Apache Software Foundation, n.d., "Overview" page, para. 1](https://spark.apache.org/docs/latest/#:~:text=Apache%20Spark%20is%20a%20unified%20analytics%20engine) |
| **Document databases**<br>文档数据库 | "MongoDB is a **document database** designed to help developers **build modern applications faster**. It stores data in **flexible, JSON-like documents**, making it easy to model data the same way your application code uses it." | MongoDB 是一种**文档数据库**，旨在帮助开发者**更快地构建现代应用**。它把数据存储在**灵活的、类似 JSON 的文档**中，让你能按应用代码使用数据的方式来建模数据。 | [MongoDB, Inc., n.d.-b, "What is MongoDB?" page, para. 1](https://www.mongodb.com/docs/manual/introduction/#:~:text=MongoDB%20is%20a%20document%20database%20designed) |
| **In-memory data stores**<br>内存数据存储 | "Redis can be used as a **database**, **cache**, **streaming engine**, **message broker**, and more." | Redis 可以用作**数据库**、**缓存**、**流处理引擎**、**消息代理**等。 | [Redis Ltd., n.d.-b, "Quick starts" page, para. 1](https://redis.io/docs/latest/develop/get-started/#:~:text=Redis%20can%20be%20used%20as%20a%20database) |
| **Relational database systems**<br>关系数据库系统 | "PostgreSQL is an **object-relational database management system (ORDBMS)** based on POSTGRES, Version 4.2, developed at the **University of California at Berkeley** Computer Science Department." | PostgreSQL 是一个**对象关系数据库管理系统（ORDBMS）**，基于 POSTGRES 4.2 版，由**加州大学伯克利分校**计算机科学系开发。 | [The PostgreSQL Global Development Group, n.d.-b, "1. What Is PostgreSQL?" section, para. 1](https://www.postgresql.org/docs/current/intro-whatis.html#:~:text=PostgreSQL%20is%20an%20object%2Drelational%20database%20management%20system) |
| **Vector databases**<br>向量数据库 | "Chroma gives you **everything you need for retrieval**: store **embeddings with metadata**, search with **dense and sparse vectors**, filter by metadata, and retrieve across text, images, and more." | Chroma 为你提供**检索所需的一切**：存储**带元数据的嵌入向量**，用**稠密和稀疏向量**搜索，按元数据过滤，并跨文本、图像等内容检索。 | [Chroma, n.d., "Introduction" page, para. 1](https://docs.trychroma.com/docs/overview/introduction#:~:text=Chroma%20gives%20you%20everything%20you%20need%20for%20retrieval) |
