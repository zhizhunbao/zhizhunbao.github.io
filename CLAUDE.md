Read README.md first. Write only Markdown and toc.yml; no HTML or components. One exception: `docs/templates/kb/public/quiz.js` renders multiple-choice quizzes from JSON data files; a quiz page is still Markdown, and marks the quiz with a link to its JSON file (see README.md). Follow the content rules in README.md. The CST8913 midterm page is generated by `build_public_page.py` in the cloud notes repo (`courses/cloud-migration-cst8913/review/midterm/`); edit its data there, not the generated page.
