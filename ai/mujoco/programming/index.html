              Term Definition 中文翻译 Source
              5 Programming
              编程              		 "This chapter is the MuJoCo programming guide." 本章是 MuJoCo 编程指南。 Google DeepMind, n.d.-c, "Introduction", para. 1
              5.1 Header files
              头文件              		 (context) "The distribution contains several header files which are identical on all platforms." （语境）发行包中包含若干在所有平台上都相同的头文件。 Google DeepMind, n.d.-c, "Header files", para. 1
              5.2 Versions and compatibility
              版本与兼容性              		 (No definition) （无定义） Google DeepMind, n.d.-c, "Versions and compatibility"
              5.3 Naming convention
              命名约定              		 (context) "All symbols defined in the API start with the prefix “mj”." （语境）API 中定义的所有符号都以前缀“mj”开头。 Google DeepMind, n.d.-c, "Naming convention", para. 1
              5.4 Simulation
              仿真              		 (No definition) （无定义） Google DeepMind, n.d.-e, "Simulation"
              5.5 Visualization
              可视化              		 (context) "MuJoCo has a native 3D visualization layer that is independent of any graphics library." （语境）MuJoCo 有一个不依赖任何图形库的原生三维可视化层。 Google DeepMind, n.d.-g, "Visualization", para. 1
              5.6 Rendering
              渲染              		 (context) "MuJoCo provides two built-in 3D rendering backends that support both interactive onscreen viewers and headless offscreen rendering:" （语境）MuJoCo 提供两个内置的三维渲染后端，既支持交互式屏幕查看器，也支持无界面的离屏渲染： Google DeepMind, n.d.-d, "Rendering", para. 1
              5.7 User Interface
              用户界面              		 (context) "MuJoCo has a native UI framework." （语境）MuJoCo 有一个原生的 UI 框架。 Google DeepMind, n.d.-f, "User Interface", para. 1
              5.8 Model Editing
              模型编辑              		 (context) "It is possible to create and modify models using the mjSpec struct and related API." （语境）可以用 mjSpec 结构体和相关 API 创建和修改模型。 Google DeepMind, n.d.-b, "Model Editing", para. 1
              5.9 Extensions
              扩展              		 (context) "At present, extensibility is provided by via engine plugins, decoders, and resource providers." （语境）目前，可扩展性由引擎插件、解码器和资源提供者提供。 Google DeepMind, n.d.-a, "Extensions", para. 1
