              Glossary

              Term Definition 中文翻译 Source
              PyTorch
              PyTorch              		 "PyTorch is an optimized tensor library for deep learning using GPUs and CPUs." PyTorch 是一个经过优化的张量库，用于在 GPU 和 CPU 上进行深度学习。 PyTorch Foundation, n.d.-a, "PyTorch documentation", para. 1
              1 Intro
              入门              		 "This is a collection of beginner-friendly resources to help you get started with PyTorch." 这是一组适合初学者的资源，帮助你开始使用 PyTorch。 PyTorch Foundation, n.d.-b, "Intro", para. 1
              2 Compilers
              编译器              		 "Explore PyTorch compilers to optimize and deploy models efficiently." 探索 PyTorch 编译器，用来高效地优化和部署模型。 PyTorch Foundation, n.d.-b, "Compilers", para. 1
              3 Domains
              领域              		 "This section contains specialized tutorials focused on applying PyTorch to specific application areas." 本节包含专门的教程，着重于把 PyTorch 应用到特定的应用领域。 PyTorch Foundation, n.d.-b, "Domains", para. 1
              4 Distributed
              分布式              		 "Distributed training is a model training paradigm that involves spreading training workload across multiple worker nodes, therefore significantly improving the speed of training and model accuracy." 分布式训练是一种把训练工作负载分散到多个工作节点上的模型训练范式，从而显著提高训练速度和模型准确率。 PyTorch Foundation, n.d.-b, "Distributed", para. 1
              5 Deep Dive
              深入              		 "Focused on enhancing model performance, this section includes tutorials on profiling, hyperparameter tuning, quantization, and other techniques to optimize PyTorch models for better efficiency and speed." 本节着重于提升模型性能，包括关于性能分析、超参数调优、量化以及其他优化 PyTorch 模型的技术的教程，以获得更高的效率和速度。 PyTorch Foundation, n.d.-b, "Deep Dive", para. 1
              6 Extension
              扩展              		 "This section provides insights into extending PyTorch’s capabilities." 本节介绍如何扩展 PyTorch 的能力。 PyTorch Foundation, n.d.-b, "Extension", para. 1
              7 Ecosystem
              生态              		 "Explore tutorials that cover tools and frameworks in the PyTorch ecosystem." 探索涵盖 PyTorch 生态中各种工具和框架的教程。 PyTorch Foundation, n.d.-b, "Ecosystem", para. 1
              8 Recipes
              实用示例              		 "Recipes are bite-sized, actionable examples of how to use specific PyTorch features, different from our full-length tutorials." 实用示例是小而可直接上手的例子，演示如何使用 PyTorch 的特定功能，不同于完整的教程。 PyTorch Foundation, n.d.-b, "Recipes", para. 1
              9 Unstable
              不稳定              		 "API unstable features are not available as part of binary distributions like PyPI or Conda (except maybe behind run-time flags)." API 不稳定的功能不包含在 PyPI 或 Conda 等二进制发行版中（可能藏在运行时开关后面的除外）。 PyTorch Foundation, n.d.-b, "Unstable", para. 1
