              OpenCV
              OpenCV              		 "OpenCV (Open Source Computer Vision Library) is an open source computer vision and machine learning software library." OpenCV（开源计算机视觉库）是一个开源的计算机视觉和机器学习软件库。 OpenCV team, n.d.-a, "About", para. 2

              核心操作              		 "In this section you will learn basic operations on image like pixel editing, geometric transformations, code optimization, some mathematical tools etc." 在本节中，你将学习图像的基本操作，如像素编辑、几何变换、代码优化、一些数学工具等。 OpenCV team, n.d.-b, "OpenCV-Python Tutorials", item 3
              2 Image Processing in OpenCV
              OpenCV 中的图像处理              		 "In this section you will learn different image processing functions inside OpenCV." 在本节中，你将学习 OpenCV 中各种图像处理函数。 OpenCV team, n.d.-b, "OpenCV-Python Tutorials", item 4
              3 Feature Detection and Description
              特征检测与描述              		 "In this section you will learn about feature detectors and descriptors" 在本节中，你将学习特征检测器和描述子 OpenCV team, n.d.-b, "OpenCV-Python Tutorials", item 5
              4 Camera Calibration and 3D Reconstruction
              相机标定与三维重建              		 "In this section we will learn about camera calibration, stereo imaging etc." 在本节中，我们将学习相机标定、立体成像等。 OpenCV team, n.d.-b, "OpenCV-Python Tutorials", item 7

              7 Object Detection (objdetect module)
              目标检测（objdetect 模块）              		 "In this section you will learn object detection techniques like face detection etc." 在本节中，你将学习目标检测技术，如人脸检测等。 OpenCV team, n.d.-b, "OpenCV-Python Tutorials", item 10
