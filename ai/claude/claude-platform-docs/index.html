              Classification

              Glossary

              Term Definition 中文翻译 Source
              Claude Platform Docs
              Claude 平台文档              		 (Summary) The developer documentation for building on Claude through its APIs and SDKs. （概述）开发者文档，介绍如何通过 API 和 SDK 基于 Claude 构建应用。 Anthropic, n.d., "Claude Platform Docs"
              1. Messages
              消息              		 (Summary) The core API for sending prompts to Claude, with tools, context and file features. （概述）向 Claude 发送提示的核心 API，包含工具、上下文和文件功能。 Anthropic, n.d., "Messages"
              2. Managed Agents
              托管代理              		 (Summary) An agent runtime hosted by Anthropic, so you need not build the loop yourself. （概述）由 Anthropic 托管的代理运行环境，你无需自己构建循环。 Anthropic, n.d., "Managed Agents"
              3. Admin
              管理              		 (Summary) APIs for running an organization on the platform: members, keys, usage and compliance. （概述）管理平台上组织的 API：成员、密钥、用量和合规。 Anthropic, n.d., "Admin"
              4. Best Practices
              最佳实践              		 (Summary) Guidance on writing better prompts and measuring and protecting results. （概述）关于写出更好的提示，以及衡量和保护结果的指南。 Anthropic, n.d., "Best Practices"
              5. Models and Pricing
              模型与定价              		 (Summary) The current and older Claude models, with how to choose among them and what they cost. （概述）现有和旧版 Claude 模型，以及如何选择和费用。 Anthropic, n.d., "Models and Pricing"
              6. SDKs, CLI, and Libraries
              SDK、CLI 与库              		 (Summary) The official command-line tool and client libraries for calling the API from code. （概述）官方命令行工具和客户端库，用于从代码调用 API。 Anthropic, n.d., "SDKs, CLI, and Libraries"
              7. API Reference
              API 参考              		 (Summary) The REST interface details, including versions, rate limits and regions. （概述）REST 接口的细节，包括版本、速率限制和地区。 Anthropic, n.d., "API Reference"

              References

              Anthropic. (n.d.). Claude Platform Docs. Retrieved November 8, 2026, from https://platform.claude.com/docs/en/home
