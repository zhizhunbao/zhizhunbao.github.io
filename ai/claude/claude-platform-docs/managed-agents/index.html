              Glossary

              Term Definition 中文翻译 Source
              2. Managed Agents
              托管代理              		 (Summary) An agent runtime hosted by Anthropic, so you need not build the loop yourself. （概述）由 Anthropic 托管的代理运行环境，你无需自己构建循环。 Anthropic, n.d., "Managed Agents"
              2.1 Define Your Agent
              定义代理              		 (Summary) What an agent is configured with: its tools, permissions and skills. （概述）代理的配置内容：工具、权限和技能。 Anthropic, n.d., "Define Your Agent"
              2.2 Configure Agent Environment
              配置代理环境              		 (Summary) The sandbox an agent runs in, and how it is set up. （概述）代理运行所在的沙箱，以及如何设置。 Anthropic, n.d., "Configure Agent Environment"
              2.3 Self-Hosted Sandboxes
              自托管沙箱              		 (Summary) Running the agent's sandbox on your own machines while Anthropic hosts the loop. （概述）在你自己的机器上运行代理沙箱，而循环仍由 Anthropic 托管。 Anthropic, n.d., "Self-Hosted Sandboxes"
              2.4 Delegate Work to Your Agent
              向代理委派工作              		 (Summary) How to hand work to an agent and follow its progress. （概述）如何把工作交给代理并跟踪进度。 Anthropic, n.d., "Delegate Work to Your Agent"
              2.5 Manage Agent Context
              管理代理上下文              		 (Summary) How an agent gets at repositories and files, and returns files to you. （概述）代理如何访问代码库和文件，以及如何把文件交还给你。 Anthropic, n.d., "Manage Agent Context"
              2.6 Build Persistent Memory
              构建持久记忆              		 (Summary) Features that let an agent keep what it learns from one session to the next. （概述）让代理保留所学内容、从一个会话延续到下一个的功能。 Anthropic, n.d., "Build Persistent Memory"
              2.7 Advanced Orchestration
              高级编排              		 (Summary) Ways to coordinate several agents or sessions and run them on a schedule. （概述）协调多个代理或会话并按计划运行的方式。 Anthropic, n.d., "Advanced Orchestration"
              2.8 Security
              安全              		 (Summary) How to reduce the risks of autonomous sessions and watch what they do. （概述）如何降低自主会话的风险并监看其行为。 Anthropic, n.d., "Security"
              2.9 Managed Agents Reference
              托管代理参考              		 (Summary) The lookup page for Managed Agents details. （概述）查询页，列出 Managed Agents 的细节。 Anthropic, n.d., "Managed Agents Reference"
