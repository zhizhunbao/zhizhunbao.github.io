              4.2.1 Success Criteria and Evaluations

              Glossary

              Term Definition 中文翻译 Source
              Success Criteria and Evaluations
              成功标准与评估              		 (Summary) The measurable goals for an LLM application and the tests that check performance against them. （概述）LLM 应用的可衡量目标，以及据此检验表现的测试。 Anthropic, n.d., "Define Success and Build Evaluations"
              Success Criteria
              成功标准              		 (Summary) Goals for an application that are specific and measurable, and also achievable and relevant to what its users need. （概述）应用要达到的目标，要具体且可衡量，同时可实现并且切合用户的需要。 Anthropic, n.d., "Define Success and Build Evaluations", "Define your success criteria"
              Task Fidelity
              任务保真度              		 (Summary) How well the model must perform the task itself, including rare or difficult inputs. （概述）模型完成任务本身要好到什么程度，包括少见或困难的输入。 Anthropic, n.d., "Define Success and Build Evaluations", "Task fidelity"
              Consistency
              一致性              		 (Summary) How similar the answers must be when the model receives similar inputs, such as the same question asked twice. （概述）回答要相近到什么程度，指模型收到相似输入时，例如同一个问题问两次。 Anthropic, n.d., "Define Success and Build Evaluations", "Consistency"
              Relevance and Coherence
              相关性与连贯性              		 (Summary) Whether the output directly addresses the request and presents its information in a logical, easy-to-follow order. （概述）输出是否直接回应请求，并以合乎逻辑、容易跟上的顺序呈现信息。 Anthropic, n.d., "Define Success and Build Evaluations", "Relevance and coherence"
              Tone and Style
              语气与风格              		 (Summary) Whether the style of the output matches expectations and its language suits the intended audience. （概述）输出的风格是否符合预期，用语是否适合目标读者。 Anthropic, n.d., "Define Success and Build Evaluations", "Tone and style"
              Privacy Preservation
              隐私保护              		 (Summary) How the model handles personal or sensitive information, and whether it follows instructions not to use or share certain details. （概述）模型如何处理个人或敏感信息，以及是否遵守不使用、不分享某些细节的指示。 Anthropic, n.d., "Define Success and Build Evaluations", "Privacy preservation"
              Context Utilization
              上下文利用              		 (Summary) How effectively the model uses the context it was given and builds on earlier information in the conversation. （概述）模型能否有效利用给它的上下文，并在先前的信息之上继续对话。 Anthropic, n.d., "Define Success and Build Evaluations", "Context utilization"
              Latency
              延迟              		 (Summary) The response time that is acceptable, which depends on the application's real-time needs and user expectations. （概述）可接受的响应时间，取决于应用的实时性需要与用户预期。 Anthropic, n.d., "Define Success and Build Evaluations", "Latency"
              Price
              价格              		 (Summary) The budget for running the model, shaped by cost per call, model size and how often it is used. （概述）运行模型的预算，由每次调用的成本、模型大小与使用频率决定。 Anthropic, n.d., "Define Success and Build Evaluations", "Price"
              Evaluation (Eval)
              评估              		 (Summary) A set of test cases that mirrors the real task, with edge cases, built so that grading can be automated and run in volume. （概述）一组贴近真实任务的测试用例，包含边界情况，设计成可以自动评分并大量运行。 Anthropic, n.d., "Define Success and Build Evaluations", "Eval design principles"
              Edge Case
              边界情况              		 (Summary) An input that is rare or hard to handle, such as missing, overly long, harmful or ambiguous data. （概述）少见或难处理的输入，例如缺失、过长、有害或含糊的数据。 Anthropic, n.d., "Define Success and Build Evaluations", "Eval design principles"
              Exact Match Evaluation
              精确匹配评估              		 (Summary) An eval that checks whether the output equals a predefined correct answer, usually after normalizing spacing and case. （概述）检查输出是否等于预先给定的正确答案的评估，通常先做规范化（空白与大小写）。 Anthropic, n.d., "Define Success and Build Evaluations", "Task fidelity (sentiment analysis): exact match evaluation"
              Cosine Similarity Evaluation
              余弦相似度评估              		 (Summary) An eval that measures how close two outputs are by comparing the vectors of their sentence embeddings. （概述）衡量两段输出有多接近的评估，做法是比较它们的句向量。 Anthropic, n.d., "Define Success and Build Evaluations", "Consistency (FAQ bot): cosine similarity evaluation"
              ROUGE-L
              ROUGE-L              		 (Summary) A score for generated summaries based on the longest common subsequence shared with a reference summary. （概述）给生成的摘要打的分，依据与参考摘要共有的最长公共子序列。 Anthropic, n.d., "Define Success and Build Evaluations", "Relevance and coherence (summarization): ROUGE-L evaluation"
              LLM-Based Likert Scale
              基于 LLM 的李克特量表              		 (Summary) A rating scale on which an LLM judges a subjective quality, such as tone, by assigning a score. （概述）一种评分量表，由 LLM 评判主观品质（如语气）并给出分数。 Anthropic, n.d., "Define Success and Build Evaluations", "Tone and style (customer service): LLM-based Likert scale"
              LLM-Based Binary Classification
              基于 LLM 的二分类              		 (Summary) A check in which an LLM sorts each output into one of two classes, for example whether it contains protected information. （概述）一种检查，由 LLM 把每条输出分到两类之一，例如是否含有受保护的信息。 Anthropic, n.d., "Define Success and Build Evaluations", "Privacy preservation (medical chatbot): LLM-based binary classification"
              LLM-Based Ordinal Scale
              基于 LLM 的顺序量表              		 (Summary) A fixed, ordered scale (1 to 5) on which an LLM rates an output, for example how well it uses context. （概述）一个固定且有序的量表（1 到 5），由 LLM 给输出评级，例如对上下文的利用程度。 Anthropic, n.d., "Define Success and Build Evaluations", "Context utilization (conversation assistant): LLM-based ordinal scale"
              Code-Based Grading
              基于代码的评分              		 (Summary) Grading by rules written in code, such as exact or string match: fastest and most reliable, but without nuance. （概述）用写成代码的规则评分，如精确匹配或字符串匹配：最快也最可靠，但缺少细微判断。 Anthropic, n.d., "Define Success and Build Evaluations", "Grade your evaluations"
              Human Grading
              人工评分              		 (Summary) Grading done by people: the most flexible and highest in quality, but slow and expensive. （概述）由人完成的评分：最灵活、质量最高，但慢而且贵。 Anthropic, n.d., "Define Success and Build Evaluations", "Grade your evaluations"
              LLM-Based Grading
              基于 LLM 的评分              		 (Summary) Grading done by a model following a rubric: fast and scalable for complex judgments, once its reliability has been tested. （概述）由模型按评分细则完成的评分：对复杂判断又快又可扩展，前提是先验证过它的可靠性。 Anthropic, n.d., "Define Success and Build Evaluations", "Grade your evaluations"
