              Term Definition 中文翻译 Source
              Claude Code Docs
              Claude Code 文档              		 (Summary) The official manual for Claude Code, the AI coding assistant. （概述）官方手册，介绍 Claude Code 这款 AI 编码助手。 Anthropic, n.d., "Claude Code Docs"
              1. Getting Started
              入门              		 (Summary) The basic ideas of Claude Code and where it can be used. （概述）Claude Code 的基本概念，以及可以在哪些地方使用它。 Anthropic, n.d., "Getting Started"
              2. Build with Claude Code
              用 Claude Code 构建              		 (Summary) Ways to run several agents at once and automate repeated work. （概述）同时运行多个代理并自动化重复工作的方法。 Anthropic, n.d., "Build with Claude Code"
              3. Plugins
              插件              		 (Summary) Shareable add-on packages that extend Claude Code with skills, hooks and more. （概述）可分享的附加包，用技能、钩子等扩展 Claude Code。 Anthropic, n.d., "Plugins"
              4. Administration
              管理              		 (Summary) How organizations roll out Claude Code and control its cost and security. （概述）组织如何部署 Claude Code，并控制其成本和安全。 Anthropic, n.d., "Administration"
              5. Configuration
              配置              		 (Summary) The settings, permissions and environments that decide how Claude Code behaves. （概述）设置、权限和环境，它们决定 Claude Code 的行为。 Anthropic, n.d., "Configuration"
              6. Reference
              参考              		 (Summary) Lookup pages for commands, variables and tools, plus the official glossary. （概述）命令、变量和工具的查询页，以及官方术语表。 Anthropic, n.d., "Reference"
              7. Agent SDK
              Agent SDK              		 (Summary) A library that puts the agent loop of Claude Code inside your own programs. （概述）把 Claude Code 的代理循环放进你自己的程序的库。 Anthropic, n.d., "Agent SDK"
