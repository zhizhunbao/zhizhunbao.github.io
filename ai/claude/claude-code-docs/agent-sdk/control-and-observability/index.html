              7.6 Control and Observability

              Glossary

              Term Definition 中文翻译 Source
              7.6 Control and Observability
              控制与可观测性              		 (Summary) How to limit what an agent may do and see what it did. （概述）如何限制代理能做的事，并查看它做了什么。 Anthropic, n.d., "Control and Observability"
              7.6.1 Permissions
              权限              		 (Summary) The modes, rules and callback that decide which tool calls may run. （概述）模式、规则和回调，它们决定哪些工具调用可以执行。 Anthropic, n.d., "Configure Permissions"
              7.6.2 Hooks
              钩子              		 (Summary) Your own callbacks triggered by agent events, used to block, log or rewrite actions. （概述）由代理事件触发的自定义回调，用于拦截、记录或改写操作。 Anthropic, n.d., "Intercept and Control Agent Behavior with Hooks"
              7.6.3 File Checkpointing
              文件检查点              		 (Summary) A record of edits made through file tools, from which you can restore earlier versions; shell edits are not covered. （概述）对通过文件工具所做修改的记录，可以恢复到之前的版本；shell 命令的修改不在其内。 Anthropic, n.d., "Rewind File Changes with Checkpointing"
              7.6.4 Cost and Usage Tracking
              成本与用量跟踪              		 (Summary) The token figures reported for each interaction, plus a cost that is only an estimate on the client side. （概述）每次交互报告的令牌数，以及仅为客户端估算的费用。 Anthropic, n.d., "Track Cost and Usage"
              7.6.5 Observability with OpenTelemetry
              用 OpenTelemetry 实现可观测性              		 (Summary) Export of an agent's traces, metrics and logs to any OTLP-compatible backend. （概述）把代理的追踪、指标和日志导出到任何兼容 OTLP 的后端。 Anthropic, n.d., "Observability with OpenTelemetry"
              7.6.6 Todo Tracking
              待办跟踪              		 (Summary) A written task list kept by Claude during multi-step work, offered only on certain models. （概述）Claude 在多步骤工作中维护的书面任务清单，仅部分模型提供。 Anthropic, n.d., "Track Todos"

              References

              Anthropic. (n.d.). Claude Code Docs. Retrieved November 8, 2026, from https://code.claude.com/docs/en/overview
