              Glossary

              Term Definition 中文翻译 Source
              1.2 Features and Capabilities
              功能与能力              		 (Summary) The things Claude can make or connect to, from artifacts and research to plugins. （概述）Claude 能创建或连接的内容，从 Artifact、研究到插件。 Anthropic, n.d., "Features and Capabilities"
              1.2.1 Artifacts
              Artifact              		 (Summary) A finished piece of work from Claude, such as a slide deck or small app, that sits next to the chat and can be revised and passed on. （概述）Claude 产出的成品，例如幻灯片或小应用，显示在对话旁边，可以继续修改并分享给别人。 Anthropic, n.d., "What are artifacts and how do I use them?"
              1.2.2 Claude Dashboards
              Claude Dashboards              		 (Summary) An artifact type that answers business questions with charts, after Claude generates SQL against a connected data source. （概述）一种 Artifact，用图表回答业务问题，由 Claude 针对已连接的数据源生成 SQL。 Anthropic, n.d., "Get started with Claude Dashboards"
              1.2.3 Claude Docs
              Claude Docs              		 (Summary) A shared writing space where Claude drafts and comments alongside your colleagues, with no separate editor needed. （概述）一个共享写作空间，Claude 与同事一起在其中起草并批注，无需另用编辑器。 Anthropic, n.d., "Get started with Claude Docs"
              1.2.4 Claude Design
              Claude Design              		 (Summary) An artifact template for visual work such as mock-ups and prototypes, made through conversation and adjusted directly on a canvas. （概述）用于样稿、原型等视觉作品的 Artifact 模板，通过对话生成，并可直接在画布上调整。 Anthropic, n.d., "Get started with Claude Design"
              1.2.5 Design System
              设计系统              		 (Summary) A stored set of brand rules (colour, type, components, layout) that Claude pulls from your files and reuses in each new design. （概述）一套保存下来的品牌规则（颜色、字体、组件、布局），由 Claude 从你的文件中提取，并在每个新设计中沿用。 Anthropic, n.d., "Set up your design system in Claude Design"
              1.2.6 Standalone Claude Design
              独立版 Claude Design              		 (Summary) The separate site for Claude Design, being replaced by the version inside Claude; it turns read-only after December 14, 2026. （概述）Claude Design 的独立网站，正被 Claude 内的版本取代；2026 年 12 月 14 日之后变为只读。 Anthropic, n.d., "Move from standalone Claude Design to Claude"
              1.2.7 When to Use Web Search, Extended Thinking, and Research
              何时使用网页搜索、扩展思考与研究              		 (Summary) A guide comparing three features by the kind of question each suits, with web search for simple factual lookups. （概述）一篇比较三项功能的指南，按各自适合的问题类型说明，其中网页搜索适合简单的事实查询。 Anthropic, n.d., "When should I use web search, extended thinking, and research?"
              1.2.8 Research
              研究              		 (Summary) A mode in which Claude chains many searches, choosing each next step from earlier results, to study a question in depth. （概述）一种模式，Claude 连续进行多次搜索，根据前面的结果决定下一步，以深入研究一个问题。 Anthropic, n.d., "Use research on Claude"
              1.2.9 File Creation
              文件创建              		 (Summary) A capability where Claude runs code inside the chat to produce downloadable Office and PDF files from plain requests. （概述）一项能力，Claude 在对话中运行代码，根据普通请求生成可下载的 Office 和 PDF 文件。 Anthropic, n.d., "Create and edit files with Claude"
              1.2.10 Projects
              项目              		 (Summary) Separate workspaces that each keep their own chats and reference material. （概述）彼此独立的工作区，各自保存自己的聊天和参考资料。 Anthropic, n.d., "What are projects?"
              1.2.11 Retrieval Augmented Generation (RAG) for Projects
              项目的检索增强生成（RAG）              		 (Summary) A mode Claude enters automatically as project files near the context limit, so a project can hold far more material. （概述）当项目文件接近上下文上限时，Claude 自动进入的一种模式，使项目能容纳多得多的资料。 Anthropic, n.d., "Retrieval augmented generation (RAG) for projects"
              1.2.12 Skills
              技能              		 (Summary) Packaged instructions and files that Claude brings in only when a task needs them, so the same job is done the same way each time. （概述）打包好的说明和文件，Claude 仅在任务需要时载入，让同一项工作每次都按同样方式完成。 Anthropic, n.d., "What are skills?"
              1.2.13 Custom Skills
              自定义技能              		 (Summary) Skills you write yourself to give Claude your own know-how and procedures, from a short note to a multi-file package. （概述）你自己编写的技能，向 Claude 提供你自己的知识和流程，可以是一段简短说明，也可以是多文件的包。 Anthropic, n.d., "How to create custom skills"
              1.2.14 Plugins
              插件              		 (Summary) One installable bundle of skills, connectors and sub-agents that sets Claude up for a given role or team. （概述）一个可安装的组合包，含技能、连接器和子代理，让 Claude 适配特定角色或团队。 Anthropic, n.d., "Use plugins in Claude"
              1.2.15 Unified Directory
              统一目录              		 (Summary) One catalogue where skills, connectors and plugins are found and installed, including those an organization publishes. （概述）一个统一目录，用于查找和安装技能、连接器和插件，也包括组织发布的内容。 Anthropic, n.d., "Browse skills, connectors, and plugins in one directory"
              1.2.16 Plugins Page
              插件页              		 (Summary) The single page that replaces the former separate tabs for skills, connectors and plugins, under Plugins in the sidebar. （概述）取代原来技能、连接器、插件各自标签页的单一页面，位于侧边栏的 Plugins 下。 Anthropic, n.d., "Manage plugins, skills, and connectors from one Plugins page"
              1.2.17 Claude in Xcode
              Xcode 中的 Claude              		 (Summary) Claude built into Apple's Xcode 26 as the model behind its coding help features. （概述）集成在 Apple Xcode 26 中的 Claude，是其编码辅助功能背后的模型。 Anthropic, n.d., "Use Claude in Xcode"
              1.2.18 Claude in Microsoft Foundry
              Microsoft Foundry 中的 Claude              		 (Summary) Claude models offered through Microsoft Foundry, so that Azure customers can build applications under their existing agreements. （概述）通过 Microsoft Foundry 提供的 Claude 模型，让 Azure 客户在现有协议下构建应用。 Anthropic, n.d., "Use Claude in Microsoft Foundry"
              1.2.19 Visual and Interactive Content
              可视化与交互内容              		 (Summary) Replies that go beyond plain text, such as data widgets and diagrams, along with clickable questions in place of typing. （概述）不只是纯文本的回复，例如数据小组件和图表，还有用来代替打字的可点选问题。 Anthropic, n.d., "Visual and interactive content"
              1.2.20 Custom Visuals
              自定义可视化              		 (Summary) Diagrams and charts Claude draws from scratch and shows within its reply, in beta on web and desktop. （概述）Claude 从零绘制并显示在回复中的图表，目前在网页端和桌面端处于测试阶段。 Anthropic, n.d., "Custom visuals in chat and Cowork"
              1.2.21 Beta and Research Preview Labels
              测试版与研究预览标签              		 (Summary) Two labels for unfinished features; a research preview is at an earlier stage and may change more. （概述）标记未完成功能的两种标签；研究预览阶段更早，变动可能更大。 Anthropic, n.d., "Available beta and research preview features"
              1.2.22 Monthly Recap
              月度回顾              		 (Summary) A personal report of how you used Claude over the month, shown only when memory is on. （概述）关于你当月如何使用 Claude 的个人报告，仅在开启记忆时显示。 Anthropic, n.d., "See your monthly recap"
              1.2.23 Claude Science
              Claude Science              		 (Summary) A beta desktop application for scientists in which Claude writes and runs analysis code from a plain-language task. （概述）面向科研的测试版桌面应用，Claude 根据用自然语言描述的任务编写并运行分析代码。 Anthropic, n.d., "Get started with Claude Science"
              1.2.24 Salesforce in Claude
              Claude 中的 Salesforce              		 (Summary) A plugin linking Claude to Salesforce data, with ready-made sales skills, so reps can do CRM work from the chat. （概述）将 Claude 接入 Salesforce 数据的插件，附带现成的销售技能，让销售人员在对话中完成客户管理工作。 Anthropic, n.d., "Use Salesforce in Claude"
              1.2.25 Claude for Google Workspace
              Claude for Google Workspace              		 (Summary) A sidebar inside Docs, Sheets and Slides through which Claude changes the open file directly. （概述）位于 Google 文档、表格和幻灯片内的侧边栏，Claude 通过它直接修改打开的文件。 Anthropic, n.d., "Use Claude in Google Docs, Sheets, and Slides"
              1.2.26 Claude Duet
              Claude Duet              		 (Summary) A research preview you text like a person, which acts in your connected apps and checks with you before risky steps. （概述）一个像给人发消息一样使用的研究预览版，可在你已连接的应用中操作，并在执行高风险步骤前先征求你的确认。 Anthropic, n.d., "Get started with Claude Duet"
