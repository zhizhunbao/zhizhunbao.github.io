              Glossary

              Term Definition 中文翻译 Source
              GGUF
              GGUF              		 (context) "Hugging Face Hub supports all file formats, but has built-in features for GGUF format, a binary format that is optimized for quick loading and saving of models, making it highly efficient for inference purposes." （语境）Hugging Face Hub 支持所有文件格式，但为 GGUF 格式提供了内置功能；GGUF 是一种二进制格式，针对模型的快速加载与保存做了优化，因而用于推理时效率很高。 Hugging Face, n.d., "GGUF", para. 1
              GGML
              GGML              		 (context) "GGUF is designed for use with GGML and other executors." （语境）GGUF 是为配合 GGML 及其他执行器使用而设计的。 Hugging Face, n.d., "GGUF", para. 1
              llama.cpp
              llama.cpp              		 (context) "GGUF was developed by @ggerganov who is also the developer of llama.cpp, a popular C/C++ LLM inference framework." （语境）GGUF 由 @ggerganov 开发，他也是 llama.cpp 的开发者；llama.cpp 是一个流行的 C/C++ LLM 推理框架。 Hugging Face, n.d., "GGUF", para. 1
              GGUF Conversion
              GGUF 转换              		 (context) "Models initially developed in frameworks like PyTorch can be converted to GGUF format for use with those engines." （语境）最初在 PyTorch 等框架中开发的模型，可以转换为 GGUF 格式，供这些引擎使用。 Hugging Face, n.d., "GGUF", para. 1
              GGUF Metadata
              GGUF 元数据              		 (context) "unlike tensor-only file formats like safetensors – which is also a recommended model format for the Hub – GGUF encodes both the tensors and a standardized set of metadata." （语境）与 safetensors 这类只存张量的文件格式不同（safetensors 也是 Hub 推荐的模型格式），GGUF 既编码张量，也编码一组标准化的元数据。 Hugging Face, n.d., "GGUF", para. 2
              GGUF Viewer
              GGUF 查看器              		 "The Hub has a viewer for GGUF files that lets a user check out metadata & tensors info (name, shape, precision)." Hub 有一个 GGUF 文件查看器，让用户查看元数据与张量信息（名称、形状、精度）。 Hugging Face, n.d., "Viewer for metadata & tensors info", para. 1

              BF16
              BF16              		 "16-bit shortened version of the 32-bit IEEE 754 single-precision floating-point number." 16 位缩短版，缩短自 32 位 IEEE 754 单精度浮点数。 Hugging Face, n.d., "Quantization Types", BF16
              I16
              I16              		 "16-bit fixed-width integer number." 16 位定宽整数。 Hugging Face, n.d., "Quantization Types", I16
              Q8_K
              Q8_K              		 "8-bit quantization (q). Each block has 256 weights. Only used for quantizing intermediate results. All 2-6 bit dot products are implemented for this quantization type. Weight formula: w = q * block_scale." 8 位量化（q）。每个块有 256 个权重。只用于量化中间结果。所有 2 至 6 位的点积都为这种量化类型实现了。权重公式：w = q * block_scale。 Hugging Face, n.d., "Quantization Types", Q8_K
              I8
              I8              		 "8-bit fixed-width integer number." 8 位定宽整数。 Hugging Face, n.d., "Quantization Types", I8
              Q6_K
              Q6_K              		 "6-bit quantization (q). Super-blocks with 16 blocks, each block has 16 weights. Weight formula: w = q * block_scale(8-bit), resulting in 6.5625 bits-per-weight." 6 位量化（q）。超级块含 16 个块，每块 16 个权重。权重公式：w = q * block_scale(8-bit)，结果为每权重 6.5625 位。 Hugging Face, n.d., "Quantization Types", Q6_K
              Q5_K
              Q5_K              		 "5-bit quantization (q). Super-blocks with 8 blocks, each block has 32 weights. Weight formula: w = q * block_scale(6-bit) + block_min(6-bit), resulting in 5.5 bits-per-weight." 5 位量化（q）。超级块含 8 个块，每块 32 个权重。权重公式：w = q * block_scale(6-bit) + block_min(6-bit)，结果为每权重 5.5 位。 Hugging Face, n.d., "Quantization Types", Q5_K
              Q4_K
              Q4_K              		 "4-bit quantization (q). Super-blocks with 8 blocks, each block has 32 weights. Weight formula: w = q * block_scale(6-bit) + block_min(6-bit), resulting in 4.5 bits-per-weight." 4 位量化（q）。超级块含 8 个块，每块 32 个权重。权重公式：w = q * block_scale(6-bit) + block_min(6-bit)，结果为每权重 4.5 位。 Hugging Face, n.d., "Quantization Types", Q4_K
              Q3_K
              Q3_K              		 "3-bit quantization (q). Super-blocks with 16 blocks, each block has 16 weights.               Quantization Accuracy Loss
              量化精度损失              		 (context) "This process however, may introduce some accuracy loss which is usually measured in Perplexity (ppl) and/or Kullback–Leibler Divergence (kld)." （语境）不过，这个过程可能带来一些精度损失，通常用困惑度（ppl）和/或 KL 散度（kld）来衡量。 ggml-org, n.d., "quantize", para. 1
              Importance Matrix
              重要性矩阵              		 (context) "use data in file_name as importance matrix for quant optimizations" （语境）把 file_name 中的数据用作量化优化的重要性矩阵。 ggml-org, n.d., "Quantize the GGUF", option --imatrix
              K-Quant Mixture
              k-quant 混合              		 (context) "disable k-quant mixtures and quantizes all tensors to the same type" （语境）关闭 k-quant 混合，把所有张量量化成同一类型。 ggml-org, n.d., "Quantize the GGUF", option --pure
              Quantization Mix
              量化混合方案              		 (Summary) A llama.cpp quantization type that assigns different block types to different tensors of the model; when k-quants were added (2023), every such type also kept the output weight tensor at 6 bits. （概述）llama.cpp 的一种量化类型，给模型的不同张量分配不同的块类型；k-quants 加入时（2023 年），每种这类类型都把输出权重张量保持在 6 位。 Kawrakow, 2023, "k-quants"
