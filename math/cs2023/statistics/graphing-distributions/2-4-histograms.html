              2.4 Histograms
              直方图              		 (No definition) （无定义） Online Statistics Education, n.d., section 2.4
              Class Frequency
              组频数              		 "One of the components of a histogram, the class frequency is the number of observations in each class interval. See also: relative frequency." 作为直方图的组成部分之一，组频数是每个组距中的观测数。另见：相对频数。 Online Statistics Education, n.d., glossary
              Class Interval
              组距              		 "Also known as bin width, the class interval is a division of data for use in a histogram. For instance, it is possible to partition scores on a 100 point test into class intervals of 1-25, 26-49, 50-74 and 75-100." 又称箱宽，组距是为绘制直方图而对数据所做的划分。例如，可以将一次满分 100 分的测验的分数划分为 1-25、26-49、50-74 和 75-100 的组距。 Online Statistics Education, n.d., glossary
              Grouped Frequency Table
              分组频数表              		 "A grouped frequency table shows the number of values for various ranges of scores. Below is shown a grouped frequency table for response times (in milliseconds) for a simple motor task." 分组频数表显示各个得分范围内值的个数。下面给出了一项简单运动任务的反应时间（以毫秒计）的分组频数表。 Online Statistics Education, n.d., glossary
              Histogram
              直方图              		 "A histogram is a graphical representation of a distribution. It partitions the variable on the \(x\)-axis into various contiguous class intervals of (usually) equal widths. The heights of the bars represent the class frequencies. …" 直方图是分布的一种图形表示。它把 \(x\) 轴上的变量划分为若干（通常）等宽的相邻组距。各条形的高度表示各组的频数。… Online Statistics Education, n.d., glossary
              Sturgis's Rule
              斯特吉斯规则              		 "One method of determining the number of classes for a histogram, Sturgis’ Rule is to take \(1 + \log_2 (N)\) classes, rounded to the nearest integer." 斯特吉斯规则是确定直方图组数的一种方法，即取 \(1 + \log_2 (N)\) 个组，四舍五入到最接近的整数。 Online Statistics Education, n.d., glossary
