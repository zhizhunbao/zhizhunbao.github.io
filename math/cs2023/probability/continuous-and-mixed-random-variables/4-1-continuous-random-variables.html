              4.1.0 Continuous Random Variables and their Distributions

              Continuous Random Variable
              连续型随机变量              		 "A random variable \(X\) with CDF \(F_X(x)\) is said to be continuous if \(F_X(x)\) is a continuous function for all \(x \in \mathbb{R}\)." 若随机变量 \(X\) 的 CDF \(F_X(x)\) 对所有 \(x \in \mathbb{R}\) 都是连续函数，则称 \(X\) 是连续的。 Pishro-Nik, 2014, section 4.1.0
              Continuous random variable
              连续随机变量              		 (context) "A random variable is a measurable function from a probability space ... into a measurable space ... known as the state space ..." （语境）随机变量是从概率空间到可测空间的可测函数……后者称为状态空间…… Weisstein, n.d.-b, "Random variable" entry, para. 1
              Continuous distribution
              连续分布              		 "A continuous distribution is a statistical distribution for which the variables may take on a continuous range of values." 连续分布是一种统计分布，其中变量可以在连续的取值范围内取值。 Weisstein, n.d.-a, "Continuous distribution" entry, para. 1
              4.1.1 Probability Density Function
              概率密度函数              		 (No definition) （无定义） Pishro-Nik, 2014, section 4.1.1
              Probability Density Function (PDF)
              概率密度函数（PDF）              		 "Consider a continuous random variable \(X\) with an absolutely continuous CDF \(F_X(x)\). The function \(f_X(x)\) defined by \(f_X(x)=\frac{dF_X(x)}{dx}=F'_X(x), \hspace{20pt} \textrm{if }F_X(x) \textrm{ is differentiable at }x\) is called the probability density function (PDF) of \(X\)." 考虑具有绝对连续 CDF \(F_X(x)\) 的连续型随机变量 \(X\)。由 \(f_X(x)=\frac{dF_X(x)}{dx}=F'_X(x), \hspace{20pt} \textrm{if }F_X(x) \textrm{ is differentiable at }x\) 定义的函数 \(f_X(x)\) 称为 \(X\) 的概率密度函数（PDF）。 Pishro-Nik, 2014, section 4.1.1
              Range of a Random Variable
              随机变量的值域              		 "The range of a random variable \(X\) is the set of possible values of the random variable." 随机变量 \(X\) 的值域是该随机变量所有可能取值构成的集合。 Pishro-Nik, 2014, section 4.1.1
