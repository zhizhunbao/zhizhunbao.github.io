              指数分布              		 (No definition) （无定义） Pishro-Nik, 2014, section 4.2.2
              Memoryless Property
              无记忆性              		 "The most important of these properties is that the exponential distribution is memoryless." 这些性质中最重要的是指数分布是无记忆的。 Pishro-Nik, 2014, section 4.2.2
              4.2.3 Normal (Gaussian) Distribution
              正态（高斯）分布              		 (No definition) （无定义） Pishro-Nik, 2014, section 4.2.3
              Standard Normal Random Variable
              标准正态随机变量              		 "We first define the standard normal random variable." 我们首先定义标准正态随机变量。 Pishro-Nik, 2014, section 4.2.3
              Standard Normal CDF
              标准正态分布函数              		 "We usually denote the standard normal CDF by \(\Phi\)." 我们通常用 \(\Phi\) 表示标准正态分布函数。 Pishro-Nik, 2014, section 4.2.3
              Normal Random Variable
              正态随机变量              		 "We say that \(X\) is a normal random variable with mean \(\mu\) and variance \(\sigma^2\)." 我们称 \(X\) 是均值为 \(\mu\)、方差为 \(\sigma^2\) 的正态随机变量。 Pishro-Nik, 2014, section 4.2.3

              伽马分布              		 (No definition) （无定义） Pishro-Nik, 2014, section 4.2.4
              Gamma Function
              伽马函数              		 "The gamma function [ 10 ], shown by \(\Gamma(x)\), is an extension of the factorial function to real (and complex) numbers." 伽马函数 [ 10 ] 记作 \(\Gamma(x)\)，是阶乘函数的推广，定义域扩展到实数（和复数）。 Pishro-Nik, 2014, section 4.2.4
              Gamma Distribution
              伽马分布              		 "The gamma distribution is another widely used distribution." 伽马分布是另一种应用广泛的分布。 Pishro-Nik, 2014, section 4.2.4
