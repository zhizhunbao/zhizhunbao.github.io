              0.1 Number Sets
              数集              		 (No definition) （无定义） (none)
              \(\mathbb{N}\)
              自然数              		 "The term "natural number" refers either to a member of the set of positive integers 1, 2, 3, ..." ... "or to a member of the set of nonnegative integers 0, 1, 2, 3, ..." 自然数指正整数 1, 2, 3, … 中的数，或指非负整数 0, 1, 2, 3, … 中的数。 Weisstein, n.d., "natural number" entry
              \(\mathbb{Z}\)
              整数              		 "One of the numbers ..., \(-2\), \(-1\), 0, 1, 2, .... The set of integers forms a ring that is denoted \(\mathbb{Z}\)." 整数是数 …, −2, −1, 0, 1, 2, … 中的一个。整数集构成一个环，记作 \(\mathbb{Z}\)。 Weisstein, n.d., "integer" entry
              \(\mathbb{Q}\)
              有理数              		 "A rational number is a number that can be expressed as a fraction \(p/q\) where \(p\) and \(q\) are integers and \(q \neq 0\)." 有理数是能写成分数 \(p/q\) 的数，其中 \(p\)、\(q\) 为整数且 \(q \neq 0\)。 Weisstein, n.d., "rational number" entry
              \(\mathbb{R}\)
              实数              		 "A real number is a member of the field \(\mathbb{R}\) containing all rational and irrational numbers." 实数是包含全部有理数和无理数的域 \(\mathbb{R}\) 的元素。 Weisstein, n.d., "real number" entry
              \(\mathbb{C}\)
              复数              		 "The complex numbers are the field \(\mathbb{C}\) of numbers of the form \(x + iy\), where \(x\) and \(y\) are real numbers and \(i\) is the imaginary unit equal to the square root of \(-1\), \(\sqrt{-1}\)." 复数是形如 \(x + iy\) 的数构成的域 \(\mathbb{C}\)，其中 \(x\)、\(y\) 为实数，\(i\) 为虚数单位，等于 \(-1\) 的平方根 \(\sqrt{-1}\)。 Weisstein, n.d., "complex number" entry
