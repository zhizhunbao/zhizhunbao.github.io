              Term Definition 中文翻译 Source
              Programming
              编程              		 "Fluency in the process of software development is fundamental to the study of computer science. To use computers to solve problems most effectively, students must be competent at reading and writing programs." 熟练掌握软件开发的过程是学习计算机科学的基础。要最有效地用计算机解决问题，学生必须能够熟练地阅读和编写程序。 Joint Task Force on Computing Curricula, 2024, SDF "Preamble" section, para. 1
              CS2023 FPL
              CS2023 FPL              		 "The Foundations of Programming Languages knowledge area is concerned with articulating the underlying concepts and principles of programming languages, the formal specification of a programming language and the behavior of a program, explaining how programming languages are implemented, ..." 编程语言基础知识领域关注阐明编程语言的底层概念与原理、编程语言的形式化规约和程序的行为，并解释编程语言是如何实现的，…… Joint Task Force on Computing Curricula, 2024, FPL "Preamble" section, para. 2
              CS2023 SDF
              CS2023 SDF              		 "The SDF knowledge area brings together fundamental concepts and skills related to software development, focusing on concepts and skills that should be taught early in a computer science program, typically in the first year." SDF 知识领域汇集了基础概念与技能，与软件开发相关，侧重于应在计算机科学课程早期讲授的概念和技能，通常在第一年。 Joint Task Force on Computing Curricula, 2024, SDF "Preamble" section, para. 2
              CS2023 SE
              CS2023 SE              		 "This is an essential insight: while programming is the skill that governs our ability to write a program, software engineering is distinct in two dimensions: time and people." 这是一个关键的洞见：编程是决定我们能否写出程序的技能，而软件工程的不同在于两个维度：时间和人。 Joint Task Force on Computing Curricula, 2024, SE "Preamble" section, para. 1
              CS2023 SPD

              SWEBOK
              软件工程知识体系              		 "The Guide to the Software Engineering Body of Knowledge (SWEBOK Guide), published by the IEEE Computer Society (IEEE CS), reflects the current state of generally accepted, consensus-driven knowledge derived from the interaction between software engineering theory and practice." 《软件工程知识体系指南》（SWEBOK Guide）由 IEEE 计算机学会（IEEE CS）出版，反映了公认的、基于共识的知识的现状，这些知识源自软件工程理论与实践之间的相互作用。 Washizaki, 2024, "About SWEBoK" section, para. 1

              Runtime environments
              运行时环境              		 "Node.js® is a free, open-source, cross-platform JavaScript runtime environment that lets developers create servers, web apps, command line tools and scripts." Node.js® 是一个免费、开源、跨平台的 JavaScript 运行时环境，让开发者能够创建服务器、Web 应用、命令行工具和脚本。 OpenJS Foundation, n.d.-c, home page, para. 1
