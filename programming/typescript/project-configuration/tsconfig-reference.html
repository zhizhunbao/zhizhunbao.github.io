              9.3 TSConfig Reference

              Glossary

              Term Definition 中文翻译 Source
              TSConfig Reference
              TSConfig 参考              		 (Definition pending) （定义待补） Microsoft, n.d., "TSConfig Reference"
              Type Checking
              类型检查              		 (Definition pending) （定义待补） Microsoft, n.d., "Compiler Options", "Type Checking" section
              No Unchecked Indexed Access
              未检查的索引访问（noUncheckedIndexedAccess）              		 "Turning on noUncheckedIndexedAccess will add undefined to any un-declared field in the type." 开启 noUncheckedIndexedAccess 会加上 undefined，作用于类型中任何未声明的字段。 Microsoft, n.d., "Type Checking", "No Unchecked Indexed Access", para. 2
              Projects
              项目              		 (Definition pending) （定义待补） Microsoft, n.d., "Compiler Options", "Projects" section
              Incremental
              增量编译（incremental）              		 "Tells TypeScript to save information about the project graph from the last compilation to files stored on disk." 让 TypeScript 把上一次编译的项目依赖图信息保存下来，写入磁盘上的文件。 Microsoft, n.d., "Projects", "Incremental", para. 1
              TS Build Info File
              增量编译信息文件（tsBuildInfoFile）              		 "This setting lets you specify a file for storing incremental compilation information as a part of composite projects which enables faster building of larger TypeScript codebases." 这个设置让你指定一个文件来存放增量编译信息，作为复合项目的一部分，从而加快构建较大的 TypeScript 代码库。 Microsoft, n.d., "Projects", "TS Build Info File", para. 1
              Completeness
              完整性              		 (Definition pending) （定义待补） Microsoft, n.d., "Compiler Options", "Completeness" section
              Skip Lib Check
              跳过库检查（skipLibCheck）              		 "Skip type checking of declaration files. This can save time during compilation at the expense of type-system accuracy." 跳过声明文件的类型检查。这能节省编译时间，代价是类型系统的准确性。 Microsoft, n.d., "Completeness", "Skip Lib Check", paras. 1–2
