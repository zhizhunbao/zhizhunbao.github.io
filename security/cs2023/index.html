              CS2023 SEC
              CS2023 SEC              		 "The Security (SEC) knowledge area focuses on developing a security mindset into the overall ethos of computer science graduates so that security is embedded in all their work products." 安全（SEC）知识领域着重于把安全思维的培养融入计算机科学毕业生的整体精神，使安全贯穿于他们所有的工作成果。 Joint Task Force on Computing Curricula, 2024, SEC "Preamble" section, para. 2
              Foundational Security
              安全基础              		 (context) "Evaluate a system for possible attacks that can be launched by an adversary." （语境）评估一个系统可能遭受的、对手能够发起的攻击。 Joint Task Force on Computing Curricula, 2024, SEC-Foundations "Illustrative Learning Outcomes", 1
              Society, Ethics, and the Profession
              社会、伦理与职业              		 (context) "Calculate the impact of a breakdown in security of a given system." （语境）计算给定系统安全失效所造成的影响。 Joint Task Force on Computing Curricula, 2024, SEC-SEP "Illustrative Learning Outcomes", 1
              Secure Coding
              安全编码              		 (context) "Identify underlying problems in given examples of an enumeration of common weaknesses and explain how they can be circumvented." （语境）在给出的常见弱点枚举示例中找出根本问题，并解释如何规避它们。 Joint Task Force on Computing Curricula, 2024, SEC-Coding "Illustrative Learning Outcomes", 1
              Cryptography
              密码学              		 (context) "Explain the role of cryptography in supporting security and privacy." （语境）解释密码学在支持安全和隐私方面的作用。 Joint Task Force on Computing Curricula, 2024, SEC-Crypto "Illustrative Learning Outcomes", 1
              Security Analysis, Design, and Engineering
              安全分析、设计与工程              		 (context) "Create a threat model for a system or system design." （语境）为一个系统或系统设计建立威胁模型。 Joint Task Force on Computing Curricula, 2024, SEC-Engineering "Illustrative Learning Outcomes", 1
              Digital Forensics
              数字取证              		 (context) "Explain what a digital investigation is and how it can be implemented" （语境）解释什么是数字调查以及如何实施 Joint Task Force on Computing Curricula, 2024, SEC-Forensics "Illustrative Learning Outcomes", 1
              Security Governance
              安全治理              		 (context) "Describe critical assets and how they can be protected." （语境）描述关键资产以及如何保护它们。 Joint Task Force on Computing Curricula, 2024, SEC-Governance "Illustrative Learning Outcomes", 1
