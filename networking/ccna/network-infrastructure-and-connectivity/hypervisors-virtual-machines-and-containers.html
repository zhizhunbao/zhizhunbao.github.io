              1.2 Hypervisors, Virtual Machines, and Containers

              Exam objective: Describe the role and function of hypervisors, virtual machines, and containers.

              Classification

              Glossary

              Term Definition 中文翻译 Source
              Hypervisors
              虚拟机管理程序              		 "A hypervisor provides management for virtualized services. It enables connections between virtual services and external interfaces." hypervisor 为虚拟化服务提供管理。它让虚拟服务能够连接外部接口。 Cisco, n.d.-d, "Virtualization software" section, para. 1
              Virtual machines
              虚拟机              		 "A virtual machine (VM) is a software-defined, hypervisor-managed, portable computing environment that resides on and uses the resources of a host computer." 虚拟机（VM）是一种软件定义、由 hypervisor 管理、可移植的计算环境，它驻留在主机上并使用主机的资源。 Cisco, n.d.-c, para. 1
              Containers
              容器              		 "A container is a unit of lightweight, executable software that packages application code and its dependencies in a standardized way." 容器是一种轻量的可执行软件单元，以标准化的方式打包应用代码及其依赖。 Cisco, n.d.-b, para. 1
