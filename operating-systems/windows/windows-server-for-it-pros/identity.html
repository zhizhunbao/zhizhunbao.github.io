              5.2 Identity

              Classification

              Glossary

              Term Definition 中文解释 Source
              Active Directory Domain Services (AD DS)
              Active Directory 域服务（AD DS）              		 "A directory service, such as Active Directory Domain Services (AD DS), provides the methods for storing directory data and making this data available to network users and administrators." 目录服务（例如 Active Directory 域服务（AD DS））提供存储目录数据、并把这些数据提供给网络用户和管理员的方法。 Microsoft, 2025, para. 1
              Replication service
              复制服务              		 "A replication service that distributes directory data across a network." 一种复制服务，在网络中分发目录数据。 Microsoft, 2025, "AD DS also includes" list, item 4
              Domain controller
              域控制器              		 (context) "All domain controllers in a domain participate in replication and contain a complete copy of all directory information for their domain." （语境）一个域中的所有域控制器都参与复制，并保存本域全部目录信息的完整副本。 Microsoft, 2025, "AD DS also includes" list, item 4
