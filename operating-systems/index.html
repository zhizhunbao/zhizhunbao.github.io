              Operating Systems
              操作系统              		 "The operating system is a collection of services needed to safely interface the hardware with applications." 操作系统是一组服务的集合，用于安全地连接硬件与应用程序。 Joint Task Force on Computing Curricula, 2024, OS "Preamble" section, para. 1
              CS2023 OS
              CS2023 OS              		 "Core topics focus on the mechanisms and policies needed to virtualize computation, memory, and Input/Output (I/O)." 核心主题侧重于机制与策略，用以虚拟化计算、内存和输入/输出（I/O）。 Joint Task Force on Computing Curricula, 2024, OS "Preamble" section, para. 1
              Linux
              Linux              		 "Linux is a clone of the operating system Unix, written from scratch by Linus Torvalds with assistance from a loosely-knit team of hackers across the Net." Linux 是操作系统 Unix 的克隆，由 Linus Torvalds 从零写成，并得到网络上一群松散组织的黑客的协助。 The kernel development community, n.d.-b, "What is Linux?" section, para. 1
              Windows
              Windows              		 "Information for Windows application developers, hardware developers, and IT pros." 面向 Windows 应用开发者、硬件开发者和 IT 专业人员的信息。 Microsoft, n.d.-b, "Windows technical documentation for developers and IT pros" page, para. 1
              Windows API
              Windows API              		 "Using the Windows API, you can develop applications that run successfully on all versions of Windows while taking advantage of the features and capabilities unique to each version." 使用 Windows API，你可以开发能在所有版本的 Windows 上成功运行的应用程序，同时利用每个版本特有的功能和能力。 Microsoft, n.d.-a, "Windows API index" page, para. 2
