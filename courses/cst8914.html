              W11: Accessible Custom Components and Widgets

              Keyword Description 中文翻译
              2.1 First Rule of ARIA Use W11 opens with this rule: build a component from native HTML first and add ARIA only to fill the gaps HTML leaves. W11 以这条规则开场：先用原生 HTML 搭组件，只在 HTML 留下空缺时用 ARIA 补上。
              Widget W11 calls a custom UI component a widget: several HTML elements that work as one piece of UI. W11 把自定义 UI 组件称为控件：几个 HTML 元素作为一个整体工作。
              ARIA Authoring Practices Guide W11 uses the APG patterns as the place to look up what a component needs: roles, states, properties and keyboard support. W11 把 APG 模式当作查找组件需要什么的地方：角色、状态、属性和键盘支持。
              1.6 Slider W11 example of a component whose pattern has a working example; the lecture's slider was missing the slider role, keyboard support and a label. W11 的例子之一：这个模式有可运行的示例；课上的滑块缺少 slider 角色、键盘支持和标签。
              1.23 Tooltip W11 example of a pattern without an example, so the lecture also checks WCAG 1.4.13 Content on Hover or Focus. W11 的例子之一：这个模式没有示例，所以课上同时对照 WCAG 1.4.13 悬停或聚焦时的内容。
              1.4.13 Content on Hover or Focus W11 uses this criterion for the tooltip: content that appears on hover or focus must be dismissible, hoverable and persistent. W11 用这条标准检查工具提示：悬停或聚焦时出现的内容必须可关闭、可悬停、能持续显示。
              1.13 Accordion (Sections With Show/Hide Functionality) Lab 11 compares an accordion with this pattern's keyboard interaction and its roles, states and properties. Lab 11 拿一个手风琴组件对照这个模式的键盘交互以及角色、状态和属性。
