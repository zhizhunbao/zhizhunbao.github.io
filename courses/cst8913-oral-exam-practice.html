              1.3.12 Constraints & Challenges

              DSAR 即 Data Subject Access Request，指个人要求公司说明持有自己哪些数据。

              Skills Skill gaps Team has basic knowledge of cloud but limited experience with Infrastructure as Code, CI/CD, and cloud security. 团队懂一点云，但在基础设施即代码、CI/CD 和云安全方面经验有限。 CI/CD 即 continuous integration and continuous delivery，持续集成和持续交付。

              Change Regional IT Regional IT teams worry about losing control when systems move to cloud. 地区 IT 团队担心系统上云后自己失去控制权。 IT 即 information technology，信息技术。

              ERP 即 Enterprise Resource Planning，企业资源计划。
              CRM 即 Customer Relationship Management，客户关系管理。
              Access RBAC Implement RBAC and least-privilege for admins and operators. 对管理员和运维人员实行 RBAC 和最小权限。 RBAC 即 role-based access control，基于角色的访问控制。
              MFA and conditional access Introduce MFA and conditional access policies for remote and privileged access. 对远程访问和特权访问启用 MFA 和条件访问策略。 MFA 即 multifactor authentication，多重身份验证。
              1.3.13.3 Networking

              VPC 即 Virtual Private Cloud，AWS 的虚拟私有云。
              DNS 即 Domain Name System，域名系统。
              Spokes Spokes for ERP, e-commerce, CRM, data & analytics, store integration services ERP、电商、CRM、数据与分析、门店集成服务各有一个辐射网络。 ERP 即 Enterprise Resource Planning，企业资源计划。
              CRM 即 Customer Relationship Management，客户关系管理。
              Connectivity VPN then ExpressRoute Hybrid connectivity with VPN initially and ExpressRoute/Direct Connect for long-term, low-latency, secure connectivity. 混合连接先用 VPN，长期用 ExpressRoute 或 Direct Connect 实现低延迟、安全的连接。 VPN 即 virtual private network，虚拟专用网络。
              ExpressRoute 是 Azure 的专线，Direct Connect 是 AWS 的专线。
              SD-WAN SD-WAN strategy for stores to reach both cloud and on-prem resources. 用 SD-WAN 方案让门店能同时访问云上和本地的资源。 SD-WAN 即 Software-Defined Wide Area Network，软件定义广域网。

              按流量自动扩缩
              静态内容走 CDN。              		 DB 即 database，数据库。

              API 即 application programming interface，应用程序接口。
              Data protection Introduce strong data retention and masking/pseudonymization patterns. 引入严格的数据保留以及脱敏和假名化模式。 CRM 即 Customer Relationship Management，客户关系管理。
              Data Cloud DW Migrate DW to a cloud-based data warehouse or lakehouse in EU region. 把数据仓库迁到欧盟区域的云数据仓库或湖仓。 DW 即 data warehouse，数据仓库。
              EU 即 European Union，欧盟。
              Pipelines Use ETL/ELT pipelines into cloud data platform, with clear governance and data classification. 用 ETL 或 ELT 管道把数据送进云数据平台，配上清晰的治理和数据分类。 ETL 即 Extract, Transform, Load，抽取、转换、加载。
              ELT 即 Extract, Load, Transform，先加载后转换。
              1.3.13.5 Security & Compliance
              Category Keyword Description 中文翻译 缩写
              Data protection Encryption Enforce encryption at rest and in transit for all services. 所有服务强制静态加密和传输加密。

              DLP and CASB Implement DLP, CASB, and data classification for personal and sensitive data. 对个人和敏感数据实施 DLP、CASB 和数据分类。 DLP 即 data loss prevention，数据防泄漏。
              CASB 即 cloud access security broker，云访问安全代理。
              Testing Regular security assessments and penetration testing. 定期做安全评估和渗透测试。
