              Term Definition 中文翻译 Source
              CS2023 SF
              CS2023 SF              		 "The System Fundamentals knowledge area, as suggested by its name, focuses on the fundamental concepts and design principles in computer systems that are shared by these courses within their respective cores." 顾名思义，系统基础知识领域着重于这些课程在各自核心内容中共有的计算机系统基本概念和设计原则。 Joint Task Force on Computing Curricula, 2024, SF "Preamble" section, para. 2
              Overview of Computer Systems
              计算机系统概述              		 (context) "Describe the basic building blocks of computers and their role in the historical development of computer architecture." （语境）描述计算机的基本组成部件及其在计算机体系结构历史发展中的作用。 Joint Task Force on Computing Curricula, 2024, SF-Overview "Illustrative Learning Outcomes", 1
              Basic Concepts
              基本概念              		 (context) "Describe the differences between digital and analog systems, and between discrete and continuous systems." （语境）描述数字系统与模拟系统之间、离散系统与连续系统之间的区别。 Joint Task Force on Computing Curricula, 2024, SF-Foundations "Illustrative Learning Outcomes", 1
              Resource Management
              资源管理              		 (context) "Define how finite computer resources (e.g., processor share, memory, storage, and network bandwidth) are managed by their careful allocation to existing entities." （语境）定义有限的计算机资源（例如处理器份额、内存、存储和网络带宽）如何通过在现有实体之间审慎分配来加以管理。 Joint Task Force on Computing Curricula, 2024, SF-Resource "Illustrative Learning Outcomes", 1
              System Performance
              系统性能              		 (context) "Describe the breakdown of the latency of computer systems in terms of memory, disk, and network." （语境）从内存、磁盘和网络的角度描述计算机系统延迟的构成。 Joint Task Force on Computing Curricula, 2024, SF-Performance "Illustrative Learning Outcomes", 1
              Performance Evaluation
              性能评估              		 (context) "Explain how the components of system architecture contribute to improving its performance." （语境）解释系统体系结构的各个组成部分如何帮助提升其性能。 Joint Task Force on Computing Curricula, 2024, SF-Evaluation "Illustrative Learning Outcomes", 1
              System Reliability
              系统可靠性              		 (context) "Explain the distinction between program errors, system errors, and hardware faults (e.g., corrupted memory) and exceptions (e.g., attempt to divide by zero)." （语境）解释程序错误、系统错误和硬件故障（例如内存损坏）与异常（例如试图除以零）之间的区别。 Joint Task Force on Computing Curricula, 2024, SF-Reliability "Illustrative Learning Outcomes", 1
              System Security
              系统安全              		 (context) "Describe some common system security issues and give examples" （语境）描述一些常见的系统安全问题并举例 Joint Task Force on Computing Curricula, 2024, SF-Security "Illustrative Learning Outcomes", 1
              System Design
              系统设计              		 (context) "Describe common criteria of system design." （语境）描述系统设计的常用准则。 Joint Task Force on Computing Curricula, 2024, SF-Design "Illustrative Learning Outcomes", 1
              Society, Ethics, and the Profession
              社会、伦理与职业              		 (context) "Describe the intellectual property rights of computer systems." （语境）描述计算机系统的知识产权。 Joint Task Force on Computing Curricula, 2024, SF-SEP "Illustrative Learning Outcomes", 1
